# Statsig — His Startup

## What Statsig does

**Statsig** is a **product experimentation platform** for software teams.
It provides:

* A/B testing
* Feature flags (gradual rollout)
* Product analytics
* Real-time decision engine
* experimentation infrastructure

It helps teams **ship features safely and measure impact**. ([GeekWire][3])

Example use case:

* Release new UI to 5% users
* Compare engagement vs old UI
* Auto decide rollout
* Monitor metrics in real time

This is the same methodology used at:

* Facebook
* Netflix
* Google
* OpenAI

## Why Statsig mattered

Statsig's vision:
