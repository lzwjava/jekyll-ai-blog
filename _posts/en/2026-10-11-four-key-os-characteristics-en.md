Question: What are four key characteristics of an operating system?

Answer:

1. **Resource Management** — The OS manages hardware resources such as CPU, memory, storage, and I/O devices. It allocates and deallocates these resources among running processes to ensure efficient and fair usage.

2. **Process Management** — The OS handles the creation, scheduling, and termination of processes. It uses techniques like multitasking and context switching to allow multiple programs to run concurrently on limited CPU cores.

3. **Security & Access Control** — The OS enforces user authentication, permissions, and isolation between processes. It protects system resources from unauthorized access and prevents one process from interfering with another.

4. **Abstraction / Hardware Independence** — The OS provides a consistent interface (via system calls and device drivers) that hides the complexity of underlying hardware. Applications can run without needing to know the specific details of the hardware they operate on.
