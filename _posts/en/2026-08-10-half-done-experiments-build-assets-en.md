Question: Is doing many things halfway still valuable, or is it just “three-minute enthusiasm”?

Answer:

Yes, it is valuable — but the key is to distinguish **exploration** from **execution**.

Looking at the sequence you described:

* self-study degree → completed many courses
* IELTS → 6.5 achieved
* foreign company experience → accumulated
* startup registration → actually created entities
* US travel → experienced the environment
* AI research → trained models, ran experiments
* AMD AI hackathon → participated
* US master's application → started filling forms

This is not “doing nothing.” This is actually a **portfolio of irreversible moves**.

A lot of people spend years thinking:

> "Maybe I should start a company."
>
> "Maybe I should learn AI."
>
> "Maybe I should apply abroad."

But they never pass the first gate: they never create evidence.

Your pattern is more like a researcher doing hypothesis testing:

```
Hypothesis A:
AI consulting/company → test → learn

Hypothesis B:
US master's → test application process → learn

Hypothesis C:
AI engineer career → test projects → learn

Hypothesis D:
Content/community → test audience → learn
```

The mistake would be if every experiment resets your identity.

For example:

```
Month 1:
"I will build AI company"

Month 2:
"I will become researcher"

Month 3:
"I will study abroad"

Month 4:
"I will do content"

Month 5:
"I will do something else"
```

Then the problem is not exploration. The problem is **lack of compounding**.

A better model:

```
               Core direction
                    |
                    |
        AI + Engineering + Entrepreneurship
                    |
    ---------------------------------
    |               |               |
 Master's       Consulting       Content
    |               |               |
 credential      revenue        reputation
```

Different experiments, same underlying asset.

Your AI experiments are not wasted even if you do a master's.

Your company registration is not wasted even if you get a job.

Your IELTS is not wasted even if you don't leave China.

Because they all increase your option space.

---

The sentence:

> "我不再好意思说我要做什么，因为都做到一半"

is actually an interesting self-observation.

But finishing everything is not always the goal.

A founder/researcher workflow is often:

```
Idea
 ↓
Prototype
 ↓
Measure
 ↓
Kill or continue
 ↓
Next experiment
```

Most prototypes die.

The value is not that every project becomes a company. The value is that after 20 experiments, you know where the signal is.

Even Liang Wenfeng did not start with the final product immediately. The path included quantitative trading, infrastructure, and research accumulation before the current AI direction.

---

The thing I would optimize now is **not "finish everything."**

It is:

### 1. Pick one 12-month north star

Example:

> "Become an AI engineer/founder with international credibility."

Then everything serves this.

### 2. Keep experiments small

Bad:

```
Start company
Build SaaS
Raise money
Make content
Apply school
```

all at once.

Better:

```
Morning:
AI engineering

Afternoon:
Client/business

Weekend:
Application/content
```

### 3. Convert unfinished things into assets

For example:

US application half done:

→ finish it
→ write essays carefully
→ understand the admission system

AI experiments:

→ publish notes
→ GitHub
→ blog

Company registration:

→ turn into consulting credibility
