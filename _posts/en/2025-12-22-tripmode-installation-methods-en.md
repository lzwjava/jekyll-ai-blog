Question: How could TripMode.app be installed on my Mac if I don't remember installing it?

Answer:

TripMode.app is a legitimate third-party macOS application and is **not preinstalled** on any Mac by Apple. It also does not come bundled with other software or install automatically without user interaction. All installation methods require explicit user action:

### Common Installation Methods:
- **Mac App Store**: You (or someone with access to your Apple ID) download and install it directly from the App Store. It offers a 7-day free trial, after which it requires a subscription or lifetime purchase.
- **Setapp Subscription**: If you have (or had) a Setapp account (a subscription service with 250+ Mac apps), you can install TripMode from the Setapp app with one click. Many users try Setapp's free trial, install several apps (including TripMode), and later forget about them—especially since Setapp apps can remain installed even after the subscription ends (though they stop working fully).
- **Direct Download from Official Website**: You download a .pkg installer from tripmode.ch and run it manually (older versions used this; current ones redirect to the App Store or Setapp).
- **Homebrew (Advanced Users)**: Installed via command line with `brew install --cask tripmode`.

### Why You Might Not Remember Installing It:
- You tried the free trial (7 days on App Store/direct, or via Setapp) some time ago and forgot.
- Setapp is a common source of "forgotten" installs: Users sign up for the trial, browse and install multiple apps, then cancel or forget.
- Someone else with access to your Mac (family member, IT admin, or shared device) installed it.
- During setup, macOS prompts for permissions (e.g., network filtering extension), which might make the process feel automatic, but it still requires approval.

TripMode requires system-level network extensions, so installation always involves visible steps and permission grants—you couldn't have installed it entirely by accident.

If you're concerned about unauthorized installation, check:
- System Settings > General > Login Items & Extensions > Network Extensions for TripMode.
- Applications folder for the app icon.
- App Store purchase history or Setapp account for records.

To remove it safely: Quit TripMode, drag the app to Trash (this also removes its extensions properly), then empty Trash.
