**Question:** How to use CMB (China Merchants Bank) U-Bank desktop application (.exe)?

---

**Answer:**

CMB U-Bank (招商银行企业网银) is China Merchants Bank's **corporate online banking** desktop client. Here's a step-by-step guide:

---

## 1. Download & Install

You can find the latest version of China Merchants Bank U-Bank on the CMB homepage. Download the installation program (`FirmBank.exe`), run it, and follow the installation guidance — it will be automatically installed to your computer.

Download URL:
> `http://www.cmbchina.com/corporate/firmbank/FirmbankInfo.aspx?pageid=download`

---

## 2. Prerequisites

To apply for U-Bank corporate online banking, you need to apply for a CMB corporate settlement account first. After opening the account, get the CMB U-Bank Service Agreement and Application Form at a CMB branch (3 copies each), seal with the corporate stamp, choose your U-Bank version, login method and services needed, then submit to the account opening branch.

The branch will then provide you with a **system administrator password envelope**, **USB Key**, and USB Key driver if needed.

---

## 3. First-Time Setup (Register Certificate & Admin)

Steps to register:

1. **Step 1** — Launch U-Bank, insert the administrator's UKey. The system will automatically pop up the "Register New Certificate" window.
2. **Step 2** — The system auto-detects the UKey certificate number. Set an **8-digit certificate password** (no repeating or sequential digits).
3. **Step 3** — Fill in the administrator registration info. The last 4 digits of your ID number must match what was written on the original application form. Set an **8-digit login password**.
4. **Step 4** — Click "Get Verification Code". The code is sent to the pre-registered mobile/email and is valid for **5 minutes**.
5. **Step 5** — Confirm to complete registration and log in.

---

## 4. Proxy / Network Settings

If you use a proxy server in a LAN to access the internet, click **"Communication Settings"** on the U-Bank login window to configure the communication parameters.

---

## 5. Updating U-Bank

To update, check the latest version info on the CMB homepage, download the new installation program, and run it — the system updates automatically.

---

## 6. User Roles Explained

U-Bank has three user roles: **System Administrator**, **Input User**, and **Approval User**. Understanding these roles is important before using the system.
