### 💡 Naming Principle for CLI tools

The best CLI tool names share these traits:

- **≤ 8 characters** — fast to type
- **No ambiguity** — no existing popular tools with same name
- **Verb or action implied** — `work`, `run`, `do`, `forge`
- **Subcommand friendly** — `<name> <command>` reads naturally in English
