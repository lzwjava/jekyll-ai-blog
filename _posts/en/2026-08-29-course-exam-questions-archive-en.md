## What the exam questions cover

The five `.md` "回忆" (recollection) files each contain **简答题** (short-answer) + **材料分析题** (material-analysis) questions. Recurring high-frequency themes across years:

- **中国式现代化** — 内涵、本质要求、中国特色、人类文明新形态 (appears 2024秋缓补、2025秋、2026春)
- **习近平新时代中国特色社会主义思想 / 新时代** — 历史地位、新发展方位 (2024秋缓补、2025秋)
- **党的全面领导 / 人民为中心** — (2025春, 2025秋)
- **全面深化改革** — 总目标、深刻革命 (2024秋、2024秋缓补)
- **法治中国** — 法治道路原则、建设法治中国 (2025春、2025秋、2026春)
- **中华优秀传统文化 / 文化软实力** — 创造性转化创新性发展 (2024秋、2025春)
- **高质量发展 / 新发展理念 / 科技自立自强** — (2024秋缓补、2025秋、2026春)
- **共同富裕 / 绿水青山 / 国内国际双循环** — (2025秋、2026春)

A `√` mark in each file indicates questions that are explicitly from the textbook (课本思考题). The README `备注` flags answer status — most are 无答案 (no answers), except the PDF which is 含非官方答案 (non-official answers, objective questions only).
