### CPU: Intel Xeon E3-1280 v5

Specs:

* Architecture: Skylake (14nm)
* Socket: LGA1151
* Cores/Threads: **4C/8T**
* Base clock: **3.7 GHz**
* Turbo: ~4.0 GHz
* Cache: 8 MB L3
* TDP: 80W
* Memory: DDR4 ECC UDIMM support (with workstation/server chipset)

Performance:

* Similar to:

  * i7-6700K (close, but lower clocks and no overclock)
  * i7-6700 (very close)
* Still fine for:

  * programming
  * AI development environment
  * GPU server host machine
  * CUDA workstation with RTX GPUs
  * general desktop

The CPU itself is not the bottleneck for GPU workloads.

---

### The tricky part: Z170 + Xeon E3 v5

Normally:

| Chipset        | Xeon E3 v5 support         |
| -------------- | -------------------------- |
| C232/C236      | ✅ Official                 |
| Z170/H170/B150 | ❌ Not officially supported |

However, some Z170 boards can run E3-1200 v5 because they share the same Skylake socket and microcode.

It depends on:

* exact motherboard model
* BIOS version
* modified BIOS

Some Z170 boards:

* boot normally with E3-1200 v5
* recognize CPU as Xeon
* work with ECC disabled/non-ECC RAM

Others:

* no boot
* CPU unsupported
* need BIOS mod

Ask seller:

1. Exact motherboard model?
2. BIOS version?
3. Can send CPU-Z screenshot?
4. Does it show "Intel Xeon E3-1280 v5"?

### For your GPU experiments (P100/M40/3090 etc.)

This platform is actually interesting:

Pros:

* cheap
* PCIe 3.0 x16
* DDR4
* M.2 support
* Skylake has good PCIe compatibility

Cons:

* only 16 PCIe CPU lanes:

  * GPU = x16
  * additional cards reduce bandwidth
* no official ReBAR support
* old platform for large GPUs

For:

* Tesla P100 16GB → ✅ reasonable
* Tesla M40 24GB → ✅ reasonable
* RTX 3090 → ✅ works
* multi-GPU → limited
