Question: Explain this DS-160 "Application Information / Application ID" page.

Answer:

This page is from the **U.S. Department of State DS-160 online visa application system**. It is telling you that your DS-160 application has been started and gives you information needed to continue later.

### 1. Application ID

> **Your Application ID is: XXXXX**

The **Application ID** is a unique identifier for your DS-160 form.

You need it to:

* Continue an unfinished DS-160 application later
* Retrieve your saved application
* Recover your application if the website has problems
* Retrieve your confirmation page after submission

Example:

```
Application ID: AA00BBBBCC
Security Answer: your chosen answer
```

Keep this ID private. It is not your visa number; it is only the ID of your DS-160 form.

---

### 2. Security Question

The system asks you to choose:

```
Security Question:
[ dropdown ]

Answer:
[ your answer ]
```

This works like a recovery password.

Example:

Question:

```
What is the name of your first pet?
```

Answer:

```
Lucky
```

Later, when you reopen the DS-160, you need:

1. Application ID
2. Exact security answer

Important:

* Answers are case-sensitive in some systems.
* Remember spelling exactly.
* Do not use an answer you will forget.

---

### 3. Date

```
Date
19-AUG-2026
```

This is the date you created the DS-160 application.

---

### 4. "Print Application ID"

You should click this and save it.

Recommended:

* Take a screenshot
* Save as PDF
* Store it in a secure place

Example file:

```
DS160_Application_ID_2026.pdf
```

---

### 5. 60-day expiration rule

The message:

> applications which have not been updated for sixty (60) days or submitted will be removed

means:

If you start DS-160 but do nothing for **60 days**, the unfinished application may be deleted.

Example:

* Started: Aug 19, 2026
* No updates until around Oct 18, 2026
* System may remove it
* You need to start a new DS-160

Saving the application does **not** mean it is submitted.

---

### 6. What happens next?

The DS-160 process:

```
Create DS-160
       |
       v
Fill personal information
       |
       v
Review answers
       |
       v
Electronically sign + submit
       |
       v
Get DS-160 Confirmation Page (barcode)
       |
       v
Pay visa fee
       |
       v
Schedule interview at US embassy/consulate
       |
       v
Visa interview
```

For your case (Chinese citizen applying in China), after DS-160 submission you normally use the embassy/consulate instructions for where you will interview (for example Guangzhou, Shanghai, Beijing, etc.).

---

### Practical advice

Before filling too much:

* Save your **Application ID**
* Choose a security question you will remember years later
* Download/save your DS-160 data periodically
* Keep passport information exactly matching your passport

Your DS-160 is not submitted yet. You are only at the beginning stage.
