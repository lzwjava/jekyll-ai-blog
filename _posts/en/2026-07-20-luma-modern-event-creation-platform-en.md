Question: What is Luma (luma.com), and what problem does it solve?

Answer:

Luma is an event creation and community platform. Think of it as a modern combination of:

* Eventbrite (ticketing)
* Meetup (community discovery)
* Google Calendar invites
* Simple landing page builder
* RSVP + attendee management

Its slogan is **"Delightful events start here"**. The core idea: make creating and attending events feel more like a social experience rather than a corporate registration workflow. ([Luma][1])

## Main workflow

### 1. Create an event

A host creates:

```
Event title
↓
Cover image
↓
Date/time
↓
Location (physical / online / hybrid)
↓
Description
↓
Registration settings
```

Luma generates a beautiful event page:

```
luma.com/xxxxxx

+ Event description
+ RSVP button
+ Calendar add
+ Attendee list
+ Chat
+ Reminders
```

([Luma Help Center][2])

Example:

```
AI Builders Meetup #12

📅 July 30, 2026
📍 San Francisco
👥 120 attendees

[Register]
```

---

## 2. RSVP / ticketing

Luma supports:

* Free registration
* Paid tickets
* Capacity limits
* Approval-based events
* Waitlists
* Guest management

Hosts can collect attendee information and manage check-in. ([Luma Help Center][2])

---

## 3. Community discovery

Unlike a pure ticketing system, Luma also acts as an event discovery network.

People browse:

* AI meetups
* Crypto events
* Startup gatherings
* Wellness groups
* Social events

The mobile app focuses on discovering events and connecting attendees. ([Google Play][3])

## Comparison

| Platform     | Best for                                       |
| ------------ | ---------------------------------------------- |
| Luma         | Community events, tech meetups, creator events |
| Eventbrite   | Large public ticketed events                   |
| Meetup       | Long-running local groups                      |
| Splash       | Corporate marketing events                     |
| Google Forms | Simple private events                          |

Community builders, especially in tech/startup circles, often use Luma because the pages look cleaner and less "enterprise". ([Reddit][4])
