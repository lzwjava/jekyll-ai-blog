Yes, you're correct:
**Command + [`** and **Command +`]** are the shortcuts in Safari to go **back** and **forward** between pages.

Here are some other useful Safari keyboard shortcuts to boost your browsing efficiency:

---

### **Navigation Shortcuts**

| Shortcut                | Action                          |
|-------------------------|---------------------------------|
| **Command + [`**        | Go back a page                  |
| **Command + `]**        | Go forward a page               |
| **Command + T**         | Open a new tab                  |
| **Command + W**         | Close the current tab           |
| **Command + Shift + T** | Reopen the last closed tab      |
| **Command + L**         | Focus the address bar           |
| **Command + R**         | Reload the current page         |
| **Command + Shift + R** | Reload page (bypass cache)      |

---

### **Tab Management**

| Shortcut                | Action                          |
|-------------------------|---------------------------------|
| **Command + 1-9**       | Switch to a specific tab        |
| **Command + Option + ←/→** | Switch to previous/next tab  |
| **Command + Shift + [`**| Go to previous tab              |
| **Command + Shift + `]**| Go to next tab                  |

---

### **Page Interaction**

| Shortcut                | Action                          |
|-------------------------|---------------------------------|
| **Spacebar**            | Scroll down a page              |
| **Shift + Spacebar**    | Scroll up a page                |
| **Command + +**         | Zoom in                         |
| **Command + -**         | Zoom out                        |
| **Command + 0**         | Reset zoom level                |

---

### **Bookmarks & History**

| Shortcut                | Action                          |
|-------------------------|---------------------------------|
| **Command + D**         | Bookmark the current page       |
| **Command + Option + B**| Show/hide bookmarks sidebar     |
| **Command + Y**         | Open History menu               |
