**Question: [What does “luma.com Guest List Locked — The full guest list is only accessible to approved guests” mean?]**

**Answer:**

This is a privacy/access-control message from **Luma**.

It means:

* The event exists on Luma.
* The organizer has enabled **guest list privacy**.
* Only people who are:

  * approved by the event host, or
  * already registered/invited,

  can see the complete attendee list.

You can probably still see some public event information:

* event title
* date/time
* description
* organizer
* registration button (if enabled)

But you **cannot see who else is attending**.

Typical reasons organizers lock the guest list:

1. **Privacy**

   * Prevent exposing attendee names/emails.
   * Common for private meetups, investor events, company events.

2. **Exclusive community**

   * They want approval before revealing members.
   * Example: AI founder dinners, VC events, closed beta groups.

3. **Anti-spam / scraping**

   * Public attendee lists are often scraped for marketing.

4. **Security**

   * Avoid letting strangers know who will attend.

The flow is usually:

```
You find event page
        |
        v
Request RSVP / sign in
        |
        v
Organizer approves you
        |
        v
Guest list becomes visible
```

If you are trying to attend, look for:

* **Request to Join**
* **RSVP**
* **Apply**
* **Join Waitlist**

If you only want to know *who is going*, you need organizer approval.
