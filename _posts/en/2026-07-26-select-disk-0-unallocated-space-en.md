Question: Which one to select — Disk 0 Unallocated Space is highlighted, correct choice?

Answer: Yes, that's correct — **Disk 0 Unallocated Space (476.9 GB)** is exactly what you want, and it's already selected/highlighted.

Click **Next** now. Setup will auto-create the partitions on Disk 0 (EFI System, MSR, Primary, Recovery) and start copying files.

Ignore Disk 1 entirely (200MB System + 14.5GB WIN11) — that's leftover from an earlier failed attempt on the wrong/smaller drive, not something to touch or install to.
