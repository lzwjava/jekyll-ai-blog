## Answer

The DS-160 is the U.S. nonimmigrant visa application form. Chinese citizens applying for **B1/B2 tourist/business visa**, **F1 student visa**, **J1**, etc. must complete DS-160 online before scheduling the visa interview. The U.S. Department of State requires answers to be accurate and in English (except names in native alphabet fields). ([Travel.state.gov][1])

Official DS-160 website:

[DS-160 Online Application (CEAC)](https://ceac.state.gov/genniv/default.aspx?2SN0FWoJ2HjzwiWXwTQ0PQ=%3D&utm_source=chatgpt.com)

---

# 0. Prepare before starting

Prepare these documents:

### Required

* Chinese passport

  * Passport number
  * Issue date
  * Expiration date
  * Place of issue

* Digital visa photo

  * Recent
  * Meets U.S. visa photo requirements

* Chinese ID information

* Current address

* Phone number

* Email

---

### Helpful information

For DS-160 you may need:

* Previous U.S. travel history (if any)
* International travel history (often last 5 years)
* Education history
* Employment history
* Resume/CV information
* Intended U.S. travel plan

The State Department recommends having passport, travel itinerary, previous travel records, and employment/education information ready. ([Travel.state.gov][2])

# 1. Start DS-160

Open:

[DS-160 Application Portal](https://ceac.state.gov/genniv/default.aspx?2SN0FWoJ2HjzwiWXwTQ0PQ=%3D&utm_source=chatgpt.com)

Choose:

```
Location where you will apply:
CHINA, GUANGZHOU
```

(or Beijing / Shanghai / Shenyang / Chengdu depending where you interview)

Then click:

```
Start an Application
```

---

# 2. Save Application ID

The first page gives:

```
Application ID: AA00XXXXX
```

Save it.

You also create a security question.

Example:

```
Security Question:
What is your favorite color?

Answer:
Blue
```

You need:

* Application ID
* Security answer

to continue later.

The DS-160 can be saved and resumed later. ([Travel.state.gov][2])

# Common mistakes for Chinese applicants

## 1. Translating names incorrectly

Passport:

```
LI ZHIWEI
```

Do not write:

```
LI ZHI WEI
```

---

## 2. Hiding previous visa refusal

If asked:

```
Have you ever been refused a U.S. visa?
```

Answer:

```
YES
```

Explain honestly.

---

## 3. Tourist visa but describing work

For B1/B2:

Allowed:

* tourism
* meetings
* conferences
* negotiations

Not allowed:

* working in USA
* taking U.S. employment

---

## 4. Inconsistent information

DS-160:

```
Income: 5000 USD/month
```

Interview:

```
I don't have income
```

creates problems.
