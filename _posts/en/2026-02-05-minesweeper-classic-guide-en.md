扫雷 (Minesweeper) is a classic Windows puzzle game! Here's how to play:

**Finding the game:**

- On older Windows (XP/7): It came pre-installed in Games
- On Windows 10/11: You can download "Microsoft Minesweeper" from the Microsoft Store for free

**How to play:**

The goal is to clear a grid of hidden mines using clues about the number of neighboring mines in each square.

**Basic controls:**

- **Left-click**: Reveal a square
- **Right-click**: Place a flag to mark where you think a mine is
- **Both buttons** (on some versions): Reveal all adjacent squares if you've flagged the correct number of mines

**Game rules:**

1. Click any square to start - the first click is always safe
2. Numbers show how many mines are in the 8 surrounding squares
3. Use logic to deduce where mines must be
4. Flag all mines and reveal all safe squares to win
5. Click on a mine and you lose

**Strategy tips:**

- Start with corners and edges where you have fewer possibilities
- If a "1" touches only one unrevealed square, that square must be a mine
- If a square's number equals the unrevealed squares around it, they're all mines
- If you've flagged all mines around a number, the remaining squares are safe

**Difficulty levels:**

- Beginner: 9×9 grid, 10 mines
- Intermediate: 16×16 grid, 40 mines
- Expert: 30×16 grid, 99 mines
