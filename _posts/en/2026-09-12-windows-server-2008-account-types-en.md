Question: What two types of accounts does Windows Server 2008 support?

Answer: Windows Server 2008 supports two types of accounts:

1. **Local Accounts** — Stored on the local machine itself, these accounts are managed through the local Security Accounts Manager (SAM) database and are only valid on that specific computer.

2. **Domain Accounts** — Stored on a domain controller (Active Directory), these accounts can be authenticated across the entire network, allowing users to log in to any machine joined to the domain.
