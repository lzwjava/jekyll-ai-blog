Question: 1. What is the primary benefit of using DHCP?  
   A) Manual IP assignment  
   B) Automatic IP address allocation  
   C) Traffic encryption  
   D) Loop prevention  

   2. [The user's answer] B

Answer: 

**Question 1**  
The correct answer is **B) Automatic IP address allocation**.  

The primary benefit of using DHCP (Dynamic Host Configuration Protocol) is that it automatically assigns IP addresses and other network configuration parameters (such as subnet mask, default gateway, and DNS servers) to devices on a network. This eliminates the need for manual configuration, reduces administrative overhead, minimizes configuration errors, and makes it easier to manage large networks where devices frequently join or leave.

- Option A (Manual IP assignment) is the opposite of what DHCP provides.  
- Option C (Traffic encryption) is handled by protocols like IPsec or TLS, not DHCP.  
- Option D (Loop prevention) is a function of protocols like Spanning Tree Protocol (STP) in switches, not DHCP.
