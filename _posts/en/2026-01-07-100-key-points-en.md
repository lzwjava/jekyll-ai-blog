### Module 1: Browser and Editor Basic Operations

1. **Mainstream Engines:** Chrome uses Blink, Firefox uses Gecko, and Edge uses Blink (formerly EdgeHTML).
2. **Browser Rendering:** Differences in how browsers interpret code necessitate "Cross-browser testing."
3. **Caching:** Clearing the browser cache (Ctrl+Shift+Del) is essential to see real-time CSS updates.
4. **Developer Tools:** Use `F12` to inspect elements, debug CSS, and view the console.
5. **VS Code Installation:** The primary editor recommended for the exam.
6. **Extensions:** Install "Chinese (Simplified)" for the UI and "JS-CSS-HTML Formatter" for code cleaning.
7. **Live Server:** A common plugin to preview web pages instantly in the browser.
8. **File Naming:** Use lowercase letters, numbers, or underscores; avoid spaces and Chinese characters.
9. **Saving Files:** Use `Ctrl + S` frequently; the exam requires specific naming (e.g., `Name_html.html`).
10. **VS Code Shortcuts:** `! + Tab` generates the HTML5 boilerplate.
11. **Auto-indentation:** Use `Shift + Alt + F` to format messy code.
12. **Multi-cursor Editing:** Hold `Alt` and click to type in multiple places at once.
13. **Comment Toggle:** `Ctrl + /` is the shortcut for adding/removing comments in both HTML and CSS.
14. **Project Structure:** Keep images in an `images/` folder and styles in a `css/` folder for organization.

### Module 2: HTML5 Page Design (Structure)

15. **Doctype Declaration:** `<!DOCTYPE html>` tells the browser the document is HTML5.
16. **Language Attribute:** `<html lang="zh-CN">` assists search engines and screen readers.
17. **Character Encoding:** `<meta charset="UTF-8">` prevents garbled text.
18. **The Head Section:** `<head>` contains metadata, titles, and links, not visible content.
19. **The Body Section:** `<body>` contains all visible content of the web page.
20. **Semantic Tags:** `<header>`, `<footer>`, `<nav>`, `<aside>`, and `<article>` improve SEO and accessibility.
21. **Headings:** `<h1>` to `<h6>` define hierarchy; `<h1>` should only be used once per page.
22. **Paragraphs:** `<p>` is a block-level element used for blocks of text.
23. **Line Breaks:** `<br>` is a void element (no closing tag) for single line breaks.
24. **Horizontal Rules:** `<hr>` creates a thematic break or horizontal line.
25. **Preformatted Text:** `<pre>` preserves spaces and line breaks exactly as written in code.
26. **Bold & Italic:** Use `<strong>` and `<em>` for semantic emphasis over `<b>` and `<i>`.
27. **Divisions:** `<div>` is the ultimate generic block container for layout.
28. **Spans:** `<span>` is an inline container used for styling specific text sections.
29. **Relative Paths:** `./` for current folder, `../` to move up one level.
30. **Absolute Paths:** Full URLs like `https://www.google.com`.
31. **Hyperlinks:** `<a href="url">` creates a link.
32. **Target Attribute:** `target="_blank"` opens a link in a new tab; `_self` is the default.
33. **Anchor Links:** Use `<a href="#id">` to jump to an element with that specific ID.
34. **Image Tag:** `<img src="..." alt="...">` is required for displaying graphics.
35. **Alt Attribute:** `alt` provides text if the image fails to load (essential for accessibility).
36. **Image Dimensions:** `width` and `height` attributes (can be set in HTML or CSS).
37. **Image Formats:** Use JPG for photos, PNG for transparency, and GIF for simple animations.
38. **Image Maps:** `<map>` and `<area>` allow clickable regions on a single image.
39. **Table Basics:** `<table>`, `<tr>` (row), `<td>` (cell).
40. **Table Headers:** `<th>` defines a header cell, usually bold and centered by default.
41. **Cell Spanning:** `colspan` merges columns; `rowspan` merges rows.
42. **Table Caption:** `<caption>` provides a title for the table.
43. **Form Container:** `<form action="server-url" method="get/post">`.
44. **Text Inputs:** `<input type="text">` and `<input type="password">`.
45. **Radio Buttons:** `<input type="radio" name="group">`; the `name` must be identical for grouping.
46. **Checkboxes:** `<input type="checkbox">` allows multiple selections.
47. **Dropdowns:** `<select>` with `<option>` child elements.
48. **Textarea:** `<textarea>` for multi-line user input.
49. **Submit Button:** `<input type="submit">` or `<button type="submit">`.
50. **Placeholder:** `placeholder="..."` provides a hint inside an input field.
51. **Required Attribute:** `required` prevents form submission if the field is empty.
52. **HTML5 New Inputs:** `email`, `url`, `number`, `date`, and `color`.
53. **Audio:** `<audio src="..." controls>` for music playback.
54. **Video:** `<video src="..." controls width="...">` for movies.
55. **Autoplay & Loop:** Attributes for media; note that browsers often block autoplaying audio.
56. **Lists:** `<ul>` (unordered) and `<ol>` (ordered) both use `<li>` (list item).

### Module 3: CSS3 Basics and Styles (Presentation)

57. **Inline CSS:** `style="..."` attribute inside an HTML tag.
58. **Internal CSS:** `<style>` block inside the `<head>`.
59. **External CSS:** `<link rel="stylesheet" href="style.css">` (best practice).
60. **Element Selector:** Selects all tags of a type (e.g., `p { ... }`).
61. **Class Selector:** `.classname` (reusable on multiple elements).
62. **ID Selector:** `#idname` (unique to one element).
63. **Descendant Selector:** `div p` selects all paragraphs inside a div.
64. **Priority Rules:** Inline > ID > Class > Element.
65. **Color Keywords:** `red`, `blue`, `transparent`.
66. **Hex Colors:** `#RRGGBB` (e.g., `#FFFFFF` for white).
67. **RGB/RGBA:** `rgba(255, 0, 0, 0.5)` allows for transparency (alpha).
68. **Font Family:** `font-family: "Microsoft YaHei", sans-serif;`.
69. **Font Size:** Use `px` for fixed sizes or `em`/`rem` for relative sizes.
70. **Font Weight:** `bold` or numeric values like `700`.
71. **Text Align:** `left`, `right`, `center`, or `justify`.
72. **Text Decoration:** `none` (to remove link underlines) or `underline`.
73. **Line Height:** `line-height` controls the space between lines of text.
74. **Text Indent:** `text-indent: 2em;` is common for paragraph starts.
75. **Box Model:** Consists of Content, Padding, Border, and Margin.
76. **Width/Height:** Defines the size of the content area.
77. **Padding:** Inner space between content and border.
78. **Margin:** Outer space between the border and other elements.
79. **Border Style:** `solid`, `dashed`, `dotted`, or `double`.
80. **Border Radius:** `border-radius: 50%;` makes an element circular.
81. **Background Color:** `background-color` fills the element's area.
82. **Background Image:** `background-image: url('bg.jpg');`.
83. **Background Repeat:** `no-repeat`, `repeat-x`, or `repeat-y`.
84. **Background Size:** `cover` (fills area) or `contain` (shows whole image).
85. **Float:** `float: left;` or `right;` used for simple horizontal layouts.
86. **Clearfix:** Use `clear: both;` to stop elements from wrapping around floats.
87. **Display Property:** `block`, `inline`, `inline-block`, or `none`.
88. **Visibility:** `visibility: hidden;` hides an element but keeps its space.
89. **Pseudo-classes:** `:hover` (mouse over), `:active` (clicked), `:visited`.
90. **List Style:** `list-style: none;` removes default bullets from `<ul>`.

### Module 4: Comprehensive Web Development (Layout)

91. **DIV+CSS Concept:** Using `div` for structure and `CSS` for all visual styling.
92. **Centering Blocks:** Use `width` and `margin: 0 auto;`.
93. **Navigation Bars:** Usually built using `<ul>` and `<li>` with `float: left` or `display: inline-block`.
94. **Relative Positioning:** `position: relative;` moves element relative to its normal position.
95. **Absolute Positioning:** `position: absolute;` moves element relative to its nearest positioned ancestor.
96. **Fixed Positioning:** `position: fixed;` stays in the same place even when scrolling.
97. **Z-index:** Controls the stacking order of positioned elements (higher number = on top).
98. **Box Sizing:** `box-sizing: border-box;` includes padding and border in the total width.
99. **Flexbox Basics:** `display: flex;` is the modern way to align items easily.
100. **Page Structure:** A standard page has a `.container` wrapping a `.header`, `.nav`, `.main`, and `.footer`.
