**Question:** What are the popular open source forum / discussion platform software options?

**Answer:**

Here are the main open source forum and discussion platforms in 2026:

---

### 🏆 Top Picks

**1. [Discourse](https://discourse.org)** — Best overall
Modern open-source forum platform with real-time notifications, excellent mobile support, and comprehensive moderation tools. Widely used by developer/tech communities. Free to self-host.

**2. [Flarum](https://flarum.org)** — Best lightweight option
Lightweight open-source forum software built in PHP with a modern UI. Fits when a small community needs a modern threaded forum and reliable moderation, then adds features via plugins.

**3. [phpBB](https://phpbb.com)** — Best proven/traditional
One of the oldest, free forum options — first launched in 2000 and still actively maintained. Open-source as well as self-hosted forum software.

**4. [NodeBB](https://nodebb.org)** — Best real-time
NodeBB is a modern, open-source forum software built on Node.js, designed for creating engaging online communities with real-time features.

**5. [MyBB](https://mybb.com)** — Best for simplicity
Free and self-hosted with a strong extension library. Fits budget-conscious teams that still care about customization.

---

### 🔁 Reddit-style / Federated

**6. [Lemmy](https://join-lemmy.org)**
Open-source link aggregation and discussion platform. Reddit alternative with federation capabilities and community-driven moderation.

**7. [Forem](https://forem.com)** (powers dev.to)
An open-source software platform designed to help individuals and organizations build and host inclusive, sustainable, and vibrant online communities.

---

### WordPress Embedded

**8. [bbPress](https://bbpress.org)**
A lightweight forum inside an existing WordPress website, GPL open-source WordPress software. Advanced community functions generally need additional WordPress plugins.
