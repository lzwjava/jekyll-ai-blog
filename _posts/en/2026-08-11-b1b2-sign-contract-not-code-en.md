Question: Can a Chinese citizen enter the US on a B1/B2 visa, sign a software project contract, and do the project?

Answer:

**Signing a contract: generally yes. Doing software work inside the US: generally no.**

A B1/B2 visa allows **business visitor activities**, including:

* meeting clients
* discussing projects
* negotiating contracts
* consulting with business associates
* attending conferences

The US State Department explicitly lists **"negotiate contracts"** as an allowed B-1 business activity. ([Travel.state.gov][1])

Example:

✅ Chinese AI/software consultant flies to California:

```
Day 1-5:
- Meet startup founders
- Discuss requirements
- Negotiate price
- Sign consulting agreement
- Return to China
```

This is usually compatible with B1. ([Travel.state.gov][1])

But:

❌ Entering the US and then:

```
- sit in a US office
- write code for a US company
- receive payment for software development performed in US territory
- work like an employee/contractor locally
```

is likely considered **unauthorized employment**. B1 is not intended for employment or performing labor in the US. ([Travel.state.gov][1])

A common structure for an overseas software consultant is:

```
Chinese company/person
        |
        | contract
        v
US company

Development happens:
China / outside US

US visit:
- sales
- meetings
- architecture discussion
- training
- negotiation
```

That is much safer.

The key distinction is:

| Activity                                     | B1/B2     |
| -------------------------------------------- | --------- |
| Meet customer                                | ✅         |
| Negotiate contract                           | ✅         |
| Sign agreement                               | ✅         |
| Discuss architecture                         | usually ✅ |
| Attend conference                            | ✅         |
| Write production code while physically in US | ❌ risky   |
| Work as US contractor                        | ❌         |
| Receive US salary                            | ❌         |

([Travel.state.gov][1])

For an AI/software entrepreneur, the usual path is:

```
China entity
    |
    | remote delivery
    |
US clients

Occasional B1 visits:
    - sales
    - partnership
    - fundraising meetings
```

If the business grows and you actually need to work in the US, then look at other immigration routes (for example L-1, O-1, H-1B, E-2 where applicable, etc.) rather than stretching B1/B2. ([USCIS][2])
