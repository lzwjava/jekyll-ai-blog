Here's a list of Angular versions from Angular 9 to the current version:

**Angular 9** (February 2020)
- Ivy compiler enabled by default
- Smaller bundle sizes
- Better debugging

**Angular 10** (June 2020)
- TypeScript 3.9 support
- Optional stricter settings
- New date range picker

**Angular 11** (November 2020)
- Faster builds
- TSLint deprecated, migration to ESLint recommended
- Updated Hot Module Replacement (HMR)

**Angular 12** (May 2021)
- Ivy everywhere (View Engine removed)
- ESLint by default for new projects
- Nullish coalescing support in templates

**Angular 13** (November 2021)
- View Engine removed completely
- No more IE11 support
- Improved ergonomics for forms

**Angular 14** (June 2022)
- Standalone components (developer preview)
- Typed forms
- Simplified page title accessibility

**Angular 15** (November 2022)
- Standalone components stable
- Directive composition API
- Image directive for optimization

**Angular 16** (May 2023)
- Signals (developer preview)
- Required inputs
- Improved server-side rendering

**Angular 17** (November 2023)
- New branding and logo
- Built-in control flow (@if, @for, @switch)
- Deferrable views
- Signals stable

**Angular 18** (May 2024)
- Zoneless change detection (experimental)
- Material 3 components
- Improved hydration

**Angular 19** (November 2024) - **Current stable version**
- Incremental hydration
- Hot module replacement improvements
- Linked signals
- Resource API

Angular follows a predictable release schedule with major versions every 6 months (typically May and November).
