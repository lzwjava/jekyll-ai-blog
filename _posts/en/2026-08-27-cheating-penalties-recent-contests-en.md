**Answer:**

### Cheating & Penalties on Codeforces

**When caught cheating (code plagiarism):**

- A contestant whose solution is successfully **hacked** loses all preliminary points for that problem, the problem is no longer counted as pre-solved, and the hacker gains **+100 points** (or **−50** for an unsuccessful hack attempt).
- For plagiarism specifically (code sharing between accounts), Codeforces uses automated coincidence detection — if your code significantly matches another user's, both submissions are flagged as rule violations, even if the leakage was unintentional (e.g., posting code publicly on sites like ideone.com).
- When a user is found cheating, their rating change for that contest is removed — but currently, this also means any *negative* delta is also removed, which critics argue allows cheaters to only ever climb in rating.

**Known weaknesses in the system:**

- The community has long complained that anti-cheat measures are insufficient, calling for stricter plagiarism checks, screen proctoring, and harsher punishments like contest bans or rating deductions for repeat offenders.
- One proposed fix is an automatic rating/contribution decrease for caught cheaters, or a "rated contest ban" where their next contest doesn't affect their rating.
