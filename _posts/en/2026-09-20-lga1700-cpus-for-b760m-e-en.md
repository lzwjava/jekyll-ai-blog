**Question:** What CPUs are compatible with the MSI PRO B760M-E DDR5 motherboard?

**Answer:**

The MSI PRO B760M-E DDR5 uses an **LGA1700 socket** and supports the following Intel processors:

### ✅ Compatible CPU Generations

| Generation | Series | Examples |
| --- | --- | --- |
| **12th Gen** | Alder Lake | Core i3/i5/i7/i9-12xxx |
| **13th Gen** | Raptor Lake | Core i3/i5/i7/i9-13xxx |
| **14th Gen** | Raptor Lake Refresh | Core i3/i5/i7/i9-14xxx |

### 💡 Recommended Picks (by budget)

- **Budget:** Intel Core i3-12100 / i3-13100
- **Mid-range:** Intel Core i5-12400 / i5-13400 / i5-14400
- **High-end:** Intel Core i5-13600K / i7-13700 / i7-14700
- **Enthusiast:** Intel Core i9-13900K / i9-14900K

### ⚠️ Things to Note

- The board uses **DDR5 memory only** (not DDR4), so make sure your RAM matches
- B760 chipset **does not support overclocking** (no "K" CPU boost beyond base), though K-series CPUs will still *work*, just won't be fully unlocked
- Check MSI's official CPU compatibility list for your specific BIOS version before purchasing
