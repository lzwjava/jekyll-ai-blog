这份为期 7 天的强化复习计划将帮助你系统地准备广东自学考试的《交换与路由技术》课程。

## Daily Study Schedule (3-4 hours per day)

### **Day 1: Network Fundamentals & OSI Model**
- **Morning (2 hours):** 复习 OSI seven-layer model 和 TCP/IP protocol suite，重点关注 data encapsulation 以及每一层的功能。
- **Afternoon (1.5 hours):** 学习 network topologies、transmission media 以及基础 network devices（hubs, switches, routers）。
- **Evening (30 min):** 练习关于 protocol layers 及其功能的题目。

### **Day 2: Switching Technology Basics**
- **Morning (2 hours):** 掌握 Ethernet 基础、MAC addresses、collision domains 和 broadcast domains。
- **Afternoon (1.5 hours):** 学习 switch 运行原理，包括 MAC address learning、forwarding 和 filtering。
- **Evening (30 min):** 复习 VLAN 概念及优势；练习概念题。

### **Day 3: Advanced Switching**
- **Morning (2 hours):** 深入研究 VLAN configuration、trunk ports 和 inter-VLAN routing。
- **Afternoon (1 hour):** 学习 Spanning Tree Protocol (STP) —— 目的、运行机制及 port states。
- **Evening (1 hour):** 复习 switch security 特性，并练习 VLAN configuration 场景题。

### **Day 4: Routing Fundamentals**
- **Morning (2 hours):** 学习 routing 原理、routing tables 和 packet forwarding 决策过程。
- **Afternoon (1.5 hours):** 学习 static routing configuration 和 administrative distance 概念。
- **Evening (30 min):** 练习计算 network addresses 和 subnet masks。

### **Day 5: Dynamic Routing Protocols**
- **Morning (2 hours):** 学习 distance-vector protocols (RIP) 和 link-state protocols (OSPF) —— 包括 algorithms、metrics 和 convergence。
- **Afternoon (1.5 hours):** 复习 routing protocol configuration 和 troubleshooting 基础。
- **Evening (30 min):** 比较各 routing protocols 并练习协议选择场景题。

### **Day 6: Advanced Topics & Integration**
- **Morning (1.5 hours):** 复习 NAT/PAT 概念和 ACL (Access Control Lists) 基础。
- **Afternoon (1.5 hours):** 学习结合了 switching 和 routing 的 network design 原则。
- **Evening (1 hour):** 完成整合了 VLANs、routing 和 security 的综合配置案例。

### **Day 7: Review & Practice Exam**
- **Morning (2 hours):** 在规定时间内完成一套完整的模拟考试。
- **Afternoon (1.5 hours):** 针对模拟考试中发现的薄弱环节进行复习，重点关注 command syntax 以及感到困惑的概念。
- **Evening (30 min):** 整理一份包含关键 commands、protocols 和 formulas 的快速参考表，用于最后冲刺。

## Study Tips

**Focus Areas:** 特别注意实际的 configuration commands、protocol 运行机制和 troubleshooting 方法论，这些是常见的考点。

**Active Learning:** 不要只是阅读 —— 动手画 network diagrams，制作协议对比表，并在纸上练习配置示例。

**Practice Questions:** 每天至少完成 20-30 道练习题，仔细阅读正确和错误选项的解析。

**Memorization Aids:** 为 port numbers、protocol 特性、command syntax 和 administrative distances 制作记忆卡片（flashcards）。

祝你考试顺利！保持专注，定期休息，确保在理解概念的基础上进行记忆。
