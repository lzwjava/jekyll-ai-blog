问题：**苏姿丰（Lisa Su）让 AMD 扭亏为盈的“三大支柱”/核心战略是什么？**

答案：

是的。苏姿丰在 2014 年成为 AMD 的 CEO 时，提出的著名的三部分战略非常简单明了：

> **1. 打造伟大的产品**
> **2. 深化客户关系**
> **3. 简化我们所做的一切**

她明确选择只定三条，正如她后来解释的那样，因为如果有五条或十条优先事项，人们就会失去焦点。（[福布斯][1]）

### 1. 打造伟大的产品

这是**核心**。

AMD 的问题主要不在于“加强营销”或“多招人”。它需要的是技术上具有差异化的产品。

苏姿丰将 AMD 的工程资源集中在少数几个主要的路线图上，最著名的是 **Zen CPU 架构**，同时让公司专注于高性能计算。这个思路是：

```text
技术路线图
      ↓
伟大的架构
      ↓
伟大的产品
      ↓
客户采用
      ↓
收入 / 现金
      ↓
更多研发
      ↓
更好的产品
```

AMD 目前官方的使命声明仍然明确写着：

> **“打造加速下一代计算体验的伟大产品。”**（[超威半导体公司][2]）

而苏姿丰最近的解释甚至更有趣：科技公司需要**向前看 3 到 5 年，并押下重大的技术赌注**，然后在研发上大力投入，让这些赌注变成现实。（[哈佛商业评论][3]）

### 2. 深化客户关系

这不是传统的“销售”。

她的模式大致是：

```text
客户：
    “这是我们三年后将会遇到的问题。”

AMD 工程师：
    “那我们需要这样的架构。”

AMD：
    把它造出来

客户：
    进行部署

反馈：
    → 下一代
```

苏姿丰曾说过，打造伟大的产品和深化客户关系是**相辅相成的**。客户——云服务提供商、OEM 厂商、企业——可以告诉 AMD 他们在未来几年试图解决什么问题。这为工程师提供了选择正确技术赌注所需的信息。（[Andreessen Horowitz][4]）

所以：

**客户 → 未来的问题 → 产品路线图 → 产品 → 客户**

而不是：

**工程师 → 造出很酷的东西 → 希望有人会买。**

### 3. 简化一切

这一点很容易被低估。

它意味着：

```text
更少的市场
更少的优先事项
更少的项目
更清晰的组织
更清晰的问责制
更少的官僚主义
更多资源放在重要的路线图上
```

当苏姿丰接手时，AMD 的资源有限。她无法做到面面俱到。

因此，战略问题变成了：

> **AMD 在哪些方面才能真正做到世界一流？**

AMD 专注于高性能计算以及游戏、数据中心和沉浸式平台等目标领域，同时让组织围绕这些优先事项进行整合。（[福布斯][5]）

## 更深的模式

我认为最有趣的部分不是这三个词本身，而是这个**因果循环**：

```text
        ┌──────────────────┐
        │  选择少数几个    │
        │  巨大的市场      │
        └────────┬─────────┘
                 ↓
        ┌──────────────────┐
        │ 集中工程资源     │
        │ 于伟大的产品     │
        └────────┬─────────┘
                 ↓
        ┌──────────────────┐
        │ 深化客户关系     │
        └────────┬─────────┘
                 ↓
        ┌──────────────────┐
        │ 了解未来的       │
        │ 客户需求         │
        └────────┬─────────┘
                 ↓
        ┌──────────────────┐
        │ 更好的路线图     │
        │ / 重大赌注       │
        └────────┬─────────┘
                 ↓
             重复
```

而**“简化”是保护这个循环的约束条件**。

这就是为什么这个战略对像 AMD 这样技术底蕴深厚的公司特别有效：**不要把稀缺的工程人才分散到 50 件平庸的事情上。把它们集中在少数几件能够做到出类拔萃的事情上。**

对于你自己的人工智能公司，有一个很直接的类比：

```text
苏姿丰 / AMD                人工智能初创公司

伟大的产品          →      伟大的智能体/模型/产品
深入的客户          →      直接与真实用户合作
简化                →      砍掉低价值的项目
长期赌注            →      投资于少数核心技术
执行                →      每周交付
```

AMD 目前的公开表述已经演变，但同样的主题仍然存在：伟大的产品、高性能/自适应计算、创新、客户价值和**卓越的执行力**。（[AMD][6]）
