**问题：** 风扇只闪烁0.1秒然后关闭——如何使用示波器诊断这个故障？

---

**回答：**

思路很棒——示波器正是诊断这种超快故障的**正确工具**。以下是具体使用方法：

---

### 🔬 示波器在这里的作用是什么？普通万用表只能显示**当前稳定电压**。但当系统在**0.1秒内**死亡时，故障发生得太快，万用表**无法捕捉到**。示波器会随时间记录电压波形，因此你可以精确看到

```
正常启动：                      你的系统：
+12V ─────────────────          +12V ──╮
                                       │ 瞬间跌落
  0V                             0V    ╰──────────────
     time →                           ↑
                                    0.1秒
```

---

### 📍 示波器探头应放在哪里

24针ATX连接器上有**3个关键测试点**：

| 待测引脚 | 线色 | 测量内容 | 正常值 |
| --- | --- | --- | --- |
| +12V | 黄色 | CPU/主12V轨道 | 11.4V – 12.6V |
| +5V | 红色 | 主板逻辑电源 | 4.75V – 5.25V |
| +3.3V | 橙色 | 内存/芯片组 | 3.135V – 3.465V |
| PS_ON | 绿色 | 电源使能信号 | 变为低电平启动 |
| PWR_OK | 灰色 | 电源正常信号 | 稳定后变为高电平 |

**探头放置：**

```
黑色探头（GND）→ 24针上的任意黑色线
红色探头（+）  → 先连接黄色线（+12V）
```

---

### 🔧 示波器操作步骤

**第一步 — 设置示波器**

- 时间刻度：**每格50ms**（这样0.1秒能显示在屏幕上）
- 电压刻度：**每格5V**
- 触发：设置为+12V通道的**下降沿**
- 这样它就能捕捉到电压**跌落**的时刻

---

**第二步 — 先测量PWR_OK（灰色线）**

对于你的情况，**PWR_OK信号**是最重要的引脚：

```
PWR_OK = 高电平（+5V）→ 电源说：“我稳定了，主板可以运行”
PWR_OK = 低电平（0V） → 电源说：“检测到问题，关机”
```

如果你看到PWR_OK先变高，然后在0.1秒内立即变低——**电源检测到过流或欠压，自行关闭。**

---

**第三步 — 开机时观察+12V轨道**

```
期望看到的波形：
+12V ────────────────────────────  （稳定平直线）

故障电源的波形：
+12V ──╮
       ╰──── 瞬间跌落到8V或更低 → 电源在负载下崩溃
```

如果+12V在CPU试图取电的瞬间崩溃 → **电源功率不足或已损坏**

---

**第四步 — 测量ATX 12V 4针（CPU供电）**

这对你的症状最为关键。测量**4针CPU连接器**上的黄色线：

```
正常：   +12V ────────────────
故障：   +12V ──╮ 立即跌落
                  ╰──── 0V（CPU无法获得持续供电）
```

如果该线路崩溃而主24针+12V保持正常 → **电源无法通过4针提供足够电流** → 电源是问题所在。

---

### 🧭 波形告诉你什么

| 示波器显示结果 | 结论 |
| --- | --- |
| +12V在4针上立即跌落 | **电源功率不足/故障** |
| PWR_OK从未变高 | **电源已死或过载** |
| PWR_OK变高后在0.1秒内跌落 | **过流保护触发** |
| 所有电压稳定但系统死亡 | **主板或CPU故障** |
| +12V稳定，+5V跌落 | **电源5V轨道故障** |
| 一切稳定，风扇仍停止 | **热保护或CPU损坏** |

---

### 💡 针对你0.1秒症状的具体分析

示波器最可能显示的情况如下：

```
t=0ms    → 你按下电源按钮
t=5ms    → 电源启动，PWR_OK变高
t=50ms   → CPU开始在4针上取电
t=100ms  → +12V轨道崩溃（Huntkey 280W功率不足）
t=100ms  → PWR_OK变低
t=100ms  → 风扇停止
```

这将确认**Huntkey 280W电源是罪魁祸首**——它在CPU负载下无法维持+12V轨道。

---

### ⚠️ 示波器使用安全提示

- 始终**先连接GND探头**，再连接信号探头
- 切勿用普通示波器探头测量**市电（240V墙插）**
- 保持探头远离旋转的风扇
- 使用**绝缘探头尖端**——不要让裸露金属接触相邻引脚
