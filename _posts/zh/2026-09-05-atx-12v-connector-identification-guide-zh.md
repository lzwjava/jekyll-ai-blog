**问题：** 如何识别并插入4+4针ATX 12V供电接口中正确的那一半？

---

**回答：**

该接口在**物理设计上只有正确的一半才能插入**——这是防呆设计。以下是识别方法：

---

**方法1 — 查看卡扣/锁扣侧：**

```
正确的一半：              错误的一半：
┌─────────┐              ┌─────────┐
│ ■ ■ ■ ■ │              │ ■ ■ ■ ■ │
│  [卡扣]  │              │  无卡扣  │
└─────────┘              └─────────┘
     ↓                        ↓
可插入主板插座           无法完全插入
                        / 感觉松动
```

- **正确的一侧有塑料卡扣/锁扣**
- 插入主板插座时会发出咔哒声并锁紧
- 错误的一半**物理上无法完全插入** —— 会感觉松动或根本插不进去

---

**方法2 — 查看塑料外壳形状：**

每一半的其中一侧都有一个**倒角（斜切/切割边缘）**：

```
正确的一半外形如下：

 ___________
|           |
| ■ ■ ■ ■  |
|_______   /   ← 此处为切角
        \_/
```

- 将切角与主板插座内的对应凹槽对齐
- 如果切角不对齐 → 则为错误的一半

---

**方法3 — 查看线缆标签：**

大多数电源线缆（包括航嘉）在接口或线缆上直接标有标签：

| 接口上的标签 | 含义 |
|---|---|
| `CPU` | 这是ATX12V线缆 |
| `ATX12V` | 正确标签 |
| `+12V` | 同一线缆 |
| 一半可能标有 `1` | 4针主板使用这一半 |
| 另一半可能标有 `2` | 仅当组合成8针时使用 |

---

**方法4 — 查看线缆颜色：**

ATX12V正确的4针一半始终为：
```
针脚1 = 黄色 (+12V)
针脚2 = 黄色 (+12V)
针脚3 = 黑色  (地线)
针脚4 = 黑色  (地线)
```

如果所选的一半有这4根线 → 则为正确的一半。

---

**最简单的实地测试：**

> 只需轻轻尝试将每一半插入主板的ATX12V插座。
> **正确的一半能顺畅滑入并发出咔哒声。**
> **错误的一半无法插入——切勿强行操作。**

塑料防呆设计使得插入错误的一半几乎不可能。因此，只要能插进去并发出咔哒声 → 你就找对了。✅
