问题：我失业了，为支付房贷或作为AI咨询/软件外包业务的启动资金，是否应该向老朋友借大约2万（或1万）元？

回答：

基于你的背景，我建议**不要将这件事表述为“因为我失业所以借钱”**，而是将其表述为**一笔短期过桥贷款，用于购买执行时间**。

你的情况很特殊：你不是一个没有赚钱能力的新手。你的简历显示你有12年的工程经验、汇丰/企业系统经验、全栈+AI工作、开源项目、LLM训练实验以及之前的创业经历（趣直播）。（[李智维][1]) 问题不是“你能不能赚到钱”，而是“如何在现金压力下避免做出错误决策”。

我会把这笔钱分成两类：

## 1. 房贷生存资金：可以接受

向少数密友借**1万–2万元作为临时过桥**是合理的，前提是：

* 你明确说明还款计划；
* 你设定一个截止日期；
* 你不隐瞒自己的处境；
* 你向那些能轻松承受的人开口。

例如：

> “我目前处于工作间隙期，正在建立自己的AI咨询业务。我需要3个月的缓冲期来支付房贷和生活费。你能借我1万元吗？我计划在获得咨询收入或找到工作后归还。如果不方便，完全没关系。”

这与以下说法截然不同：

> “投资我的创业项目。”

前者是个人过桥，后者会创造投资者的期望。

## 2. 创业资金：谨慎对待

我建议**暂时不要为了创业资金去向朋友借钱**。

为什么？

因为2万元并不是真正的创业资本，而是生存资本。

对于AI咨询业务，你最大的瓶颈不是：

* GPU成本
* 办公室
* 公司注册
* 服务器

你的瓶颈是：

* 找到客户
* 将信任转化为合同
* 收到付款

你自己咨询页面已经指向了高价值服务模式：LLM/Agent项目、GPU基础设施、企业AI系统，费率超过500元/小时。（[李智维][2])

最快的验证路径大概是：

```
旧人脉
    |
    v
5-10次对话
    |
    v
1个付费试点项目
    |
    v
重复
```

而不是：

```
借10万
    |
    v
开发产品
    |
    v
期待用户出现
```

## 如果你借2万元，我建议的分配方案

大致如下：

```
20,000 元

房贷 + 伙食：
15,000

业务实验：
5,000
```

业务实验：

* 域名/邮箱
* 小额云成本
* 演示托管
* 差旅/咖啡会面
* 可能的小额营销

而不是：

* 购买GPU
* 在没客户前搭建大型SaaS
* 雇佣人员

## 我会如何联系老朋友

不要向20个人各借1000元。那样会损害关系。

更好的做法：

* 选择3-5个真正亲密的朋友；
* 单独询问；
* 给他们容易说“不”的空间；
* 定期向他们更新情况。

例如：

```
嘿，好久没聊了。

我最近离职了，正在重新探索AI咨询/创业。
我拥有足够的技能和经验来产生收入，但由于房贷压力，我需要一个短暂的缓冲期。

你方便借我1万元，为期3-6个月吗？
等收入稳定后我就会归还。

如果不行，完全没问题。我珍视我们的友谊胜过金钱。
```

## 另一个想法：你最快的赚钱路径可能是咨询，而不是创业

从你的资料来看，你的不对称优势是：

```
12年工程经验
+
银行经验
+
AI Agent/LLM
+
公开沟通能力
+
已有的技术声誉
```

这自然对应：

* AI自动化咨询
* 企业内部Agent
* 开发者效率工具
* 企业AI培训
* 遗留系统+AI集成

你已经有公开材料展示这种定位。（[李智维][2])

一个现实的90天计划：

### 第1-7天

创建：

```
AI咨询落地页
3个案例研究
20个目标公司
```

### 第8-30天

联系：

```
前同事
汇丰联系人
创业公司创始人
在公司里的朋友
```

目标：

```
50次对话
5份提案
1个付费项目
```

### 第30-90天

转化：

```
1个项目，2万-5万元
+
小额的定期维护
```

这比筹集资金更现实。

我的结论：**向密友借1万–2万元作为临时缓冲是合理的。让他们为你的创业想法出资则为时过早。借足够让你摆脱恐慌的钱，然后用你的技能和人脉快速创造收入。**
