**问：**微星 PRO B760M-E DDR5 主板可以用哪些 CPU？

**答：** **微星 PRO B760M-E（DDR5）** 采用 **LGA1700** 插槽，官方支持英特尔 **第12、13、14代酷睿处理器**，以及 Pentium Gold 和 Celeron。([微星][1])

### CPU 兼容性

| 代次              | 示例                                                         | 是否兼容？ |
| ----------------- | ------------------------------------------------------------ | ---------- |
| 第12代            | i3-12100, i5-12400, i5-12600K, i7-12700, i9-12900K            | ✅          |
| 第13代            | i3-13100, i5-13400, i5-13600K, i7-13700, i9-13900K            | ✅          |
| 第14代            | i3-14100, i5-14400, i5-14600K, i7-14700, i9-14900K            | ✅          |
| Pentium Gold      | 各种 LGA1700 型号                                            | ✅          |
| Celeron           | 各种 LGA1700 型号                                            | ✅          |
| Core Ultra / 第15代 | LGA1851                                                     | ❌          |

关键在于 **LGA1700**。它无法使用已改用 LGA1851 接口的新款 Intel Core Ultra 桌面处理器。

### 但有一项重要注意事项

**B760M-E 是一款非常入门级的主板**。尽管插槽兼容，但我**不建议将其与 i9-13900K/14900K 搭配**。虽然 CPU 在技术上可以被支持，但这款主板的供电和散热设计并不适合持续高功耗负载。

对于这款主板，我推荐的目标是：

* **i3-12100 / 13100 / 14100** → 价格便宜
* **i5-12400** → ⭐ 极佳的超值选择
* **i5-13400 / 14400** → ⭐ 不错
* **i5-13500** → ⭐ 二手市场很有价值的选择
* **i5-13600K / 14600K** → 可能可用，但已接近建议升级更好主板的分界点
* **i7/i9** → 技术上兼容，但不建议用于此主板

另外，由于您的是 **DDR5 版本**，根据微星当前规格，它拥有 **2 个 DDR5 DIMM 插槽，最高支持 128 GB**。([微星][1])

如果您正在寻找 **便宜的二手 CPU + 主板组合**，我建议优先考虑 **二手 i5-12400/13400/13500**，而不是昂贵的第14代芯片。
