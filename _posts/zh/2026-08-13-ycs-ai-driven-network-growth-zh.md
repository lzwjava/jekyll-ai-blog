问题：**Y Combinator未来会如何发展？**

回答：**我认为YC的结构决定了它能够变得比传统加速器模式更大、更重要。**有趣的是，其增长越来越依赖**网络驱动和AI驱动**，而不仅仅是“更多批次”。

截至2026年，YC表示已资助**5000多家公司和7000多位创始人**，每三个月收到**超过10000份申请**，录取率约为**1%**。它还报告有400多家公司估值超过1亿美元，100多家超过10亿美元。（[Y Combinator][1]）

### 1. 显而易见的增长：更多创始人

YC已经证明了它可以大幅扩大公司数量。

2021年，YC明确阐述了其理念：

> 如果有更多优秀的创始人申请，YC希望资助其中更多的人。

它从**第一批的8家公司 → 100多家 → 200多家 → 每批300多家**，同时将大部分项目移至线上，以消除物理限制。（[Y Combinator][2]）

如今，YC每年举办**四批**，而不是两批。（[Y Combinator][3]）

因此，简单的轨迹可能是这样的：

```text
2005
  ↓
小型精英加速器
  ↓
每年数百家初创公司
  ↓
每年数千家初创公司
  ↓
每年10000+家初创公司？
```

我不会假设YC真的能达到每年10000家公司，但**经济模式并不要求YC保持小规模**。

---

### 2. AI使YC的规模化问题容易得多

这才是真正有趣的部分。

旧版YC：

```text
1位合伙人
    ↓
亲自指导
    ↓
约10家公司
```

AI时代的YC可以逐渐变成：

```text
1位合伙人
    ↓
AI辅助知识系统
    ↓
数百位创始人
```

想象一下：

```text
YC知识库
  ├── 20年的创业建议
  ├── 创始人对话
  ├── 成功/失败的初创公司
  ├── 融资数据
  ├── 产品经验
  ├── 投资人网络
  └── 校友网络
          ↓
      AI创始人助手
          ↓
     数千位创始人
```

YC多年来一直在朝这个方向努力：文档、软件、虚拟批次、线上演示日等。YC明确表示，虚拟化使其能够突破以往的物理限制。（[Y Combinator][2]）

**AI使下一个版本更加强大。**

---

### 3. YC真正的护城河正在变成网络

这比50万美元的支票更重要。

假设YC拥有：

```text
5000家初创公司
7000位创始人
100+家独角兽
400+家估值超1亿美元的公司
```

每一家加入YC的新公司都能获得一个愈发有价值的网络：

```text
          创始人
             |
     +-------+-------+
     |       |       |
   YC       YC      YC
 创始人   投资人   创始人
     |               |
   客户            员工
     |
   人才
```

随着每一家成功公司的出现，网络变得更强。

这就是为什么YC明确表示**批次本身的价值会随规模增加而增加**，因为创始人有更多人可以向其学习、销售、招聘、合作以及建立关系。（[Y Combinator][2]）

这形成了一个正向反馈循环：

```text
更多优秀创始人
        ↓
更多成功初创公司
        ↓
更强的YC品牌
        ↓
更多申请
        ↓
更好的创始人筛选
        ↓
更多优秀创始人
```

这就是一个**网络效应业务**。

### 5. AI实际上可能增加YC可以资助的初创公司数量

这是一个微妙之处。

在AI之前：

```text
初创公司 = 5名工程师 + 设计师 + 销售 + 运营
```

现在：

```text
初创公司 = 1-3名能力极强的创始人
          +
          AI代理
          +
          API
          +
          云服务
```

因此，有能力创办严肃公司的人数增加了。

YC已经看到了这一点。在W24批次中，**至少50%的团队围绕AI构建**，YC表示AI使创始人能够完成以前需要更大资源才能做到的事情。（[Y Combinator][4]）

YC的2024年报告还强调了25家YC初创公司正在训练/微调自己的模型，有些在三个月的批次内从模型开发→生产→付费客户。（[Y Combinator][5]）

其2026年“创业需求”明确向**AI+物理世界**、基础设施、医疗、国防、金融、教育等领域推进。（[Y Combinator][6]）

所以YC不仅仅是在借助AI的浪潮。

**YC正在成为生产AI创业生态系统的机器之一。**

### 7. 但存在真正的天花板

最大的风险是**质量稀释**。

YC的核心等式是：

```text
YC价值 =
初创公司数量
×
平均初创公司质量
×
网络价值
```

如果他们增加：

```text
N ↑↑
```

但：

```text
质量 ↓↓
```

网络可能会变得混乱。

YC在规模化时明确认识到了这个问题：其公开标准不仅仅是批次大小，而是**YC公司的成功率是否保持强劲**。（[Hacker News][7]）

这可能是未来十年YC面临的核心战略问题。

| ------------------------ | ------------------------ |
| 申请数量                 | **大幅增加**             |
| 批次规模                 | **更大**                 |
| 批次数量                 | **更多/更持续**          |

| 全球创始人比例           | **大幅提高**             |
| YC校友网络               | **极其强大**             |
| AI辅助创始人支持         | **规模巨大**             |
| 资本/网络服务            | **更加重要**             |
| 录取率                   | **仍然极低**             |
| YC品牌                   | **很可能更强**           |

而最重要的转变是：

**YC正从一家帮助几百人创办公司的机构，转变为一个可能协调数万名创始人的网络。**

这就是为什么我认为你上一个问题中的直觉——“YC相信人的力量”——其实很接近核心机制。

疯狂之处在于，**AI使YC的理念更具可扩展性**。YC不一定需要变成拥有数千名员工的巨型公司。它可以利用软件+AI+校友来放大一个相对较小的核心团队。

这是一个比单纯“YC接受更多初创公司”更有趣的增长模式。
