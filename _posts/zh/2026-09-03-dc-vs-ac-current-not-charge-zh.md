问题：DC 是指“直接充电”而 AC 是指“交流充电”吗？

回答：差不多——正确的术语是：

* **DC = Direct Current（直流电）**
* **AC = Alternating Current（交流电）**

而不是“直接充电”。

### DC

电流主要沿**一个方向**流动：

```text
DC:

+ ───────────────→ ─────────────── -
       current
```

电池是典型的直流源：

```text
Battery
+  ───────────→  -
```

PC 主板内部主要使用 **DC 电压**，如 12 V、5 V、3.3 V、1.8 V、~1.5 V、~1 V 等。

### AC

电流会周期性**改变方向**：

```text
AC:

→ → → →
← ← ← ←
→ → → →
← ← ← ←
```

普通墙壁插座提供的电力是交流电。在许多国家，其频率约为 **50 或 60 Hz**，意味着电压周期性交替变化。

你可以将电压想象成：

```text
Voltage
  +
  │      /‾\      /‾\
  │     /   \    /   \
0 ├────/─────\──/─────\──── time
  │   /       \/       \
  │  /        /\        \
  -
```

因此，当你使用万用表时：

**`V⎓` / DC 电压** → 主板、电池、USB、电源输出等。

**`V~` / AC 电压** → 墙壁插座/市电交流电。

一个微妙之处：**AC/DC 描述的是电流/电压的行为，而不是“电荷”。** 电荷是另一个不同的物理概念。
