在Chrome中连接Claude：

1. **安装extension** — 前往 [Chrome Web Store](https://chromewebstore.google.com) 搜索 Anthropic 的 "Claude"，或在 [claude.ai/chrome](https://claude.ai/chrome) 找到它。

2. **登录** — 点击 Chrome 工具栏中的 extension 图标，使用你的 Anthropic 账户（与 claude.ai 相同）登录。

3. **保持 Chrome 打开** — extension 需要 Chrome 在前台运行。如果 Chrome 最小化或 extension 标签页被关闭，连接会断开。

4. **检查 extension 是否激活** — extension 图标应为彩色/亮起状态，而非灰色。若为灰色，点击图标并重新认证。

连接后，我可以直接在浏览器中截取屏幕、点击、导航和读取页面内容，而无需获取原始HTML。
