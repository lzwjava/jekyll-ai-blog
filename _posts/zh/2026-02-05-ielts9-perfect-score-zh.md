IELTS 的最高分是 **9.0**，这被视为满分。

IELTS (International English Language Testing System) 使用 9 分制评分系统：

- **9.0** = Expert user (完全掌握该语言)
- **8.0-8.5** = Very good user
- **7.0-7.5** = Good user
- **6.0-6.5** = Competent user
- 依此类推，最低为 1.0 (non-user)

你的 IELTS 总分是四个部分得分的平均分：Listening, Reading, Writing 和 Speaking。每个部分也同样采用 0-9 分的评分标准，总分（Overall Band Score）会四舍五入到最近的半分（例如 6.5, 7.0, 7.5）。

获得总分 9.0 非常罕见，这代表具备接近母语或母语水平的 English 熟练程度。大多数大学和移民项目根据具体的项目和国家要求，分数通常要求在 6.0-7.5 之间。
