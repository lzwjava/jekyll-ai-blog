`R005` 是一个**电流感测分流电阻**——一个 0.005 Ω（5 mΩ）的低阻值电阻，用于测量流入电源轨的电流。而**它两端的 12.3 V** 是个好迹象。以下说明了这意味着什么：

## R005 的含义

- 它**串联在一条大电流电源轨上**——在 GA104 显卡上，它几乎总是**为 GPU 核心供电（VCore）的 12V 输入**。
- **R005 处的 12.3 V = 12V 电源轨已到达 VRM 的高侧 MOSFET。** ✅

> 注意：“R005 两端”——如果你将红表笔接在一侧、黑表笔接在另一侧，12.3 V 仅确认 12V 总线在该处有电（*正常工作的 5 mΩ 分流电阻上的电压降*只有毫伏级，所以 12.3 V 意味着你的一根表笔接在 12V 上，另一根接在地/另一侧上）。

## 因此输入电源链路是健康的

```
PSU → 8-pin → 12V 总线 → R005 (12.3V ✅) → VRM 高侧 MOSFET → ??? (VCore)
```

故障现已确认**位于此点之后**——VRM 没有将 12V 转换为 VCore。

## 下一步测试：VCore 电感（芯片周围那排灰色线圈）

1. **黑表笔** → 接地（安装孔 / 支架）
2. **红表笔** → 每个 **VCore 电感**（GPU 芯片周围最近的灰色线圈）
3. 万用表拨至 **20V 直流档**

**解读：**

| 读数 | 诊断 |
| --------- | ----------- |
| **0.6 – 1.1 V** | VCore 正在运行——芯片应该发热；故障在其他地方（考虑到芯片发凉，可能性不大） |
| **0 V** | **VRM 未开关**——控制器/MOSFET/使能信号故障（最有可能） |
| **12 V** | 高侧 MOSFET 短路 → VCore 与输入短路（**危险**，可能烧毁芯片） |

## 顺手也可以测量这些

**VRM 控制器芯片**（VCore MOSFET 附近的小型 QFN/IC——通常是 **uP9512 / NCP45491 / IR35217** 系列）：

- 其 **VCC 引脚** → 预期为 5V 或 12V
- 其 **EN（使能）引脚** → 预期约为 3.3V（这是 GPU 的“开启核心电源”指令）

**如果 EN = 0 V → GPU/BIOS 未发出 VCore 开启指令**（上游故障：BIOS、晶振、复位或核心已损坏）。
**如果 EN = 3.3 V 但 VCore = 0 V → VRM 控制器或某个 MOSFET/驱动器已损坏。**
