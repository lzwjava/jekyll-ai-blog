## 测试 2 — 5V 和 3.3V 供电轨

**万用表：** 仍设为 **20V 直流**
**主板：** 已通电

## 在哪里找到测试点

这些低压供电轨通常由靠近**显卡背面/显示输出接口**或靠近 **PCIe 金手指**的小型降压转换器生成。最佳探测点：

1. **PCIe 插槽 5V/3.3V 引脚** —— 金手指上的 3.3V 和 12V 引脚（但它们很小/难以触达）
2. **电压调节器** —— 小型 8 脚 SOIC 芯片及其输出电感/电容
3. **BIOS/闪存芯片第 8 脚**（VCC）—— 通常为 **3.3V**
4. **风扇接口** —— 通常为 **12V** 或 **5V**

最简单的可靠测试点：

| 供电轨 | 常见测试点 | 预期值 |
| ------ | ------------------- | ---------- |
| **5V** | 5V 降压转换器输出端，或 USB/HDMI 相关电容，或风扇接口 | **5.0 V** |
| **3.3V** | BIOS 芯片 VCC 引脚（8 脚 SPI 闪存的第 8 脚），或 3.3V 调节器输出 | **3.3 V** |

## 如何探测

1. **黑色表笔** → 接地（安装孔、挡板，或大电容的负极焊盘）
2. **红色表笔** → 测试点
3. 读取直流电压

## 逐步操作顺序

### 2a. 找到 SPI 闪存（BIOS）芯片

- 在 PCIe 金手指附近的小型 **8 脚 SOIC 芯片**，通常标识为 **25Q... / MX25... / W25...**
- **第 8 脚（VCC）** 应读取到 **3.3 V**（第 1 脚有圆点标记，逆时针数）

### 2b. 找到 5V 转换器

- 通常位于显示输出接口（HDMI/DP）或背面边缘附近的**小型降压转换器 + 电感**
- 测量其输出电感两端 → **5.0 V**

### 2c. 风扇接口

- 如果有风扇接口，**其中一个引脚 = 12V 或 5V** —— 这是一个有用的基本检查

## 结果解读

| 读数 | 含义 |
| --------- | --------- |
| **5V 正常 + 3.3V 正常** | ✅ 进入 **1.8V 测试** |
| **两者均为 0V** | ❌ 12V→5V 转换器损坏（或其使能信号缺失） |
| **5V 正常，3.3V 缺失** | ❌ 5V→3.3V 转换器/调节器损坏 |
| **3.3V 正常，5V 缺失** | ❌ 5V 降压电路损坏（但主板可能仍能部分运行） |
