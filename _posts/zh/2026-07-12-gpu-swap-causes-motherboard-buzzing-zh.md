问题：为什么我的MSI B760M + i9-13900KF + Corsair CX650F 系统在将RTX 4070换成二手AMD MI50后，主板SATA5/6区域开始出现 buzzing 噪音？

回答：

根据你的描述，最可能的原因 **不是电源**。时间点强烈指向 **更换显卡触发了主板电源/PCIe/供电问题**。

你的操作顺序：

1. 系统使用RTX 4070时正常。
2. 移除RTX 4070。
3. 安装二手AMD MI50。
4. 主板立即开始出现 buzzing 声。
5. 移除MI50并重新安装RTX 4070后， buzzing 声仍然存在。
6. 声音集中在SATA5/6区域附近。
7. 电源短接测试可能通过。

这种情况暗示以下几种可能性。

---

## 1. 最可能：主板VRM/扼流线圈电气噪音（线圈啸叫）

许多mATX主板上的SATA5/6区域靠近：

* 芯片组供电电路
* SATA控制器区域
* 主板电源滤波元件

当电流波形改变时，小型电感（"扼流圈"）可能产生 **高频 buzzing / 啸叫声**。

示例：

```
12V 电源
 |
 +---- CPU VRM
 |
 +---- PCIe插槽供电
 |
 +---- 芯片组/SATA供电
          |
          +--- 线圈振动
```

更换显卡可能改变：

* PCIe功耗
* PCIe信号
* 芯片组负载
* 电源状态转换

并使之前静音的线圈开始振动。

这 **不一定意味着主板已损坏**。

---

## 2. MI50是一款非常特殊的PCIe设备

AMD MI50是一款数据中心GPU。

与RTX 4070相比：

|          | RTX 4070      | AMD MI50       |
| -------- | ------------- | -------------- |
| 架构     | Ada Lovelace  | Vega 20        |
| PCIe     | Gen4 x16      | Gen4 x16       |
| 功耗     | ~200W         | ~300W          |
| 供电接口 | 8-pin         | 8-pin          |
| 散热     | 消费级风扇    | 鼓风机/服务器  |
| 固件     | 消费级        | 企业级         |

MI50具有更高的瞬时功耗特性。

你的电源：

Corsair CX650F 650W

对于RTX 4070可能足够：

```
13900KF
~250W 峰值

RTX4070
~200W

系统
~500W 峰值
```

但MI50：

```
13900KF
250W

MI50
300W+

系统
600W+
```

你非常接近电源极限。

功耗瞬态可能会对主板供电轨造成压力。

---

## 3. 可能的PCIe插槽接触问题

更换显卡时：

* PCIe插槽承受机械应力
* 显卡挡板可能产生侧向推力
* 较大的MI50更重

轻微不良的PCIe接触可能导致奇怪症状：

* 无法启动
* 主板噪音
* 显卡初始化失败
* PCIe电源不稳定

尝试：

1. 完全移除显卡。
2. 向PCIe插槽吹压缩空气。
3. 用手电筒检查插槽。
4. 小心地重新安装RTX4070。

---

## 4. 首先检查EZ Debug LED

你的MSI主板在右上角附近有：

```
CPU
DRAM
VGA
BOOT
```

开机时：

* CPU灯？
* DRAM灯？
* VGA灯？
* BOOT灯？

这是最快的诊断方法。

示例：

### VGA LED

通常表示：

```
未检测到显卡
PCIe问题
显卡供电问题
```

### CPU LED

可能表示：

```
插槽问题
VRM问题
BIOS问题
```

---

## 5. "SATA5/6 buzzing" 可能具有误导性

声音通过PCB传播。

靠近PCIe/芯片组的线圈听起来可能像是来自SATA区域。

使用：

* 纸管
* 螺丝刀柄抵住耳朵
* 听诊器

比较：

```
PCIe插槽区域
|
VRM区域
|
SATA区域
|
芯片组散热片
```

通电时请勿触摸元件。

---

## 6. 重要问题：MI50是否需要不同的电源接线？

MI50通常期望：

```
8-pin EPS风格的PCIe供电
```

而不是主板CPU EPS。

如果意外连接错误：

* 错误线缆
* 模组电源线缆不匹配
* 使用其他电源的线缆

可能会损坏元件。

海盗船模组线缆 **并非通用**。

切勿混用：

```
海盗船线缆
+
其他电源
```

即使接口能插上。

5. 再次启动

```

（无显卡）

重要：

```

因此预计无显示输出，但检查声音。
