问题：美团王兴曾说过“对成功极度渴望的人很少”是真的吗？

回答：

是的，这个观点接近王兴的一个著名表述：**“极度渴望成功”的人不多，愿意付出非凡代价的人更少**。（[知乎][1]）

关键不仅在于 **想要成功**。许多人会说：

* “我想变得有钱。”
* “我想创办一家伟大的公司。”
* “我想要自由。”

但愿意接受代价的人却少得多：

* 5到10年的不确定性
* 反复失败
* 社会误解
* 别人休息时你在工作
* 没有即时回报地持续学习
* 冒险赌上声誉和金钱

区别在于：

```
普通渴望：
“如果这条路舒服，我就想要成功。”

极度渴望：
“我对成功的渴望足以让我围绕目标重新设计生活。”
```

很多人喜欢 **结果**，但不喜欢 **过程**。

例如，很多人羡慕成功后的创业公司创始人。但在成功之前，创始人往往看起来很不理性：

* 放弃稳定工作
* 投入多年时间却没有保障
* 做没人相信的事
* 面对资金更充裕的竞争对手

王兴自己在美团成功之前有过多次创业尝试。他的道路经历了许多失败才最终达到美团的成功。（[TechNode][2]）

然而，仅有极度渴望并不足够。

一个有用的公式：

```
成功 ≈ 渴望 × 能力 × 学习速度 × 时间 × 运气
```

极度渴望提供能量，但如果没有：

* 正确的方向
* 执行能力
* 从现实中学习的能力

就可能变成盲目的坚持。

最强大的创始人通常结合：

```
高野心
+
长期耐心
+
快速学习
+
准确判断
```

这就是为什么王兴也强调耐心和理解趋势，而不仅仅是努力工作。（[新浪财经][3]）

对于正在构建AI产品/创业的人来说，这一特质很重要，因为反馈循环往往很慢：

```
构建 → 没人关注 → 改进 → 再试 → 少量用户 → 收入 → 规模化
```

大多数人在“没人关注”的阶段就放弃了。

罕见的人不一定是每天工作18小时的人，而是那些能够保持十年方向的同时不断调整的人。
