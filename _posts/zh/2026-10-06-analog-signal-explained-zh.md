**问题：什么是模拟信号 (analog signal)?**

**答案：**

**模拟信号 (analog signal)** 是一种随时间**连续变化**的信号。它通过改变物理量（如**电压、电流、声压或电磁波振幅**）来表示信息。

在数学上，模拟信号可以表示为：

$$
x(t)
$$

其中：

* \\(t\\) = 连续时间
* \\(x(t)\\) = 信号值，可在一定范围内取任意值

示例：

```
电压

5V       /‾‾\      /‾‾\
        /    \    /
0V ____/      \__/______ 时间
```

电压平滑变化。在任何时刻，它可能是：

* 1.234V
* 2.567V
* 3.891V

有无限多个可能的值。

### 模拟信号的常见例子

**1. 人声**

你的声音产生空气压力波：

```
声波：

     /\      /\
    /  \    /  \
___/    \__/    \___
```

麦克风将此连续的气体振动转换为连续变化的电压。

**2. 无线电广播**

传统的AM/FM无线电使用模拟电磁波。通过改变以下量来编码信息：

* 振幅（AM：调幅）
* 频率（FM：调频）

**3. 老式电话系统**

老式座机将声音作为模拟电信号传输。

### 模拟信号与数字信号对比

|                  | 模拟               | 数字     |
| ---------------- | -------------------- | ----------- |
| 值               | 连续           | 离散    |
| 示例          | 2.345V, 2.346V 等 | 0 或 1      |
| 波形         | 平滑               | 方波状 |
| 抗噪声能力 | 较低      | 较高      |
| 存储          | 更难      | 更容易      |

示例：

模拟：

```
~~~~~~~ 连续波 ~~~~~~~
```

数字：

```
___|‾‾‾|___|‾‾‾|___
 0   1   0   1
```

---

现代系统通常将模拟信号转换为数字信号：

```
现实世界
（声音/光线/温度）
        |
        v
 模拟信号
        |
        v
 ADC（模数转换器）
        |
        v
 数字数据
        |
        v
 计算机处理
```

例如，智能手机麦克风：

1. 空气振动 → 模拟声波
2. 麦克风 → 模拟电信号
3. ADC → 数字采样（44.1 kHz, 48 kHz 等）
4. 手机处理数据

因此关键概念：

**模拟信号 = 由连续变化的物理信号承载的信息。数字信号 = 由离散值（通常为比特0和1）表示的信息。**
