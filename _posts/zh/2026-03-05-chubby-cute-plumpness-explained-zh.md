问题：“chubby”是什么意思？

答案：

**Chubby** 是一个英语形容词，用来描述某人（或某物）**以一种愉快、可爱或看起来健康的方式略胖**——不是 obese 或非常超重。

### 主要含义和常见用法

- **For people**（最常见用法）：
  拥有柔软、圆润、略显丰满的身体——通常被认为吸引人或可爱，而不是负面。
  示例：
  - a chubby baby / chubby cheeks
  - chubby toddler thighs
  - "He's a bit chubby but very cute."
  - "She has a chubby face and dimples."

- 典型积极/亲切的感觉：
  Chubby 常常听起来**亲切**，特别是在谈论婴儿、幼儿或拥有柔软圆润特征的人时。
  比较：
  - chubby = cute-plump
  - fat = 更中性或负面
  - overweight / obese = 医学或明显负面术语

- **For animals**：
  - A chubby hamster / chubby cat / chubby puppy（同样——可爱且圆润）

- **For objects**（较少见）：
  - chubby fingers, chubby crayons, chubby bottle（短而粗的形状）

### 类似词的快速比较

- **skinny / thin** ← 对立面
- **slim / slender** = attractively thin
- **chubby** = pleasantly plump
- **chunky / stocky** = strong + thick build
- **fat / overweight** = 更明显地重

总之：**chubby** = 柔软、圆润、略胖，通常以**cute / lovable**的方式。
