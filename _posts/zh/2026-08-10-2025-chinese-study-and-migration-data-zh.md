问题：2025年中国赴美留学/移民的数据如何？

答案：

2025年的数据显示 **疫情后复苏**，但中国学生数量已不再像2010-2018年期间那样增长。

## 1. 美国大学中的中国学生（2024/25学年）

根据 **Open Doors 2025** 报告：

* 美国国际学生总数：

  * **1,177,766 人**
  * 同比增长 **5%**

* 中国学生人数：

  * **265,919 人**
  * 中国仍是 **第二大生源国**
  * 比上年减少约 **4%**

* 印度学生人数：

  * **363,019 人**
  * 第一大生源国
  * 增长 **10%**

([IIE Open Doors][1])

概况如下：

```

```

中国学生规模依然庞大，但印度已超越中国。

## 2. 与疫情期间对比

疫情期间数据异常：

```
2019        强劲增长
2020-2022   崩溃
2023        复苏
2024-2025   基本正常
2026        新常态
```

美国目前拥有近120万国际学生，接近疫情前规模。([IIE Open Doors][1])

对中国学生而言：

* 签证中心已重新开放。
* 航班恢复正常。
* 大学再次积极招收国际学生。

因此 **2025/2026 年比 2020-2022 年容易得多**。

## 3. 但与2015-2018年相比呢？

难度更大。

约2015-2018年期间：

* 中国中产阶级迅速扩张。
* 美国大学积极招收中国学生。
* 中美关系较好。
* 签证环境更顺畅。

现在：

* 更多地缘政治审查。
* 印度申请者竞争加剧。
* 一些人工智能/半导体领域受到更多审查。

([Reuters][2])

## 4. 研究生 / 人工智能硕士情况

对于人工智能/计算机科学领域：

2025年数据很有意思：

* STEM仍是国际学生的主要领域。
* 数学和计算机科学持续成为最大专业领域之一。([IIE Open Doors][1])

市场正在分化：

### 顶尖院校

难度极大：

* CMU
* Stanford
* MIT
* Berkeley

因为：

```
中国计算机科学申请者
+
印度计算机科学申请者
+
全球人工智能申请者
=
极度竞争
```

### 普通美国硕士

仍可实现。

尤其对于具备以下条件的人：

* 8-12年工程经验
* LLM训练经验
* 开源项目
* 已部署AI系统

其背景与应届本科生截然不同。

## 5. 移民数据视角

中国移民趋势正在转变。

以前：

```
中国 -> 美国留学 -> 美国工作 -> 绿卡
```

是主要路径。

现在：

```
中国 -> 美国
中国 -> 加拿大
中国 -> 新加坡
中国 -> 香港
中国 -> 欧洲
中国 -> 远程/全球AI工作
```

更加多元化。

美国仍是人工智能研究和创业最强大的生态系统，但已不再是唯一有吸引力的目的地。
