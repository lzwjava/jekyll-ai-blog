**KDD = ACM SIGKDD Conference on Knowledge Discovery and Data Mining。**

它是围绕 machine learning + data mining + applied AI + large-scale data systems 的主要会议之一。2026 年会议于 8 月 9–13 日在韩国济州举行。（[KDD 2026][1]）

重要的是，现代的 KDD 比“data mining”这个名字所暗示的领域要广泛得多。

### 人们实际在讨论什么

KDD 2026 设有以下 tracks：

* **Research** — ML/data mining 算法与方法
* **Applied Data Science** — 真实世界的 ML 系统与应用
* **Datasets & Benchmarks**
* **AI for Science**（[KDD 2026][2]）

而且 2026 年的 program 中，LLM/agent 相关工作的数量惊人地多：

* Agentic Software Engineering
* Agentic AI 评估/可信度
* 企业级 AI Agents
* 用于信息检索的 AI agents
* 科学/社会型 agents
* 安全且可信的 LLMs
* 大模型时代的 Graph ML
* 用于 LLMs 的 Multi-turn RL
* RAG
* LLM 可解释性
* 让 LLMs 为 AI accelerators 编写 system kernels
* 用于推理的 AI（[KDD 2026][3]）

所以对于从事 LLM training、reasoning、agents、RL、evaluation 和 AI systems 的人来说，KDD 现在绝对相关。

## 关于 KDD 2026，有一个特别有意思的地方

**workshop/tutorial 层面**对你来说可能比 main papers 更有意思。

例如，KDD 2026 有一个专门的 hands-on tutorial，主题是：

> **Multi-Turn Reinforcement Learning for Large Language Models**

另一个则关于教 LLMs 为 AI accelerators 编写 system kernels，涵盖 post-training、reasoning 和 agentic optimization。（[KDD 2026][4]）

这与你最近一直在问的那些内容非常接近：

```text
LLM
 │
 ├── pretraining
 │
 ├── SFT
 │
 ├── RL / verifiable rewards
 │      ├── code execution
 │      ├── Lean
 │      └── mathematical verification
 │
 ├── reasoning
 │
 ├── agents
 │
 └── systems optimization
        ├── kernels
        ├── CUDA
        ├── inference
        └── accelerators
```

KDD 也明确将自己定位为 research 与 real-world applications 之间的桥梁，而不是纯粹理论性的 ML。（[KDD 2026][5]）

### 如果你的目标是“该去哪里关注论文？”

对于你当前的 LLM 方向，我大致会按主题而不是按名气来优先关注这些社区：

```text
LLM reasoning / training
    → NeurIPS / ICML / ICLR

LLM agents / applied AI / data
    → KDD

RAG / retrieval / search
    → SIGIR / KDD / WWW

LLM NLP
    → ACL / EMNLP

Training + inference infrastructure
    → MLSys / OSDI / SOSP

Databases + data infrastructure
    → SIGMOD / VLDB

Computer vision
    → CVPR / ICCV / ECCV
```

而且，KDD 眼下格外有意思，是因为这个传统的“data mining”会议正在吸收大量现代 LLM/agent 研究——2026 年的 workshop 和 tutorial 列表让这种转变非常明显。（[KDD 2026][3]）

我还可以把 **KDD / NeurIPS / ICML / ICLR / MLSys / ACL** 分别对照你的 LLM-training + agent 工作，包括什么样的 paper/project 适合投到哪个 venue。
