以下是针对 GA104 显卡（RTX 3060 Ti/3070）从输入到核心的精确测试步骤：

---

## 步骤 1 — 断电，检查短路（电阻/通断模式）

这是最重要的第一步测试。任何电压轨上的对地短路都会阻止显卡上电。

| 测试点 | 预期值 | 故障情况 |
| ----------- | ---------- | ---------- |
| **12V 输入**（8 针 + PCIe 12V 引脚）对地 | ~500 Ω – 数 kΩ | 接近 0 Ω = 高端 MOSFET 或电容短路 |
| **VCore（VDDC）** 电压轨 — 核心周围的大电感 | **极低 Ω（0.5–2 Ω）** 对 GPU 核心来说是 *正常* 的 | 0.0 Ω = 对地短路；10 Ω 以上可能正常 |
| **VMEM（VRAM）** 电感 | ~10–100 Ω | 0 Ω = VRAM/MOSFET 短路 |
| **5V / 3.3V / 1.8V** 电压轨 | ~kΩ | 0 Ω = 短路 |

> ⚠️ VCore 正常电阻非常低，因为核心消耗巨大电流。不要误把 1 Ω 当作短路。

---

## 步骤 2 — 上电，用直流电压档测量（你的故障点就在这里）

按以下精确顺序检查：

### A. 输入电源是否就绪？

1. **8 针 PCIe 电源接口上的 12V** → 预期 **12 V**
2. **PCIe 插槽引脚上的 12V** → 预期 **12 V**
3. **5V 和 3.3V** 是否存在于板上 → 预期 **5 V / 3.3 V**

如果 12V 缺失 → 电源/线缆/保险丝问题。如果 12V 存在但其他没有 → 执行 B。

### B. 待机/低压轨

4. **5V** 电压轨 → 预期 **5.0 V**
5. **3.3V** 电压轨 → 预期 **3.3 V**
6. **1.8V** 电压轨（通常靠近 BIOS 芯片/显存附近） → 预期 **1.8 V**

### C. 关键步骤 — VRAM 和 VCore

7. **VMEM（VRAM）** 电感 → 预期 **1.35 V**（GDDR6）
8. **VCore（VDDC）** 核心周围电感 → 预期 **0.6–1.1 V**（启动时升高）

**如果 VMEM 存在但 VCore = 0 V → VRM 未启动。** 这就是经典的“核心冷”故障。

---

## 步骤 3 — 如果 VCore = 0 V，测试 VRM 控制器

核心 VRM 控制器（在 GA104 板上通常为 **uP9512 / NCP45491 / IR35217** 类型）需要：

1. **VCC**（控制器供电，通常为 5V 或 12V） → 是否存在？
2. **EN / EN_VCORE**（使能引脚） → 预期 **~3.3 V**（这是来自 GPU/BIOS 的“开启核心”信号）
3. **PGOOD / PowerOK** 输出 → 运行后应为高电平

**关键诊断：** 如果 EN 为 **0 V**，GPU/BIOS *没有* 命令核心开启 → 问题出在上游（BIOS、晶振、复位或核心本身）。如果 EN 为 **3.3 V** 但没有 VCore → VRM 控制器或 MOSFET/驱动器已损坏。

---

## 快速判断树

```
上电，核心冷
├─ 没有 12V 输入          → 电源 / 线缆 / 保险丝
├─ 没有 5V / 3.3V          → 低压轨转换器损坏
├─ 5V/3.3V 正常，没有 VMEM   → VRAM VRM 或其使能信号
├─ VMEM 正常，没有 VCore     → 核心 VRM：检查控制器 VCC + EN + MOSFET
└─ VCore 存在但核心冷 → 核心本身已坏（罕见）或 VRM 负载时不供电
```
