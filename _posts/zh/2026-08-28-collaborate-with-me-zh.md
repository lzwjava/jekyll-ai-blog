### LLM 与 Agent 研究合作

### 热门研究方向（ICML / NeurIPS）

对于 LLM 与 agent 合作，前沿正在从**语言建模 → 能够学习、推理、行动和改进的智能系统**转变：

- **Agent RL / Reasoning RL**——RLVR、GRPO/PPO、self-improvement loops、DAPO 式系统。
- **Agent World Models**——学习 `state + action → next state`，以使 agent 能预测“如果我这样做会发生什么？”（文本、视觉、多模态）。
- **Synthetic environments**——由 LLM 构建的世界生成数百万次仿真，以驱动 agent RL（“面向一切的 OpenAI Gym”）。
- **Transformer 架构**——long context、MoE，以及 next-token prediction 的替代方案（latent/recurrent reasoning、test-time compute）。
- **SFT → data engineering**——高质量 trajectory data、synthetic data、preference optimization。
- **Multi-agent 与 multi-model 系统**——planner/coder/research/verifier agents，以及 multimodal、multi-model pipeline。

就我个人的背景而言（small-LLM training、GPU infra、agent CLIs），我的首选是 **agent RL + synthetic environments**、**coding agents 的 world model**（“如果我编辑这个文件，会破坏什么？”），以及在 consumer GPUs 上进行 **efficient training/inference**。一篇顺理成章的 2026 年论文：**Learning Software Engineering World Models for Autonomous Coding Agents**。
