这是一个**团队知识库**（Team Knowledge Base）——一个基于分层知识模型构建的全栈Web应用程序，用于管理和治理团队知识。

**技术栈：**
- **后端**：Python FastAPI（控制器、服务、中间件、SQL数据库）
- **前端**：Vue 3 + TypeScript + Vite + Vue Router
- **存储**：Git仓库中的Markdown文件，并带有机器可验证的JSON元数据块

**知识层**（核心组织概念）：
| 层级 | 描述 |
|------|------|
| 层 0-P | 个人经验 |
| 层 0-T | 团队约定 |
| 层 1 | 技术知识 |
| 层 2 | 业务知识 |
| 层 3 | 项目知识 |

**知识类型**：模型、决策、指南、陷阱、流程

**功能**（来自路由和视图）：
- 知识创建引导流程（创建 → 预览 → 完成）
- 按层级/分类筛选的知识浏览
- 权限管理（阅读者 / 贡献者 / 维护者 / 超级管理员 角色）
- 超级管理员面板
- 成员管理与业务领域管理
- 用于外部共享知识的预览令牌
- 治理CLI工具（`knowledge_governance.py`）用于基于文件的验证
- 审计日志

**已填充内容**：`tech-wiki/` 目录包含18条知识条目——决策（例如“Python 3.12”、“Vue 3 + TypeScript”）、指南（例如“隐藏镜像层方案”、“bash一键开发脚本”）、模式、反模式、陷阱——均以Markdown格式维护，并带有机器可解析的元数据。

基本上它是一个**知识治理平台**——一个结构化的维基系统，将知识视为代码（存储在Git中，经过审查，版本控制），并带有用于注入和浏览的Web UI，以及一个用于治理强制执行的CLI工具。
