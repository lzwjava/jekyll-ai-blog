问题：有没有工具可以扫描微信联系人，找出谁删除了我？

答案：

确实存在一些声称能检测谁删除了你的工具/脚本，但**请务必小心**：微信并未提供官方API来实现此功能。大多数"好友检测器"通过尝试发送消息、创建群聊或批量检查联系人状态来工作，但这可能：

* 违反微信服务条款
* 触发账户风控机制
* 泄露你的联系人/会话数据
* 导致账户被临时限制

### 这些工具通常的工作原理

有以下几种方法：

#### 1. 群聊检测（常见）

脚本会临时创建一个包含选定联系人的群聊。

如果有人删除了你：

* 微信可能显示"你不是对方好友"（添加时）
* 如果立即解散群聊，对方可能收不到通知（不同版本行为有差异）

问题：

* 添加数百人可能触发反垃圾保护。

#### 2. 转账/支付检测

部分脚本尝试：

```
好友 -> 发送小额支付请求 -> 观察错误提示
```

例如：

```
"请输入支付密码"
vs
"你还不是对方好友，请发送好友请求"
```

问题：

* 有风险。
* 可能打扰联系人。
* 不可靠。

#### 3. 导出+对比联系人

部分安卓工具会提取微信数据库：

常见路径：

```
/data/data/com.tencent.mm/
```

数据库：

```
EnMicroMsg.db
```

然后分析：

```
联系人表
    用户名
    昵称
    别名
    类型
```

问题：

* 需要root权限。
* 微信数据已加密。
* 现代安卓版本操作困难。

### 开源项目

历史上曾有过：

* `wechaty`

[Wechaty GitHub](https://github.com/wechaty/wechaty?utm_source=chatgpt.com)

Wechaty是一个微信机器人框架。它曾支持个人微信自动化，但由于微信收紧限制，个人账户支持已变得有限。

旧脚本：

* `wxpy`

[wxpy GitHub](https://github.com/youfou/wxpy?utm_source=chatgpt.com)

同样，对于现代个人账户大多已无法使用。

### 更安全的手动方法

如果你只需检查少量联系人：

1. 打开联系人资料。
2. 点击"发消息"。
3. 观察：

   * 正常聊天界面 → 大概率仍是好友
   * "你还不是对方好友..." → 已被删除/拉黑

或者：

```
通讯录 → 搜索 → 姓名 → 资料
```

---

### 我的建议

对于重要的微信账户：

* **不要**安装来路不明的"微信好友扫描APK"。
* **不要**将微信二维码登录/会话授权给网站。
* 如果你有数千联系人需要清理，仅在辅助账户上使用受控脚本。

一种更稳妥的工程方法是：

```
安卓模拟器
        |
        v
uiautomator/Appium
        |
        v
微信UI自动化
        |
        v
缓慢验证
```

并设置速率限制：

```
每天检测20-50个联系人
随机延迟
不创建群聊
不发送消息
```

但即便如此仍存在账户风险。

目前尚无官方、可靠的"扫描所有已删除我的好友"API。
