问题：微信“群笔记”（底部群工具旁边的那个）会通知所有群成员吗？还是更像投票功能？

回答：
**简要回答：**

* **群公告** → 会向**所有成员发送强提醒通知**。
* **群笔记（底部群工具）** → **不会通知所有人**；它的行为更接近**共享文档/类投票的协作笔记**。

### 区别

**1. 群公告**

* 由群主/管理员发布
* 自动**@所有成员**
* 每个人都会收到通知
* 通常置顶显示
* 用于发布公告

此功能明确“一次性通知所有群成员”，起到强制提醒的作用。（[China Clife][1]）

**2. 群笔记（接龙 / 群工具里的笔记）**

* 共享的可编辑笔记 / 清单 / 类投票条目
* 需用户**手动点击打开**
* 成员可以填写条目
* 通常**不会向所有人推送通知**
* 出现在“群工具”区域

所以你的理解是正确的：

* 它**不像群公告**
* 它**更接近投票 / 共享列表**
* 它**不会自动提醒所有人**

### 功能对比

| 功能          | 通知所有人 | 推送通知     | 主要用途               |
| ------------- | ---------- | ------------ | ---------------------- |
| 群公告        | 是         | 强提醒       | 发布公告               |
| @所有人消息   | 是         | 强提醒       | 紧急提醒               |
| 群笔记        | 否         | 通常没有     | 收集信息 / 清单        |

因此，如果你希望每个人**立即看到**，请使用：

* 群公告
* @所有人

如果使用**群笔记**，人们只有在以下情况才会看到：

* 他们打开群工具
* 他们浏览聊天记录
* 他们手动查看
