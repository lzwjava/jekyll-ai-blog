问题：如何制作一个非常简单的烤箱版：只需将菜心和切好的牛肉放在一起烤？

答案：

是的，可以做得非常简单。最简单的方法如下：

### 简易烤箱版菜心 + 牛肉

**食材**

* 菜心
* 切好的薄牛肉片
* 食用油
* 盐
* 酱油（可选）

### 步骤

1. 预热烤箱：

```
220°C (430°F)
```

2. 将菜心放在烤盘上。

3. 将切好的牛肉片放在上面。

4. 加入：

```
1–2勺油
少许盐
少许酱油（可选）
```

5. 用手或筷子将所有食材混合均匀。

6. 烘烤：

```
10–12分钟
```

7. 取出，搅拌一次，检查牛肉是否完全熟透。

就这样。

如果想在不增加额外工作的情况下获得更好效果：

* 将**牛肉放在菜心叶片下方** → 牛肉能吸收更多水分。
* 将较粗的菜心茎切小，叶子保持较大。
* 不要将烤盘摆得太挤，否则食材会蒸而不是烤。

懒人版“一锅烤”方案：

```
烤盘
 ├── 菜心茎
 ├── 牛肉片
 └── 菜心叶

220°C
10分钟
```

搭配米饭食用。这基本上是快手中式炒菜的烤箱版。
