**AIO_PUMP** = 主板上的**一体式水泵接口**。

这是一个专用的4针风扇接口，专门为AIO（一体式）水冷泵所标注。

### 在您的微星MAG B760M Mortar主板上

主板拥有以下相关接口：

| 接口 | 板载标识 | 用途 |
| -------- | ---------------- | --------- |
| **AIO_PUMP** | 顶部边缘，靠近CPU插槽 | 用于水冷**泵** |
| **CPU_FAN** | CPU插槽右侧 | 用于**冷排风扇**（或风冷散热器风扇） |
| **PUMP_FAN** | 有时与AIO_PUMP相同 | 备用泵接口 |
| **SYS_FAN1-4** | 主板上各位置 | 用于机箱风扇 |

### 您当前的接线（可能错误）

```
AIO水泵线缆  ──→  CPU_FAN     ← 水泵由CPU温度曲线控制（不佳）
冷排风扇       ──→  ???
```

这会导致：

- 水泵转速随CPU温度瞬间波动
- 水流量变化 → 水温震荡
- 风扇忽快忽慢 → 烦人噪音

### 正确接线应为

```
AIO水泵线缆  ──→  AIO_PUMP    ← 水泵固定100%全速运行（良好）
冷排风扇       ──→  CPU_FAN     ← 风扇由CPU温度曲线控制
```

### 如何区分利民Frozen Prism 240水冷各线缆

该水冷泵头共有**两根线缆**：

1. **水泵电源线**（3针或4针，线径较粗）— 标注为"PUMP"或从泵体引出
2. **风扇线缆** — 来自两个冷排风扇，通常串联为一个接头

请检查您的线缆走向，确保：

- **水泵线缆**连接至主板的**AIO_PUMP**接口
- **冷排风扇线缆**连接至**CPU_FAN**接口（或通过分线器连接至CPU_FAN）
