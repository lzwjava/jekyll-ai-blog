问题：当MSI MAG B760M Mortar WiFi的下方PCIe插槽被转接卡/线缆阻挡时，如何使用第二个GPU插槽？

回答：

你的主板在技术上拥有两个PCIe插槽，但物理布局是限制因素。

MSI MAG B760M Mortar WiFi DDR5布局：

```
CPU
 |
 |  PCIe x16（顶部插槽）
 |  =======================
 |        GPU（RTX 4070 / MI50）
 |
 |  M.2 / 芯片组区域
 |
 |  PCIe x16 物理插槽（底部插槽，x4电气）
 |  =======================
 |
 |  PCI卡 / 转接卡
```

问题通常在于：

* 你的第一个GPU厚度为**2-3槽**
* MI50是**服务器鼓风机卡**，通常约2槽厚
* 下方PCIe插槽非常靠近
* M.2转接卡 / USB转接卡 / 采集卡 / 线缆阻挡了气流或物理插入

这是一个常见的mATX问题。

解决方案：

### 方案一 — PCIe延长线（最佳方案）

使用PCIe x16延长线：

```
主板底部PCIe插槽
          |
          |
     PCIe延长线
          |
          |
     垂直安装的GPU
```

示例：

```
[CPU]
 |
[RTX 4070]
 |
-----------------
底部PCIe
 |
延长线
 |
机箱外的MI50
```

对于AI工作负载来说这没问题，因为底部插槽只有PCIe 4.0 x4。你不会进行游戏SLI。

对于LLM推理/训练：

* GPU带宽不如VRAM容量重要
* PCIe x4通常可以接受

---

### 方案二 — 移除转接卡

如果转接卡是：

* 无线网卡
* USB扩展卡
* 声卡
* NVMe PCIe转接卡

请将其移除。

你的主板本身已具备：

* WiFi 6E
* 多个USB接口
* M.2插槽

你可能不需要PCIe转接卡。

---

### 方案三 — 使用更大的ATX主板

如果你的目标是：

```
RTX 4070
+
AMD MI50
+
未来可能再加一块GPU
```

mATX是错误的外形规格。

全尺寸ATX主板提供：

```
GPU 1
（空闲间隔）
GPU 2
（空闲间隔）
GPU 3
```

示例：

* Z790 ATX主板
* W790工作站主板

---

### 方案四 — 移除机箱插槽限制

有时主板有空间，但机箱支架阻止了第二块GPU。

检查：

* 机箱扩展插槽数量
* GPU厚度
* 电源仓是否阻挡底部区域

---

针对你的具体配置：

```
i9-13900KF
MSI B760M Mortar WiFi
RTX 4070
AMD MI50
```

我会这样做：

```
顶部PCIe x16：
RTX 4070

底部PCIe x4：
PCIe延长线
        |
        MI50外部/垂直安装
```

这实际上是一个非常常见的AI工作站配置。对于大多数LLM实验，MI50不需要PCIe x16；**16GB HBM2内存**才是最有价值的部分。
