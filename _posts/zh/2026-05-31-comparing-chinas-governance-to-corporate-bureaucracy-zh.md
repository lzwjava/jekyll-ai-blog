## 中国的规模问题 ≈ 大公司的规模问题

**根本原因相同：大规模协调必然导致标准化。**

| 大公司 | 中国 |
| ---------- | ------- |
| 锁定的工作笔记本 | 防火墙、受监控的互联网 |
| 软件开发生命周期官僚流程 | 监管审批链条 |
| IT 安全策略 | 社会信用、监控摄像头 |
| 人力资源合规规定 | 严格的言论/集会法律 |
| “我们这里不这么干” | 对异议的审查 |

当你管理 **10万名员工** 或 **14亿人口** 时，你不能信任个人——你信任的是体系和规则。数学逻辑迫使如此。

一家10人的初创公司不会制定笔记本使用政策。一家5万人的银行会对所有设备进行严格管控。治理14亿人口的中国 → 同样的本能，只是被极大地放大了。

## 不信任的循环

严格的规定 → 人们感到被监视/不被信任 → 他们对体制产生怨恨 → 政府将怨恨视为威胁 → 进一步收紧规则。经典的管控螺旋。在具有有毒自上而下文化的组织中也会发生同样的情况。

## 但关键区别在于

在公司里，你可以 **辞职**。这种退出的选择保持了一定的平衡——过度控制的企业会流失人才。

公民无法轻易“退出”一个国家。这种不对称使得国家过度控制在结构上比企业过度控制更危险。

## 让中国的情况更棘手的原因

- **没有选举反馈机制** 来纠正过度矫正
- **技术放大了控制**——人脸识别、数字支付、手机定位让监控比以往任何时候都更便宜
- **合法性基于绩效**（经济增长）而非基于同意——一旦增长放缓就行不通
