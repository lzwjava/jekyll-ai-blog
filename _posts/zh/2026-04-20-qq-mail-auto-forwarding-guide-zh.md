# 🔍 “自动转发”功能实际位置（精确路径）

必须使用**网页桌面版**，而非手机应用。

### 操作步骤（重要细节）：

1. 打开：[https://mail.qq.com](https://mail.qq.com)
2. 登录
3. 点击右上角**设置**
4. 点击 **“常规”标签页**（非“账户”）

👉 随后**向下滚动较长时间（此处是关键）**

你需要找到：

> **邮件自动转发 / 自动转发**

✔ 它**不在 POP3/IMAP 区域内**
✔ 通常位于以下功能附近：

* 反垃圾设置
* 自动回复

接下来：

* 启用功能
* 输入你的Gmail地址
* 验证
* 保存

📌 该功能确实存在，但因位置靠下容易被忽略（[bkqs.com.cn][1]）

# 🚫 重要现实情况（关键限制）

近年腾讯可能：

* 对部分账户移除或隐藏自动转发功能
* 因反垃圾/安全原因进行限制
* 仅对以下账户显示：

  * 老账户
  * 特定地区用户
  * 桌面完整版界面用户

👉 因此若**滚动后仍找不到该选项**，则说明：

👉 **你的账户很可能未开通此功能**

# ✅ 最佳替代方案（实际有效的方法）

改用Gmail收取邮件：

## 使用Gmail POP3收取功能

既然你已开启：

> POP3/IMAP/SMTP ✔

可执行以下操作：

### 在Gmail中：

1. 设置
2. 账户和导入
3. 添加邮件账户
4. 使用以下配置：

   * 服务器：`pop.qq.com`
   * 端口：995
   * SSL：是
   * 密码：QQ邮箱授权码

👉 效果：

* Gmail自动收取QQ邮件
* 非实时同步，但100%有效
