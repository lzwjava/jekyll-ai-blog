您的 MacBook Air M2 在点击 **Continue** 后卡在“Software Update Complete”屏幕（无进一步响应、出现转轮或进度条停滞），是 macOS Tahoe (macOS 15) 安装期间或更新后启动时较为常见的报告问题，尤其是在您使用的 Apple Silicon 机器上。这通常与最终设置阶段挂起、第三方软件冲突、磁盘问题或安装后进程中的某个故障有关。

不用担心——您的数据通常是安全的，而且这个问题通常无需完全擦除即可修复。以下是根据类似情况下大多数用户的成功经验制定的分步故障排除指南：

### 1. 强制重启并重试
- 按住 **电源按钮** (Touch ID 键) 约 10 秒钟，直到 Mac 完全关机（屏幕变黑，无风扇/灯光）。
- 等待 10–30 秒，然后按一次电源按钮重新启动。
- 它可能会直接回到同一个“Software Update Complete”屏幕——再次尝试点击 **Continue**。
- 如果再次循环或挂起，请重复强制关机 2–3 次。有时它需要多次尝试来“解冻”更新后的设置。

许多用户报告说，在几次强制重启后，系统会进入桌面或完成任何待处理的设置。

### 2. 进入 Safe Mode (安全模式)
这将加载具有最少扩展/驱动程序的 macOS，通常可以绕过导致挂起的任何因素（例如，不兼容的登录项、Kernel Extensions 或后台进程）。

对于您的 M2 MacBook Air：
- 完全关闭 Mac（如有必要，按住电源按钮）。
- 按住 **电源按钮** 直到看到启动选项窗口（显示您的启动磁盘/卷）。
- 选择您的启动磁盘（通常是 "Macintosh HD"）。
- 按住 **Shift** 键，然后点击 **Continue in Safe Mode**。
- 开始启动后释放 Shift 键。
- 如果弹出提示，请登录（第一次启动可能需要较长时间）。
- 如果在 Safe Mode 中进入了桌面：
  - 让它静置几分钟——它可能会完成任何待处理的更新任务。
  - 从 Apple 菜单中正常重启（不按 Shift 键）。
- 如果在 Safe Mode 启动后仍然挂起，请继续下一步。

### 3. 重置 NVRAM (非易失性随机存取存储器)
这会清除可能干扰启动/更新过程的临时设置。
- 关闭 Mac。
- 按下电源按钮，然后立即按住 **Option + Command + P + R**。
- 按住约 20 秒（直到您听到两次启动铃声，或者在 M 系列 Mac 上看到 Apple Logo 出现并消失两次）。
- 释放按键并让它正常启动。

### 4. 进入 Recovery Mode 并运行 Disk Utility
如果上述方法都不起作用：
- 关机。
- 按住 **电源按钮** 直到启动选项出现。
- 点击 **Options** > **Continue** 进入 macOS Recovery。
- 如果有提示，选择您的用户/语言。
- 在实用工具窗口中：
  - 选择 **Disk Utility** > **Continue**。
  - 在侧边栏选择您的主驱动器（通常是 "Apple SSD" 或 "Macintosh HD"——如果需要，点击 **View > Show All Devices**）。
  - 点击 **First Aid** > **Run**（如果显示错误，则修复磁盘和容器）。
  - 完成后退出 Disk Utility。
- 回到 Recovery，您还可以尝试 **Reinstall macOS**（如果可用请选择 Tahoe——这会重新安装 OS 而不擦除您的数据/应用程序）。
- 如果重新安装再次挂起，请先退出并尝试正常重启。

### 其他提示
- 确保已连接电源（插上充电器）和稳定的 Wi-Fi 网络——某些更新后的步骤需要互联网来完成最终确认。
- 在尝试上述步骤前，断开所有外部设备（USB 驱动器、集线器、显示器）——它们有时会导致冲突。
- 如果您有最近的 Time Machine 备份（或者可以通过另一台 Mac 访问），那是非常好的保障，但大多数人在这里并不需要从备份恢复。
- 如果尝试多次后仍无法跳过该屏幕（例如，卡在循环中数小时/数天），则可能需要从 Recovery 进行全新安装（这会擦除数据——如果可能，请先通过 Target Disk Mode 备份到另一台 Mac）或联系 Apple Support/硬件检查。
