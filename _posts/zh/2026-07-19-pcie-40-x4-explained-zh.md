问题：主板上的 PCIe 4.0 x4 是什么意思？“x4” 是指四个 PCIe 4.0 接口吗？

答案：

不是。**“x4” 并不代表四个 PCIe 接口**，它表示**四条 PCIe 通道**。

PCIe 命名包含两部分：

```
PCIe 4.0 x4
│       │
│       └── 通道数量
└────────── 代际/速度
```

* **PCIe 4.0** = 第四代，每条通道约 **2 GB/s（单向）**
* **x4** = 设备使用 **4 条通道**

因此：

```
PCIe 4.0 x4
= 4 条 PCIe 4.0 通道
= 各方向约 8 GB/s 带宽
```

物理 PCIe 插槽可以有不同的通道规格：

```
物理插槽规格：

[x1]       一条通道
[x4]       四条通道
[x8]       八条通道
[x16]      十六条通道
```

主板上可能看起来像这样：

```
CPU PCIe 通道：

PCIe x16 插槽
====================  GPU
████████████████

PCIe x4 插槽
========          NVMe 转接卡 / 网卡

M.2 插槽
========          NVMe SSD（PCIe 4.0 x4）
```

关键点在于：

**接口物理尺寸与电气通道数是不同的。**

示例：

一个长的 GPU 插槽：

```
PCIe x16 物理插槽
████████████████████
```

实际可能运行在以下模式：

```
PCIe 4.0 x16
或
PCIe 4.0 x8
或
PCIe 4.0 x4
```

取决于主板的布线方式。

---

对于 M.2 SSD，你常会看到：

```
M.2 NVMe：
PCIe 4.0 x4
```

这意味着：

* SSD 通过 PCIe 第四代连接
* SSD 获得 4 条通道
* 并非四个独立的连接器

典型速度：

```
PCIe 4.0 x1  ≈ 2 GB/s
PCIe 4.0 x4  ≈ 8 GB/s

三星 990 Pro：
约 7.4 GB/s
```

---

针对你的 GPU 使用场景（多块 RTX 3090/4070）：

主板规格可能这样写：

```
2 × PCIe x16 插槽

插槽 1：
PCIe 5.0 x16

插槽 2：
PCIe 4.0 x4
```

它表示：

```
GPU #1：
16 条通道

GPU #2：
只有 4 条通道
```

第二块 GPU 可以工作，但带宽会低很多。

对于 AI 推理/训练，这一点很重要：

* 跨 GPU 拆分模型的 LLM 推理 → PCIe 带宽重要
* 每块 GPU 独立运行任务 → 不太重要
* NVLink（仅 3090）可以绕过部分 PCIe 限制

对于双 RTX 3090，理想情况下应寻找：

```
PCIe x16 插槽 1：x16
PCIe x16 插槽 2：x16 或 x8
```

而不是：

```
x16 + x4
```

因为第二块 3090 会受带宽限制。
