### 为什么你之前找不到“无线信号页面”？

- 你之前使用的路由器可能是国际版（Archer AX3000、AX55 或类似型号），这些型号**没有无线中继或 WDS 选项** —— 仅支持 OneMesh（需要兼容设备）。
- XDR3050 EasyMesh 版是**中国特供型号**（TL-XDR 系列）。其 firmware 包含 **EasyMesh** 功能，无线中继是通过 **EasyMesh 一键设置**完成的，而不是传统的 WDS 扫描页面。
- 在管理页面（tplinkwifi.net 或 192.168.0.1）中，**没有独立的“无线中继”或“扫描信号”按钮**；一切都在统一的 **EasyMesh** 功能下进行管理。

### 如何使用 XDR3050 EasyMesh 版进行无线中继（包括二次中继）

EasyMesh 支持**无线 + 有线混合组网**，最多可连接 8 台设备（官方支持 multi-hop 多级跳跃，但实际操作中建议限制在 3-4 跳以内，以避免严重的速率损失）。完全支持二次中继（两级级联）：主路由器 → 子路由 1 → 子路由 2。

#### 操作步骤（推荐最简单的“一键设置”方法）

1.  **准备工作**：
    - 所有路由器必须是 **TP-Link EasyMesh** 版型号（如带有“EasyMesh”标签的 XDR3010/3020/3030/3040/3050/3060 系列）。
    - 将一台路由器设置为**主路由器**（连接到 modem/宽带，并正确配置 Wi-Fi 名称、密码和上网账号）。
    - 将要作为中继器的 XDR3050 恢复出厂设置（按住 RESET 键 10 秒，就像你之前做的那样）。

2.  **一键配对（无线 Mesh 中继）**：
    - 将主路由器和子路由器（XDR3050）放置在信号覆盖良好的位置（起初不要放得太远；配对成功后再移动）。
    - 开启两台路由器的电源。
    - 在**任一路由器**上，按住 **EasyMesh 按钮**（通常在背面，标有“EasyMesh”或 Mesh 图标，按下 1-3 秒）。
    - 指示灯将闪烁（红灯/橙灯闪烁表示正在搜索/连接）。
    - 另一台路由器会自动响应；灯光闪烁 → 逐渐变为常亮或蓝色/绿色（表示成功）。
    - 整个过程耗时 10-60 秒，无需登录管理页面。
    - 成功后：子路由器会自动同步主路由器的 Wi-Fi 名称、密码和设置，实现 **seamless roaming**（单一 SSID，设备自动切换）。

3.  **进行第二次中继（两级级联）**：
    - 对第二个子路由器（另一个 EasyMesh 型号）重复上述步骤。
    - 将其放置在第一个子路由器信号良好的位置。
    - 按下 EasyMesh 按钮进行配对；它将自动加入**整个 Mesh 网络**（优先连接到最近/最强的节点）。
    - 支持 **multi-hop**：主路由 → 子路由 1（无线）→ 子路由 2（无线），或者主路由 → 子路由 1（有线）→ 子路由 2（无线）以获得更好性能。

4.  **如果一键配对失败，请使用 App 或 Web 界面**：
    - 下载 **TP-Link Wi-Fi App**（或“普联路由器”小程序）。
    - 登录主路由器账号 → 添加设备 → 选择“EasyMesh 组网”或“Mesh 扩展”。
    - 按照提示按下 EasyMesh 按钮或扫描二维码。
    - Web 界面：登录主路由器 → 高级设置 → EasyMesh（或 Mesh 设置）→ 添加子节点。

#### 性能注意事项

- **无线中继**：速度会明显下降（特别是在多级跳跃时）。第一跳通常保留 50-70% 的速度，第二跳保留 30-50%（取决于距离和墙壁情况）。
- **推荐方案**：从主路由器到子路由 1 使用网线连接，然后从子路由 1 到子路由 2 使用无线连接（混合组网稳定性最佳）。
- EasyMesh 支持 **multi-band backhaul**（2.4 GHz + 5 GHz 链路），性能优于旧的 WDS，且穿墙能力更强。
- 如果设置后出现掉线或速度慢的情况：检查 firmware 更新（从官网下载最新的 TL-XDR3050 版本），或将子路由器移近一些进行测试。
