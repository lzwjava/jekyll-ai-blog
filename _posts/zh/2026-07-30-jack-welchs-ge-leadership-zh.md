## 1. 从一个简单规则开始：“数一数二”

韦尔奇认为，通用电气的每个业务单元都应做到：

* 在其市场中排名第一或第二
* 或者有可信的计划成为第一或第二
* 否则就出售、关闭或重组

示例：

他上任时，通用电气有数百项业务。他对其进行了积极评估：

```
业务单元
      |
      v
是否第一/第二？
      |
  +---+---+
 是      否
 |        |
投资    整改或出售
```

这创造了著名的“整改、出售或关闭”文化。

## 2. “无边界组织”

在韦尔奇之前，大公司往往存在部门壁垒：

```
工程部
     |
     X
制造部
     |
     X
销售部
```

各部门保护信息。

韦尔奇推动：

```
工程部 <--> 制造部 <--> 客户
```

想法应该在公司内部流动。

他借鉴了丰田汽车公司等企业的做法，尤其是持续改进。

## 3. 积极对员工进行排名和奖励

他最著名的体系之一：

### 通用电气“活力曲线”

员工大致分为：

```
前20%
-------------
重奖

中间70%
-------------
培养

后10%
-------------
淘汰
```

他的论点：

* 伟大的公司需要伟大的人才
* 保留表现不佳的员工会损害所有人

批评者认为这造成了过度的内部竞争。

---

## 4. 将通用电气打造成学习型组织

韦尔奇创建了克劳顿维尔，通用电气著名的管理培训中心。

高管们被期望既教学又学习。

他的理念：

首席执行官的工作不仅是制定战略。

而是：

```
CEO
 |
 +-- 配置资本
 |
 +-- 培养领导者
 |
 +-- 创造文化
 |
 +-- 更快决策
```

## 5. 从制造业转向服务业和金融业

韦尔奇上任时：

```
旧通用电气：
机器
涡轮机
家电
工厂
```

他将其转型：

```
新通用电气：
工业技术
+
金融服务（GE Capital）
+
医疗保健
+
媒体（NBC）
```

GE Capital 成为巨大的利润引擎。

在其鼎盛时期，GE Capital 贡献了通用电气相当大一部分利润。

这后来受到批评，因为金融业务增加了风险。

## 6. 六西格玛质量革命

韦尔奇在20世纪90年代采纳了六西格玛。

理念：

通过测量减少缺陷。

工程视角：

```
流程
  |
测量变异
  |
找到根本原因
  |
改进
  |
重复
```

通用电气培训了数千名“黑带”。

## 8. 人们为何钦佩他

支持者认为韦尔奇：

* 大幅提升了通用电气的市场价值
* 创造了强大的执行文化
* 培养了许多未来的首席执行官（“通用电气校友帮”）
* 使管理更加数据驱动

许多首席执行官研究过他：

* 杰夫·贝佐斯
* 史蒂夫·乔布斯（理念不同，但也痴迷于聚焦）
* 许多财富500强领导者

---

## 9. 人们为何批评他

后来的分析指出：

### 短期财务压力

“股东价值”时代推动了：

* 削减成本
* 裁员
* 金融工程

### GE Capital 风险

韦尔奇离开后，通用电气在2008年金融危机中严重受挫。

### 排名与淘汰问题

强制排名可能：

* 破坏协作
* 让人们优化政治行为

## 更深层的教训

韦尔奇的核心思想是：

> 首席执行官的主要产品不是公司的产品。首席执行官的主要产品是组织本身。

他将通用电气视为一台巨大的机器：

```
战略
   +
人才
   +
文化
   +
资本配置
   =
公司业绩
```

对于当今的人工智能公司，其等价物是：

```
CEO
 |
 +-- 选择正确的模型赌注
 |
 +-- 招聘精英研究员/工程师
 |
 +-- 建立快速实验循环
 |
 +-- 尽早淘汰薄弱项目
 |
 +-- 积累组织学习
```

这就是为什么尽管韦尔奇时代的一些做法存在争议，但《赢》仍然被许多创始人阅读的原因。
