问题：**对于 B150M + i5-6500 GPU 测试平台，应该买哪款 8GB DDR4：影驰 GAMER II 2666 还是金士顿 2133？**

答案：**如果价格相近，我会选金士顿 8GB DDR4-2133。**

|                  | 影驰 GAMER II              | 金士顿                              |
| ---------------- | -------------------------- | ----------------------------------- |
| 容量             | 8GB                        | 8GB                                 |
| 速度             | 2666 → 在 B150 上降为 **2133** | **原生 2133**                      |
| 电压             | 可能是 1.2V                | **1.2V**                            |
| 桌面 DIMM        | ✅                          | ✅                                   |
| 你的 B150M 主板  | ✅                          | ✅                                   |
| RGB 灯效         | ✅                          | ❌                                   |
| 品牌/口碑        | 不错                       | **更可靠，无趣但稳定**              |
| 成色             | 二手                       | 二手                                |
| GPU 测试平台     | 👍                          | **⭐**                               |

### 为什么金士顿胜出

你的 B150 + i5-6500 无法发挥 2666 频率的优势：

```text
影驰 DDR4-2666
       ↓
B150 + i5-6500
       ↓
DDR4-2133
```

所以你是在为用不上的速度买单。

对于 **GPU 诊断机**，我其实更倾向于那个“无趣”的选择：

```text
金士顿 8GB
DDR4-2133
1.2V
单条
       ↓
B150M + i5-6500
       ↓
稳定的测试平台
```

不需要 RGB、高频率或游戏内存。

### 一个注意事项

金士顿的列表中没有给出 **具体型号**。这一点值得确认。如果卖家能发一张标签照片，我可以判断它是否是普通的 **8GB 1Rx8 / 2Rx8 桌面 UDIMM**，并确认具体的 IC/型号。

**结论：** 如果金士顿价格在 **¥40–60** 左右，我会买它。如果影驰便宜很多，影驰也完全没问题。**对于这台工作站，8GB 容量更重要；2133 和 2666 基本没区别。**
