## 🛠 如何修复：BIOS 逐步指南

### 1. 进入 BIOS

- 重启电脑
- 当 MSI 标志出现时，立即反复按 **Del**（删除）键
- 如果 Del 键无效，可按 **F2** 键

### 2. 将 AIO_PUMP 设置为 100% 固定速度

```
- 按 F7 切换到高级模式（如果你在简易模式中）
- 进入：硬件监控（或：设置 → 硬件监控）
- 找到：PUMP_FAN（或 AIO_PUMP 接口条目）
- 设置为：DC 模式（非 PWM）
- 设置温度源：CPU
- 将风扇曲线设置为一条平直线：
    将所有点拖动到 100%
    或手动设置：
        0°C → 100%
        100°C → 100%
  这样即可将水泵始终锁定在全速运行。
```

**原因：** Thermalright Frozen Prism 240 水泵应以恒定速度运行。水泵速度变化会导致水流变化 → 温度波动 → 风扇转速提高而产生噪音。

### 3. 设置 CPU_FAN 自定义曲线

```
- 保持在：硬件监控
- 找到：CPU_FAN（或 FAN1）
- 设置为：PWM 模式（非 DC）
- 温度源：CPU
- 选择：“自定义”或“用户”曲线（非默认的“智能风扇”）

  设置以下点：
       ┌──────────┬──────────┐
       │ 温度 (°C) │ 占空比 (%) │
       ├──────────┼──────────┤
       │    30    │    30    │
       │    50    │    50    │
       │    70    │    75    │
       │    85    │    100   │
       └──────────┴──────────┘

  在 MSI 主板上，通常操作步骤为：
    - 选择图表上的一个点
    - 按 +/- 键或输入数值
    - 移动到下一个点
```

**此曲线为何重要：**

| 当前（空闲） | 修复后 |
|---|---|
| 31% PWM → **1546 RPM** | 在30°C时30% PWM → **~550 RPM** |
| CPU 35°C，风扇噪音大 | CPU 35°C，风扇安静 |

Thermalright 棱镜风扇的 **最低转速较高**（约 1000-1200 RPM 下限）。因此，在 30°C 时设置 30% 占空比，实际转速可能约为 1000-1200 RPM，而非理论上的 550 RPM——但这仍然比 **1546 RPM 安静得多**。

### 4. （可选但推荐）降压 + 功耗限制

```
BIOS 路径：
    超频 → 高级 CPU 配置

设置：
    CPU 轻载模式：模式 5-7（模式 7 是更激进的降压）
    → 这能降低电压 = 热量更少 = 风扇无需高速旋转

    长期功耗限制（PL1）：200W
    短期功耗限制（PL2）：200W
    时间常数（Tau）：56秒或自动
    → 在游戏性能无明显损失的前提下限制最大发热量
```

**预期改善效果：**

| 设置 | Cinebench R23 | 最高温度 | 噪音 |
|---------|----------------|----------|-------|
| 默认（253W） | ~40000分 | 100°C | 吵 |
| CPU 轻载模式7 + 200W限制 | ~37000分 | 80-85°C | 安静 |

### 5. 同时检查你的硬盘

你有一个 **WD20EZBX 1.8TB**（7200 RPM）机械硬盘挂载在 `/mnt/data`。这是一个独立于风扇的 **物理噪音源**。

**快速测试：**
```bash
# 卸载该分区，观察噪音是否消失
sudo umount /mnt/data
sudo hdparm -Y /dev/sda   # 使硬盘停转
# 聆听——如果噪音停止，那就是你的硬盘发出的
```

### 6. 应用并退出

```
按 F10 → 保存更改并重启 → 是
```

重启后，再次运行 `ww linux check-fan` 以验证风扇1的转速是否下降。

### 总结检查清单

| 步骤 | 操作内容 | 预期结果 |
|------|------|-----------------|
| ✅ 1 | AIO_PUMP → 100% DC 固定 | 水流稳定，无水汞转速波动 |
| ✅ 2 | CPU_FAN → 自定义 PWM 曲线 | 风扇1在空闲时从1546降至~1000-1200 RPM |
| ✅ 3 | CPU 轻载模式7 | 更低电压，更低温 |
