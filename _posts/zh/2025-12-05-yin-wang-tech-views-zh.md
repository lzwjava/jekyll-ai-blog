问题：博客 <https://www.yinwang.org> 的作者王垠表达了哪些不受欢迎或有争议的观点？

答案：

王垠（Yin Wang），一位以其在编程语言和静态分析领域的工作而闻名的计算机科学家，是博客“我肯定是在开玩笑”（<https://www.yinwang.org）的作者，他在其中分享了关于技术、教育和社会的逆主流观点。他的文章经常挑战编程和学术领域的主流教条，这使他在中国科技社区赢得了一批追随者，但也因其过于好辩而受到批评。以下是他一些最著名的不受欢迎观点的总结，这些观点来源于他的帖子、Substack> 文章以及关于他作品的讨论。这些观点经常优先考虑函数式编程原则（例如 Scheme/Lisp），而非流行的范式，并驳斥科技趋势中的炒作。

### 主要不受欢迎的观点

- **面向对象编程 (OOP) 被过分吹捧且有害**：王垠认为，由 Java 和 C++ 等语言推广的 OOP 是一种“教条”，它通过继承和类等概念不必要地使代码复杂化。他声称这会导致臃肿、不灵活的系统，并促进糟糕的软件设计。相反，他提倡函数式编程（例如使用 Scheme）更简单、更优雅。这种观点攻击了现代软件工程的基石，经常被批评者戏称为“攻击稻草人”。

- **不存在真正的人类水平计算机视觉**：在 2019 年的一篇文章中，王垠驳斥了人工智能实现类人视觉（例如谷歌或 OpenAI 的系统）的说法，称其为营销炒作。他断言，当前的模型缺乏真正的理解，只是统计模式匹配，远非生物视觉。这种逆主流立场挑战了科技界普遍存在的AI乐观主义。

- **过分强调程序的“正确性”是毫无意义的迂腐**：在 2022 年他的 Substack 文章“论程序的正确性”中，王垠嘲讽了学术界和工业界对形式验证和无 bug 代码的痴迷，称其为颤抖的恐慌。他将其比作以证明者给定理重新命名（例如，“黎曼定理”仍然以黎曼命名，而不是证明者），认为真实世界的软件优先考虑实用性而非完美。这淡化了可靠系统研究的一个主要焦点。

- **现代教育系统未能教授基础知识**：通过他的著作《自底向上学计算机科学》（草稿可在其网站上找到），王垠批评大学计算机科学课程跳过变量、函数和逻辑等基础知识，转而偏爱时髦的工具（例如用 Python 代替 Scheme）。他提倡从第一性原理开始的“自底向上”方法，认为主流教育是教条化的，对培养深度思维无效。

- **Linux 狂热和反微软偏见是不理性的**：在 2000 年代早期像“完全使用 Linux 进行工作”（在中国 Linux 社区引起轰动）这样的帖子中，王垠最初倡导全面采用 Linux，但后来批评了极端的开源纯粹主义。他认为工具的选择应该务实，而不是意识形态化，挑战了 FOSS 社区中“我们vs他们”的心态。

王垠的风格具有挑衅性——他经常使用讽刺和个人轶事，导致反弹（例如，Reddit 帖子称他的论点自命不凡）。他的想法与那些厌倦科技炒作的人产生共鸣，但也疏远了 OOP/AI 爱好者。如需更深入的了解，请浏览他的博客档案或 Substack (<https://yinwang0.substack.com)。>
