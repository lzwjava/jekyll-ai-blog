问题：一个299元/年的社区会员，如何处理不同家长在不同时间加入以及每年续费的问题？

答案：

对于社区来说，**不要使用自然年会员制**。

错误模式：

```
1月1日 - 12月31日
299元/年

家长11月加入：
支付299元
仅获得2个月
```

这感觉不公平。

采用**滚动12个月会员制**。

示例：

```
加入：2026-08-14

支付：
299元

到期：
2027-08-14
```

每位会员都有自己独立的续费日期。

大多数SaaS订阅都是这样运作的。

---

实现方式：

数据库：

```sql
users
-----
id
name


subscriptions
-------------
user_id
start_date
expire_date
status
```

支付成功时：

```python
if user.subscription_expire > now:
    new_expire = old_expire + timedelta(days=365)
else:
    new_expire = now + timedelta(days=365)
```


## 另一种模式：月付 + 年付

更适合测试：

```
免费：
- 阅读内容
- 参加公开活动

299元/年：
- 私密微信群
- 每周AI工作坊
- 项目分享

999元/年：
- 小组指导
- 每月儿童项目回顾
```

---

关键点：

不要先优化支付系统。

首要目标：

```
100位家长
    |
    |
高信任度
    |
    |
家长邀请朋友
```

一个299元/年的社区本质上是一个**信任产品**。

如果家长感觉：

> “这个社区帮助我的孩子成长，而且我认识里面的人。”

那么299元/年非常便宜。

如果感觉是：

> “又一个AI课程广告群。”

那么即使99元/年也很贵。
