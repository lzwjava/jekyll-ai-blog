问题：**申请美国伊利诺伊理工大学硕士项目时，我应该选择哪种签证状态？我只有过期的旅游签证（B1/B2）。**

答案：

对于**伊利诺伊理工大学（Illinois Tech）的硕士项目**，你通常需要**F-1学生签证**。请**不要**选择你旧的旅游签证（B-1/B-2）作为期望的签证状态。伊利诺伊理工大学会为被录取的学位-seeking国际学生签发**I-20**表格，你使用该文件申请**F-1签证**。（[伊利诺伊理工大学][1]）

请这样填写表格：

### 1. "你目前持有美国签证吗？"

选择：

```
无 - 我目前没有持有美国签证
```

因为你的B1/B2签证已于2025年过期，你目前没有有效的美国签证。

### 2. "你期望的签证状态是什么？"

选择：

```
F-1
```

列表中有：

```
F-1
F-2
...
```

选择 **F-1**。

你的情况：

```
国籍：中国
申请：计算机科学硕士 / 人工智能相关硕士
当前美国签证：无
先前美国签证：B1/B2（已过期）
期望状态：F-1
```

旧的旅游签证对学习没有帮助。你不能持B1/B2身份进入美国并就读全日制硕士项目。

流程：


（[伊利诺伊理工大学][1]）

根据你的背景，还有一点需要注意：由于你有丰富的工程经验和AI项目经历，你的F-1签证面试故事应当非常明确：

> "我正在攻读硕士学位，以深化我在AI/ML研究和工程方面的能力。毕业后，我计划将这一专长应用于AI工程/研究领域。"

避免将其表述为"我想移民美国"；F-1是非移民学生签证。
