路由追踪结果如下：

  跳点 1:  192.168.22.1     ← NAT #1：你的家庭路由器
  跳点 2:  172.16.3.252     ← NAT #2：运营商 CGNAT 网关
  跳点 3:  ** *            （隐藏）
  跳点 4:  14.147.195.133   ← 公网骨干
  ...
  跳点 9:  14.29.117.178    ← 接近目标

  172.16.3.252 是一个私有 IP（属于 172.16.0.0/12 范围）。
  这是中国电信的 CGNAT——你的流量在到达公网前会经过
  两层 NAT：

    你 (192.168.22.5)
      → 家庭路由器 (192.168.22.1) [NAT #1]
        → 运营商 CGNAT (172.16.3.252) [NAT #2]
          → 公网 IP [已隐藏]

  为什么中国电信这样做？

- IPv4 地址枯竭——没有足够的公网 IP 分配给所有用户
- 他们通过 CGNAT 让多个用户共享一个公网 IP
- 自 2015 年左右起，这是中国居民宽带的常见做法
