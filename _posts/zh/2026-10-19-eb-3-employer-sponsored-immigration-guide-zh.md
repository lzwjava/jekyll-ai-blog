**问题：** 美国EB-3雇主担保移民途径是什么？它是如何运作的？

---

**回答：**

## 什么是EB-3？

EB-3（第三优先就业类）是美国的一种移民签证类别，为受美国雇主担保的工人提供获得永久居留权的途径。它是涵盖范围最广的雇主担保绿卡类别，包括三个子类别：**技术工人**、**专业人士**和**其他工人**。每种情况都要求雇主担保、具体的工作邀请以及PERM劳工认证。没有自行申请选项。

---

## 三个子类别

| 子类别 | 要求 | 示例 |
| --- | --- | --- |
| **技术工人** | 2年以上培训/经验 | 电工、厨师、IT技术人员 |
| **专业人士** | 美国学士学位 | 会计师、工程师、护士 |
| **其他工人** | 少于2年培训 | 体力劳动者、家政人员、护工 |

所有三个子类别都要求雇主担保和PERM劳工认证。雇主必须证明在担保外国工人之前，没有合格的美国工人可用。

---

## 完整移民流程（分步说明）

### 第一阶段 — 现行工资标准确定（PWD）

雇主向DOL的国家现行工资中心提交现行工资请求。DOL发布裁定，确定雇主必须提供的最低工资。PWD处理目前大约需要**6至10个月**。

### 第二阶段 — 强制性招聘（PERM劳动力市场测试）

在获得PWD后，雇主执行强制性招聘步骤以测试美国劳动力市场，包括向州劳动力机构提交至少30天的职位订单、在周日报纸上刊登两则印刷广告、为期30天的内部职位公告，以及（针对专业职位）至少三项额外的招聘步骤。这一阶段通常需要**2至3个月**。

### 第三阶段 — PERM申请（ETA表格9089）

如果未发现合格的美国工人，雇主向DOL提交PERM申请。DOL进行审核，如果一切合规，则认证PERM。审理在提交后大约需要**6至12个月**。DOL可能会选择申请进行审计，这会增加时间。

### 第四阶段 — I-140申请（由雇主向USCIS提交）

PERM获得认证后，雇主向USCIS提交**I-140表格**（外籍工人移民申请），包括经过认证的PERM、受益人满足职位要求的证据，以及雇主支付能力的证明。可选择加急处理，在**45个工作日**内获得决定。

### 第五阶段 — 等待优先日期（签证公告）

I-140提交后，受益人获得一个**优先日期**——即PERM提交给DOL的日期。这决定了他们在签证号码排队中的位置。在您的优先日期按月度签证公告显示变为当前之前，您不能提交I-485或完成领事处理。

### 第六阶段 — I-485（身份调整）或领事处理

I-140获批且优先日期变为当前后：

- **如果在美国境内：** 提交I-485表格（身份调整）。如果与I-140同时提交，受益人可以在等待期间申请EAD（工作许可）和 Advance Parole。
- **如果在美国境外：** 在美国大使馆或领事馆完成领事处理，然后进入美国，绿卡将邮寄给您。

## 时间线与费用汇总

| 阶段 | 预计时间 |
| --- | --- |
| 现行工资标准确定 | 6–10个月 |
| 招聘活动 | 2–3个月 |
| PERM审理 | 6–12个月 |
| I-140（常规） | 6–12个月 |
| I-140（加急处理） | 45个工作日 |
| I-485身份调整 | 8–14个月 |
| 领事处理 | 4–10个月 |

| 费用 | 金额 |
| --- | --- |
| PERM申请（ETA表格9089） | 无政府费用 |
| PERM招聘费用（雇主支付） | $3,000–$8,000 |
| I-140申请费 | $715 |
| 加急处理（可选） | $2,965 |
| I-485（身份调整） | $1,440 |
| DS-260（领事处理） | $345 |

> 在2026年，许多EB-3案件从初次提交到绿卡签发大约需要**48个月**（4年）。

---

## 重要警告

- **优先日期积压可能非常严重。** 来自印度和中国的申请人面临多年的等待。来自这些国家的其他工人可能需要等待**10年或更久**。
- **您受担保雇主的约束**，直到您的I-485已等待审理满180天，此时AC21可携性适用，允许更换到相同或类似职位。
- **雇主不能将PERM费用转嫁给雇员。** 法律要求雇主支付所有与PERM相关的费用，包括招聘广告和律师费。

## 路线概览图

```
雇主承诺
      ↓
PWD（6–10个月） → 招聘（2–3个月） → PERM申请（6–12个月）
      ↓
向USCIS提交I-140申请
      ↓
分配优先日期 → 等待签证公告中的当前日期
      ↓
I-485（在美国境内）或领事处理（在国外）
      ↓
绿卡签发 → 永久居民（绿卡持有人）
      ↓
（5年后） → 申请美国公民身份
```
