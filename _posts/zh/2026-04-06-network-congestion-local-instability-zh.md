# 如何确认

运行：

```
mtr -rwzc 100 1.1.1.1
```

以及

```
mtr -rwzc 100 8.8.8.8
```

如果两者都显示丢包 → ISP问题
如果只有此主机丢包 → 特定路由拥塞
