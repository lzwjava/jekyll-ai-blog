问题：近年来 native 与跨平台移动开发（Flutter、React Native）的趋势是什么？

回答：

## 近年来移动开发趋势（2019–2026）

---

### 1. 跨平台急剧崛起，侵蚀纯 Native 的份额

总体趋势很明确：跨平台框架在开发者采用率上显著增长，企业越来越偏好“一次构建，到处运行”以降低成本和上市时间。纯 native 开发（Swift/Kotlin）在企业和性能关键型应用中仍占有强势地位，但其在新项目中的份额相对于跨平台解决方案有所下降。

---

### 2. Flutter 已成为主导的跨平台框架

在超过两年的追赶 React Native 后，2020 年 4 月 Flutter 成为全球搜索频率更高的查询，并在 2025 年全球范围内继续保持这一地位。

Stack Overflow 的 2024 开发者调查将 Flutter 评为最常用的跨平台框架，采用率为 46%，而 React Native 为 35%。

GitHub 数据显示，截至 2025 年，Flutter 拥有 170,000 颗星，而 React Native 为 121,000 颗。

---

### 3. 市场份额快照（2024–2025）

根据 2024 Stack Overflow 开发者调查，Flutter 和 React Native 共同占据所有跨平台移动项目 60% 的份额，其中 Flutter 为 32.8%，React Native 为 27.2%。

Statista 的最新研究显示，Flutter 占据跨平台市场份额约 46%，而 React Native 为 35%。

---

### 4. React Native 仍具相关性 — 但正在失势

从 2015 年到约 2020 年，React Native 是跨平台无可争议的王者。此后，它在搜索趋势、GitHub 活动和开发者调查中稳步被 Flutter 超越。然而，尽管 Flutter 的人气持续上升，对 React Native 开发者的强劲需求表明它在市场上仍是热门选择。由于其更长的存在时间和更大的采用率，React Native 可能为开发者提供更多就业机会。

---

### 5. 代理机构越来越多地同时支持两者

43% 的开发团队规模超过 20 人以上的代理机构现在维护同时精通 Flutter 和 React Native 的团队。这种双重能力使这些机构能够根据每个项目的具体需求匹配合适的工具，而不是强迫所有客户采用单一技术路径。

---

### 6. Flutter 正在成熟 — 进入“生产时代”

Google 认为 Flutter 现在已进入生产时代 — 意味着它足够成熟，即使是企业级项目也不再是挑战。Flutter 3.29 于 2025 年 2 月发布，带来了性能优化和小部件改进，进一步巩固了这一成熟度。

---

### 7. Native 开发并未消亡 — 它在演进

虽然跨平台框架有所增长，但 native 也在适应。SwiftUI 和 Jetpack Compose 大幅现代化了 native 开发，缩小了生产力差距。Flutter 在性能和安全要求严格的领域日益被接受，这给纯 native 带来了压力，但对于任务关键型、硬件密集型和企业应用，native 仍占据主导地位。

---

### 总结时间线

| 时期 | 趋势 |
|---|---|
| 2015–2019 | React Native 主导跨平台；native 是默认选择 |
| 2019–2020 | Flutter 快速崛起，在搜索兴趣上超越 React Native |
| 2021–2022 | Flutter 成为最受欢迎的框架；React Native 在就业市场仍领先 |
| 2023–2024 | Flutter 占据 46% 跨平台市场份额；native 采用 SwiftUI/Compose |
| 2025–2026 | Flutter 进入“生产时代”；两种跨平台框架共存；native 仍为企业/性能应用首选 |

总体叙述是：**跨平台已成为新创业公司和 MVP 的默认选择，而 native 仍是性能要求高和企业应用的黄金标准。**
