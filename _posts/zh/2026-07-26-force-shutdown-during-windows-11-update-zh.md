Question: **在“Windows 11 更新正在进行中，请不要关机”时，可以强制关机吗？**

Answer:

从技术上讲，**可以强制关机**，但在 Windows 正在应用更新时**不建议这样做**。

风险取决于更新阶段：

### 1. 如果是在 Windows 内下载或安装

通常较安全：

```
开始菜单 → 关机
```

Windows 通常会正常完成或安全暂停。

### 2. 如果屏幕显示：

```
Windows 更新正在进行中
请不要关机
Working on updates
不要关闭计算机
```

并且百分比在变化（例如 30%、75%、100%），**请勿强制断电**。

Windows 可能正在：

* 替换系统文件
* 更新注册表
* 更新启动组件
* 迁移驱动程序

在此过程中中断可能导致：

* 自动修复循环
* 启动失败
* 更新状态损坏

### 3. 如果长时间卡住

实用经验法则：

* 少于 1 小时：等待
* 1–3 小时：对于大型更新（尤其是 SSD + 慢速 CPU）仍有可能
* 超过 3 小时且**百分比无变化 / 无磁盘活动**：考虑强制关机

强制关机方法：

按住电源按钮：

```
按住电源按钮约 5–10 秒
```

然后重新启动。

Windows 11 通常具有恢复机制：

```
自动修复
→ 疑难解答
→ 高级选项
→ 启动修复
```

针对你的联想小新 14 的情况（你最近重新安装了 Windows 11），我特别建议不要中断安装后的首次更新周期，因为它可能仍在安装芯片组 / VMD / 存储驱动程序。如有可能，请等待。
