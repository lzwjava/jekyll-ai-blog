**问题：** 在 `ww host`（计算端点）的上下文中，“host”的中文名称/翻译是什么？

**回答：**

**主机** (zhǔjī)

就是这个。以下是它完美契合的原因：

- **主** = 主要/首要，**机** = 机器——字面意思是“主要机器”或“计算单元”
- 涵盖全部三种：本地 Mac、工作站、云 VPS——正如“host”所做的那样
- 标准计算机/运维中文：服务器主机、本地主机、云主机——全都自然使用
- **本地主机** (běndì zhǔjī) = `ww host local`
- **工作站主机** (gōngzuò zhàn zhǔjī) = `ww host workstation`
- **云主机** (yún zhǔjī) = `ww host dmit`

备选方案及其不适用原因：

| 中文 | 拼音 | 不适用原因 |
|---|---|---|
| 机器 | jīqì | 过于通用——指任何机器，包括物理硬件 |
| 电脑 | diànnǎo | =“计算机”，概念上排除了 VPS |
| 节点 | jiédian | = 节点，暗示集群成员关系 |
| 服务器 | fúwùqì | = 服务器，暗示在提供某种服务——对本地语义错误 |
| 终端 | zhōngduān | = 终端/端点，面向 UI |

**主机** 正是阿里云、腾讯云和 AWS 中国区对其计算实例使用的术语——这是行业标准名称。`ww host` → `ww 主机`。自然、简短、精准。
