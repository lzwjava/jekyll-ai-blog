问题：**对于优才计划（QMAS），受雇于广州外包公司并参与香港项目，能否算作“具有国际工作经验”？**

答案：**通常不能——并不仅仅因为项目/客户在香港。**

优才计划的官方定义非常明确：

> “申请人原居国家/地区以外的的工作经验。”（[香港入境事务处][1]）

因此，关键区别在于**实际工作地点**，而非客户/项目所在地。

### 你的例子

假设：

* 雇主：广州公司
* 雇佣合同：广州
* 实际工作地点：广州
* 客户/项目：香港数字银行
* 你为香港项目开发后端/API/支付系统

**我不会仅凭此就勾选“国际经验”选项。**

原因何在？从一般商业角度看，你确实具备**国际经验**，但优才计划的评选标准明确要求工作经验必须是在**原居国家/地区以外**获得。（[香港入境事务处][1]）

### 但以下情况则不同

如果你是：

* 受雇于广州外包公司；
* 被派往香港项目；
* **实际在香港工作**一段时间；
* 并能提供香港出入境记录、外派函件、住宿证明、工作记录等证据，

那么这段时间被视为国际经验的可能性就大得多。

雇佣合同由内地公司签订**并不会自动 disqualify 此经历**。关键事实在于，你实际的学位/专家级别工作是在原居国家/地区以外完成的。

### 换个角度理解

| 情况 | 是否具备国际经验？ |
| ---------------------------------------------------------------- | ---------------------------------------------: |
| 广州公司 → 广州工作，客户在香港 | ❌ 很可能否 |
| 广州公司 → 广州工作，参与香港数字银行项目 | ❌ 很可能否 |
| 广州公司 → 实际派驻香港工作 | ✅ 有力证据 |
| 广州公司 → 定期赴港出差参与项目 | 🟡 视时长和证据而定 |
| 香港雇主 → 实际在香港工作 | ✅ 是 |
| 广州公司 → 在广州远程为美国/香港公司工作 | ❌ 不符合优才计划字面定义 |

官方指引异常清晰：第（9）项条件并非简单的“国际客户经验”，而是特指**申请人原居国家/地区以外的学位/专家级别工作经验**。（[香港入境事务处][2]）

因此，在你的优才申请中，我建议将以下两个概念区分开来：

**国际项目/客户经验** ≠ **优才计划认可的国际工作经验**

你参与的香港数字银行项目在申请的其他部分仍有价值——尤其是用于证明你**专家工作的性质和级别**以及潜在的金融/科技经验——但除非你确实在内地之外工作过，否则我不建议将其计入**2年国际经验要求**。
