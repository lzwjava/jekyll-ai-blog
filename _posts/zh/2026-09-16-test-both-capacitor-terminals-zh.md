问题：如果RTX 3060电容在通断模式下显示**蜂鸣**，在200 Ω档位显示**0.1 Ω**，这是否意味着该线路短路了？

答案：**是的，0.1 Ω强烈表明存在短路——但首先排除测量设置本身的问题。**

如果你正在测量：

```text
黑色表笔 → HDMI金属屏蔽壳（GND）
红色表笔 → 5KA51的一侧
```

并且万用表显示：

```text
通断模式：蜂鸣
200 Ω档位：0.1 Ω
```

那么该电容焊盘基本上处于地电位。

### 但有一个关键细节

电容本身可能有一端**直接连接到地**。所以如果`5KA51`是普通的去耦电容：

```text
GPU电源轨 ─────┬──── 电容 ──── GND
                    │
                  5KA51
```

那么：

```text
焊盘A → GND ≈ 0 Ω       ← 正常
焊盘B → GND ≈ 低阻值     ← 可能电源轨短路
```

所以**电容单侧测到0.1 Ω不足以判定短路。**

### 执行此测试

测量`5KA51`**两侧**分别对HDMI屏蔽壳的阻值：

```text
          5KA51
          ┌───┐
焊盘A ────┤   ├──── 焊盘B
          └───┘
            │
           GND
```

记录：

```text
焊盘A → GND = ____ Ω
焊盘B → GND = ____ Ω
```

另外，在GPU**完全断电并断开连接**的情况下，将两个表笔直接短接：

```text
表笔 ↔ 表笔 = 可能约为0.1 Ω
```

如果表笔短接时测得约0.1 Ω，那么**0.1 Ω部分来自表笔/引线的电阻**，因此测得的0.1 Ω实际上可能意味着“基本为零”。

**请把`5KA51`两侧分别对地的两个阻值读数发给我**，最好再附上该电容的近距离照片。这样我们就能判断你看到的到底是不是GPU电源轨短路。
