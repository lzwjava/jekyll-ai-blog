**问题：** 由于内存价格上涨，基础版M4 Mac mini在中国售价现已约为5000元人民币。但苹果使用的是"统一内存"——这也是DRAM吗？

**回答：**

是的——统一内存**就是**DRAM。具体来说，M4使用的是**LPDDR5X**（低功耗双倍数据速率5X），这仅仅是驱动本轮价格周期的三家厂商（三星、SK海力士、美光）生产的DRAM针对移动设备的优化版本。因此苹果完全暴露在供应短缺中。

**"统一内存"的实际含义（及非含义）**

"统一内存"是一个*架构*术语，而非*内存技术*术语。其堆栈如下：

```
存储单元技术：   DRAM（每比特1个晶体管+1个电容）
├── DDR5      → 桌面DIMM
├── LPDDR5X   → Apple M系列、手机      ← 仍是DRAM
├── GDDR7     → 独立GPU               ← 仍是DRAM
└── HBM3E     → AI加速器（MI300X）    ← 仍是DRAM
```

苹果的不同之处在于**封装和寻址**：

1. **封装：** LPDDR5X芯片与SoC位于同一封装基板上（而非焊在主板上，也非插槽式DIMM）。短走线 → 宽总线（基础版M4为128位，约120 GB/s），功耗低。
2. **统一地址空间：** CPU、GPU和神经网络引擎共享一个物理内存池，由单个内存控制器管理。无需通过PCIe在"系统内存"和"显存"之间拷贝——这正是为什么你的16GB M系列Mac可以运行在PC上需要16GB独立GPU才能运行的LLM推理。

但那些封装内部的硅芯片仍是来自相同晶圆厂的通用DRAM单元，出自相同晶圆，且与HBM目前消耗的产能竞争。

**苹果为何遭受重创**

AI数据中心建设将晶圆厂产能转向HBM（由于TSV堆叠，每比特占用约3倍晶圆面积），挤压了LPDDR/DDR的供应。本轮周期的数据：自2025年9月以来，DDR5价格上涨超过300%；2026年第一季度LPDDR4X/LPDDR5X合约价格环比上涨约90%——创有记录以来最大季度涨幅。LPDDR5X正是你M4封装内部所用的内存。

苹果的应对时间线：

- **2026年4月：** 顶配Mac mini/Mac Studio交付时间延长至16–18周；内存配置越高，等待时间越长。
- **2026年5月：** 16GB+256GB基础配置（4499元）从全球苹果商店下架；最便宜的配置变为16GB+512GB，售价5999元。库克承认苹果低估了本地AI工作负载的需求，削减了高内存SKU以保证基础型号供应。
- **2026年6月25日：** 苹果在全球范围内将Mac和iPad价格平均上调约15–25%；Mac mini涨幅最大（香港地区上涨41%，从4599港元涨至6499港元）。

所以你在第三方渠道（京东/拼多多）看到的旧款256GB配置约5000元的价格，实际上相对于苹果目前官方5999元的起步价已经算*便宜*了。在V2EX上，网友们提到春节前其售价为2999元——并指责"代理农场"群体大量购买用于openclaw类工作负载。

**给你的实用建议**

- "内存总会越来越便宜"的经验法则至少在2026年下半年（甚至2027年）之前已经失效——新晶圆厂要到2027年底才能投产，尽管华强北的一些交易商押注2026年下半年会出现崩盘。这是一个真实的不确定性，而非共识。
- 如果你曾考虑将Mac mini作为廉价的常开代理盒子（Claude Code / iclaw runner），套利窗口基本关闭。你那台192.168.1.36上的RTX 4070工作站不受影响——其GDDR6已经买断。
- 同样的力量也在间接推高你的MI300X云服务成本：HBM3需求是这整个周期的*根本原因*。
