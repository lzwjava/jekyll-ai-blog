**问题：** 最高4位为 **1110** 的 D 类 IP 地址用于什么？

**回答：** 最高4位为 **1110** 的 D 类 IP 地址保留用于 **IP 多播（IP Multicasting）**。

- 地址范围为 **224.0.0.0 – 239.255.255.255**。
- 与将数据包发送到单个主机（单播）或所有主机（广播）不同，多播允许将单个数据包同时发送给 **一组感兴趣的接收者**。
- 典型用例包括视频会议、直播、IPTV 以及路由协议更新（例如，OSPF 使用 224.0.0.5）。
- 主机通过 **IGMP（互联网组管理协议）** 加入多播组。

| 类别 | 最高位 | 范围 | 用途 |
| ------- | ------------- | ------- | --------- |
| A | 0 | 0–127 | 单播（大型网络） |
| B | 10 | 128–191 | 单播（中型网络） |
| C | 110 | 192–223 | 单播（小型网络） |
| **D** | **1110** | **224–239** | **多播** |
| E | 1111 | 240–255 | 保留/实验用途 |
