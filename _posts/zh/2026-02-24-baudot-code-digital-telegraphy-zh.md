**Jean-Maurice-Émile Baudot**（1845–1903）是一位法国电报工程师和发明家，他革新了数字通信。他最著名的是发明了 **Baudot code**，第一个真正的数字字符编码，以及开发了一种多路电报系统，允许在单根电线上同时发送多条消息。

---

### 1. **Baudot Code**（数字基础）

在 Baudot 之前，电报主要依赖 Morse code，它使用可变长度的信号（点和划）。Baudot 的突破是创建了 **5-bit binary code**。

* **固定长度：** 每个字符正好是五个 bit 长。
* **二进制特性：** 每个 bit 要么“开”要么“关”（有电流或无电流）。
* **容量：** $2^5 = 32$ 种可能组合。为了处理完整的字母表加上数字和符号，他引入了“Letter”和“Figure” shift 键——这一概念至今仍在现代键盘中使用。

### 2. 多路系统

Baudot 的系统旨在提高效率。使用同步的 **distributor**（一个旋转机械开关），他使最多六个操作员能够共享单条电报线路。

* **同步时序：** 发送和接收机器必须以完全相同的速度旋转。
* **时分复用 (TDM)：** 这是 TDM 的原始版本，是现代光纤和蜂窝通信的基石。

### 3. **Baudot** 键盘

与 Morse 键不同，Baudot 的界面看起来像一个有五个键的钢琴。

* 操作员用左右手按下键的组合。
* 操作员必须保持稳定的节奏，以与旋转的 distributor 保持同步，通常由机器发出的“咔嗒”声提示。

### 4. 遗产与“**Baud**”单位

Baudot 的影响如此根本，以至于他的名字被永载通信速度的 SI 单位：

* **Baud (Bd)：** 该单位测量通信信道中每秒符号变化（事件）的数量。虽然常与“bits per second”混淆，但 Baud 特别表彰他在基于脉冲信号方面的贡献。

| 特性 | Morse Code | Baudot Code |

| **自动化** | 难以自动化 | 适合机器打印 |
| **用途** | 人对人 | 机对机（Telex） |
