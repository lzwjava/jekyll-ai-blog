**问题：** 如果PC主板（如H81主板）通电后，用万用表随意探测是否会损坏主板？哪种万用表模式是安全的？

**回答：** **是的，如果探测不当会损坏主板，但使用万用表正确模式测量电压通常是安全的。** 最大的风险在于探针意外短路相邻的两个针脚/元件。

### 安全规则

| 万用表模式             | 主板通电状态？ | 风险                                                   |
| ---------------------- | -------------- | ------------------------------------------------------ |
| **直流电压 (V⎓)**       | ✅ 是           | 低（操作需谨慎）                                       |
| 电阻 (Ω)               | ❌ 否           | 可能给出错误读数 / 对电路产生潜在压力                   |
| 通断/蜂鸣              | ❌ 最好不       | 原因同上；请勿在通电主板上随意使用                     |
| 二极管模式             | ❌ 否           | 必须断电                                               |
| 电流 (A/mA)            | ❌ **绝对不要**  | **短路风险极高**                                         |

对于通电的H81主板，请按以下方式开始：

**黑色探针 → GND（接地）**
**红色探针 → 要测量的点**
**模式 → 直流电压**

例如，可以测量：

```text
PSU 12V 供电轨 → 约 12 V
PSU 5V 供电轨  → 约 5 V
PSU 3.3V 供电轨 → 约 3.3 V
USB VBUS       → 约 5 V
CPU Vcore      → 通常约 0.7–1.3 V（视状态而定）
内存电压       → DDR3 通常约 1.5 V
```

### 真正的风险：探针滑脱

假设两个小型元件/针脚如下：

```text
      探针
        |
        v
       \|
        *
       | |    <- 相邻针脚
       | |
       | |
```

如果探针桥接了两条供电轨：

```text
+12V  --------*
               \
                *-------- GND
```

就会造成短路。

这比万用表本身危险得多。

### 电阻模式不同

测量电阻时，万用表会向电路注入一个小测试电压/电流：

```text
万用表
  │
  ├── 小测试电流 ──> 主板
  │
  └── 测量产生的电压
```

因此**请勿在通电主板上随意使用Ω/通断模式**。

在进行电阻/通断/二极管测量前，请完全关闭PC，并最好断开PSU与交流电源的连接。

### 一条非常重要的规则

**切勿将红色探针插入电流A插座后，再去探测主板电压。**

正常电压测量时：

```text
COM   → 黑色探针
VΩHz  → 红色探针

模式 → V DC
```

而不是：

```text
COM
A
```

电流输入模式会在电路中形成一个极低电阻的路径。在主板上，这可能导致严重的短路。

如果你打算进入**主板/GPU维修领域**，我建议学习一套标准的探测流程：**GND → 12V/5V/3.3V → 待机供电轨 → 电源时序轨 → 断电状态下对地电阻**。这比随意测量元件有用得多。
