问题：如何将IPv4头部拆分为16位字，用反码加法求和，并计算最终的校验和？

答案：

---

## 逐步示例

我们使用一个**最小的20字节IPv4头部**（无选项）：

```
45 00 00 3c
1a 2b 40 00
40 06 00 00   ← 校验和字段 = 0000（清零）
c0 a8 01 01   ← 源IP：192.168.1.1
c0 a8 01 02   ← 目的IP：192.168.1.2
```

---

## 第1步 — 拆分为16位（2字节）字

从左到右**每次读取2字节**头部：

```
字1：  45 00  →  0x4500
字2：  00 3c  →  0x003c
字3：  1a 2b  →  0x1a2b
字4：  40 00  →  0x4000
字5：  40 06  →  0x4006
字6：  00 00  →  0x0000  ← 校验和（清零）
字7：  c0 a8  →  0xc0a8
字8：  01 01  →  0x0101
字9：  c0 a8  →  0xc0a8
字10： 01 02  →  0x0102
```

---

## 第2步 — 反码加法

普通加法，但如果结果**溢出16位**，将进位回绕并加到低位（“端绕进位”）。

```
  0x4500
+ 0x003c  = 0x453c
+ 0x1a2b  = 0x5f67
+ 0x4000  = 0x9f67
+ 0x4006  = 0xdf6d
+ 0x0000  = 0xdf6d
+ 0xc0a8  = 0xa015  ← 溢出！0x1a015 → 进位=1 → 0xa015+1 = 0xa016
+ 0x0101  = 0xa117
+ 0xc0a8  = 0x61bf  ← 溢出！0x161bf → 进位=1 → 0x61bf+1 = 0x61c0
+ 0x0102  = 0x62c2
```

最终和 = **`0x62c2`**

---

## 第3步 — 对结果取反码

翻转每一位（按位取反）：

```
0x62c2  =  0110 0010 1100 0010
取反      1001 1101 0011 1101
        =  0x9d3d
```

**校验和 = `0x9d3d`** → 插入头部第10–11字节。

---

## 接收端验证

将**所有10个字**（包括实际校验和`0x9d3d`）相加：

```
0x62c2 + 0x9d3d = 0xffff
```

`0xffff`的反码 = `0x0000` → **有效！**
*（某些实现检查：若和 == `0xffff` → 有效）*

---

## 进位回绕规则（关键概念）

```
普通加法：   0xffff + 0x0001 = 0x10000  ← 17位溢出
反码：       保留低16位 → 0x0000
             加上进位（1）→ 0x0001   ✓ 回绕
```

这就是为什么它被称为**端绕进位**——溢出位循环返回。
