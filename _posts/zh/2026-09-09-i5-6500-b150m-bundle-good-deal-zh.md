**问题：i5-6500 + MSI B150M主板套装 200元 划算吗？**

**答案：是的——200元是相当不错的价格**，特别是如果你在组装一个便宜的GPU测试平台。

| 部件         | 详情                |             价值 |
| ------------ | ------------------- | ---------------: |
| CPU          | Intel Core i5-6500  |     约70–100元   |
| 主板         | MSI B150M           |     约100–150元  |
| 合计         | CPU + 主板          | **约170–250元**  |
| 要价         |                     |     **200元**    |

### 为什么我喜欢这个组合

**i5-6500**

* 4核4线程
* 基础频率3.2GHz，睿频最高3.6GHz
* 65W TDP
* LGA1151接口
* 支持DDR4
* 集成Intel核显 → 可用于诊断GPU

**B150M**

* LGA1151接口 → 与i5-6500完全匹配
* 通常支持DDR4
* 配备PCIe x16插槽用于GPU测试
* 廉价且相对简单的平台
* 不支持超频，但对测试平台来说无关紧要

对于你的**GPU维修/测试设置**来说，这实际上比花钱买现代平台更有吸引力。你主要需要：

```text
电源
 │
 ├── B150M
 │    └── i5-6500
 │
 ├── DDR4
 │
 └── PCIe x16
       │
       └── 待测GPU
```

i5-6500的集成显卡特别有用：**移除独立GPU后仍能输出视频**，这使得故障排查更容易。

### 付款前需要检查的一件事

商品描述说：

> 功能正常，无拆无修

这很好，但我建议让卖家演示以下内容：

```text
1. BIOS成功启动
2. CPU-Z显示i5-6500
3. 所有内存插槽正常工作
4. PCIe x16插槽正常工作
5. SATA接口正常工作
6. USB接口正常工作
7. LGA1151针脚无弯曲
```

**最重要：检查CPU插槽针脚。** 损坏的LGA1151插槽可能让这个200元的便宜货变成头痛问题。

如果你能发给我**实际的闲鱼商品照片**，我可以检查B150M型号、插槽、PCIe插槽、VRM区域以及可见损伤。
