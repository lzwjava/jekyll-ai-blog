**DMIT.io 支持 IP 地址更换**，包括洛杉矶 (LAX) 地区服务器，但需遵守特定规则和条件，具体取决于您的计划类型。

---

## ✅ 免费 IP 更换

如果满足以下所有条件，您可以请求**免费** IP 更换：

- 实例必须已购买**至少 7 天**（从第 8 天起符合资格）。
- 自上次 IP 更换请求（包括付费请求）起至少已过去**15 天**。
- 当前 IP 上**ICMP 和所有 TCP 端口被封锁**。
- 服务剩余有效期**至少 7 天**。

---

## 💰 付费 IP 更换 ($5 USD)

如果满足以下条件，您可以请求**付费** IP 更换（每次 $5）：

- 实例已购买**至少 24 小时**（从第二天起符合资格）。
- 自上次 IP 更换请求起至少已过去**24 小时**。
- 服务剩余有效期**至少 3 天**。

---

## ⚠️ 重要限制与注意事项

- IP 地址由系统**随机分配**——您**无法**指定特定 IP 范围或具体 IP 地址。
- 分配的 IP 地址**不保证**特定地区地理信息或特定网站/服务的可用性。
- 一旦发票支付并完成 IP 更换，**IP 地址更换无法撤销或退款**。
- 滥用此功能可能导致**被禁止**使用 IP 更换功能。

---

## 🚫 LAX.sPro 系列例外

**LAX.sPro 系列** 产品的 IP 地址在正常情况下**不允许**更换。但是，如果分配给您的 IP 在任何国家或地区无法访问，您可以在**24 小时** 内请求更换。

此外，**Lite profile** 不包含免费 IP 更换政策，且即使首次分配，也无法保证 IP 与所有国家或地区均有连通性。

---

## 总结表格

| 条件 | 免费更换 | 付费更换 ($5) |
|---|---|---|
| 最低账户年龄 | 7 天 | 24 小时 |
| 更换间冷却时间 | 15 天 | 24 小时 |
| IP 被封 (ICMP + 所有 TCP)？ | 必需 | 不必需 |
| 剩余有效期 | ≥ 7 天 | ≥ 3 天 |
| 可以指定特定 IP？ | ❌ 否 | ❌ 否 |
