## 回答

DS-160 是美国非移民签证申请表。中国公民申请 **B1/B2 旅游/商务签证**、**F1 学生签证**、**J1 等** 必须在预约签证面试前在线完成 DS-160。美国国务院要求回答准确且使用英文（母语字母字段除外）。（[Travel.state.gov][1]）

DS-160 官方网站：

[DS-160 在线申请 (CEAC)](https://ceac.state.gov/genniv/default.aspx?2SN0FWoJ2HjzwiWXwTQ0PQ=%3D&utm_source=chatgpt.com)

---

# 0. 开始前的准备

准备以下材料：

### 必需材料

* 中国护照

  * 护照号码
  * 签发日期
  * 有效期
  * 签发地

* 电子签证照片

  * 近期拍摄
  * 符合美国签证照片要求

* 中国身份证信息

* 当前地址

* 电话号码

* 电子邮箱

---

### 辅助信息

填写 DS-160 可能需要：

* 以往赴美记录（如有）
* 国际旅行记录（通常近5年）
* 教育经历
* 工作经历
* 简历/CV 信息
* 计划中的美国行程

国务院建议准备好护照、旅行计划、过往旅行记录以及工作/教育信息。（[Travel.state.gov][2]）

# 中国申请人常见错误

## 1. 姓名填写错误

护照显示：

```
LI ZHIWEI
```

不要写成：

```
LI ZHI WEI
```

---

## 2. 隐瞒以往签证拒签记录

若问及：

```
您是否曾获得美国签证被拒？
```

回答：

```
YES
```

如实解释。

---

## 3. 旅游签证却描述工作内容

B1/B2 允许：

* 旅游
* 会议
* 研讨会
* 商务洽谈

不允许：

* 在美国工作
* 接受美国雇佣

---

## 4. 信息不一致

DS-160：

```
收入：5000 USD/月
```

面试时：

```
我没有收入
```

会引起问题。

# 针对您的情况（AI 工程师，中国 → 美国短期访问）

如果申请 B1/B2：

合理的描述：

**目的：**

```
商务与旅游
```

可能的商务活动：

```
参加技术会议，
会见潜在商业伙伴，
探索 AI 行业机会。
```

避免说：

```
我会在美国期间为美国客户工作。
```

因为 B1/B2 不允许就业。
