**问题：** B1/B2签证持有人（中国公民或其他国家公民）是否可以通过每半年入境一次，在美国居住10年？

**答案：**

不能。B1/B2签证**不允许**持有人在美居住10年，它仅允许**临时访问**。([美国国务院 - 旅行][1])

混淆源于两个不同概念：

1. **签证有效期**

   * 许多B1/B2签证（包括许多中国公民的签证）有效期为**10年**，并允许多次入境。([CBP帮助中心][2])
   * 这意味着：“你可以在10年期间申请入境美国。”
   * 但**不意味着**：“你可以停留10年。”

2. **每次停留时长**

   * 每次入境由边境的CBP官员决定。
   * 许多B1/B2访客通常被允许停留最多约**6个月**。([CBP帮助中心][3])
   * 示例：

   ```
   2026年1月：入境美国
   2026年7月：离开美国

   2027年1月：再次入境美国
   2027年7月：离开美国
   ```

   从技术上讲，重复访问是可能的。

   但如果某人这样做：

   ```
   美国6个月
   离境1个月
   美国6个月
   离境1个月
   持续数年
   ```

   CBP可能会判定：

   > “此人并非真正访问，而是试图在美国居住。”

   他们可以拒绝入境。CBP特别关注访客是否在境外维持住所，以及旅行目的是否真正临时。([CBP帮助中心][3])

   典型的可接受模式：

   ```
   母国：
     生活、工作、家庭、纳税

   美国：
     2-3个月度假
     探亲
     旅游
   ```

   高风险模式：

   ```
   美国：
     每年10个月

   母国：
     几乎没有生活
   ```

   这看起来像是非正式居住。

   此外：

   * B1/B2持有人不得在美国工作。([美国国务院 - 旅行][1])
   * 不能将其用作绿卡或移民身份的替代品。([美国国务院 - 旅行][1])

   针对中国公民：

   * 常见的B1/B2安排是**10年多次入境签证**，但持有10年B1/B2签证的中国公民在旅行前还需满足EVUS要求。([CBP帮助中心][2])

   因此实际答案：

   **可以：** 一个人可以在10年内多次访问美国。
   **不可以：** 他们不能简单地“通过每6个月离境一次在美国居住10年”。频繁长期停留可能导致被盘问或拒绝入境。
