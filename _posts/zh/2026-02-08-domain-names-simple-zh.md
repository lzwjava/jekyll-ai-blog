你在询问互联网为了配合 IP addresses 而采用的命名机制。

## 答案：**Domain Names（域名）**

### 解释

**IP addresses**（例如 192.168.1.1）是计算机在网络上互相定位所使用的数字标识符。然而，这些数字具有以下缺点：

- 人类难以记忆
- 用户体验不友好
- 难以进行口头传播

为了解决这个问题，Internet 采用了一套名为 **Domain Names** 的并行命名系统。

### Domain Names 的工作原理

**Domain names** 是人类可读的地址，它们映射到 IP addresses。例如：

- Domain name：`www.google.com`
- IP address：`142.251.41.14`（Google 的其中一台服务器）

### 核心组成部分

1. **Domain Name System (DNS)** - 将 domain names 转换为 IP addresses 的基础设施
2. **Hierarchical structure（层级结构）** - 按层级组织，例如 `.com`、`.org`、`.edu` 等
3. **Intuitive naming（直观命名）** - 使用单词而非数字

### 为什么两种系统并存

- **IP addresses** - 计算机和网络进行实际数据 routing（路由）时所必需的
- **Domain names** - 人类为了方便导航和记忆所必需的

这种双重系统使得 Internet 既具备技术上的功能性（通过 IP），又具备用户友好性（通过 domain names）。
