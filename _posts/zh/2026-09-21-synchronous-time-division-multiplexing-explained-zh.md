问题：什么是**同步时分多路复用**？

答案：

**同步时分多路复用（Synchronous Time-Division Multiplexing，简称 Synchronous TDM）**。

其核心理念极为简单：

> **多个数据流通过轮流使用固定的、预先分配的时间片来共享一条物理链路。**

可以这样理解：

```text
A ──┐
B ──┼──> [ 复用器 ] ──> 一条物理链路 ──> [ 解复用器 ] ──> A
C ──┘                                                    ├─> B
                                                         └─> C
```

假设每个输入在每个周期产生 1 字节：

```text
时间：   | t0 | t1 | t2 | t3 | t4 | t5 | ...
         +----+----+----+----+----+----+
信道：   | A  | B  | C  | A  | B  | C  |
         +----+----+----+----+----+----+
```

复用器发送的内容为：

```text
A0 B0 C0 A1 B1 C1 A2 B2 C2 ...
```

接收端事先知道：

```text
时隙 0 → A
时隙 1 → B
时隙 2 → C
```

因此可以完成解复用。

### 为什么称为“同步”？

因为**时间片是固定且同步的**。

即使 B 没有数据要发送：

```text
A0 B0 C0 A1 B1 C1
   ↑
   B 的时间片依然存在
```

B 的时间片只是空置/空闲状态。

这正是它与**统计时分多路复用（Statistical TDM）**的关键区别：

```text
同步时分多路复用：

A B C A B C A B C
| | | | | | | | |
固定时间片


统计时分多路复用：

A C A A C B C
| | | | | | |
动态时间片
```

统计时分多路复用会将时间片分配给当前有数据的节点，因此在流量突发时能更有效地利用带宽。

### 一个具体的电信实例

假设有 4 路语音信道，每路需要 64 kbps：

```text
信道 A：64 kbps
信道 B：64 kbps
信道 C：64 kbps
信道 D：64 kbps
-------------------
             256 kbps
```

使用同步时分多路复用，可以创建如下帧结构：

```text
┌───────┬───────┬───────┬───────┐
│   A   │   B   │   C   │   D   │
└───────┴───────┴───────┴───────┘
    1       2       3       4
```

每一帧中，每个信道都占用一个时间片。

因此，物理链路传输的内容为：

```text
[A][B][C][D] [A][B][C][D] [A][B][C][D] ...
```

接收端无需在每个时间片内读取地址信息。**位置本身即可标识信道**。

这就是同步至关重要的原因：如果接收端丢失帧/时间片的对齐信息，可能会错误地解析：

```text
A B C D
```

为：

```text
B C D A
```

从而导致所有信道的数据都变成乱码。

### 一句话模型

> **同步时分多路复用 = “我为每个数据流在每一帧中保留一个固定位置，无论该数据流是否有数据要发送。”**

这与分组复用有本质区别，后者每个分组都包含足够的信息来确定其去向。
