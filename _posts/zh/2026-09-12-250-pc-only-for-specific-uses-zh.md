问题：这台 **¥250 的二手 PC** 值得买吗？

答案：**¥250 的话，值得——但只适用于非常特定的用途。**

硬件相当古老：

* **Xeon L5640** — 6核12线程，Westmere 架构，约 2010 年产品。适合简单的 Linux/服务器工作，但单核性能非常弱。
* **16 GB 内存** — 对于廉价家用服务器来说其实挺有用。
* **GT 620** — 现在基本没用；别指望它能做 GPU 计算。
* **2×120 GB SSD** — 这是最大的警示信号。卖家明确说第二块 SSD 快坏了。
* **1×100 Mbps + 1×1 Gbps 网卡** — 对于廉价路由器/NAS/实验机来说意外地有用。
* **¥250 含运费** — 价格足够低，这台机器本身几乎可以视为一次性消耗品。

### 我会用它做什么

**适合：**

* Proxmox / Linux 家庭实验室
* 运行小型服务的 Docker
* Git 服务器 / CI runner
* Tailscale / VPN 网关
* DNS、反向代理、监控
* 网络实验
* 轻量级 NAS（**换掉硬盘后**）

**不适合：**

* 现代 Docker 为主的开发
* 大型 Java/Node/Rust/C++ 项目
* 本地 LLM 推理
* GPU 工作负载
* 任何编译时间重要的工作

CPU 的 **单线程性能是真正的问题**，而不是表面上 12 线程。而且我会把两块 SSD 都当成临时/电子垃圾级别的存储。

### 我的结论

**¥250：买，如果你想要一个便宜的实验室/服务器。**

我其实觉得 **1 Gbps 网卡 + 16 GB 内存 + L5640 平台** 本身就已经值 ¥250 了，只要主板和电源是好的。

但目标是 **“便宜且能跑 Docker 和大项目的开发 PC”** 的话，**别买**。多花点钱买更新的二手 Intel 平台（例如 8 代或更新的 Core/i5，或 Ryzen），编译和容器性能会好得多。
