**习近平“四大全球倡议”是什么？**

答：

截至2026年，**四大全球倡议**是习近平在2021至2025年间提出的四项重大外交政策倡议的框架：

| 倡议         | 英文                                | 年份 | 核心问题                                 |
| ------------ | ----------------------------------- | ---: | ---------------------------------------- |
| 全球发展倡议 | Global Development Initiative (GDI)  | 2021 | **世界应该如何发展？**                     |
| 全球安全倡议 | Global Security Initiative (GSI)     | 2022 | **世界如何实现安全？**                     |
| 全球文明倡议 | Global Civilization Initiative (GCI) | 2023 | **不同文明如何共存？**                     |
| 全球治理倡议 | Global Governance Initiative (GGI)   | 2025 | **世界应该如何治理？**                     |

中国官方将其表述为一个相互关联的体系，涵盖**发展→安全→文明→治理**。（[中国外交][1]）

### 1. 全球发展倡议

提出于**2021年**。

基本理念：

> 发展应更加平衡、包容和可持续，尤其对发展中国家而言。

其强调减贫、粮食安全、绿色发展、数字经济以及落实联合国2030年可持续发展议程等。

**核心：经济发展。**

---

### 2. 全球安全倡议

提出于**2022年**。

其核心理念是**“共同、综合、合作、可持续的安全”**。

关键论点是，一国安全不应以损害他国安全为代价。它强调对话、谈判和政治解决冲突，而非集团对抗。

**核心：国际安全与战争/和平。**

---

### 3. 全球文明倡议

提出于**2023年**。

基本理念是：

**不同文明应被视为多样而非划分为“高等”和“低等”。**

其强调：

* 尊重文明多样性
* 全人类共同价值
* 文明间对话
* 互学互鉴
* 反对文明优越论

**核心：文化、价值观与文明。**

这与您之前问到的**“全人类共同价值”**——和平、发展、公平、正义、民主、自由——密切相关。（[中国外交][2]）

---

### 4. 全球治理倡议

这是最新的一项倡议。习近平于**2025年9月**在天津举行的上海合作组织“上海+”会议上提出。（[中国政府网][3]）

其五项原则是：

1.  **主权平等**
2.  **国际法治**
3.  **多边主义**
4.  **以人民为中心**
5.  **切实行动**

既定目标是改革/完善国际治理体系，朝着中国所说的**更加公正合理的全球治理体系**迈进。（[国务院新闻办公室][4]）

**核心：谁制定国际体系的规则，以及这些规则如何制定。**

---

## 有趣之处：它们本质上是一个四层模型

整个体系可以压缩为：

```text
                    人类命运共同体
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
      发展                   安全                  文明
   全球发展倡议             全球安全倡议            全球文明倡议
        │                     │                     │
    繁荣                   和平                  共存
        └─────────────────────┼─────────────────────┘
                              │
                       全球治理倡议
                              │
                       规则 / 秩序
```

或者更简单地说：

**全球发展倡议 = 金钱/发展**
**全球安全倡议 = 安全/和平**
**全球文明倡议 = 文化/价值观**
**全球治理倡议 = 制度/规则**

这就是为什么中国官方描述称其为**系统性框架**，而非四个互不相关的口号。（[中国外交][1]）

### 一个重要区分

请勿将**四大全球倡议**与中国其他重大外交政策概念混淆：

* **“一带一路”倡议** → 基础设施/经济联通
* **人类命运共同体** → 总体愿景
* **全人类共同价值** → 价值观
* **四大全球倡议** → 发展、安全、文明、治理

因此，概念上：

```text
                  愿景
             人类命运共同体
                       │
          ┌────────────┴────────────┐
          │                         │
       价值观                    倡议
    全人类共同价值         ┌──────────┼──────────┐
                         │          │          │
                         GDI        GSI        GCI
                   发展        安全       文明
                                      │
                                     GGI
                                   治理
```

**全球治理倡议尤其重要**，因为它被明确视为补齐此前三项的第四块拼图。（[中国政府网][3]）
