问题：PCIe x16 是否意味着速度是 PCIe x4 的 4 倍？

答案：**是的，在其他条件相同的情况下。** `x16` 表示 16 条 PCIe 通道；`x4` 表示 4 条通道。

可以将通道理解为并行线路：

```text
PCIe x1   = █
PCIe x4   = ████
PCIe x8   = ████████
PCIe x16  = ████████████████
```

因此：

```text
x16 / x4 = 4
```

x16 链路在相同 PCIe 代际下的**理论带宽是 x4 链路的 4 倍**。

例如，大致数据如下：

| 链路 | PCIe 3.0 单方向带宽 |
| ---- | -------------------------------: |
| x1   |                          ~1 GB/s |
| x4   |                          ~4 GB/s |
| x8   |                          ~8 GB/s |
| x16  |                         ~16 GB/s |

但有一个重要区别：**物理插槽尺寸 ≠ 电气链路宽度**。

你的 B350 主板可能具有以下配置：

```text
插槽 1：x16 物理 → x16 电气
插槽 2：x16 物理 → x4 电气
```

因此两个插槽外观相同：

```text
[================]  ← x16 物理
[================]  ← x16 物理
```

但在电气层面：

```text
插槽 1：  ████████████████  x16
插槽 2：  ████              x4
```

对于 GPU 而言，这通常意味着第二个 GPU 获得的 PCIe 带宽要少得多，尽管 **GPU 计算性能不一定慢 4 倍**。一旦模型/数据加载到显存中，PCIe 带宽通常不会成为瓶颈。
