我会为你搜索关于 Vercel 创始人的全面信息。**问题：** Vercel 创始人的全面介绍是什么？

---

## 答案

Vercel 由 Guillermo Rauch 于 2015 年创立，最初名为 ZEIT，并于 2020 年 4 月更名为 Vercel。

### 早年生活和背景

Guillermo Rauch 出生于阿根廷的一个小镇（Lanús，靠近 Buenos Aires），没有完成高中学业，17 岁时前往瑞士工作，18 岁移民到美国，开始作为企业家实现他的想法。他在青少年早期倡导并教人们使用 Linux，后来对 JavaScript 和 Web 开发产生了热情。

### 早期职业生涯和开源贡献

仅仅 13 岁时，当他的同龄人专注于高中时，Rauch 已经在为国际客户构建网站。他 11 岁时在 Buenos Aires 创立了他的第一家公司。

加入 MooTools 核心团队后，他 18 岁时获得了第一份全职前端工程师工作，并搬到加利福尼亚州旧金山。2010 年，18 岁的 Rauch 创立了 Socket.IO，这是一个用于实时 Web 应用、即时消息和实时分析的 JavaScript 事件驱动库。使用 Socket.IO 的知名公司包括 Microsoft Office、Yammer、Trello、Notion 和 Zendesk。

Rauch 还在 2012 年共同编写了 Mongoose Node.js，并为 MongoDB、ODM、Node.js 和 MooTools 做出贡献。

### Cloudup 和 Automattic

2013 年，Rauch 创立了 Cloudup，这是一个基于云的文件共享平台。Automattic（WordPress 背后的公司）于 2013 年以未披露金额收购了 Cloudup。在推出 Vercel 之前，Rauch 和 Kovanen 都在 Automattic 工作。

### Next.js 和 Vercel 的创立

Rauch 此前创建了实时事件驱动通信库 Socket.IO 和 Next.js，后者是 Vercel 为其平台优化的开源框架。Vercel 由 Guillermo Rauch（CEO）、Tony Kovanen（前 CTO）和 Naoyuki Kanezawa 于 2015 年创立。

### Vercel 的增长和当前状态

2021 年 6 月，Vercel 在 C 轮融资中筹集了 1.02 亿美元。2024 年 5 月，Vercel 在一轮融资中筹集了 2.5 亿美元，公司估值达到 32.5 亿美元。2025 年 9 月，Vercel 在 Accel 和 GIC 领投的 F 轮融资中筹集了 3 亿美元，公司估值达到 93 亿美元。这使 Vercel 的总融资额达到 8.63 亿美元。

### AI 和 v0 平台

2023 年，Vercel 发布了 AI Web 开发工具 v0，该工具使用自然语言提示创建 Web 应用；它获得了 2025 年 Webby Award 开发者工具奖。2023 年，Vercel 发布了 AI SDK，这是一个软件开发工具包，旨在允许开发者在 JavaScript 和 TypeScript 中构建对话式流接口。

### 愿景和理念

Rauch 的使命是民主化开发并简化 Web 开发过程。根据 Guillermo Rauch 的说法，公司愿景是成为“一个端到端平台，所有 Web 上的软件开发都从中发生，从想法到生产，再到获取分析以改进下一步，到下一个想法。”他是消除创意 Web 开发障碍的热情倡导者，他的愿景是“Vercel 将前端开发者放在首位，提供全面工具来创建高性能、可全球扩展的网站和应用。”
