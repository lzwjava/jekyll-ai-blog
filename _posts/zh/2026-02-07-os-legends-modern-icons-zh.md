问题：谁是最著名的 Open Source 贡献者？请列出前 30 名。

回答：

并没有一个官方的“前 30 名”最著名 Open Source 贡献者排名，因为名望和影响力取决于多种标准，如历史影响、赋能的贡献者数量、项目的普及程度、Commits 数量、GitHub 上的 Stars 数量或生态系统影响力。

最**著名**的贡献者通常是那些创建了塑造现代计算的基础性 Open Source 项目的人。最近的高活跃贡献者（例如 2025 年在 GitHub 上非常活跃的人）虽然生产力极高，但在开发者圈子之外的知名度往往较低。

以下是整理出的 30 位极具知名度和影响力的 Open Source 贡献者名单（优先考虑历史影响力和认可度，其次是知名的现代 Maintainer）：

1. **Linus Torvalds** — Linux Kernel 和 Git 的创建者。
2. **Richard Stallman** — GNU Project 和 Free Software Foundation 创始人。
3. **Dennis Ritchie** (†) — C 语言和 Unix（Open Source 的基石）的共同创建者。
4. **Ken Thompson** — Unix 和 Go 语言的共同创建者。
5. **Guido van Rossum** — Python 的创建者。
6. **Bjarne Stroustrup** — C++ 的创建者。
7. **Tim Berners-Lee** — World Wide Web (HTML/HTTP) 的发明者。
8. **Larry Wall** — Perl 的创建者。
9. **Yukihiro "Matz" Matsumoto** — Ruby 的创建者。
10. **James Gosling** — Java 的创建者（尽管现在更多偏向企业级）。
11. **Brendan Eich** — JavaScript 的创建者。
12. **Ryan Dahl** — Node.js 和 Deno 的创建者。
13. **Rasmus Lerdorf** — PHP 的创建者。
14. **Brian Kernighan** — C 语言和 Unix 工具的合著者。
15. **Theo de Raadt** — OpenBSD 创始人。
16. **Theo Ts'o** — 资深 Linux Kernel Maintainer (ext4 Filesystem)。
17. **Greg Kroah-Hartman** — Linux Kernel Stable Tree Maintainer。
18. **Sindre Sorhus** — 多产的 npm Package 创建者和 Awesome Lists Maintainer。
19. **Fabian "ryg" Giesen** — 在 Demoscene 和代码优化领域极具影响力。
20. **Evan You** — Vue.js 的创建者。
21. **Dan Abramov** — Redux 共同创建者及 React 贡献者。
22. **Sebastian McKenzie** — Parcel 创建者及 Babel Maintainer。
23. **TJ Holowaychuk** — Express.js 的创建者。
24. **Jake Wharton** — 重要的 Android Open Source 贡献者 (Square, Kotlin)。
25. **Anthony Fu** — VueUse 和现代 JS 生态系统 Maintainer。
26. **Kent C. Dodds** — 教育家及 Remix/Testing Library 贡献者。
27. **Addy Osmani** — Google 工程师，Web Performance 倡导者。
28. **TJ Fontaine** — 前 Node.js 负责人。
29. **Rich Harris** — Svelte 的创建者。
30. **Jason Miller** — Preact 创建者。

这份名单融合了**划时代的传奇人物**（他们创建了整个生态系统）以及维护着极受欢迎项目的**高知名度现代贡献者**。

成千上万的其他开发者也做出了巨大贡献（特别是对 Linux Kernel、Apache、Mozilla 等），但在关于“影响力”和“知名度”的讨论中，这些名字出现得最为频繁。
