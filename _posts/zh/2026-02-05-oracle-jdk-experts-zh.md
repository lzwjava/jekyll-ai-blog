我将搜索有关在 Oracle 工作过的 JDK 博客文章和 OpenJDK 杰出贡献者的信息。让我搜索更多在 Oracle 工作过的知名 JDK 博主和贡献者的具体姓名。根据我的搜索，以下是多年来在 Oracle 工作的一些最杰出的 JDK 博客文章和 OpenJDK 贡献者：

## Key Oracle Java Experts

**Brian Goetz** - Oracle 的 Java Language Architect，以及 JSR-335 (Lambda Expressions) 的规范负责人。他是《Java Concurrency in Practice》一书的作者，并撰写了 75 多篇关于 Java 开发的文章。Brian 深入参与了 Amber、Loom 和 Valhalla 等主要的 Java 项目，并且是 Inside.java 博客文章的常客。

**Mark Reinhold** - Oracle Java Platform Group 的 Chief Architect，在 OpenJDK 社区领导 JDK Project。他自 1996 年起就在 Oracle/Sun 工作，曾是 JDK 1.2、5.0 版本的首席工程师，并担任 Java SE 6、7、8 和 9 的规范负责人。Mark 在提议 Java 每六个月发布一次的周期方面发挥了关键作用。

**José Paumard** - Oracle 的 Java Developer Advocate，曾在 University Sorbonne Paris Nord 担任助理教授 25 年，是 Java Champion Alumni 和 JavaOne Rockstar。他对 dev.java 做出了广泛贡献，在 YouTube 上发布 JEP Café 视频系列，并且是 Inside.java 博客文章的定期贡献者。

**John Rose** - 经常与 Brian Goetz 和 Mark Reinhold 一起被提及为 Java 的维护者之一，特别是负责 Java Virtual Machine 的工作。

**Sharat Chander** - Oracle 的 Java 开发者关系总监，参与 Java Community 已有 15 年，并担任 JavaOne 会议内容主席。

这些专家定期在 **Inside.java**（Oracle 官方关于 Java 团队新闻和观点的博客）上发布文章，并为 OpenJDK 开发、JEP 提案以及更广泛的 Java 生态系统做出贡献。
