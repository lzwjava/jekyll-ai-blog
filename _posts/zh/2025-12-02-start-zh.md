问题：和朋友共同创立一家初创公司时，我应该如何处理股权期权和股权分割？理想的联合创始人人数是多少，以及如何公平地分配股权？

答案：

和朋友共同创立公司很常见，但股权决策是导致朋友创立的初创公司失败的首要原因。从第一天起就将其视为商业决策，而不是像分披萨一样。

### 1. 理想的联合创始人人数

- **对于大多数早期初创公司来说，2-3人是最佳选择**
  - 1人也可能，但会很孤独且风险很高（投资者不喜欢单创始人公司）
  - 4人以上会显著增加复杂性和冲突风险
- 数据（来自Startup Genome、哈佛研究等）：
  - 2人团队的失败率比单创始人低约30%
  - 3人团队的平均表现略好于2人团队
  - 4人以上团队的联合创始人分道扬镳的比例高得多

### 2. 如何公平（而非平等）地分割股权

永远不要默认“因为我们是朋友所以平等分配”。平等分配只有在贡献真正随时间推移而相等时才有效——而这种情况几乎从不发生。

#### 更好的方法（按偏好顺序）

A. **动态 / “Slicing Pie”模型**（最适合尚未盈利的朋友公司）

- 每个人以固定的 hourly rate（例如，100-200美元/小时）跟踪时间、现金投资、设备等
- 股权每月根据实际贡献进行调整
- 当你进行融资或设定固定份额时，它会“冻结”并转换为固定百分比
   → 书籍：Mike Moyer的《Slicing Pie》（强烈推荐）

B. **固定分割，带有4-5年 vesting + cliff**（最常见）
   投资者期望的标准条款：

- 1年 cliff（直到12个月后才开始 vesting，然后你获得25%）
- 接下来3年每月 vesting（总共4年）
- 如果有人提前离开 → 公司以原始价格（通常为0.001美元）回购未归属的股份

C. **基于贡献的初始分割**（使用框架）
   常用工具：

- Foundrs.com（免费股权计算器）
- Gust Founder Equity Split Tool
- Harvard Business Review 框架

   每个创始人评分（0-10）的因素：

- 想法提出者
- CEO / 业务负责人
- 技术负责人 / CTO
- 全职投入
- 先前经验 / 领域专长
- 投资现金
- 机会成本 / 牺牲的薪水
- 风险（例如，辞掉工作）

   示例结果（朋友之间常见）：

- CEO/愿景者：40-50%
- 技术联合创始人：35-45%
- 第三位联合创始人（业务发展/营销）：10-20%

D. **仅在以下情况下进行大致平等的分割：**

- 每个人在同一天辞职
- 每个人都全职工作
- 经验水平相似
- 你为未来招聘留出大量的“股权池”（15-25%）

### 3. 关键的法律和结构性提示

1. 尽早成立 Delaware C-Corp（即使现在只是朋友）——投资者以后会坚持要求这样做
2. 为每个人（无例外，即使是“最好的朋友”）发行带有4年 vesting + 1年 cliff 的股份
3. 在第一位投资者进入之前创建期权池（15-20%）——保护你免受稀释
4. 使用适当的法律文件：
   - 联合创始人协议（角色、知识产权分配、vesting、以及有人离开时的情况）
   - Restricted Stock Purchase Agreements
   - 在30天内提交83(b) election (US)
   → 工具：Clerky、Cooley GO、Orrick 模板，或一家初创公司律师（总费用约3k-7k美元）

### 4. 与朋友合作的危险信号

- “我们彼此信任，不需要文书工作” → 保证未来会是灾难
- 有人想要很大的百分比，但暂时不想辞掉工作
- 投入不平等但股权平等
- 没有 vesting（最常见的杀手）

### 今晚即可使用的快速清单

- [ ] 讨论角色和谁是 CEO
- [ ] 所有人都会全职投入吗？何时？
- [ ] 一起使用 Foundrs.com 或 Slicing Pie 计算器
- [ ] 同意所有人都采用4年 vesting + 1年 cliff
- [ ] 预留15-20%的期权池
- [ ] 聘请一位初创公司律师（物有所值）

大多数朋友关系破裂发生在12-24个月内，那时一个人做了80%的工作却只拥有33%的股份。通过 vesting 和明确的协议提前解决这个问题——你的友谊会因此感谢你。
