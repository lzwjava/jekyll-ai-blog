**问题：相比于学习人类和社会的规则，更倾向于学习数学、计算机科学、自然和物理的规则，这是一种好的策略/哲学吗？**

**回答：**

是的，这可以是一种非常强大的策略，尤其是对于从事技术构建的人来说。但最强版本并非 **“忽略人类和社会”**，而是：

> 首先理解现实世界中深层且稳定的规则。然后以此为基础去理解人类系统。

这里存在一个层次结构：

```
物理学
  ↓
数学
  ↓
计算机科学 / 信息
  ↓
生物学
  ↓
心理学
  ↓
经济学 / 社会 / 组织
```

底层依赖于上层，但上层增加了复杂性。

例如：

* 物理学：物体遵循方程。
* 计算机科学：信息遵循算法。
* 生物学：生物体优化生存与繁衍。
* 人类：思维在情感、文化、激励、历史背景下进行优化。
* 社会：数十亿人类创造出复杂系统。

学习基础规则的优势在于它们更 **稳定**。

像梯度下降、贝叶斯定理、能量守恒或计算复杂性这样的定律，不会因为某个国家改变政策或某家公司改变文化而改变。

这就是为什么许多伟大的工程师和科学家会深入钻研基础：

* 理查德·费曼专注于从第一性原理理解自然。
* Andrej Karpathy 经常通过将 AI 简化为简单的数学机制来解释它。
* 黄仁勋（Jensen Huang）围绕理解计算和硬件趋势构建公司。

然而，这里有一个陷阱。

人类系统也有“定律”，但它们更多是概率性的，而非确定性的。

例如：

物理学：

```
F = ma
```

在相同条件下，你会得到可预测的结果。

人类系统：

```
激励 + 文化 + 信息 + 心理学 → 行为概率
```

不是确定性的。

一个优秀的工程师最终需要兼顾两者：

```
现实模型
    +
人类模型
    =
创造影响力的能力
```

对于一位 AI 创业者来说，这种结合尤为重要：

技术层面：

```
Transformer 架构
GPU 系统
分布式训练
优化
算法
```

人类层面：

```
人们愿意为哪些问题付费
组织如何采纳工具
用户如何改变行为
市场如何运转
```

许多才华横溢的技术人员失败的原因，并非技术薄弱，而是误解了人类。

一个好的哲学或许是：

```
研究自然，以理解什么是真实的。
研究人类，以理解什么是重要的。
```

如果钻研深层基础是你的比较优势，那就把大部分时间花在这上面。但也要保持一个“人类传感器”的活跃状态。阅读历史、传记、心理学、经济学——不是为了成为政治家，而是为了理解你的技术所处的环境。

对于构建 AI 系统的人来说，最优比例大概是：

```
70%  数学 / 计算机科学 / 工程 / 科学
20%  人类心理学 / 经济学 / 历史
10%  时事 / 社会趋势
```

错误不在于选择物理而非社会学。

错误在于认为人类只是噪音。

人类是你试图为之构建的系统的一部分。
