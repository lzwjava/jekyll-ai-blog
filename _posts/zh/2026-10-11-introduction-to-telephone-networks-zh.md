问题：电话网（电话网）简介是什么？

答案：

## 电话网（电话网）——简介

**电话网**（电话网）是一个由基础设施和协议组成的互联系统，支持用户在本地区、全国乃至全球范围内进行语音（和数据）通信。它是世界上最古老、最普及的通信网络之一。

---

### 核心概念

- **交换（Switching）** —— 为通话连接两个终端的机制
- **电路交换（Circuit switching）** —— 为通话全程保留一条专用路径（传统PSTN）
- **分组交换（Packet switching）** —— 语音被分解为数据包并动态路由（VoIP/现代网络）
- **双工（Duplex）** —— 电话通话是**全双工**的（双方可同时说话和收听，与对讲机不同）

---

### 电话网类型

| 类型 | 全称 | 描述 |
| ------ | ------ | ------ |
| **PSTN** | 公共交换电话网 | 传统铜线固定电话网络；即“老式电话系统” |
| **PLMN** | 公共陆地移动网 | 蜂窝/移动网络（2G–5G）的骨干网 |
| **VoIP** | 互联网协议语音 | 通过互联网传输语音（WhatsApp、Skype、Zoom） |
| **ISDN** | 综合业务数字网 | PSTN的早期数字化升级；现已基本淘汰 |
| **PBX** | 专用交换机 | 私有内部电话系统（办公室、酒店） |

---

### 传统通话流程（PSTN）

```
主叫方 → 本地回路 → 中心局（CO） → 中继线路 → 中心局（CO） → 本地回路 → 被叫方
```

1. **本地回路** —— 从用户家庭到最近交换局的“最后一公里”铜线
2. **中心局（CO）** —— 负责本地路由的电话交换局
3. **中继线路** —— 高容量局间链路（光纤、微波、卫星）
4. **电路预留** —— 通话全程端到端预留一条64 Kbps信道

---

### 移动电话网（移动电话网）

现代蜂窝网络是电话网的主要形式：

| 代 | 年代 | 主要特性 |
| ---- | ------ | ---------- |
| **1G** | 1980年代 | 仅模拟语音 |
| **2G（GSM/CDMA）** | 1990年代 | 数字语音、短信、基本数据 |
| **3G（WCDMA/CDMA2000）** | 2000年代 | 移动互联网、视频通话 |
| **4G（LTE）** | 2010年代 | 宽带数据、原生VoIP |
| **5G（NR）** | 2020年代 | 超低延迟、大规模物联网、高带宽 |

蜂窝网络将覆盖区域划分为**小区**，每个小区由**基站（基站）**提供服务。移动时，通话会在小区间无缝切换。

---

### VoIP —— 现代转型

如今大多数“电话”都在某一层是**VoIP**：

- 语音数字化 → 压缩（编解码器如G.711、Opus） → 打包 → 通过IP发送
- 协议：**SIP**（会话发起协议）、**RTP**（实时传输协议）
- 示例：WhatsApp通话、FaceTime、微信语音、企业Teams/Zoom
- 优势：成本更低，与互联网基础设施集成
- 挑战：质量取决于网络条件（延迟、抖动、丢包）

---

### 电话网的关键组件

| 组件 | 作用 |
| ------ | ------ |
| **终端/话机** | 最终用户设备（电话） |
| **本地回路** | 用户到交换局的连接 |
| **交换局/交换机** | 在用户之间路由通话 |
| **中继/骨干网** | 长途高容量链路 |
| **信令系统（SS7）** | PSTN通话建立、路由、计费的协议 |
| **HLR/HSS** | 移动网络用户数据库 |
| **SIM卡** | 在PLMN上标识移动用户 |

---

### 电话网 vs. 对讲机

| 特性 | 电话网 | 对讲机 |
| ------ | -------- | -------- |
| 双工 | 全双工 | 半双工 |
| 基础设施 | 需要网络 | 直接无线电，无基础设施 |
| 范围 | 全球 | 本地（米到数十公里） |
| 成本 | 按次或按月付费 | 一次性硬件 |
| 灾害可靠性 | 依赖基站/电网 | 更抗毁 |

### 监管

- 在香港，电话网由**OFCA**（通讯事务管理局）监管
- 运营商必须持有**统一牌照（UCL）**
- 香港主要运营商：HKT（PCCW）、SmarTone、中国移动香港、3HK
