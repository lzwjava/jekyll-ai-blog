问题：**近年来，湾区就业市场发生了哪些变化，尤其是对科技/人工智能工程师而言？**

回答：

简而言之：**2022年至2024年，湾区科技市场变得艰难得多，但人工智能在2024年至2026年期间催生了一个非常强劲的新招聘周期。** 这不再是过去那种“每位软件工程师都能拿到5个offer”的市场。它正变成一个**高技能、人工智能主导、极度挑剔的市场**。

### 1. 大致时间线

| 时期        | 湾区科技市场                                                                 |
| ----------- | --------------------------------------------------------------------------- |
| **2020–2021** | 🔥 招聘热潮，远程工作，资金充裕                                                |
| **2022**    | 🔥 年初仍强劲，随后美联储收紧政策                                              |
| **2023**    | 🥶 裁员，招聘冻结，回归常态                                                    |
| **2024**    | 🟡 复苏，但更加挑剔                                                          |
| **2025**    | 🟢 人工智能成为主要招聘引擎                                                    |
| **2026**    | 🟢/🔥 人工智能基础设施 + 前沿模型生态系统推动另一轮强劲周期                      |

湾区整体经济在2019年至2021年间失去了超过**28万个工作岗位**，随后在2024年左右恢复至约**410万个工作岗位**。（[Vital Signs][1]）

但有趣的部分在于**复苏发生在哪里**。

---

## 2. 人工智能从根本上改变了湾区市场

这是最大的新闻。

CBRE 2025年的数据显示：

* 湾区人工智能科技人才：**76,079人**
* 较一年前的**61,497人**有所增加
* 大约增长**+24%**
* 湾区人工智能相关职位占科技职位总数的**42%**
* 人工智能职位达到**11,400个**，创下报告发布时的纪录。（[CBRE][2]）

相比之下，美国整体科技市场：

> 2024年美国科技就业仅增长**1.1%**，而2022年增长**7%**。

因此，这并非又一次2021年式的广泛软件招聘热潮。

它更像：

**旧科技招聘 ↓
人工智能招聘 ↑↑↑**

CBRE将湾区评为**北美第一大科技人才市场**。（[CBRE][3]）

## 3. 湾区正变得过度集中于人工智能

这正是湾区与奥斯汀甚至纽约市不同的地方。

该地区拥有大量集中的：

* OpenAI
* Anthropic
* Google DeepMind
* Meta AI
* xAI
* NVIDIA 生态系统
* Scale AI
* Databricks
* Cursor/Anysphere
* Perplexity
* 机器人初创公司
* 人工智能基础设施初创公司
* 前沿模型初创公司
* 人工智能原生应用公司

而且资本集中度极高。

CBRE在2025年的分析报告中指出，自2019年以来，湾区吸引了大约**四分之三的美国人工智能风险投资**。（[CBRE][2]）

因此，湾区不仅仅是人工智能公司存在的地方。

它已经变得类似于：

**资本 → 研究人员 → 工程师 → 创始人 → 模型 → 初创公司 → 资本**

这个反馈循环极其强大。

# 4. 但对于普通软件工程师来说，市场要艰难得多

这个区别很重要。

在2021年：

```text
优秀的计算机科学学位
+ 软件工程实习
+ LeetCode
       ↓
众多机会
```

如今：

```text
普通软件工程师
       ↓
竞争来自
- 美国工程师
- 被裁工程师
- 应届毕业生
- 国际候选人
- 人工智能辅助的工程师
       ↓
艰难
```

而：

```text
强大的系统工程师
+ 机器学习
+ 分布式系统
+ GPU
+ 推理/训练
+ 人工智能代理
       ↓
强得多
```

市场越来越奖励那些**能够真正构建复杂系统的人**，而不是仅仅掌握标准CRUD/后端开发的人。

---

# 5. 人工智能正在提高门槛，而非简单地消除工作岗位

这是一个重要的2026年观察。

尽管有大量关于人工智能摧毁软件工作的预测，但尚未出现大规模人工智能导致的失业证据。Anthropic和经济学家最近讨论的研究发现，**自2022年底以来，高人工智能暴露度劳动者的失业率并未系统性上升**。（[The Guardian][4]）

相反：

```text
以前：

工程师
 ├── 编写代码
 ├── 调试
 ├── 测试
 └── 部署


现在：

工程师
 ├── 使用人工智能
 ├── 设计系统
 ├── 监督代理
 ├── 评估输出
 ├── 调试人工智能生成的代码
 ├── 理解模型
 └── 更快交付
```

因此，公司可以雇用更少的人，**同时期望每个人产出更多**。

这就是为什么市场可以同时存在：

> 更少的职位空缺

和

> 对杰出工程师的极高薪酬。

# 6. 远程工作也发生了巨大变化

这是湾区的另一个重大转变。

2025年6月，湾区科技职位中只有约**10%是远程职位**，低于2022年中期的**24%**。

人工智能公司尤其倾向于要求员工到办公室工作。（[CBRE][5]）

如果你正在考虑搬到那里，这一点实际上很重要。

湾区的竞争优势不仅仅是薪酬。

它是：

```text
OpenAI
Anthropic
Google
Meta
xAI
Cursor
人工智能初创公司
      ↓
同一物理生态系统
      ↓
研究人员 + 工程师 + 创始人 + 投资者
      ↓
信息/网络效应
```

这在远程环境下很难复制。

# 7. 旧金山本身正在复苏

有趣的是，旧金山的表现比2022–2023年的叙事好得多。

2026年6月，旧金山的季节性调整失业率为**4.1%**，该市同比增加了约**14,500个工作岗位**。（[Axios][6]）

也有证据表明，技术生态系统的重心已在一定程度上**向北移至旧金山市区**，而不仅仅是帕洛阿尔托/南湾。

最近的评论指出，OpenAI和Anthropic等公司正在推动这种集中。（[Business Insider][7]）

因此，如今我会这样看待：

```text
旧金山
   ↕
南湾 / 帕洛阿尔托
   ↕
山景城
   ↕
桑尼维尔
   ↕
圣克拉拉 / 圣何塞
```

作为一个巨大的劳动力市场，而非独立的生态系统。


并非实际的就业数字——只是**相对机会方向**。

**2021年：** "科技很热"

→ **2023年：** "科技崩盘"

→ **2025–26年：** "人工智能很热，但只有特定类型的技术人才极度热门。"
