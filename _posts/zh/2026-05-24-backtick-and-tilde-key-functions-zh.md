**问题：** 在典型的 macOS 键盘上，数字 1 旁边的按键是什么——在 Tab 键上方两行，Esc 键下方？

**答案：**

那是 **反引号/波浪号键** — `` ` `` / `~`。

布局示意：

```
[ Esc ]  [ 1 ][ 2 ][ 3 ]...
[  `~  ]  [ Q ][ W ][ E ]...
[ Tab  ]  [ A ][ S ][ D ]...
```

所以 `` ` `` 的位置是：

- **在 `1` 的左边**
- **在 `Tab` 的上方**
- **在 `Esc` 的下方**

---

### 此键上的两个字符

| 按键组合 | 字符 | 名称 |
|-----------|------|------|
| (直接按) | `` ` `` | 反引号 / 重音符号 |
| `Shift` + `` ` `` | `~` | 波浪号 |

---

### 此键的重要性（尤其对您而言）

**1. Shell — `cd` 到家目录的快捷方式**

```bash
cd ~        # ~ 展开为 $HOME
cd ~/projects/lzwjava.github.io
```

**2. Markdown 中的反引号 — 内联代码和代码块**

````
`内联代码`

```python
# 围栏代码块
```
````

**3. Python/JS 模板字面量（JS）**

```js
const msg = `Hello ${name}, tokens used: ${count}`;
```

**4. Vim — 跳转到上次光标位置**

```
``    # 跳回精确位置
`^    # 跳到最后插入位置
`.    # 跳到最后修改处
```

**5. tmux / 终端 — 反引号作为前缀键**
某些 tmux 配置使用 `` ` `` 作为前缀键替代 `Ctrl-b`：

```bash
set -g prefix `
```

**6. Bash — 命令替换（旧式风格）**

```bash
# 旧式风格（反引号）—— 新脚本中避免使用
result=`ls -la`

# 现代推荐风格
result=$(ls -la)
```

**7. macOS — 切换输入源快捷键**
`Ctrl + `` ` `` 有时绑定为循环切换 IME 输入源（如果您在英文/中文输入之间切换，会用到此功能）。
