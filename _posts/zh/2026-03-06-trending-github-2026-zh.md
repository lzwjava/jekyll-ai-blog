问题：过去几个月 GitHub 上哪些项目在流行？

答案：

以下是截至 2026 年 3 月初的 GitHub 热门项目全面概述，按类别分组：

---

## 🤖 AI & LLM Agents（当前最热门类别）

**OpenClaw** — 有史以来增长最快的 GitHub 仓库，仅 60 天内星标从 9,000 飙升至 188,000。它是一个开源的个人 AI 助手，可在您自己的硬件上运行，并连接到 WhatsApp、Telegram、Slack、Discord、Signal、iMessage 和 Microsoft Teams。其 ClawHub 技能注册中心拥有超过 5,700 个社区构建的技能。

**Ollama** — 星标突破 162,000。最简单的方法在本地运行 LLM — 一个命令即可下载并运行任何支持的模型，包括 DeepSeek、Gemma、Qwen 和 Llama。

**Dify** — 星标达到 130,000。一个适合团队的 workflow 构建器，用于需要连接现有工具的 AI 驱动自动化。

**agency-agents** — 一个完整的 AI 代理框架 — 从前端向导到 Reddit 社区代理和现实检查器。每个代理都是具有个性、流程和已验证交付成果的专业专家。

**Shannon Lite** — 一个完全自治的 AI Web 应用和 API 渗透测试器，在无提示、源代码感知的 XBOW 基准变体上达到了 96.15% 的成绩。

**CyberStrikeAI** — 一个用 Go 构建的 AI 原生安全测试平台，集成了 100+ 安全工具、智能编排引擎，以及基于预定义安全角色的角色测试。

---

## 🛠️ Developer Tools & Utilities

**DevToys** — 将数十种必需工具（如 JSON 格式化、编码、正则测试等）集成到一个离线桌面应用中。非常适合经常操作、测试或检查数据的开发者。

**Hoppscotch** — 一个用于 REST、GraphQL 和 WebSocket API 测试的闪电般快速界面 — Postman 的强大开源替代品。

**D2** — 允许您使用简单脚本语言创建清晰、可维护的图表。适用于无需手动拖拽工具即可记录架构或工作流。

**GitInsights** — 将您的工程团队的 GitHub 活动转化为可操作指标，如平均 PR 大小、接单时间和缺陷率，通过 Web 仪表板、电子邮件或 Slack 交付。

---

## ☁️ Infrastructure & Local Development

**Localstack** — 允许您在本地启动完整的 AWS 环境，非常适合快速原型设计和 CI 测试 — 在部署到生产环境前隔离运行 serverless 栈。

**Netdata** — 77,965 星标，积极维护。提供 AI 驱动的全栈可观测性，即使对于精简团队也适用。

**Puppeteer** — 一个 Node.js 库，可程序化控制 Chrome 或 Chromium — 非常适合端到端测试、UI 自动化和数据抓取。

---

## 🧠 AI/ML Research & Frameworks

**Open R1 (Hugging Face)** — 一个雄心勃勃的项目，在开源环境中重现并扩展 DeepSeek-R1 管道，通过使高级推理、数学和编码模型人人可及，来民主化前沿 AI 研究。

**Hugging Face Transformers** — 用于文本、视觉、音频和多模态最先进机器学习模型的模型定义框架 — 支持推理和训练。

## 📊 Big Picture Trends

GitHub 的开发者数量已增长至超过 1.8 亿，总仓库超过 6.3 亿。GitHub Copilot 现在被超过 2,000 万开发者使用，每日 GitHub Actions workflow 数量攀升至超过 500 万。

所有热门仓库的主导主题是 **AI tooling** — 特别是本地 LLM 运行器、AI 代理和代理式编码框架 — 这反映了从纯云 AI 依赖向自托管、注重隐私的替代方案的重大转变。
