当然可以！Windows 远程桌面（RDP）本身支持在远程服务器和本地电脑之间复制文件。以下是主要方法：

## 1. **启用驱动器重定向**（最常用）

连接前，先配置 RDP 客户端以共享本地驱动器：

1. 打开 **远程桌面连接**（`mstsc`）
2. 点击 **显示选项** → **本地资源** 选项卡
3. 在 **本地设备和资源** 下，点击 **详细信息**
4. 展开 **驱动器**，勾选你希望在远程服务器上使用的驱动器（例如 `本地磁盘 (C:)`）
5. 连接到服务器

连接后，你的本地驱动器会出现在远程服务器的 **文件资源管理器** 中，路径如下：
```
此电脑 > 重定向的驱动器和文件夹
```
然后，你就可以像在本地一样，通过拖放的方式在服务器和本地电脑之间复制粘贴文件。

## 2. **复制粘贴（剪贴板）**

RDP 默认也会共享剪贴板。你可以：
- 在远程服务器上 **复制** 文件（`Ctrl+C`）
- 在本地电脑上 **粘贴** 文件（`Ctrl+V`）

这种方法适用于大多数文件类型和大小，但超大文件可能会较慢。

## 3. **通过命令行使用 mstsc /admin 启用驱动器重定向**

你也可以通过 RDP 文件格式（`.rdp`）以编程方式设置驱动器重定向：

```
drive redirect i:drives=C:\
```

## 4. **替代方法：通过映射驱动器使用 Robocopy 或 xcopy**

驱动器重定向后，可以使用命令行工具，例如：
```cmd
robocopy \\tsclient\C\path\to\file C:\local\destination file.txt
```

## 注意事项：
- ✅ 适用于 Windows 10/11 专业版、企业版、服务器版
- ✅ **远程桌面会话主机** 必须允许驱动器重定向（Windows Server 通常默认启用）
- ⚠️ 某些 **企业/IT 管理的服务器** 可能出于安全原因通过组策略禁用了驱动器重定向和剪贴板共享

如果你的服务器 **不允许** 驱动器重定向，则需要使用其他方法，例如：
- `scp` / `rsync`（如果 SSH 可用）
- 共享网络文件夹
- 云存储（OneDrive、Dropbox 等）
