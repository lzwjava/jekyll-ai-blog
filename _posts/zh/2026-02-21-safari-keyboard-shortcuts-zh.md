是的，你说得对：
**Command + [`** 和 **Command + `]** 是 Safari 中用于在页面间**后退**和**前进**的快捷键。

以下是一些其他实用的 Safari 键盘快捷键，可提升你的浏览效率：

---

### **导航快捷键**

| 快捷键                  | 动作                          |
|-------------------------|-------------------------------|
| **Command + [`**        | 后退一页                      |
| **Command + `]**        | 前进一页                      |
| **Command + T**         | 打开新标签页                  |
| **Command + W**         | 关闭当前标签页                |
| **Command + Shift + T** | 重新打开最近关闭的标签页      |
| **Command + L**         | 聚焦到地址栏                  |
| **Command + R**         | 重新加载当前页面              |
| **Command + Shift + R** | 重新加载页面（绕过缓存）      |

---

### **标签页管理**

| 快捷键                  | 动作                          |
|-------------------------|-------------------------------|
| **Command + 1-9**       | 切换到指定标签页              |
| **Command + Option + ←/→** | 切换到上一个/下一个标签页  |
| **Command + Shift + [`**| 转到上一个标签页              |
| **Command + Shift + `]**| 转到下一个标签页              |

---

### **页面交互**

| 快捷键                  | 动作                          |
|-------------------------|-------------------------------|
| **Spacebar**            | 向下滚动页面                  |
| **Shift + Spacebar**    | 向上滚动页面                  |
| **Command + +**         | 放大                          |
| **Command + -**         | 缩小                          |
| **Command + 0**         | 重置缩放级别                  |

---

### **书签与历史记录**

| 快捷键                  | 动作                          |
|-------------------------|-------------------------------|
| **Command + D**         | 将当前页面加入书签            |
| **Command + Option + B**| 显示/隐藏书签侧边栏           |
| **Command + Y**         | 打开历史记录菜单              |
