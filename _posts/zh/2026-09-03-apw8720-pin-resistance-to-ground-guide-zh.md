问题：当**黑表笔接GND**时，在**APW8720**的8个引脚上应该测得什么数值？哪些引脚对地应有电阻？

答案：现在我们可以对**APW8720**给出更精确的答案。数据手册确认它是8引脚单降压PWM控制器。（[Scribd][1]）

### APW8720 — 精确的8引脚排列

对于**SOP-8封装**，从顶部俯视，引脚1位于标记角：

```text
              APW8720
          ┌─────────────┐
 引脚1    │             │   引脚8
 BOOT     │             │   PHASE
 引脚2    │             │   引脚7
 UGATE    │             │   COMP
 引脚3    │             │   引脚6
 GND      │             │   FB
 引脚4    │             │   引脚5
 LGATE    │             │   VCC
          └─────────────┘
```

这是制造商定义的引脚配置。（[Scribd][1]）

### 黑表笔接GND时

假设**黑表笔 → 板子GND**，关键点如下：

| 引脚 | 名称         | 连接对象                              | 对地电阻                                    |
| ----: | ------------ | -------------------------------------- | -------------------------------------------- |
| **1** | BOOT         | 自举电容/栅极驱动电路                  | 通常**不是简单短路**                         |
| **2** | UGATE        | 高端MOSFET栅极                         | 通常**高阻/可变**                            |
| **3** | **GND**      | 地                                     | **~0 Ω**                                     |
| **4** | LGATE/OCSET  | 低端MOSFET栅极 + 电流设定              | 通常**不是0 Ω**                              |
| **5** | VCC          | IC供电                                 | 通常**有一定电阻**，不一定低                  |
| **6** | FB           | 输出电压反馈分压器                     | 通常**可测到一定电阻**                       |
| **7** | COMP         | 补偿网络                               | 通常**可测到一定电阻/电容**                  |
| **8** | PHASE        | MOSFET开关节点                         | **低阻/取决于MOSFET**                        |

数据手册明确指出引脚3是信号/电源地，引脚5是5–12 V供电，引脚6是反馈，引脚2/4驱动高/低端MOSFET，引脚8是PHASE节点。（[Scribd][1]）

### 但这是维修的关键点

**不要把“电阻”简单理解为“这个引脚必须有电阻”或“这个引脚必须显示OL”。**

例如：

```text
引脚6 FB
   │
   ├── 电阻 ── VOUT
   │
   └── 电阻 ── GND
```

因此测量：

```text
黑 → GND
红 → 引脚6
```

会得到一个有限电阻值。

但是：

```text
引脚8 PHASE
   │
   └── MOSFET ── GND
```

也可能测到有限/低电阻，因为你是通过**外部MOSFET电路**测量的，不一定通过APW8720本身。

### 我建议你在Quadro 410上这样测量

**先断电。**

将万用表设置为电阻挡（Ω）。

黑表笔：

```text
黑表笔 → PCB GND
```

然后测量：

```text
红表笔 → 引脚1
红表笔 → 引脚2
红表笔 → 引脚3
红表笔 → 引脚4
红表笔 → 引脚5
红表笔 → 引脚6
红表笔 → 引脚7
红表笔 → 引脚8
```

记录实际数值，例如：

```text
1:  18.2 kΩ
2:  OL
3:  0.2 Ω
4:  12.4 kΩ
5:  2.1 kΩ
6:  4.7 kΩ
7:  8.3 kΩ
8:  1.2 Ω
```

**这些数字比简单地说“有电阻”有用得多。**

另外，在GPU VRM上，**引脚8特别值得关注**，因为PHASE是高/低端MOSFET之间的切换节点。APW8720数据手册明确将其标识为高端返回/低端MOSFET电流检测节点。（[Scribd][1]）

对于**V5F20 5引脚**，我仍然需要PCB或照片才能确定其准确引脚排列。仅凭`V5F20`不足以安全分配引脚1–5。
