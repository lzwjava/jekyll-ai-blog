问题：除了 新衣、混合、丝绸、摇篮柔洗 和 定时 之外，Haier 洗衣机上还有哪些其他模式？

回答：

Haier 洗衣机（特别是亚洲/中国常见的 前开门/滚筒 型号）除了您提到的那些之外，还包括许多额外的专业洗涤程序。确切列表因型号系列而异（例如，crystal drum、智能系列，或特定如 HW 或 XQG 系列），但以下是 Haier 洗衣机上最常见的额外模式：

- **筒清洁 / Drum Clean / 自清洁** — 滚筒和桶的自清洁程序。每月运行一次（空机运行，必要时添加清洁剂）以去除霉菌、细菌和残留物。通常使用高温。

- **羊毛 / Wool** — 专为羊毛毛衣、毯子或含羊毛物品设计。非常温和的动作，低速脱水（通常 ≤800 rpm），冷/温水以防止收缩或毡化。使用羊毛专用洗涤剂。

- **快洗 / Quick Wash / 速洗 / Express 15'** — 短周期（15–45 分钟），适用于轻污衣物或小量衣物。节省时间、水和能源，但清洁不彻底。

- **强力 / Strong / Heavy Duty / 强洗** — 适用于重污物品如工作服、牛仔裤或毛巾的强力程序。更高的搅动、更长的时间、更热的水（高达 60–90°C）和更强的脱水。

- **棉麻 / Cotton** — 纯棉物品（如床单、T恤）的标准程序。清洁与织物护理的良好平衡，通常支持较高温度选项。

- **化纤 / Synthetics** — 适用于合成纤维如聚酯、尼龙混纺。中等搅动以避免起球或拉伸。

- **婴儿 / Baby Care / 婴幼儿** — 额外漂洗和高溫洗涤（通常 60–90°C）以去除洗涤剂残留并杀死细菌。适合婴儿衣物、敏感肌肤。

- **羽绒 / Duvet / Down Jacket** — 适用于蓬松物品如被子、羽绒服、枕头。低速脱水以保护填充物，防止结块。

- **运动服 / Sportswear / 健身服** — 适用于健身服、运动服。去除汗渍/异味，通常低温以保持弹性。

- **牛仔 / Jeans** — 专为牛仔布设计。处理厚重面料，防止褪色，并使用合适的脱水。

- **除菌 / Hygiene / 高温杀菌** — 高温（70–90°C）程序以消毒并杀死细菌/螨虫。适合毛巾、内衣或过敏人群。

- **空气洗 / Steam Refresh / 蒸汽清新** — 无水蒸汽程序，刷新、除臭、减少轻度穿着衣物（如西装、外套）的褶皱。

- **单脱水 / Spin Only** — 仅脱水（无洗涤/漂洗）。手洗后使用。

- **漂洗+脱水 / Rinse + Spin** — 额外漂洗和脱水，如果衣物感觉有肥皂味。

许多型号还具有：
- **预洗 / Pre-wash**（适用于极脏衣物的附加程序）
- **高温洗 / High Temp** 或 **Eco 40-60**（节能标准洗涤）
- **手洗 / Hand Wash / Delicate**（类似于丝绸，但适用于其他易损物品）

### 如何在这些模式中选择
- 日常混合衣物 → 坚持使用 **混合**
- 娇贵/特殊面料 → 使用 **丝绸**、**羊毛**、**摇篮柔洗** 或 **手洗**
- 新衣服 → **新衣**
- 快速需求 → **快洗**
- 重污 → **强力** 或 **棉麻** 加高温
- 注重卫生 → **除菌** 或 **婴儿**
- 机器维护 → **筒清洁**

检查您型号的控制面板或用户手册（按型号号在线搜索）以获取确切的图标/名称，因为有些可能合并或重命名。大多数 Haier 洗衣机允许您在基础程序基础上调整温度、脱水速度和额外功能（如额外漂洗或蒸汽）。
