**问题：** 什么是网络层？

**答案：**

## 概述

**网络层**是OSI模型中的**第3层**。其主要职责是**跨多个网络进行端到端的数据包传输**——它确定从源到目的地的最佳路径，即使它们位于全球不同的网络上。

> 如果说数据链路层是*楼内的本地邮政服务*，那么网络层就是*连接城市和国家的国际快递系统*。

---

## 主要职责

| 功能 | 描述 |
|---|---|
| **逻辑寻址** | 分配IP地址以全局标识主机 |
| **路由** | 选择数据包在网络间传输的最佳路径 |
| **数据包转发** | 逐跳将数据包向目的地移动 |
| **分片** | 必要时将大数据包拆分为更小的数据包 |
| **错误处理** | 报告传送失败（通过ICMP） |

---

## IP地址——核心概念

网络层使用**IP地址**（而非MAC地址）来标识设备：

```
IPv4 示例：   192.168.1.100
                └──┬──┘ └─┬─┘
              网络部分   主机部分

IPv6 示例：   2001:0db8:85a3::8a2e:0370:7334
```

- **IPv4**：32位地址 → 约43亿个地址
- **IPv6**：128位地址 → 3.4 × 10³⁸个地址（几乎无限）

---

## 数据包结构（IPv4）

```
┌─────────┬────────┬──────────┬──────────┬──────────────────────┐
│ 版本    │  TTL   │ 协议     │ 源IP     │   目的IP             │
│ IHL/TOS │        │          │ 4字节    │      4字节           │
├─────────┴────────┴──────────┴──────────┴──────────────────────┤
│                       负载（数据）                            │
└────────────────────────────────────────────────────────────────┘
```

- **TTL（生存时间）**：防止数据包无限循环；每经过一跳递减
- **协议**：指示内部承载的内容（TCP=6，UDP=17，ICMP=1）
- **源/目的IP**：数据包从哪里来，到哪里去

---

## 路由工作原理

数据包**逐跳**经过路由器传输：

```
你的电脑 ──► 路由器A ──► 路由器B ──► 路由器C ──► 网络服务器
（源IP）                                         （目的IP）

每个路由器：
  1. 接收数据包
  2. 在其路由表中查找目的IP
  3. 转发给下一最佳跳
```

### 路由表示例

| 目的网络 | 下一跳 | 接口 |
|---|---|---|
| 192.168.1.0/24 | 直连 | eth0 |
| 10.0.0.0/8 | 172.16.0.1 | eth1 |
| 0.0.0.0/0 | 203.0.113.1 | eth2（默认） |

## 关键协议

| 协议 | 用途 |
|---|---|
| **IP**（v4/v6） | 核心寻址和数据包传送 |
| **ICMP** | 错误消息与诊断（`ping`、`traceroute`） |
| **OSPF** | 内部路由协议（同一网络内） |
| **BGP** | 外部路由协议（ISP/AS之间） |
| **RIP** | 简单的距离矢量路由协议 |
| **NAT** | 私网IP ↔ 公网IP的转换 |

---

## 子网划分（30秒速览）

IP地址通过**子网掩码**分为**网络部分 + 主机部分**：

```
IP地址：       192.168.1.100
子网掩码：     255.255.255.0  （或 /24）

网络部分：     192.168.1.0    ← LAN内所有设备相同
主机部分：            .100     ← 每个设备唯一
```

- `/24` = 256个地址（254个可用）
- `/16` = 65,536个地址
- `/8`  = 16,777,216个地址

---

## 关键设备：路由器

| 特性 | 交换机（第2层） | 路由器（第3层） |
|---|---|---|
| 使用的地址 | MAC地址 | IP地址 |
| 作用范围 | 本地网络 | 网络之间 |
| 决策依据 | 帧 | 数据包 |
| 连接对象 | 同一网络 | 不同网络 |

---

## 所处位置

```
第4层  传输层      ← TCP/UDP 段
─────────────────────────────────────────
第3层  网络层      ← IP 数据包         ← 你在这里
─────────────────────────────────────────
第2层  数据链路层  ← 以太网帧
第1层  物理层      ← 原始比特
```

> **重要关系**：网络层的**数据包**在每一跳被*封装在*数据链路层的**帧**内。帧在每个路由器上都会改变；数据包在端到端传输中保持不变。

---

## 快速总结

```
数据链路层  →  在相邻节点（同一网络）之间传送帧
网络层      →  在任何两个节点（跨网络）之间传送数据包
```
