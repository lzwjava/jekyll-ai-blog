**问题：在深信服运维安全管理系统中，“RDP / RDP Web”是什么意思？**

**回答：**

在深信服运维安全管理系统（Sangfor OSM / 运维安全审计）中，**RDP** 和 **RDP Web** 是指通过远程桌面协议连接 Windows 服务器的两种方式。

### 1. RDP

**RDP = 远程桌面协议（Remote Desktop Protocol）**

这是微软原生的远程桌面协议。

典型流程：

```
你的电脑
  |
  | RDP 客户端 (mstsc.exe)
  |
  | TCP 3389
  |
Windows 服务器
```

示例：

```
mstsc.exe
→ 服务器 IP
→ 用户名/密码
→ Windows 桌面
```

你会获得完整的 Windows GUI 会话。

---

### 2. RDP Web

**RDP Web = 基于浏览器的 RDP 连接**

无需安装 Microsoft 远程桌面客户端：

```
浏览器
   |
HTTPS
   |
深信服网关
   |
RDP 协议
   |
Windows 服务器
```

你打开：

```
https://深信服管理系统/
```

登录 → 选择服务器 → 点击“RDP Web”

深信服系统会启动一个 Web 终端（通常基于 HTML5）并代理 RDP 会话。

优势：

* 无需安装 mstsc
* 在 Linux/macOS 浏览器上也可运行
* 更易于审计
* 深信服可以录制会话

---

### 3. 为什么深信服提供这个选项

普通的 RDP 连接：

```
工程师
   |
   | RDP
   |
服务器
```

存在以下问题：

* 缺乏集中控制
* 难以审计
* 密码共享风险
* 无法轻松记录操作

深信服增加了堡垒机：

```
工程师
        |
        |
        v
+----------------+
| 深信服 OSM    |
| 堡垒机         |
|                |
| 审计           |
| 权限           |
| 录制           |
+----------------+
        |
        |
        v
 Windows 服务器
```

深信服系统可以：

* 认证用户
* 检查权限
* 隐藏真实服务器密码
* 录屏操作
* 记录命令
* 提供审批流程

---

### 4. 区别

| 特性               | RDP                        | RDP Web                              |
| ------------------ | -------------------------- | ------------------------------------ |
| 客户端             | Windows mstsc              | 浏览器                               |
| 协议               | 直接 RDP                   | 通过深信服隧道传输的 RDP             |
| 安装软件           | 是                         | 否                                   |
| 审计               | 取决于配置                 | 内置                                 |
| 会话录制           | 有限                       | 通常支持                             |
| 在 Mac/Linux 上运行 | 较难                       | 容易                                 |

---

### 5. 在企业环境中

通常架构如下：

```
员工笔记本电脑
       |
       |
 HTTPS 443
       |
深信服运维安全管理系统
       |
       |
 RDP 3389
       |
Windows Server 2012 / 2016 / 2022
```

因此，如果你看到：

```
连接类型：
  RDP
  RDP Web
```

请选择：

* **RDP** → 如果你有 Windows 远程桌面客户端且需要更好的性能
* **RDP Web** → 如果你想通过浏览器访问，或者公司要求通过堡垒机审计

对于银行/大型企业环境（如汇丰风格的环境），**通过堡垒机使用 RDP Web 非常常见**，因为每个管理员操作都必须被记录。
