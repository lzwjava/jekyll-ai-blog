## “编译Linux内核”是什么意思？

Linux内核是**操作系统的核心**——它管理硬件（CPU、内存、磁盘、USB、网络）、运行程序并处理安全机制。你刚刚将**源代码**（位于 `/projects/linux` 中的内容）转换成了计算机可以实际运行的**二进制文件**。

## 逐步发生了什么

1. **源代码**（C语言、汇编、头文件——3.0 GB）→ **编译器**（GCC）→ **二进制内核**（15 MB）
2. 二进制文件被复制到 `/boot/vmlinuz-...`
3. 构建了**initramfs**（初始RAM文件系统——启动时所需的驱动程序）→ 30 MB
4. **内核模块**（编译为 `.ko` 文件的驱动程序）被安装到 `/lib/modules/7.2.0-rc1-...`
5. **GRUB**（引导菜单）已更新——你的新内核已经是**默认选项**

## 你能用它做什么？

**重启进入自定义内核。** 下次重启时，GRUB 将自动引导**你的**编译内核，而不是Fedora的默认内核。你将在GRUB菜单中看到：

```
Fedora Linux (7.2.0-rc1-00044-g87320be9f0d2) 44 (Workstation Edition)
```

现在要重启，请运行：

```bash
sudo reboot
```

## 为什么要这样做？

| 目的 | 下一步操作 |
| ------ | ----------- |
| **学习**内核工作原理 | 阅读源码，添加 printk() 调试信息，重新编译 |
| **自定义** | 编辑 `.config` —— 启用/禁用驱动程序，调整性能 |
| **添加功能** | 编写内核模块，修补某个子系统 |
| **测试修复** | 应用补丁，重新编译，重启并验证 |
| **去除臃肿** | 禁用不需要的驱动程序，精简内核 |
| **安全加固** | 启用 CONFIG_DEBUG_*、SELinux 功能、锁定特性 |

你构建的默认 `x86_64_defconfig` 是一个**通用**配置——它几乎可以在任何 x86_64 机器上运行，但包含许多你不需要的驱动程序。你可以裁剪它以获得更快的启动速度和更小的体积。
