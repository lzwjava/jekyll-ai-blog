问题：**晨洲岛 8901S 万用表上的黑色和红色表笔**代表什么？该如何使用？

答案：

基本原理非常简单：

* 🔴 **红色表笔 = 测量 / 正极**
* ⚫ **黑色表笔 = COM / 参考 / 负极**

在万用表上，按如下方式插入：

```text
黑色表笔 → COM
红色表笔 → V / Ω / mA（根据测量对象而定）
```

### 针对你的主板/GPU实验

由于你测量的是**直流电压**，请将万用表拨到**直流电压档**（`V⎓`）。

然后：

```text
          主板
        ┌─────────────────┐
        │                 │
黑色 ──┤ GND             │
        │                 │
红色 ──┤ 测试点          │
        └─────────────────┘

显示：红色表笔相对于黑色表笔的电压
```

例如，如果你这样连接：

```text
黑色 → 主板金属地 / GND
红色 → 12V 供电轨
```

你应该会看到大约：

```text
+12 V
```

如果反过来：

```text
红色 → GND
黑色 → 12V
```

万用表通常会显示：

```text
-12 V
```

负号仅仅表示**你的红色表笔电压低于黑色表笔**。

### 非常重要：电压 vs 电流

对于你目前的操作，**先测量电压**。

电压：

```text
万用表跨接在两个点之间

        ┌─── 电路 ───┐
红色 ───●               ●──── 黑色
        │               │
        └───────────────┘
```

**绝对不要**将万用表置于电流（`A`）档，然后跨接在供电轨和 GND 之间。这相当于通过万用表造成短路，可能损坏主板或万用表。

因此，对于你的联想主板和 GT730：

```text
直流电压测试：

黑色 → GND
红色 → 你想测量的点
```

你可以安全地学习很多东西，例如测量 **5V、12V、3.3V、USB VBUS、PCIe 供电轨**等。
