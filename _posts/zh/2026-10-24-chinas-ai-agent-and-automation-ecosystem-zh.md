**问题：** 中国的 AI agent 和工作流自动化生态系统具体是怎样的——工具、平台、参与者？

**回答：**

中国的市场与全球市场在结构上有所不同。三大超级生态系统占据主导地位，政府是顺风助力，而工具链正日益本土化。以下是完整图景。

---

## 总体概况

中国的企业级 AI agent 解决方案市场预计将从 2024 年的 56 亿元人民币增长到 2029 年的 591 亿元人民币——年复合增长率 60.2%——从概念验证走向商业落地。中国的五年规划明确要求将 AI agent 作为核心基础设施部署到制造业、物流、教育和医疗领域——这意味着政府合同和国企采购是真实存在的渠道，而不仅仅是私营企业。

2026 年下半年的国内 agent 产业正处于从验证走向规模化扩张的关键节点。

## 第一层——基础模型（Agent 的构建基础）

中国拥有强大的本土选择，这一点很重要，因为数据主权和内容合规要求排除了大多数企业客户直接使用 OpenAI/Claude 的可能性。

| 模型 | 公司 | 说明 |
|---|---|---|
| **DeepSeek V3 / R1** | DeepSeek | 开源、最便宜、性价比最高、开发者采用率极高 |
| **Qwen3** | 阿里巴巴 | 强大，原生集成钉钉/阿里云 |
| **ERNIE 4.0** | 百度 | 用户基数最大（2 亿+），千帆企业平台 |
| **Doubao** | 字节跳动 | 驱动 Coze，集成到飞书 |
| **GLM-4** | 智谱 AI（清华） | 在多智能体协同方面表现出色 |
| **Kimi** | 月之暗面 (Moonshot AI) | 长上下文，受开发者欢迎 |

**实操建议：** 如今中国大多数开发者默认选择 **DeepSeek**，因为性价比高，**Qwen** 作为企业钉钉集成的第二选择。

## 第二层——Agent 构建平台

### 🟦 Coze（扣子）——字节跳动
Coze 在国际版以 `coze.com` 运行，中国市场使用 `coze.cn`（相互隔离）。这是一个低门槛的机器人/agent 构建器，提供拖拽式界面、开箱即用的模板，以及 2026 年 4 月推出的"Coze 2.5 Agent World"生态系统。最适合：快速原型、面向客户的机器人、非技术用户。与抖音和飞书深度集成。

### 🟩 Dify——开源
开发者最爱。Dify 在 2026 年持续更新其 RAG 和工作流编辑器，并且可以私有化部署在自己的服务器上——这对于担心数据离开企业环境的企业客户至关重要。支持 DeepSeek、Qwen 以及任何兼容 OpenAI API 的模型。最适合：技术团队、RAG 系统、自定义 agent 工作流。

### 🟧 百度 AgentBuilder——百度生态系统
百度的 AgentBuilder 提供零代码和低代码模式用于 agent 开发和部署，通过百度生态矩阵为开发者提供分发渠道。已服务超过 16 万开发者和 5 万+ 企业，覆盖 100+ 应用场景。最适合：通过百度搜索和文心一言触达百度庞大的用户基础。

### 🟪 QwenWork——阿里巴巴/钉钉
2026 年 8 月，QwenWork 与钉钉直接集成，为销售、接待、营销和合规配备专属 agents。最适合：已使用阿里云和钉钉的企业客户。

## 第三层——RPA + AI（企业自动化的"双手"）

这是传统企业的核心价值所在。这些工具能完成 LLM 无法单独完成的事情：点击按钮、填写表单、操作旧版软件、抓取屏幕。

### 来也科技 (Laiye)——市场领导者
连续六年入选 Gartner 机器人流程自动化魔力象限——是唯一上榜的中国公司。来也科技构建了企业级 agent 平台，通过调用企业级技能完成任务，任何第三方 agent 都可以直接调用来也的技能。客户包括中国移动、南方电网、大型保险公司。这是中国版的 UiPath。

### 影刀 (Yingdao)——对开发者友好的 RPA
在小型企业中很受欢迎，比来也科技更容易上手，在电商自动化（淘宝、京东工作流）方面表现出色。成本更低。

### 实在智能 (Shizai Intelligence)
定位为"全栈 AI + 自动化"，核心技术名为 ISSUT（屏幕语义理解），强调"所见即所得"和零代码开发。通过视觉理解屏幕来绕过 API 集成的需求——对于没有 API 的旧系统非常有用。

### 艺赛旗 (IS-RPA)
深度嵌入金融和财务垂直领域，注重流程挖掘和效率分析。

## 第四层——企业通讯平台（分发渠道）

这是中国独有的现象。你的 agent 必须*生活*在这些平台*里*才能触达员工：

| 平台 | 所属 | 用户 | 说明 |
|---|---|---|---|
| **钉钉 (DingTalk)** | 阿里巴巴 | 7 亿+ | 在企业中占主导地位，尤其是中小企业和制造业 |
| **企业微信 (WeChat Work)** | 腾讯 | 1.8 亿+ | 银行、房地产、零售 |
| **飞书 (Feishu/Lark)** | 字节跳动 | 快速增长 | 科技公司、初创企业 |

如果你构建的 agent 不能与至少其中一个集成，企业客户不会买单。工作流就在聊天应用里。

## 第五层——控制一切的三大生态系统

腾讯的 WorkBuddy、阿里巴巴和字节跳动在 2026 年 6 月合计产生了 6060 万总访问量中的约 5650 万次办公 agent 访问——约占总流量的 93%。竞争正从推出独立产品转向控制 AI 赋能工作的主要入口。

这意味着：
- **字节跳动** → Coze + 豆包 + 飞书
- **阿里巴巴** → Qwen + 钉钉 + 阿里云
- **腾讯** → WorkBuddy + 企业微信 + 腾讯云

作为独立开发者，你不是在与他们竞争——你是在**他们的基础之上构建**。

## 独立工程师的机会窗口

三大巨头拥有平台，但**不拥有垂直行业的解决方案**。机会在于：

- 一家**广东的制造业中小企业**需要自动化处理发票和质检报告——阿里巴巴不会派人去现场配置
- 一家**房地产中介**需要自动化微信线索跟进并与 CRM 对接
- 一家**物流公司**需要将钉钉审批流程连接到他们的 WMS

巨头卖平台。**你销售的是针对特定行业的可落地方案。** 这就是机会——而在中国，数千家中型制造商、物流公司和服务企业仍在运行手工流程，这个缺口非常大。
