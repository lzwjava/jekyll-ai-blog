在汇丰的全球职位等级体系中，**高级顾问专家**通常对应 **GCB 4**（全球职业等级 4）。

汇丰的等级结构（从高到低）：

| 等级 | 级别 |
| ------ | ------ |
| GCB 0 | 集团首席执行官 |
| GCB 1 | 集团高管 |
| GCB 2 | 高级执行官 |
| GCB 3 | 高级领导 / 总监 |
| **GCB 4** | **高级顾问 / 高级经理 / 副总裁级别** |
| GCB 5 | 顾问 / 经理 / 助理副总裁级别 |
| GCB 6 | 分析师 / 专员 |
| GCB 7 | 初级 / 入门级 |
| GCB 8 | 支持人员 |

因此 **高级顾问专家 = GCB 4**，属于坚实的中高级别——相当于大型投行术语中的副总裁，或咨询公司中的高级经理。

如果你的职位具体是“顾问专家”（不带“高级”），则对应 **GCB 5**。

> 注意：汇丰并不总是公开内部等级对应关系，请以你的录用通知书或人力资源部门确认为准——合同通常会明确注明等级。
