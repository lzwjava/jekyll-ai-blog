问题：如何在不破坏关系的情况下拒绝那些不匹配的工作机会（遗留 Java、旧项目、合同工、糟糕的职位）？

答案：

针对您的情况，关键在于 **不要拒绝人，而是拒绝机会的方向**。

您有一个明确的发展轨迹：

* AI engineer / AI infra
* LLM training, inference, distributed systems
* Python + PyTorch + CUDA + vLLM
* building products

一个十年的 Java CRUD 系统可能会付钱，但它有很高的机会成本：它会使你偏离你的复利优势。

心态：

> “我不是说这个项目不好。我是说它与我的未来五年发展方向不匹配。”

### 1. 简短礼貌的拒绝

针对招聘人员：

> 感谢您的联系。这个项目看起来很有趣，但最近我一直专注于 AI 基础设施、LLM 工程和机器学习系统方向。这个职位似乎更侧重于传统的后端维护，所以我认为现阶段不太匹配。
>
> 感谢您想到我，请在有 AI 相关的机会时继续考虑我。

---

### 2. 当有人亲自推荐你时

不要这样说：

❌ “Java 老了”
❌ “这个项目很垃圾”
❌ “我不想做遗留工作”

要说：

> 我感谢这个机会。我目前的重心是深入 AI 系统领域，因此在选择有助于我积累这方面经验的工作时会比较谨慎。如果有 AI 平台、模型工程、推理或数据基础设施的项目，我肯定会感兴趣。

---

### 3. 关于合同项目

合同项目很棘手，因为它可能成为一个陷阱。

问：

```
1. 这能增强我的 AI 能力吗？
2. 这能产生公开证明/作品集吗？
3. 这能扩大我的人脉吗？
4. 这的报酬足以弥补所花费的时间吗？
```

如果所有答案都是否：

拒绝。

示例：

> 感谢分享。目前我优先考虑长期的 AI 工程工作，而非短期维护项目。这次我就先不参与了，但很高兴未来能讨论 AI 相关的合作。

---

### 4. 如果你因为房贷需要钱

不要使用二元决策：

“只做 AI 工作” vs “做遗留工作”

使用杠铃策略：

```
70% 精力：
AI 基础设施 / LLM 工程

30% 精力：
现金流项目
```

但要谨慎选择现金项目。

好的“现金桥”：

✅ Java 后端现代化（你可以添加 AI 功能）

示例：

旧系统：

```
Spring Boot
Oracle
MyBatis
Redis
```

你添加：

```
+ RAG search
+ AI assistant
+ document extraction
+ workflow agents
+ LLM integration
```

现在它变成了一个 AI 转型项目。

不好的：

```
维护 15 年老的 Struts 应用
修复 JSP 错误
手动部署
```

这会破坏你的定位。

---

### 5. 你的拒绝过滤器

在接受之前：

```
                AI 相关性
                     |
                     |
          +----------+----------+
          |                     |
        高                   低
          |                     |
    强烈接受              需要高报酬
          |
     建立声誉


低 AI + 低报酬
          |
        拒绝
```

你最大的资产不再是 Java 技能。

你的资产是：

```
11 年软件经验
+
训练过的 GPT 模型
+
PyTorch
+
GPU 基础设施
+
生产工程经验
```

很少有人拥有这种组合。

不要把自己重置为“找工作的 Java 开发者”。

将自己定位为：

> “正在转型为 AI 基础设施的软件工程师，拥有生产后端和模型训练经验。”

这要稀有得多。

接下来 12 个月的实用规则：

接受：

* vLLM serving
* inference optimization
* GPU cluster
* training pipeline
* AI agents
* data engineering for LLM
* AI product backend

或许可以接受：

* 带有 AI 组件的后端现代化

拒绝：

* 纯维护
* 外包人员租赁
* 没有 AI 路径的十年老 Java 栈
* 低薪短期合同

你当前的职业转型更接近 **Karpathy / AI 基础设施工程师路径**，而不是普通的 Java 后端路径。困难的部分是在财务上度过转型期，而不是决定方向。
