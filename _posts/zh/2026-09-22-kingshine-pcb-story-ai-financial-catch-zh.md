问题：**科翔股份（300903），这家惠州PCB公司怎么样？背后的故事是什么？**

回答：

如果你说的是**广东科翔电子科技股份有限公司 / Kingshine**，我觉得有意思的部分不是股价走势——而是**产业故事**。

广东科翔电子科技股份有限公司是一家总部位于惠州的PCB制造商，成立于**2001年**，于**2020年**在创业板上市，股票代码**300903**。公司总部位于惠州大亚湾。（[科翔股份官网][1]）

### 1. 创业故事其实相当不错

创始人/董事长**郑晓蓉**上世纪90年代从车间一线进入PCB制造行业。她于**2001年在大亚湾**创办科翔，据报道当时只有十几个人和大量二手设备。（[上海证券报][2]）

早期的故事基本上是：

> **学制造 → 解决供应链瓶颈 → 活下来 → 积累工艺know-how → 逐步向PCB复杂度曲线高端攀升。**

其中一个特别有说服力的细节：大约在2002年，一家海外关键材料供应商据报道涨价30%。公司没有简单消化成本上涨，而是在全国寻找国产化工材料供应商，最终与一家小型化工企业合作进行联合开发。（[上海证券报][2]）

这是一个非常典型的**珠三角制造创业者**故事。

不是“我们发明了革命性技术”。

更多是：

**工厂 → 工艺 → 供应链 → 规模 → 工程能力 → 更高端产品。**

---

### 2. 科翔到底做什么？

PCB基本上是把芯片和元器件连接在一起的物理基板。

但“PCB”覆盖的复杂度范围极其广泛。

科翔目前的产品包括：

* 高多层PCB
* HDI
* 高频/高速PCB
* 厚铜
* 金属基板
* 陶瓷基板
* 软硬结合板
* IC载板
* 等

目标市场：

**AI服务器/数据中心/光模块/汽车电子/通信/工业控制/医疗/消费电子。**（[新浪财经][3]）

这是一个重要转型：

**普通PCB制造商 → 逐步高端的PCB制造商。**

这才是投资/商业故事的核心。

---

### 3. AI概念是真的，但不要把“AI PCB”和AI公司混为一谈

这就是当前叙事变得有趣的地方。

AI基础设施需要海量的：

**GPU → 载板 → 高速互连 → 服务器 → 交换机 → 光模块 → 机柜**

随着带宽、层数、信号完整性、热负荷和功率密度的提升，PCB的要求也大幅提高。

科翔表示已进入以下领域：

* AI服务器
* 高速光模块
* 高密度互连
* 精密控制

其2025年研发投入为**2.11亿元**，约占营收的**5.67%**。（[中证网][4]）

所以潜在的投资逻辑不是：

> “AI让科翔变成了一家AI公司。”

而是：

> **AI资本开支增加了对更复杂PCB的需求，科翔正在努力将产品结构向PCB产业链中更高价值的部分迁移。**

这是一个有意思得多的逻辑。

---

### 4. 但财务上，有一个很大的问题

2025年：

|             |       2025年 |
| ----------- | ----------: |
| 营业收入     | **37.2亿元** |
| 营收同比     | **+9.56%** |
| PCB收入 | **33.8亿元** |
| 归母净利润  | **-2.46亿元** |
| 研发投入     |  **2.11亿元** |

公司实际上在2025年**亏损**了，尽管营收在增长。不过，亏损同比收窄了28.32%。（[中证网][4]）

2026年一季度营收为**9.54亿元，同比增长9.39%**。（[中证网][4]）

所以核心问题不是：

> “AI对PCB有没有帮助？”

显然有。

更难的问题是：

> **科翔能否将更高端的AI/汽车/光通信PCB需求转化为可持续的毛利率，并最终转化为净利润？**

这才是我关注的重点。

### 5. 客户故事也越来越有意思

公司表示已进入以下企业的供应链：

* 比亚迪
* 安波福（Aptiv）
* 均胜电子（Joyson）
* 华勤技术（Huaqin）
* 立讯精密（Luxshare）
* 大疆（DJI）

以及其他主要汽车/智能设备企业。前十大客户占2025年营收的**36.57%**。（[中证网][4]）

这很有价值，因为PCB制造存在一个棘手的鸡生蛋问题：

**高端客户 → 认证 → 量产验证 → 规模 → 工艺学习 → 更多高端客户**

一旦进入汽车或服务器供应链的合格供应商名单，替换供应商并不是一件容易的事。

所以客户认证可以成为护城河。

但客户集中度也意味着你需要密切关注议价能力。

**这个“？？？”就是整个投资故事的核心。**

公司已经证明了它能成长为一家相当规模的PCB制造商。悬而未决的部分是，**高端产品结构 + AI基础设施周期**能否从根本性上改变它的盈利模式。

### 7. 为什么惠州很重要

这同时也是一个非常“惠州”的故事。

公司起步于**大亚湾**，目前生产基地/运营覆盖**惠州、深圳、九江和赣州**，约有**6,000名员工**，2025年营收为37亿元。（[科翔股份官网][1]）

这是一条典型的广东制造发展路径：

```text
深圳电子产业生态
          ↓
       惠州
          ↓
   制造基地
          ↓
   供应商生态
          ↓
   规模制造
          ↓
      上市公司
```

这就是为什么我觉得这家公司作为**产业史故事**比纯粹作为“AI概念股”更有意思。

## 我对这家公司业务的判断

我会把科翔定义为：

**“一家有25年历史的惠州PCB制造商，正在尝试第二次转型——从规模制造向面向AI、汽车和高速通信的高端PCB转型。”**

第一次转型——**小厂 → 37亿元营收的上市公司**——已经完成了。

第二次正在进行中：

**传统PCB → 高端PCB → AI基础设施。**

目前的财务数据表明**转型正在进行中，但盈利结果尚未被验证**。（[中证网][4]）

我接下来会做的一件事是**将科翔2020–2026年的财务数据与沪电股份、深南电路、胜宏科技进行对标分析**——包括营收、毛利率、研发、资本开支、客户结构和AI相关占比——来看科翔是在技术上真正追赶，还是仅仅在享受同一波PCB周期。
