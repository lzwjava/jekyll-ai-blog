问题：**为什么美团的王兴在多次失败后依然坚持？**

答案：关键在于**王兴似乎并不将失败解读为“我是一个失败的创业者。”他将每家公司视为一场更长期游戏中的一次实验。**

他的经历异常清晰：

* **校内网** — 成功的产品，但资金耗尽，以约200万美元出售。
* **饭否** — 强大的产品，但因监管原因被关闭。
* **海内网** — 未能成为主流社交网络。
* **美团** — 进入残酷的“千团大战”，最终胜出。
* **大众点评合并** — 没有坚持美团必须独自取胜，而是与主要竞争对手合并。
* 随后美团从团购扩展到外卖 → 酒店 → 旅行 → 本地服务 → 即时零售。（[新浪财经][1]）

因此，我认为他的坚持背后存在**五个重要机制**。

### 1. 他将*自我*与*项目*分离

这可能是最重要的一个。

常见的心理循环是：

```text
项目失败
    ↓
“我失败了”
    ↓
身份受损
    ↓
避免再次尝试
```

王兴的循环更接近于：

```text
假设
    ↓
构建
    ↓
市场反馈
    ↓
失败
    ↓
更新对现实的认知模型
    ↓
新假设
    ↓
再次构建
```

这更接近于**科学实验**，而非传统的职业思维。

他的第一家重要公司没有成功，但创始人并未消失。他的第二家公司因外部环境被迫关闭。他仍然继续前进。（[中国故事][2]）

---

### 2. 他的失败实际上并非“归零”

这一点很重要。

假设：

```text
校内网 → 失败
饭否   → 失败
海内网 → 失败
美团   → 成功
```

你可能会计算：

```text
成功率 = 1 / 4 = 25%
```

但这是错误的模型。

每一次迭代都让他获得了：

```text
工程经验
+ 招聘经验
+ 融资经验
+ 产品直觉
+ 对用户的理解
+ 对竞争的理解
+ 对资本的理解
+ 对监管的理解
```

所以真实状态更接近于：

```text
S0
 ↓
失败 → S1
 ↓
失败 → S2
 ↓
失败 → S3
 ↓
成功
```

失败**改变了创业者的状态**。

这就是为什么从外部看，有经验的创始人会显得非理性地坚持。你在计算失败的公司的数量；他们在计算积累的信息量。

---

### 3. 他学会了改变*游戏*，而不仅仅是更努力

这是王兴变得特别有趣的地方。

他没有一直尝试复制Facebook。

最终他认识到：

> 社交网络非常强大，但也严重依赖于网络效应、资本和监管。

然后他转向了本地服务。

美团最初是一家Groupon式的团购公司。但当“千团大战”变得异常激烈时，王兴逐渐聚焦于餐饮领域，因为在这里交易可以重复发生，而不是一次性优惠券购买。（[爱尔兰审查报][3]）

这是一个关键区别：

```text
固执：
    “我会一直做同样的事，直到赢为止。”

坚持：
    “我会继续玩下去，但我会改变策略。”
```

王兴显然更接近后者。

---

### 4. 他拥有异常长的时间视野

有一个与王兴相关的著名概念：

> **无限游戏 — infinite game**

在有限游戏中：

```text
赢得这场比赛。
击败这个竞争对手。
拿下本季度的利润。
```

在无限游戏中：

```text
保持存活。
持续学习。
持续积累能力。
持续寻找值得玩的新游戏。
```

这解释了一些美团看似奇怪的决定。

例如，美团近期在外卖领域与阿里巴巴和京东展开了巨额投入。在补贴大战中遭受重大损失，包括2026年第一季度亏损68.2亿元。但随着竞争缓和，第二季度恢复净利润21.55亿元。（[华尔街日报][4]）

从短期视角看：

> “为什么要烧掉数十亿？”

从无限游戏视角看：

> “我们在购买什么战略资产？”

可能的答案：

```text
用户
商户关系
骑手网络
物流密度
配送基础设施
消费习惯
即时零售基础设施
```

而这正是公司目前的发展方向：外卖 → 即时零售 → 越来越普适的本地履约。路透社报道，2026年第二季度美团在即时零售领域约占**45.3%**，非常接近阿里巴巴的45.7%。（[路透社][5]）

因此，某一场战斗的“失败”并不必然意味着整体战略的失败。

### 5. 他似乎对不确定性有极高的容忍度

这一点常被低估。

大多数人会优化：

```text
风险 ↓
确定性 ↑
收入稳定性 ↑
```

像王兴这样的创业者似乎更倾向于优化：

```text
可选性 ↑
学习速率 ↑
上行空间 ↑
生存 ↑
```

这是不同的效用函数。

想象两个人：

**人A**

```text
工作
→ 薪水
→ 晋升
→ 稳定职业生涯
```

**人B**

```text
尝试
→ 失败
→ 尝试
→ 失败
→ 新信息
→ 尝试
→ 巨大上行空间
```

对于人B来说，多次失败是理性的，**只要下行风险可控，上行空间足够大**。

这基本上是将风险投资逻辑应用于自己的人生。

## 更深层的教训

我不会将王兴总结为：

> **“永不放弃。”**

那太肤浅了。

更有趣的原则是：

> **不要混淆具体执行的失败与根本目标的失败。**

例如：

```text
目标：
构建有价值的东西

执行方案#1：
校内网       → 失败/出售

执行方案#2：
饭否        → 被关闭

执行方案#3：
海内网       → 失败

执行方案#4：
美团        → 成功
```

目标相对稳定：

```text
互联网
→ 大规模产品
→ 海量用户网络
→ 现实世界服务
```

但执行方案不断变化。

这与训练AI系统非常相似：

```python
while not_solved:
    trajectory = run(policy)
    error = evaluate(trajectory)
    policy = update(policy, error)
```

一次失败的运行对模型来说并非生存危机。

它是**训练数据**。

老实说，这可能是王兴成为构建AI产品的人眼中如此有趣的创业者的原因之一：**失败后有用的问题不是“我够不够好？”而是“现实刚刚告诉了我什么？”**

一个提醒：流行的“九败一胜”叙事部分属于事后构建；他早期创业的确切次数和描述因来源而异。但反复尝试的基本模式是有充分记录的。（[新浪财经][1]）

我还可以分析**王兴 vs 埃隆·马斯克 vs 梁文锋/Karpathy**作为三种截然不同的应对失败和长期不确定性的方式。
