问题：**什么是交换式网络（switched network）？**

答案：**交换式网络 = switched network**。这是一种由**网络交换机决定每个数据包/帧的转发目的地**的网络，而非所有设备共享同一通信介质。

最简单的例子是以太局域网：

```text
PC A ──┐
PC B ──┤
PC C ──┼── [以太网交换机] ── 服务器
PC D ──┘
```

交换机学习MAC地址：

```text
MAC A → 端口 1
MAC B → 端口 2
MAC C → 端口 3
服务器 → 端口 4
```

当A向服务器发送以太网帧时：

```text
A
 │
 │ 帧：目的MAC = 服务器
 ▼
[交换机]
 │
 └──────────────► 服务器
```

交换机在其**MAC地址表**中查找目的MAC，并将帧仅转发到对应端口。

### 为什么叫“交换式”？

“交换”意味着**交换**：网络基础设施动态选择流量路径/端口。

与传统的**共享式以太网/集线器**网络对比：

```text
             ┌── PC A
             │
PC B ── [集线器] ┼── PC C
             │
             └── PC D
```

如果A发送数据，集线器本质上会将电信号广播到所有端口：

```text
A ──► 集线器 ──► B
         ├──► C
         └──► D
```

而使用交换机：

```text
A ──► 交换机 ─────────► C
```

因此交换式以太网提供：

* **专用的冲突域** — 每个交换机端口独立构成一个冲突域。
* **全双工** — 现代以太网通常允许同时发送和接收。
* **更好的可扩展性**。
* **基于MAC的转发**（第二层）。
* 交换机还能实现**VLAN**、STP、链路聚合等功能。

### 层级视角

典型的交换式以太网结构如下：

```text
应用层       HTTP / SSH / ...
       ↓
传输层       TCP / UDP
       ↓
网络层       IP
       ↓
数据链路层   以太网
       ↓
物理层       电信号 / 光信号
```

**以太网交换机主要工作在第二层**：

```text
以太网帧
┌──────────┬──────────┬───────┐
│ 目的MAC  │ 源MAC    │ 数据   │
└──────────┴──────────┴───────┘
      │
      ▼
   交换机
      │
      ▼
MAC表 → 输出端口
```

此外，还有使用路由器的**第三层分组交换**，因此“交换式网络”的概念比单纯的以太网交换机更广。但在基础网络/计算机网络教材中，通常指**交换式以太网**。

一个有用的理解模型是：

> **集线器 = 重复一切。**
> **交换机 = 学习地址并有选择地转发。**
> **路由器 = 连接不同IP网络并选择路由。**
