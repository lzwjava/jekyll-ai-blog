问题：介绍更多中国常见的蔬菜

回答：

以下是用于中国菜的更多常见蔬菜，以上一份清单为基础。这些蔬菜在不同地区都很受欢迎，常用于炒菜、汤、火锅和腌制食品中。

*   **白萝卜 (Daikon radish 或 luóbo)**：大型白色根茎蔬菜；用于汤、炒菜、腌制或切丝做沙拉。中国是主要生产国。
*   **胡萝卜 (Carrots 或 húluóbo)**：常用于炒菜、加入汤中或做馅料；味道甜脆。
*   **菜花 (Cauliflower 或 càihuā)**：在炒菜中很受欢迎；中国是主要的生产国和消费国之一。
*   **菜心 (Choy sum 或 cài xīn 或 flowering cabbage)**：嫩绿色叶菜，带黄色花朵；味道清淡微甜，常与大蒜一起炒。
*   **冬瓜 (Winter melon 或 dōngguā)**：味道清淡的瓜类；用于清凉汤品或炖菜。
*   **竹笋 (Bamboo shoots 或 sǔn)**：脆脆的笋；加入炒菜、汤中或与肉一起炖。
*   **荷兰豆 (Snow peas 或 hélán dòu 或 pea pods)**：扁平的豆荚；快速翻炒以保持酥脆口感。
*   **韭菜 (Garlic chives 或 jiǔcài)**：扁平、有蒜味的叶子；用于炒菜、饺子或与鸡蛋一起烹饪。
*   **芹菜 (Chinese celery 或 qíncài)**：比西式芹菜更细、更香；用于炒菜或汤中。
*   **菠菜 (Spinach 或 bōcài)**：嫩叶；可以焯水、炒食或做汤。
*   **洋葱 (Onions 或 yángcōng) 和 大葱 (green onions 或 cōng)**：重要的增香剂；大葱用作点缀或在炒菜中使用。
*   **花生 (Peanuts 或 huāshēng)**：在菜肴中常被视为蔬菜；可煮、炸或用于宫保菜肴。

地区特色菜包括四川的芥菜 (mustard greens 或 jiècài) 用于腌制，以及南方菜肴中的苋菜 (amaranth 或 xiàncài)。香菇和木耳等蘑菇也是主要食材，但它们在技术上属于真菌。
