**问题：** AMD Dev Cloud 在创建卷时提示“无效大小”——如何解决？

您能否分享确切的错误信息和截图？这将有助于确定是 UI 验证问题、大小限制还是单位格式问题。

即便如此，常见原因如下：

---

## AMD Dev Cloud 上常见的“无效大小”问题

### 1. 单位格式——输入纯整数，不带单位

某些 UI 仅期望输入 `100`，而不是 `100GB` 或 `100GiB`。请尝试：
```
100        ✓
100GB      ✗
100 GB     ✗
100GiB     ✗
```

### 2. 最小大小要求

大多数块存储都有最小容量要求（通常为 **1 GB 或 10 GB**）。输入 `0` 或非常小的数字会静默失败并显示“无效大小”。

### 3. 最大大小限制

AMD Dev Cloud 可能根据项目层级限制卷大小。常见限制：500 GB 或 1 TB。如果您输入了较大的值如 `2000`，请先尝试 `500`。

### 4. 项目配额未设置

如果您的账户处于免费/试用层级，块存储可能根本未启用——“无效大小”错误实际上是在误导性地提示“您的套餐不支持此功能”。

---

## 尝试以下方法

1. 输入 `50`（纯整数，不带单位），查看是否接受
2. 在 Dev Cloud 控制台的账户设置中检查您的项目配额/限制
3. 如果是试用账户，您可能需要联系 AMD Dev Cloud 支持以启用持久存储
