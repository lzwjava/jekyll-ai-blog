不完全正确——实际的快捷键是 **Ctrl+Tab**（Control + Tab），而不是单独按 Tab 和 Caps Lock。

在 macOS 的 GitHub Desktop 中，`Ctrl+Tab` 用于在 Changes 和 History 选项卡之间切换。这是大多数应用中用于切换选项卡的跨平台标准快捷键。

**其他有用的 GitHub Desktop 快捷键：**

- F5 — 刷新所有 git 数据
- ⌘G — 聚焦提交信息字段

所以，Tab 和 Caps Lock 只是在物理上堆叠在键盘上，但它们是具有各自功能的独立按键。Ctrl+Tab 将它们与 Control 修饰键组合起来，从而激活选项卡切换功能。
