问题：如何用烤箱一起烹饪菜心和牛肉片？

答案：

烤箱并不是制作**菜心（Choy sum）** + **牛肉片**的传统工具，因为两者都熟得很快，需要高温。通常用平底锅或炒锅更好。但如果只有烤箱，可以制作一道简单的**烤箱烤牛肉和菜心托盘菜**。

### 食材（2人份）

* 菜心：300–400克
* 牛肉片（薄切）：250克
* 大蒜：3–5瓣，切末
* 油：1–2汤匙

**牛肉腌料**

* 酱油：1汤匙
* 蚝油：1汤匙
* 绍兴酒（可选）：1汤匙
* 玉米淀粉：1茶匙
* 糖：1/2茶匙
* 黑胡椒粉：少量

### 步骤

#### 1. 处理牛肉

将牛肉片与以下材料混合：

```
牛肉片
+ 酱油
+ 蚝油
+ 绍兴酒
+ 玉米淀粉
+ 黑胡椒粉
+ 少许油
```

腌制15–30分钟。

玉米淀粉会形成一层薄薄的保护膜，防止牛肉变干。

---

#### 2. 处理菜心

* 洗净。
* 将茎切成3–5厘米的段。
* 叶子单独放置，因为叶子熟得更快。

与以下材料混合：

```
少许油
一小撮盐
大蒜末
```

---

#### 3. 烤箱烹饪

预热：

```
220°C（430°F）
```

使用烤盘。

先放入：

```
菜心茎
```

烤：

```
5分钟
```

然后加入：

```
牛肉片 + 菜心叶
```

将所有食材平铺成一层。

烤：

```
5–8分钟
```

直到牛肉变色。

---

#### 4. 完成

从烤箱取出后，加入：

```
几滴芝麻油
额外蚝油（可选）
现磨黑胡椒粉
```

拌匀，配米饭食用。

---

### 更好的烤箱方法（更中式）

像炒锅一样使用烤箱：

1. 将一个空金属烤盘放入烤箱内。
2. 将烤箱加热至最高温度（230–250°C）。
3. 将牛肉和蔬菜放在热烤盘上。
4. 初始接触热力能带来更好的“镬气”式焦香。

---

### 重要提示

薄切牛肉很容易变老：

* 合适：总烹饪时间5–8分钟
* 不合适：15–20分钟 → 干柴口感

如果牛肉片非常薄（火锅用），甚至**3–5分钟**就足够了。
