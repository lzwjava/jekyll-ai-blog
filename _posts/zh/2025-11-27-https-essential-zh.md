## 🔐 什么是 SSL/TLS 证书？

**SSL 证书**（更准确地说，是 **TLS - 传输层安全** 证书，因为 SSL 是已弃用的旧标准）是一种数字文件，主要有两个目的：**身份验证** 和 **加密**。

它安装在网络服务器上，包含：

1. **公钥：** 一种加密密钥，用于加密发送*到*服务器的数据。
2. **身份信息：** 关于证书所有者的详细信息（域名、组织等）。
3. **数字签名：** 来自受信任的第三方（称为 **证书颁发机构**，例如 Let's Encrypt, DigiCert）的签名，用于验证证书所有者的身份。
4. **有效期信息：** 证书的有效日期范围。

### 工作原理

当浏览器通过 HTTPS 连接到网站时，服务器会出示其 SSL/TLS 证书。浏览器随后执行以下步骤：

1. **验证（身份验证）：** 浏览器检查 CA 的数字签名，以确认证书是合法的，并且服务器是其声称的身份。这可以防止冒牌网站。
2. **密钥交换（加密）：** 客户端和服务器使用证书中的公钥来建立一个唯一的、临时的 **会话密钥**。在该会话期间传输的所有后续数据都使用此密钥进行加密。

## 🔒 为什么 HTTPS 对现代商业网站是强制性的

**HTTPS** 就是 HTTP 的安全版本。它将常规的 HTTP 协议与 **SSL/TLS 加密** 提供的安全性相结合。对于商业网站而言，出于三个关键原因，它是强制性的：**信任、安全和 SEO**。

### 1. 防范中间人攻击的安全性（"原因"）

这是你提到的主要安全好处。没有加密，通过 HTTP 发送的数据是 **明文** 的。

* **数据窃听：** 同一网络（如公共 Wi-Fi）上的攻击者可以轻松读取敏感信息，如登录凭据、信用卡号或个人详细信息。
* **数据篡改：** 正如你提到的，未加密的数据可以*在传输过程中*被修改。攻击者可以注入恶意代码、未经授权的广告或将用户重定向到网络钓鱼页面。

**HTTPS 阻止了这种情况**，因为连接是端到端加密的。即使攻击者截获了数据，他们看到的也只是无法理解的字符序列。

### 2. 建立客户信任和权威性（"商业性"）

商业成功取决于用户进行交易或分享信息的意愿。

* **浏览器指示器：** 浏览器会用明显的警告（如"**不安全**"）标记不安全的 HTTP 站点。HTTPS 站点在地址栏中显示 **锁形图标**，向用户保证连接是安全的。
* **法律/合规性：** 对于处理支付（例如电子商务）的网站，**PCI DSS** 等合规标准 **强制要求** 使用 TLS 加密来保护持卡人数据。

### 3. 搜索引擎优化

谷歌已明确表示 **HTTPS 是一个排名信号**。使用 HTTPS 的网站在搜索结果中的排名通常会高于可比的 HTTP 站点。这使其成为任何旨在获得可见性和商业流量的网站的关键技术要求。
