问题：解释香港中文大学研究生院“签证文件提交”

回答：

此页面是关于在被 **香港中文大学（CUHK）** 研究生课程录取后，**提交香港学生签证/入境许可所需文件** 的说明。主要面向需要签证才能在香港学习的 **非本地学生**。（[CUHK International][1]）

流程如下：

```
CUHK 录取你
        |
        v
CUHK 在你的申请系统中开放签证申请
        |
        v
你提交签证文件
        |
        v
CUHK 作为你的担保人并处理提交
        |
        v
香港入境事务处批准签证
        |
        v
你进入香港并完成注册
```

## 1. 谁需要办理？

如果你 **没有香港居留权或入境权**，则需要办理。

例如：

* 中国大陆学生 → 通常需要学生入境许可
* 国际学生 → 需要学生签证
* 香港永久居民 → 通常不需要

CUHK 规定，没有居留权的非本地学生必须在开始学习前获得有效的学生签证/入境许可。（[CUHK Web Archive][2]）

---

## 2. 需要提交哪些文件？

通常包括：

### A. 学生签证申请表

香港入境事务处表格：

```
ID995A
来港就读申请表格
```

由你本人填写。

包含：

* 个人信息
* 护照详细信息
* 教育背景
* 学习课程
* 担保人信息

---

### B. 护照复印件

通常：

```
护照个人信息页
```

需有足够有效期。

---

### C. 录取通知书

来自 CUHK：

```
录取通知书
```

证明你已被录取。

---

### D. 财力证明

通常：

* 银行对账单
* 奖学金证明
* 担保人财力证明

目的：

香港入境事务处需要确认你有能力负担学习和生活费用。

---

### E. 照片

符合护照规格的照片。

---

### F. 其他支持文件

根据你的国籍不同，可能包括：

* 香港入境事务处表格
* 身份证明文件
* 过往签证信息

CUHK 会根据申请人类别提供不同的签证申请材料包。（[CUHK International][1]）

---

## 3. 谁向香港入境事务处提交？

通常 **你不需要自己直接提交所有材料**。

关系如下：

```
你
 |
 | 提交文件
 v
CUHK 研究生院
 |
 | 担保你
 v
香港入境事务处
```

大学是你的担保人。

这与美国 F-1 签证不同：

美国：

```
大学 -> I-20
学生 -> 美国大使馆面签
```

香港：

```
大学担保
大学提交签证申请
入境事务处签发入境许可
```

CUHK 具体通过大学流程处理学生签证申请。（[CUHK International][1]）

---

## 4. 批准后

你会收到：

```
香港学生签证 / 入境许可
```

然后：

1. 前往香港
2. 通过入境检查
3. 领取入境标签
4. 完成 CUHK 注册

非本地学生还需在抵达后更新大学系统中的签证/入境信息。（[CUHK Resources][3]）

---

## 5. 时间线

典型流程：

```
录取通知书
      |
      | 1-3周
      v
提交签证文件
      |
      | 约6-8周
      v
签证批准
      |
      v
前往香港
```

尽早申请，因为入境事务处处理时间可能需要数周。CUHK 建议学生在规定截止日期前完成签证申请。（[CUHK International][1]）

## 针对你的情况（AI 硕士 / 计算机科学研究）

如果你申请 CUHK 的 MSc/MPhil/PhD：

你很可能需要：

```
✓ 护照
✓ 录取通知书
✓ 学位证书
✓ 成绩单
✓ 财力证明
✓ 签证表格 ID995A
✓ 照片
✓ CUHK 申请系统提交
```

重点：

**被录取 ≠ 获得在香港学习的许可。**

录取给你学位名额；签证流程给你合法入境和学习的权利。
