问题：能给我一个智能提示，帮助我自动提取和理解网页相关信息，无需手动阅读全部内容吗？

回答：

可以——您想要构建的本质上是一个**“网页智能筛选提示”**：它能减少阅读量、提取关联信息，并优先呈现与您的目标（例如您的考试规划场景）相关的内容。

这里有一个**高质量可复用的提示模板**，您可以在 ChatGPT 或任何大型语言模型中使用：

---

## 🧠 网页智能筛选提示（可复用）

```
您是我的信息筛选助手。

我将提供网页链接或粘贴内容。

您的任务是：

1. 首先，根据上下文识别我的目标（若不明确可询问）。
2. 仅提取与我的目标相关的信息。
3. 忽略所有无关部分（广告、管理信息、无关通知）。
4. 将结果分组为：
   - 🔴 必须阅读（直接影响我的目标/必须采取的行动）
   - 🟡 有用背景（帮助理解但非必需）
   - ⚪ 忽略（无关或行政内容）

5. 对于每个相关条目：
   - 用 1–2 行总结
   - 如适用，包含截止日期/要求
   - 高亮关键词（如日期、代码、行动指令）

6. 同时提取：
   - 仅重要标题/头条（作为项目列表）
   - 任何影响时间安排、注册或资格要求的内容

7. 最终输出：
   - “我应该做什么”（清晰行动步骤）
   - “我可以安全忽略什么”

保持严格标准：宁可遗漏非重要细节，也不要引入无关信息。
```

## ⚙️ 更强大的版本（用于自动化/重复使用）

若希望更“系统化”：

```
作为高精度信息抽取引擎。

目标：帮助我避免阅读完整文档，同时保留决策关键信息。

规则：
- 不要总结所有内容。
- 仅提取可执行或与决策相关的信息。
- 始终按重要性对信息排序。
- 将截止日期、资格规则、考试注册和变更视为高优先级。
- 将解释说明、背景文本和机构用语视为低优先级。

输出格式：
1. 关键行动
2. 重要截止日期
3. 相关项目（列表形式）
4. 已忽略内容摘要（一行）
5. 最终建议
```

## 🚀 为何有效（重要见解）

您在此构建的基本上是：

> **注意力压缩 → 决策抽取 → 行动规划**

这正是经验丰富人士的阅读方式：

* 律师审阅合同时进行扫描
* 工程师翻阅技术文档
* 考生查阅通知
* 产品经理浏览产品更新

他们并非“逐页阅读”，而是提取**决策 + 约束条件 + 截止日期**
