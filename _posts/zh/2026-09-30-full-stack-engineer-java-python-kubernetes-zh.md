# 全栈工程师（Java或Python方向）

## 职位要求/技术技能

1. 具备丰富的Java和Python技术栈经验，熟悉Kubernetes、PostgreSQL、React和Angular。

2. 精通现代Web技术，包括JavaScript、jQuery、HTML和CSS。

3. 拥有高级Python脚本编写与自动化经验，用于平台配置、验证、运维及执行跟踪。

4. 深入了解Kubernetes，涵盖调度、网络、存储、安全、扩缩容及故障排查。

5. 具备Docker实战经验，包括镜像生命周期管理、安全加固及运行时优化。

6. 掌握Apache Spark平台的专家级知识，包括集群调优、作业隔离、批处理与流处理。

7. 理解Apache Iceberg平台，涵盖目录管理、分区、压缩与治理。

8. 具备使用Azure DevOps进行CI/CD工程的经验，包括策略驱动的发布管控。

9. 拥有丰富的可观测性与可靠性工程经验，熟练使用Prometheus和Grafana。
