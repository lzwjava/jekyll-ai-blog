**问题：什么是网络拓扑，常见的五种类型有哪些？**

**答案：**

**网络拓扑** = 计算机网络的结构/布局——设备（节点）之间如何相互连接。

**有5种经典拓扑类型**：

| 类型     | 结构                                     | 核心概念                         |
| -------- | ---------------------------------------- | -------------------------------- |
| **总线** | `A — B — C — D`                         | 所有设备共享一根主干电缆         |
| **星型** | `A ↘`<br>`B → 集线器/交换机 ← C`<br>`D ↗` | 每台设备都连接到中央设备         |
| **环型** | `A → B → C → D → A`                     | 设备连成闭合环路                 |
| **网状** | `A ↔ B`<br>`↕ ╲ ↗`<br>`C ↔ D`          | 设备之间拥有多条互连路径         |
| **树型** | `根节点`<br>`↙ ↓ ↘`<br>`A B C`<br>`↙ ↘`  | 星型拓扑的分层组合               |

### 1. 总线拓扑

```text
A    B    C    D
|    |    |    |
================
    主干线
```

共享一种通信介质。

* 廉价且简单
* 单根电缆故障可能影响整个网络
* 旧式以太网中冲突曾是主要问题

### 2. 星型拓扑

```text
       A
       |
B ---- SW ---- C
       |
       D
```

现代以太网局域网在物理上通常是围绕交换机呈现**星型**结构。

* 易于管理
* 单根端点电缆故障 → 通常仅影响该设备
* 中央交换机成为重要的故障点

### 3. 环型拓扑

```text
A → B
↑   ↓
D ← C
```

每台设备连接两个相邻节点。

* 路径可预测
* 若无冗余机制，一处中断可能破坏整个环
* 历史上用于令牌环网等技术

### 4. 网状拓扑

```text
A -------- B
|\        /|
| \      / |
|  \    /  |
|   \  /   |
C -------- D
```

节点之间有多条路径到达其他节点。

* 极佳的冗余性
* 成本更高、更复杂
* 在**广域网、路由网络、无线Mesh网络**中概念上很常见

包含 `n` 个节点的**全网状**拓扑拥有：

$$
E = \frac{n(n-1)}{2}
$$

条链路。

对于5个节点：

$$
E = \frac{5(4)}2 = 10
$$

### 5. 树型拓扑

```text
             核心层
          /    |    \
        SW1   SW2   SW3
       /  \   / \   /  \
      A    B C   D E    F
```

它是分层的：**根 → 分支 → 设备**。

这种结构在企业网络中非常常见，因为它比庞大的扁平网络具有更好的扩展性。

### 关键区别

不要混淆**物理拓扑**与**逻辑拓扑**。

例如，一个以太网网络在物理上可以是：

```text
PC ─┐
PC ─┼─ 交换机
PC ─┘
```

这是**星型拓扑**，而其逻辑行为则由以太网交换和路由决定。

对于你的网络考试，一个简单的记忆口诀是：

> **总线、星型、环型、网状、树型**
