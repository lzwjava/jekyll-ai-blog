**问题：MSI MAG B760M Mortar — 如何重置/安装新BIOS，以及插电时出现的“滋滋”声是否与此有关？**

## 1. 重置BIOS（清除CMOS）

对于**MSI MAG B760M Mortar**（DDR4或DDR5版本），有三种方法：

### 方法A — 清除CMOS跳线（推荐）

1. 关闭电脑。
2. 关闭电源开关（`0`）。
3. 拔掉交流电源线。
4. 按住机箱开机键约10秒（释放电容余电）。
5. 在主板上找到**JBAT1**针脚。
6. 用螺丝刀短接两个针脚约5–10秒。
7. 重新接通电源并开机。

此操作会重置：

* XMP内存设置
* CPU超频/降压
* 风扇曲线
* 启动顺序
* BIOS设置

---

### 方法B — 取下CMOS电池

1. 完全关机。
2. 取出圆形CR2032电池。
3. 等待5分钟。
4. 装回电池。
5. 开机。

效果相同。

---

## 2. 安装/更新新BIOS

MSI主板具备**M-FLASH**和**Flash BIOS按钮**功能。

### 选项1：M-FLASH（常规方式）

1. 下载BIOS：

[MSI MAG B760M Mortar 支持页面](https://www.msi.com/Motherboard/MAG-B760M-MORTAR/support?utm_source=chatgpt.com)

2. 将U盘格式化为**FAT32**格式。
3. 解压BIOS文件。
4. 将BIOS文件复制到U盘根目录。
5. 进入BIOS：

```
启动时按DEL键
```

6. 选择：

```
M-FLASH
→ 选择BIOS文件
→ 确认
```

请勿：

* 断电
* 重置电脑
* 触碰U盘

通常需要5–10分钟。

---

### 选项2：Flash BIOS按钮（即使无CPU/RAM也可使用）

以下情况适用：

* 主板无法启动
* CPU不被旧版BIOS支持
* BIOS损坏

步骤：

1. 下载BIOS。
2. 重命名文件：

MSI通常要求：

```
MSI.ROM
```

3. 仅将该文件放入FAT32格式的U盘。
4. 插入专用USB端口：

```
Flash BIOS USB端口
```

5. 连接：

* 24针主板供电
* 8针CPU供电

6. 按下：

```
Flash BIOS按钮
```

LED灯闪烁表示正在刷写。

# 3. 关于插电时的“滋滋”声

这很有意思。

**当电源接通时立即出现轻微的嗡嗡/滋滋声**，可能来自以下几个地方。

## 情况1：正常的线圈啸叫（可能）

现代主板包含：

* VRM电感
* 待机5V电路
* 电容

当交流电进入电源时，主板获得：

```
交流220V
   ↓
电源待机5V
   ↓
主板待机电路
   ↓
EC/ RGB控制器/ LAN芯片
```

某些电感可能振动：

```
电流 → 磁场 → 线圈振动 → "滋滋"
```

非常微弱的高频声通常无害。

---

## 情况2：电源问题

如果出现以下情况则更值得关注：

* 声音来自电源本身
* 噼啪声
* 有电气味
* 声音随显卡负载变化

例如：

```
插交流电
 ↓
电源待机电路
 ↓
电容充电
 ↓
嗡嗡/噼啪声
```

廉价或老化的电源可能出现此现象。

---

## 情况3：短路/主板问题

不良迹象：

* 主板LED灯异常闪烁
* 电源反复发出咔哒声
* 电脑反复开关机
* 烧焦味
* USB设备行为异常

此时应断开所有连接：

仅连接：

```
主板
CPU
CPU散热器
1根内存条
电源
```

不接显卡、不接固态硬盘。

尝试启动。

# 4. BIOS重置与滋滋声的关系

通常：

```
BIOS损坏
       ❌
       |
       无关
       |
电源插电滋滋声
```

BIOS是存储在SPI闪存中的固件。

滋滋声发生在**供电模拟硬件**部分，与BIOS无关。

然而，如果BIOS设置错误：

* 极端内存电压
* 超频
* 不稳定的CPU电压

可能导致启动问题，但通常不会在插交流电时发出滋滋声。

2. 更新最新BIOS。
3. 加载优化默认值。
4. 仅在稳定启动后启用XMP。

对于二手主板，还应检查：

* VRM区域（烧痕）
* 电容鼓包
* CPU插槽针脚弯曲
* 8针CPU供电接口

**滋滋声的具体位置**非常重要：

* 靠近电源 → 怀疑电源
* 靠近CPU VRM → 线圈啸叫
* 靠近后部I/O → 待机电路

如果你在插交流电时录制一段5–10秒的音频/视频片段，通常可以判断声源位置。
