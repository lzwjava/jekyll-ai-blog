问题：ATM 网络环境由两部分组成：ATM end users 和  。

答案： 

完整且正确的陈述是：

ATM 网络环境由两部分组成：**ATM terminal users** 和 **ATM network**。

在 ATM (Asynchronous Transfer Mode) 网络的上下文中，系统通常分为：

- **ATM terminal users** (或 ATM end systems / user equipment)：诸如 computers、具有 ATM 接口的 routers、具有 ATM uplinks 的 LAN switches、video codecs 等连接到 ATM network 的设备。

- **ATM network**：由 ATM switches、transmission links 以及相关的 network management functions 组成的 core infrastructure，为端点之间提供高速 cell-switching 服务。

因此，空白处应填入 **ATM network**。
