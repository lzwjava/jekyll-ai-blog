问题：什么是**虚电路服务**和**数据报服务**，它们的区别是什么？

答案：

它们是**分组交换网络**提供通信服务的两种不同方式。

### 1. 虚电路服务 — Virtual-circuit service

可以类比为**先打电话，再通话**。

发送数据前：

```text
主机A                         主机B
  |                              |
  |--- 建立虚电路 --->|
  |<-- 连接已建立 ---|
  |                              |
  |====== 数据包1 =============>|
  |====== 数据包2 =============>|
  |====== 数据包3 =============>|
  |                              |
  |-------- 拆除连接 ------------>|
```

网络首先建立一条逻辑路径：

```text
A → 路由器1 → 路由器2 → 路由器3 → B
```

每个数据包随后都沿着同一条虚电路传输。

路由器为虚电路维护**状态**，通常类似于：

```text
入向VC标识 → 出向VC标识
```

例如：

```text
路由器1：
VC 17 → 端口3, VC 42
```

数据包不一定包含完整的目的地址，它们可以携带一个简短的**VC标识符**。

**特点：**

* 需要建立连接
* 网络维护连接状态
* 数据包通常遵循同一条逻辑路径
* 数据包按序到达
* 能更自然地提供服务质量/资源预留
* 虚电路故障时可能需要重新建立另一条

历史上的典型例子包括**X.25、帧中继、ATM**。

---

### 2. 数据报服务 — Datagram service

可以类比为**通过邮政系统发送独立的信件**。

无需建立连接：

```text
A
├── 数据包1 ──→ 路由器1 → 路由器2 → B
├── 数据包2 ──→ 路由器1 → 路由器4 → B
└── 数据包3 ──→ 路由器5 → 路由器4 → B
```

每个数据包被独立处理。

路由器本质上会询问：

```text
"目的地址在哪里？"
              ↓
        路由表
              ↓
"我应该使用哪个下一跳？"
```

因此数据包1和数据包2**可能走不同的路径**。

网络本身通常不维护每连接状态的电路状态。

**特点：**

* 无需建立连接
* 每个数据包独立路由
* 数据包可能走不同路径
* 数据包可能乱序到达
* 数据包可能丢失或重复
* 网络拓扑变化时更灵活

**IP是数据报网络的典型例子。**

---

### 关键区别

|                   | 虚电路                          | 数据报                     |
| ----------------- | ------------------------------- | -------------------------- |
| 连接建立          | 是                              | 否                         |
| 网络状态          | 每虚电路状态                    | 主要为路由状态             |
| 数据包路由        | 同一条逻辑路径                  | 独立路由                   |
| 数据包顺序        | 通常保持                       | 不保证                     |
| 故障处理          | 虚电路可能需要重建              | 数据包可重新路由           |
| 数据包中的地址    | 通常为短VC标识                  | 目的地址                   |
| 示例              | ATM, X.25                       | IP                         |

最简单的理解模型：

```text
虚电路：

        ┌─────── 相同逻辑路径 ───────┐
A ──────R1────────R2────────R3─────────── B
       数据包1    数据包1    数据包1
       数据包2    数据包2    数据包2
       数据包3    数据包3    数据包3


数据报：

A ──数据包1──→ R1 ──→ R2 ──→ B
 \
  ──数据包2──→ R4 ──→ R3 ──→ B
 \
  ──数据包3──→ R1 ──→ R5 ──→ B
```

### 一个微妙之处

**虚电路 ≠ 物理专用电路。**

"电路"是**逻辑上**的，而非专用线路。

多个虚电路可以共享同一条物理链路：

```text
             ┌── VC A ──┐
A ── R1 ── R2 ── R3 ── B
             └── VC B ──┘
```

这就是为什么它被称为**虚拟**电路。

另外，不要将此与**TCP**混淆：TCP提供面向连接的传输服务，但其底层的IP仍然是**数据报网络**。
