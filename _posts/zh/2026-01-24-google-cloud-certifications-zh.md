Question: What certificates can we get in Google Cloud?

Answer:

Google Cloud 提供了一系列的 **certifications**，分为三个主要级别：Foundational、Associate 和 Professional。这些认证验证了在使用 Google Cloud 产品和服务方面不同深度的知识和技能。

以下是当前 Google Cloud 认证的主要列表（截至 2026 年初，基于官方网站）：

### Foundational Level

- **Cloud Digital Leader** — 验证对云概念、Google Cloud 产品、服务、工具、优势和使用场景的广泛理解。是初学者和非技术角色的理想起点。
- **Generative AI Leader** — 侧重于理解使用 Google Cloud 工具的 generative AI 概念和应用（面向非技术人员/领导层）。

### Associate Level

- **Associate Cloud Engineer** — 验证使用 Google Cloud 部署应用程序、监控运营和管理企业解决方案的基础技能。（最受欢迎的入门级技术认证。）
- **Associate Cloud Data Practitioner**（或类似的 Data Practitioner 职称）— 侧重于使用 Google Cloud 工具的核心数据技能。

### Professional Level

这些是更高级的、基于角色的认证（通常需要 3 年以上经验）：

- **Professional Cloud Architect** — 在 Google Cloud 上设计和规划可扩展、可靠、安全且具有成本效益的解决方案。
- **Professional Cloud Developer** — 使用 Google 推荐的实践构建可扩展且高可用的应用程序。
- **Professional Data Engineer** — 设计和构建数据处理系统。
- **Professional Machine Learning Engineer** — 使用 Google Cloud 技术设计、构建和将 ML 模型产品化。
- **Professional Cloud DevOps Engineer** — 在整个系统开发生命周期中实施流程。
- **Professional Cloud Network Engineer** — 实施和管理网络架构。
- **Professional Cloud Security Engineer** — 配置访问权限、保护数据和应用程序并确保合规性。
- **Professional Cloud Database Engineer** — 在 Google Cloud 上规划和优化数据库解决方案。

Google Cloud 认证的有效期为 **2–3 年**，具体取决于级别（Foundational/Associate：通常为 3 年；Professional：通常为 2 年），您需要通过重新认证来维持其有效性。

有关最新、最完整的列表（包括 2025-2026 年新增的任何认证），请直接查看官方页面。
