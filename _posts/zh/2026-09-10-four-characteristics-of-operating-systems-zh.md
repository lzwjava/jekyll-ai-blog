问题：**操作系统的四个经典特性是什么，例如虚拟化和并发性？**

回答：

记住**操作系统的四个基本特性**的一个有用方式是：

1. **虚拟化** —— 为每个程序提供其拥有独立CPU、内存和设备的假象。

   * CPU → 进程/线程看起来独立运行。
   * 内存 → 虚拟地址空间。
   * 存储 → 文件/目录抽象化磁盘。
   * 示例：进程 `P1` 认为它独占地址 `0x400000`，尽管许多进程共享物理RAM。

2. **并发性** —— 多个程序可以"同时"推进。

   * 单CPU上：快速上下文切换。
   * 多CPU上：真正的并行执行。
   * 操作系统必须处理同步、竞态条件、死锁等。

3. **持久性** —— 数据能够在程序终止和断电后存活。

   * RAM是临时的。
   * 操作系统在磁盘/SSD上提供文件系统/存储抽象。
   * 示例：

     ```bash
     echo hello > a.txt
     ```

     `a.txt` 在进程退出后依然存在。

4. **保护/隔离** —— 一个程序/用户不应随意干扰另一个。

   * 用户/内核模式
   * 进程地址空间隔离
   * 文件权限
   * 系统调用边界
   * 硬件保护机制

一个简洁的心智模型是：

```text
                 操作系统
                       │
       ┌───────────────┼────────────────┐
       │               │                │
   虚拟化           并发性           持久性
       │               │                │
  CPU / 内存       进程           文件 / 磁盘
  设备             线程           文件系统
       │               │
       └────── 保护 ──────┘
               隔离
```

如果你想到的是**经典操作系统教材的表述**，尤其是*《操作系统：三个简单的部分》（OSTEP）*，核心的三个其实是**虚拟化、并发性和持久性**。**保护**是操作系统的另一个基本关注点，但通常不被计入OSTEP的"三个简单的部分"。

关键是：**操作系统本质上是一个抽象+资源管理层**。它将混乱的物理硬件转化为有用的抽象，如进程、虚拟内存、文件和权限。
