问题：广州哪些区支持公司注册的“住所自主承诺申报制”？  
答案：  
在广州，这**并非仅限某个区**。广州市已逐步推广“住所（经营场所）自主承诺申报”制度。具体是否适用取决于地址类型、行业以及该地址是否在政府认可的地址数据库中。（[广州市政府][1]）  
已实施或推行该政策的区包括：  

| 区                               | 支持情况   | 备注                                                                                                                             |
| -------------------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **海珠区**                       | ✅ 支持     | 最早实施该制度的区之一。许多互联网/软件公司采用此方式。（[广州市政府][2]）                                                         |
| **天河区**                       | ✅ 支持     | 非常适合软件/AI公司；天河软件园区域有许多科技公司。（[广州市政府][1]）                                                             |
| **黄埔区**                       | ✅ 支持     | 常被科技初创企业和创新公司使用。（[广州市政府][1]）                                                                               |
| **南沙区**                       | ✅ 支持     | 拥有自身的市场主体登记确认制改革规则和地址数据库系统。（[广州市政府][1]）                                                         |
| **其他区（越秀、荔湾、白云、番禺、增城、花都、从化）** | 普遍可用   | 需核查具体地址和经营范围。（[广州市政府][1]）                                                                                     |

对于**AI/软件咨询公司**，我的推荐排序如下：  

### 1. 天河区 ⭐⭐⭐⭐⭐  

最佳匹配：  

* AI公司  
* 软件开发  
* 咨询服务  
* 客户认知度更高  

典型地址：  

```

广州市天河区科韵路  
广州市天河智慧城  
```  

### 2. 黄埔区 ⭐⭐⭐⭐⭐  

适合如果您需要：  

* 创业生态

* 孵化器  

典型区域：  

```
广州科学城

知识城  
```  

### 3. 海珠区 ⭐⭐⭐⭐  

适合：  

* 互联网公司  
* 自由职业者  
* 小型AI初创企业  

示例：  

```
海珠区琶洲  
```  

针对您的情况（AI代理开发 + 咨询 + 可能的AI实验室），我可能会选择：  

```
首选：天河区  
次选：黄埔区

```  

关键点：不要只问“该区是否支持？”——而要问**您的具体地址是否在允许的地址数据库中**。同一个区可能允许一栋楼而拒绝另一栋。广州的规定使用标准地址库和负面清单来确定承诺申报是否可以替代证明文件。（[广州市政府][1]）  

实用方法：  

1. 找一个天河/黄埔的联合办公或孵化器地址。  
2. 询问：“这个地址可以做科技有限公司注册吗？支持住所自主申报吗？”  
3. 在支付租金前确认。
