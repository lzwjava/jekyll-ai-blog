**Question:** Azure 是否有线下考试认证，类似于 GCP Professional Cloud Developer 认证？

**Answer:**

是的，Microsoft Azure 认证提供 **On-site (in-person)** 监考考试选项，就像 Google Cloud Platform (GCP) 认证一样。

与 **Google Cloud Professional Cloud Developer** 最具可比性的 Azure 认证是 **Microsoft Certified: Azure Developer Associate**（考试代码：**AZ-204**）。这是 Azure 上主要针对 Developer 角色设计的认证。

对于 Azure 和 GCP 认证：

- 考试均通过 **Pearson VUE**（与 Google Cloud 使用的考试服务商相同）进行。
- 你可以从两种主要的交付方式中进行选择：
  - **Online proctored** (OnVUE) —— 在家或办公室远程参加，通过摄像头监控。
  - **On-site / Test center proctored** —— 在 Pearson VUE 授权的测试中心现场参加。

这多年来一直是 Microsoft 角色化认证（包括 AZ-204、AZ-104、AZ-305 等）的标准选项。通过 Microsoft Certification 仪表板或 Pearson VUE 网站预约考试时，你可以选择交付方式（测试中心或在线），系统会根据你所在的地区显示测试中心地点。

因此，Azure 确实有“现场认证”选项——在考试交付可用性方面，与 GCP 的 Professional Cloud Developer 考试没有本质区别。
