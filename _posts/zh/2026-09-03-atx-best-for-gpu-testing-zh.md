问题：**哪种主板外形尺寸更适合 GPU 测试：ATX 还是 ITX？**

回答：**ATX 更适合 GPU 测试。**

|                    | ATX         | ITX                     |
| ------------------ | ----------- | ----------------------- |
| 物理尺寸            | 较大        | 小得多                  |
| PCIe 插槽           | 通常 4–7 个 | 通常 1 个                |
| 多 GPU 支持         | ✅ 方便      | ❌ 通常不可能            |
| 探测/操作空间        | ✅ 更好      | ❌ 拥挤                  |
| GPU 维修/测试        | ⭐⭐⭐⭐⭐       | ⭐⭐                      |
| 廉价测试平台        | 极佳        | 紧凑但受限              |

对于你的 **GPU 维修/测试设置**，我建议选择 **ATX 主板**，最好具备以下特点：

```text
ATX 主板
├── PCIe x16 #1  ← 待测 GPU
├── PCIe x16 #2  ← 第二块 GPU / 诊断卡
├── PCIe 插槽    ← 其他扩展卡
├── M.2 / SATA
└── GPU 周围便于操作
```

关键不仅仅是 ATX 与 ITX 的对比。对于 GPU 诊断，请注意以下事项：

1. **自检/诊断 LED 指示灯** — CPU / DRAM / VGA / BOOT。
2. **至少 2 个物理 PCIe x16 插槽**（若需测试多块显卡）。
3. **方便接触 GPU 背面**，用于万用表/示波器探测。
4. **已知良好的 CPU + 内存**，以便隔离 GPU 问题。
5. **廉价二手平台** — 无需昂贵的新款 CPU。
6. 最好选择能**在不安装 GPU 的情况下引导**的主板（使用集成显卡），从而区分 GPU 故障与平台故障。

对于你正在搭建的这类设置，我建议更进一步：

**ATX 开放式测试平台 > 普通 ATX 机箱。**

你可以将主板放在工作台上，GPU 可垂直或水平放置（必要时使用 PCIe 转接卡），电源放在旁边，从而直接接触探针。这会使得反复进行 **GPU → 测量 → 更换 → 启动 → 测量** 的实验变得容易得多。

如果你专门为 GPU 维修购买一块便宜的二手主板，**二手 ATX LGA1151/LGA1200/AM4 主板是非常好的测试平台**——你不需要一颗强大的 CPU。
