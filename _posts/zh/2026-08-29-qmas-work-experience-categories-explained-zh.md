问题：QMAS申请中提到的四类工作经验是什么意思？有什么要求？

回答：

这些字段**并非四个独立的要求**，而是对你申请中填入的合格工作经验的总结。

| QMAS 字段                                                  | 含义                                                                                          |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **跨国企业或知名企业的工作经验**                         | 在符合资格的跨国企业或知名企业中从事**毕业生/专业级别**工作的年限                               |
| **特定领域/行业的工作经验**                               | 在**创新科技、金融或国际贸易**领域从事毕业生/专业级别工作的年限                                 |
| **具有国际视野的工作经验**                                 | 涉及实质性**国际视野**的工作年限，例如国际业务、海外客户/团队、跨境项目等                       |
| **累计毕业生或专业级别工作经验**                           | 你**总体符合资格的毕业生/专业级别工作经验**，无论是否属于上述类别                             |

关键区别在于：**一份工作可能同时计入多个类别**。

例如，如果你曾在一家知名跨国企业从事国际项目，担任软件/人工智能工程师：

```text
工作
 ├── 毕业生/专业级别经验       → 计入 累计年限
 ├── 创新科技                 → 计入 特定领域
 ├── 国际项目/客户             → 可能计入 国际视野
 └── 知名跨国企业             → 可能计入 知名企业/跨国企业
```

### 针对你的情况

鉴于你约有11年的软件工程经验，关键问题并非简单问“我工作了多少年？”

而是：

> **这些年中有多少年你能证明是毕业生/专业级别的工作，又有多少年符合QMAS的具体类别？**

对于**特定领域标准**，香港明确表示评估主要看你的**岗位性质、职位/职衔**，而不仅仅是你雇主所属的行业分类。

因此，从事软件、人工智能、机器学习、云基础设施等工作的**后端工程师/人工智能工程师/软件工程师**，有可能支持**创新科技**类别。

因此，你在**LeanCloud、Beyondsoft、HSBC/PayMe、Meitai**等公司的工作经验，应**逐份工作**进行审查，而不仅仅是简单累加所有工作年限。

一个特别重要的点是：**“毕业生或专业级别”并不一定意味着你每一年工作经验都必须拥有本科学位**。它指的是工作的级别/性质。但你需要可信的书面证据来证明该岗位确实是专业级别。

如果你使用的是QMAS的**综合计分制**，这些经验类别之所以重要，是因为该计划会根据某些类型的专业经验给予加分。具体的评分/资格标准应参照当前官方的QMAS规定，而非依赖旧的摘要。
