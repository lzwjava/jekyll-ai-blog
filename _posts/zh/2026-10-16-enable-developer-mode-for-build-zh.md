构建被硬性中止：iPhone 13 的 **Developer Mode 已禁用** — Apple 要求必须开启后才能安装任何开发应用。

## 请在 iPhone 13 上启用 Developer Mode

1. 在手机上：**Settings → Privacy & Security → Developer Mode**
2. 将 **Developer Mode** 切换为 **ON**
3. 手机会要求**重启** — 让它重启
4. 重启后，会出现提示（“Turn on Developer Mode?”）→ 确认（Face ID/密码）

> ℹ️ 此设置仅在首次将设备接入开发工具时显示 — 如果在 Privacy & Security 中没有看到“Developer Mode”，请让手机保持连接并重启一次，然后再次检查。

**当它启用后告诉我**（手机在 Settings 中显示 Developer Mode 为“On”），我会一次性完成 build + install + launch。
