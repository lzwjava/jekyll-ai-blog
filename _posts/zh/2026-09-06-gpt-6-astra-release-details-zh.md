**问题：** OpenAI 新模型 GPT-6 Astra 的最新消息是什么？

**答案：**

GPT-6 Astra 非常新——它几天前刚刚发布。以下是概要：

**发布**
GPT-6 Astra 是 OpenAI 于 2026 年 9 月 3 日发布的前沿 AI 模型。OpenAI 称其为迄今为止能力最强且对齐程度最高的模型，在计算机使用、编程、科学推理、网络安全和专业工作流程方面均取得了重大进展。

**不同之处**
Astra 更像是一个计算机操作员，而不是聊天机器人——它可以使用软件、检查屏幕、构建网站、生成文档、运行 QA 检查、在编程环境中工作、分析科学数据，甚至能在 Blender 中进行环境建模。

**基准测试**
OpenAI 声称 GPT-6 Astra 在关键推理基准测试中获得了满分或接近满分的成绩，击败了其之前的模型 GPT-5.6 Sol 和竞争对手 Anthropic 的 Claude Fable 5。

**AGI 声明**
OpenAI 总裁 Greg Brockman 称其为“代际飞跃”，并表示它最终可能被视为通用人工智能（AGI）的到来。这也标志着 OpenAI 首次让其他 AI 模型在监督模型训练中扮演重要角色。

**网络安全**
Astra 是 OpenAI 首个在其 Preparedness Framework 下被认定为达到“critical”网络安全阈值的模型——这意味着它有可能在没有人类逐步指导的情况下，在受良好保护的系统中发现并利用此前未知的漏洞。OpenAI 在发现这一点后，放缓了发布，以增加安全测试。

**推出与可用性**
GPT-6 Astra 将首先向一组有限的机构推出，并在未来几天内向所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户开放，同时也可通过 OpenAI API 和 AWS 使用。

**API 定价**
API 定价为每百万输入 token 10 美元，每百万输出 token 50 美元，支持 1,050,000 token 的上下文窗口，最大输出 128K，知识截止日期为 2026 年 4 月 30 日。
