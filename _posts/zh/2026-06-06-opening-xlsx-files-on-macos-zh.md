问题：macOS Excel、Pages 等是什么？如何在 macOS 上打开 `.xlsx` 文件？

回答：

在 macOS 上，微软和苹果提供了不同的办公软件：

1. **Microsoft Excel for macOS**

   * 这是你所熟悉的 Windows 版 Excel，但针对 macOS 进行了适配。它完全支持 `.xlsx` 文件，包括公式、图表和宏。
   * 你可以通过 **Microsoft 365 订阅** 或一次性购买 Microsoft Office for Mac 来安装。

2. **Apple Pages、Numbers、Keynote**

   * **Pages** → 文字处理（类似 Word）
   * **Numbers** → 电子表格（类似 Excel）
   * **Keynote** → 演示文稿（类似 PowerPoint）
   * 这些应用在 macOS 上免费使用。
   * **Numbers** 可以打开 `.xlsx` 文件，但非常复杂的 Excel 文件可能会丢失部分格式或功能。

3. **在 macOS 上打开 `.xlsx` 的其他方式**

   * **LibreOffice**（免费开源）可以打开和编辑 Excel 文件。
   * **Google Sheets**（基于浏览器）允许你上传 `.xlsx` 文件并在线编辑。
   * **快速查看**：在 Finder 中选择一个 `.xlsx` 文件，按下 **空格键**，即可预览内容，无需打开。

**如何在 macOS 上打开 `.xlsx` 文件**：

1. **使用 Excel**：如果已安装 Excel，双击 `.xlsx` 文件即可。
2. **使用 Numbers**：右键点击 → 打开方式 → Numbers。
3. **使用 Google Sheets**：将文件上传到 Google Drive，然后用 Sheets 打开。
4. **使用 LibreOffice**：在 LibreOffice Calc 中打开 `.xlsx`。

提示：如果你需要 **完全兼容** 复杂的 Excel 功能（宏、数据透视表、高级公式），Excel for macOS 是最安全的选择。
