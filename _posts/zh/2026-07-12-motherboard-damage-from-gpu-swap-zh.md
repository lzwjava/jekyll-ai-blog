问题：分析为什么 MSI B760M + i9-13900KF + Corsair CX650F 在将 RTX4070 更换为 AMD MI50 后开始出现嗡嗡声，并且现在无法启动。

回答：

根据你的描述，关键时间线如下：

1. 系统原本稳定运行：

```
MSI B760M Mortar WiFi
i9-13900KF
Corsair CX650F
RTX4070
```

2. 你拆下了 RTX4070。

3. 安装了一块二手的 AMD MI50。

4. 随后立即出现：

* 主板区域发出"滋滋"的电流声
* 无显示输出 / 无法启动
* 噪音集中在 SATA5/SATA6 接口附近
* 即使拆除水冷，噪音依然存在
* 重新安装 RTX4070 后，故障依旧

这强烈表明是**主板供电线路出现问题或主板损坏**，而非电源供应器的问题。

---

## 1. 最可能发生的情况：MI50 导致 PCIe 供电故障

AMD MI50 是一款服务器级 GPU：

* Vega 20 架构
* PCIe 4.0 x16
* 300W TDP
* 采用 8-pin EPS 式供电接口（非普通游戏 GPU 标准）
* 专为工作站/服务器平台设计

关键点在于：

**MI50 并非 RTX4070 的常规替代品。**

RTX4070：

```
PCIe 插槽供电：
75W

12VHPWR 接口：
最高 200W+
```

MI50：

```
PCIe 插槽供电：
75W

8-pin 接口：
约 225W
```

但两者的主板设计、固件、上电时序和散热要求均不相同。

一块二手的 MI50 可能存在：

* 损坏的 VRM（电压调节模块）
* 短路的电容
* 失效的供电级
* 损坏的 PCIe 金手指

插入后，主板的 PCIe 12V 供电轨可能承受了过大压力。

---

## 2. 为什么噪音来自 SATA5/SATA6 区域？

这一点值得注意。

在 MSI B760M Mortar 主板上：

SATA 接口在物理位置上靠近：

* 芯片组 (PCH)
* PCIe 供电分配线路
* 主板 VRM 辅助电路

你听到的噪音很可能并非来自 SATA 本身。

可能的噪音源：

```
24-pin ATX 电源接口
     |
     |
 主板电源层
     |
     +---- PCH/芯片组供电 VRM
     |
     +---- SATA 控制器
```

高频开关噪音：

```
VRM 线圈
   |
   |
  ~~~~~
 电气振动
```

这种现象被称为：

**线圈啸叫**

损坏的 VRM 会产生：

```
滋滋滋滋滋
嗡嗡声
```

即使系统无法启动，这种噪音也可能存在。

## 3. 仅用电源供应器回形针测试是不够的

海盗船官方指导：

短接：

```
PS_ON
（通常为第16针）
+
接地
```

意味着：

```
电源供应器能启动
```

这仅能证明：

* 待机电路工作正常
* 电源供应器可以启动

这并**不能**证明：

* 负载下的电压稳定性
* 瞬态响应能力
* PCIe 供电质量

不过，你的症状指向了电源供应器之外的问题，因为：

> 噪音物理上位于主板上

---

## 4. 关键测试：最小化主板启动

请按以下步骤操作：

移除：

* 显卡
* 固态硬盘
* SATA 设备
* USB 设备
* RGB 控制器

仅保留：

```
主板
+
CPU
+
CPU 散热器
+
1 根内存条
+
24-pin ATX 供电
+
8-pin CPU EPS 供电
```

然后通电开机。

预期结果：

13900KF 没有集成显卡：

```
无显卡 = 无显示输出
```

但：

* EZ Debug LED 应显示 VGA 报错

此时你不应听到主板发出嗡嗡声。

如果嗡嗡声依然存在：

=> 主板已损坏。

---

## 5. 检查 EZ Debug LED 指示灯

MSI 主板上有：

```
CPU
DRAM
VGA
BOOT
```

通常位于右上角。

含义：

### CPU 红灯亮

可能原因：

* CPU 供电问题
* 主板 VRM 故障

### DRAM 黄灯亮

内存初始化失败

### VGA 白灯亮

显卡问题

### BOOT 绿灯亮

POST 自检通过，存储设备问题

你的情况很可能是：

```
VGA 指示灯
或
CPU 指示灯
亮起
```

## 6. 可能的损坏情况排序（按概率）

我的概率评估：

### #1 主板 PCIe/供电电路损坏

概率：60%

理由：

* 故障恰好发生在更换显卡过程中
* 噪音来自主板
* 更换回原显卡后问题依旧

### #2 MI50 本身存在缺陷并导致主板损坏

概率：25%

二手 MI50 显卡风险较高。

可能情况：

```
MI50 VRM 短路
        |
        |
PCIe 12V 供电轨
        |
        |
主板损坏
```

### #3 电源供应器损坏

概率：10%

可能性较低，因为：

* CX650F 的保护机制很可能已触发
* 噪音位置与电源供应器不符

### #4 CPU/水冷问题

概率：<5%

拆除水冷后情况没有任何改变。

## 7. 请勿反复通电尝试

如果主板供电元件已损坏：

每次通电：

```
12V 电压
 |
VRM
 |
发热
 |
可能导致进一步损坏
```

应避免：

* 再次插入 MI50
* 反复尝试启动

---

## 8. 我建议接下来采取的措施

操作顺序：

### 第一步

完全移除显卡。

清除 CMOS：

```
关闭电源供应器
拔掉电源线
按住机箱开机键10秒释放余电
取下主板纽扣电池等待5分钟
```

使用最小化配置启动。

---

### 第二步

再次聆听噪音。

如果：

```
嗡嗡声依然存在
```

请对主板进行返厂保修。

---

### 第三步

如果可能，将 RTX4070 放到另一台机器上测试。

在确认主板健康之前，不要再测试 MI50。

## 我的结论

最可能的故障链条：

```
RTX4070 被移除
        |
        v
插入 MI50
        |
        v
MI50 存在异常的供电行为
        |
        v
PCIe 供电轨 / 主板 VRM 承受压力
        |
        v
B760M 主板现在出现线圈啸叫 / 供电故障
        |
        v
无法通过 POST 自检
```

你能够将噪音定位到 SATA5/SATA6 附近，这是一个强有力的线索：噪音很可能来自主板电感或芯片组供电电路，而非显卡或电源供应器。

你的 MSI B760M + 13900KF 配置属于中高端平台，在接入异常的 PCIe 设备后发生主板故障，是令人遗憾但可能发生的情况。我建议停止测试，优先确认主板健康状况。
