问题：什么类型的服务器为局域网上的工作站提供完整的数据和目录信息共享？

答案：

正确答案是 **C. 集散 (Distribution/Centralized-Distributed)**。

**解释：**
在局域网 (LANs) 的上下文中，**集散服务器**（通常翻译为 distribution server 或管理集中存储并分布式访问的服务器）专门设计用于为工作站提供对完整数据集、文件目录和其他资源的共享访问。

- **选项 A (联机/Online)** 和 **选项 B (脱机/Offline)** 指的是系统的连接状态，而不是专用于资源共享架构的特定服务器角色。
- **选项 D (分时/Time-sharing)** 指的是通过划分 CPU 时间让多个用户共享计算机资源的一种计算技术，这是一个更广泛的操作系统概念，而不是问题中描述的 LAN 文件/资源服务器的特定功能。
- **选项 C (集散)** 准确描述了将数据集中聚合（收集）并分发到网络上各种工作站的功能，从而实现查询中提到的“完整数据和目录信息共享”。

*注：在现代网络术语中，此功能最常与 **File Server** 相关联。但是，根据特定选项和您查询中提供的考试答案，“集散”是此特定测试上下文中的预期答案。*
