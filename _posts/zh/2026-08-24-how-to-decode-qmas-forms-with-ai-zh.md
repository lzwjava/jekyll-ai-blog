问题：我能否通过复制前端代码/使用浏览器控制台来检查QMAS在线表单，并将其交给AI来理解评审标准？

答案：可以，这实际上是一种非常实用的方式，用于理解复杂的政府表单，尤其是现代网页应用。思路如下：

1. **检查前端**

   * 打开Chrome DevTools：

     * `F12` → 网络/来源/应用程序
     * 查找：

       * JSON 模式
       * API 响应
       * JavaScript 包
       * 字段名称
       * 验证规则
       * 隐藏选项

2. **提取表单结构**

   例如：

```javascript
// 在浏览器控制台中
document.querySelectorAll("input, select, textarea")
```

或：

```javascript
copy(document.documentElement.innerHTML)
```

然后将提取的 HTML/JS 交给 AI，并提问：

> "分析此移民表格。提取每个字段、必需文件、验证规则，并说明应上传哪些证明材料。"

AI 通常能够重构：

* 字段含义
* 必填项 vs 选填项
* 预期格式
* 字段间的依赖关系
* 评分标准

对于 QMAS 来说，这一点尤其有用，因为该申请不仅仅是一个普通表格，它对应着评估标准：

* 年龄
* 学历
* 语言能力
* 工作经验
* 收入
* 企业所有权
* 成就

入境事务处表示，网上申请信息必须与提交的证明文件相符，而综合计分制下的信息应与您所声明的年龄、学历、语言能力、工作经验、年收入及企业所有权一致。（[香港入境事务处][1]）

官方上传类别已揭示了评估结构：

* 旅行证件
* 照片
* 资产净值证明
* 学历/专业资格
* 工作经验
* 公司证明
* 收入记录
* 语言证明
* 成就
* 受养人文件

（[香港政府][2]）

一个良好的工作流程：

```text
浏览器
  |
  |-- 检查 HTML/JS/API
  |
  v
提取字段
  |
  v
AI 分析
  |
  +--> "此字段含义是什么？"
  +--> "用什么文件证明？"
  +--> "我的证据有多强？"
  +--> "我能申领多少分？"
```

例如：

```
字段：
"专业资格"

AI 分析：
- 很可能要求证书/执照
- 与学术学位不同
- 上传 PDF 扫描件
- 包含颁发机构
- 若非中文或英文，则需附翻译件
```

对于你的情况，这非常有用，因为你的背景比较特殊：

* 丰富的软件工程经验
* AI/LLM 相关工作
* 创业/商业经验
* 非传统教育背景

你可以利用 AI 进行映射：

```
你的证据
      |
      v
QMAS 评审标准
      |
      v
可能得分/风险
```

有一点需要注意：不要仅依赖前端代码。政府系统通常将真正的规则隐藏在后端。官方的指引说明和文件清单仍然是最终依据。（[香港入境事务处][1]）

一个更强大的方法是：

1. 下载官方 QMAS 指引 PDF。
2. 检查在线表单。
3. 构建个人 "QMAS 证据矩阵"：

```
评审标准              证据                      强度
--------------------------------------------------------
工作经验              雇佣证明信                  强
AI 成就               论文/项目                   中
学位                  自学文凭                    风险
收入                  税务记录                    取决于情况
企业所有权            公司记录                    若有则强
```

这样你就可以在提交前确切了解申请中的薄弱环节。
