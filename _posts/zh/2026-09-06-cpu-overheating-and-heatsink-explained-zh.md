**问题：** CPU 如何知道它过热了，散热片到底是什么？

---

**回答：**

---

### 🧠 什么是散热片？

**散热片** 是一块金属块（通常是铝或铜），直接安装在 **CPU 顶部**。它的作用是吸收 CPU 的热量并将其散发到空气中。散热片顶部有鳍片以增加表面积，通常还有一个风扇来吹过这些鳍片。

```
      [ 风扇 ]
   ___________
  |  | | | |  |   ← 金属鳍片
  |___________|
  |  平坦底座 |   ← 安装在 CPU 上
       ↕
   [  CPU  ]
```

**导热硅脂**（灰色/银色粘性化合物）涂抹在 CPU 表面和散热片底座之间，以 **填充微观空气间隙** —— 因为空气是热的不良导体，而即使是金属表面也无法做到完全平整。

---

### 🌡️ CPU 如何“知道”它过热了？

现代 CPU 内部有一个内置的 **数字温度传感器**，称为 **TJ（热结）传感器** 或 **DTS（数字温度传感器）** —— 这是一个直接集成在 CPU 芯片内部的微小电路。它会实时持续测量温度。

以下是逐步发生的流程：

```
CPU 变热
     ↓
内部 TJ 传感器读取温度
     ↓
温度达到警告阈值（约 90–100°C）
     ↓
CPU 通过 PROCHOT# 引脚向主板发送信号
     ↓
主板触发立即关机
     ↓
风扇短暂闪烁 → 系统停止运行
```

这种安全机制称为 **热节流 / 热保护** —— 用于防止 CPU 物理烧毁。

---

### ⚡ 为什么会在 1 秒内发生？

如果散热片：
- **未与 CPU 接触**（安装方向错误或卡扣未锁紧）
- **缺少导热硅脂**（CPU 与散热片之间有空气间隙）
- **导热硅脂老化干涸**（碎裂且无法导热）

那么 CPU **完全得不到冷却**。即使处于空闲状态，CPU 产生的热量也足以在 **不到 1 秒内** 达到危险温度 —— 传感器会立即触发，在所有损坏发生之前关闭系统。

---

### 🔧 你应该检查什么

| 检查项 | 需要确认的内容 |
|---|---|
| 散热片卡扣 | 所有 4 个推针必须完全锁紧 |
| 散热片接触 | 散热片底部必须与 CPU 顶部平贴 |
| 导热硅脂 | 应薄而均匀——不能太多，不能缺失 |
| 老化干涸的硅脂 | 灰色/白色碎屑状残留物 = 需要更换 |
| 风扇连接 | CPU 风扇接头必须插在主板上 |

---

### 🧪 简单测试

取下散热片，用异丙醇清洁旧导热硅脂，在 CPU 中心滴一小粒 **豌豆大小** 的新鲜导热硅脂，重新牢固安装散热片，然后再次尝试。
