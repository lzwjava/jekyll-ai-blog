问题：**广州最顶尖的IT/AI公司有哪些？**

答案：

广州不像北京（智谱、百度）或杭州（阿里巴巴、DeepSeek生态）那样以AI模型为核心，但拥有强大的**AI应用、云服务、企业软件、机器人、智能硬件和行业AI**公司。

对于AI工程师/LLM基础设施背景的人，我大致会这样排名：

| 公司                        | 主要AI/技术方向                                | 为什么值得关注                                                                               |
| ------------------------------ | ------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Tencent（广州研发中心）        | LLM、腾讯云、混元、推荐系统、NLP、基础设施             | 广州最强的AI工程品牌。腾讯在天河设有广州研发办公室。 |
| CVTE                           | AI教育、智能会议、机器人、边缘AI                       | 工程文化非常浓厚；硬件+AI软件结合。([CVTE][1])                 |
| 佳都科技               | 计算机视觉、智慧城市、智能交通 | 广州代表性AI公司之一。([南方+][2])                                |
| 华为广州               | 云、AI基础设施、分布式系统           | 适合系统工程师。华为在广州有软件研发布局。                   |
| 科大讯飞广州              | 语音AI、NLP应用                             | 在语音、教育、企业AI方面实力强劲。([iFlytek][3])                                     |
| 京华信息技术 | 企业软件、AI知识系统               | 更偏向企业AI/数字化转型。                                                  |
| 广州睿帆科技    | 数据平台、AI分析                             | 企业数据+AI应用。                                                                          |

## 广州AI初创生态

有意思的小公司：

* AI营销/全球化：

  * 钛动科技 — AI+出海营销。([南方+][2])

* 行业AI：

  * 智能交通
  * 制造AI
  * 政务数字化

广州的AI优势主要体现在：

```
AI+行业
AI+硬件
AI+企业
AI+机器人
AI+云
```

而不是：

```
基础模型训练
前沿LLM研究
```
