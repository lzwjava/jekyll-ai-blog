问题：**如果 AI 能强力辅助 Codeforces/Kaggle，那么在真实工作中到底什么仍然困难？哪些证书/竞赛仍然能体现能力？**

答案：

关键区别在于：

> **竞赛衡量的是“你能否在受控约束下解决一个定义明确的问题？”真实工作衡量的是“你能否在模糊环境中发现、负责并交付正确的问题？”**

AI 让第一类变得更廉价。可以说，它让第二类**更加重要**，而非更不重要。

### 1. AI 首先摧毁了什么

许多传统的技能信号正在变弱：

| 信号 | AI 影响 |
| --- | --- |
| LeetCode/Codeforces 解题 | 高 |
| 样板代码编写 | 非常高 |
| 语法/API 知识 | 非常高 |
| Kaggle 特征工程 | 高 |
| 可带回家的实现任务 | 高 |
| “我会 React/PyTorch/K8s” | 高 |
| 记忆算法 | 高 |

这并不意味着这些技能变得无用。而是说**技能与产出软件的能力之间的相关性变弱了**。

Codeforces 本身已经做出了回应：其现行规则明确禁止在有评级竞赛中使用 AI 生成核心算法、推理问题或调试被拒绝的解答。（[Codeforces][1]）

这基本上承认了根本问题：**如果允许模型进行推理，竞赛就不再衡量预期的人类能力。**

---

# 2. 在现实生活中什么变得更难

有几个层面是 AI 无法消除的。

### A. 问题选择

真实工作：

> “我们的推理成本太高。”

这并不是：

```text
输入 → 算法 → 输出
```

你必须去发现：

```text
为什么成本高？
“太高”意味着什么？
哪些用户受到影响？
我们能容忍延迟吗？
我们可以缓存吗？
应该做蒸馏吗？
应该换模型吗？
应该改产品吗？
这真的是瓶颈吗？
```

一位优秀的工程师可能会发现：

> 不要优化推理。真正的问题是我们每次请求调用了模型 47 次。

用一个静态的问题描述很难对此进行基准测试。

---

### B. 系统所有权

AI 可以生成：

```python
async def foo():
    ...
```

但生产环境会问：

```text
谁拥有这个服务？
Redis 挂了怎么办？
回滚流程是什么？
延迟为什么从 p95 300ms 变成了 4s？
GPU 利用率为什么崩溃了？
数据库账单为什么是 8 万美元/月？
这次迁移为什么损坏了 0.1% 的用户？
```

困难的单位不再是**一个函数**。

而是：

> **一个系统 + 它的状态 + 它的用户 + 它的故障模式 + 它的经济学。**

---

### C. 验证

这很可能是 AI 时代最重要的工程技能。

LLM：

```text
“这是一个很棒的解决方案。”
```

工程师：

```text
证明它
基准测试它
红队测试它
检查生成的代码
找反例
衡量生产行为
```

这种不对称很有趣：

> **生成变便宜；验证变昂贵。**

这在 AI 工程中已经非常明显。

如果我让一个智能体修改一个 10 万行的仓库，生成补丁并不特别令人印象深刻。

难的是知道补丁是否**真正正确**。

---

### D. 品味

假设一个智能体提供了 10 种架构：

```text
Kafka + Flink
Postgres + 工作者
Redis 流
Temporal
Ray
无服务器
...
```

仍然需要有人来决定：

> 我们应该构建哪一个？

这不是纯粹的算法能力。

而是以下内容的累积理解：

* 故障模式
* 运维复杂度
* 团队能力
* 延迟
* 成本
* 未来需求
* 产品约束
* 组织约束

这就是为什么即使经验丰富的工程师和经验不足的工程师**拥有完全相同的 AI 工具**，前者仍然可以显著更高效。

# 3. 那么离线竞赛还有用吗？

**有用——但出于非常特定的原因。**

ICPC 在 AI 时代是一个引人注目的资质，因为它创造了一个故意将模型排除在外的环境。

2026 年 ICPC 规则给每支队伍**一个共享的工作站**，并禁止参赛者自带电脑或电子设备进入竞赛区域。（[ICPC Global][2]）

关键不在于 ICPC 像软件工作。

它不像。

其价值在于它提供了一个相对干净的衡量：

```text
人类推理
+
算法知识
+
压力下的实现
+
团队沟通
+
调试
+
时间管理
```

并且由于环境是受控的，该资质仍然是可解释的。

这与以下情况根本不同：

> “我在某个在线编程平台上取得了第 98 百分位。”

---

# 4. 有趣的资质层级正在变化

我大致将资质视为**证据**，而非声望。

### 原始技术推理的强证据

```text
ICPC 世界总决赛 / 区域赛
IMO / IOI / 类似奥林匹克级别成绩
顶级研究成果
```

ICPC 明确描述其目标围绕团队合作、编程和解决问题的能力。（[ICPC][3]）

当**竞赛本身排除 AI 辅助时**，这些资质极难被 AI 伪造。

---

### 机器学习能力的强证据

Kaggle 仍然有用，但有一个巨大警示：

**Kaggle 正在变得异质化。**

一些竞赛允许 AI/自动化机器学习；另一些则明确禁止生成式 AI。例如，当前 Kaggle 竞赛的规则可能允许使用 GPT/Claude/Gemini（需披露），而其他竞赛则明确禁止使用 LLM。（[Kaggle][4]）

所以：

```text
“Kaggle 大师”
```

已经不能说明全部情况。

更好的信号是：

```text
Kaggle 结果
+ 竞赛名称
+ 规则
+ 写作
+ 代码
+ 可复现性
```

# 5. 但还有一个更强的资质：交付过的东西

对于实际招聘工程师的人来说，这可以更有信息量：

```text
GitHub 仓库
       ↓
真实用户
       ↓
真实流量
       ↓
真实故障
       ↓
真实收入 / 影响
       ↓
你能解释每一个设计决策
```

例如：

> “我构建了一个处理每月 20 亿 token 的推理服务。”

是一个更有趣的面试起点，远胜于：

> “我解决了 2000 道 LeetCode 题。”

因为现在面试官可以问：

```text
为什么用这个架构？
瓶颈在哪里？
什么出过问题？
成本是多少？
你衡量了什么？
为什么不用 X？
流量扩大 10 倍你会怎么改？
```

而你要么知道——要么不知道。

AI 无法方便地掩盖这种差距，因为面试官可以持续深挖系统。

---

# 6. 这催生了一种新的面试

我推测未来的技术面试将更少是：

```text
“实现 LRU 缓存。”
```

而更多是：

```text
这是一个出故障的生产系统。

这里有：
  日志
  追踪
  指标
  源代码
  客户投诉

找出问题。

然后：

  提出修复方案
  实现它
  基准测试它
  解释权衡
```

或者：

```text
这是一个智能体。

它通过了我们 80% 的测试。

让它达到 98%。

你有 4 小时。
```

或者：

```text
这是一个 50 万行的仓库。

添加功能 X。

你可以使用任何 AI 工具。

我们将评估：
  正确性
  回归率
  测试
  架构
  安全性
  性能
  解释
```

这更接近实际工作。

# 7. 奇怪的结果

AI 未必会让**精英人类变得不那么有价值**。

它可能使分布更加极端。

想象两位工程师：

```text
工程师 A：
  推理：5
  编码：8
  AI 使用：5

工程师 B：
  推理：9
  编码：7
  AI 使用：9
```

使用 AI 后：

```text
A → 能产出更多代码

B → 能产出更多系统
```

因为 B 可以：

```text
分解
→ 委托给智能体
→ 检查
→ 拒绝
→ 重新设计
→ 测试
→ 迭代
→ 交付
```

瓶颈向上移动。

从：

> **“你能写代码吗？”**

到：

> **“你能将大量计算引导到正确的目标上吗？”**

这更接近 AI 原生工程师的角色。

# 8. 那么你实际上应该优化什么？

我会用**三个正交的信号**来构建个人档案：

```text
              人类推理
                    ↑
                    │
              ICPC / 奥林匹克
                    │
                    │
                    │
现实世界 ←─────────┼────────→ AI 原生
系统               │            执行
                    │
              交付的产品
                    │
                    ↓
              收入 / 用户
```

你不需要每一项资质。

一个特别强的组合是：

```text
1. 一个高难度离线资质
   ICPC / 奥林匹克 / 严肃研究

2. 一个严肃的技术产物
   模型 / 分布式系统 / 编译器 / 智能体框架

3. 一个不可否认的真实世界成果
   用户 / 收入 / 延迟 / 规模 / 开源采用
```

第三项越来越重要。

**一枚奖牌告诉我你能解决难题。**

**一个交付的系统告诉我你能在现实中存活。**

**一个 AI 原生系统告诉我你理解了新的杠杆。**

而真正有趣的人最终会同时拥有这三项。
