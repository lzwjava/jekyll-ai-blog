**问题：分析高等教育自学考试全国统一命题考试课程 02141 Computer Networks（计算机网络技术），包括对广东历年真题的分析。**

**回答：**

课程 **02141 Computer Networks** (计算机网络技术) 是中国高等教育自学考试（自考）体系中的全国统一命题考试科目。它通常包含在专科层次的计算机相关专业中（如计算机应用技术、计算机信息管理等）。在广东省，该课程遵循全国大纲，并在大多数考次中使用全国统考卷。

### 教材与大纲

- **主编教材**：张海霞（Zhang Haixia）主编，《计算机网络技术》(Computer Networks Technology)，机械工业出版社 (China Machine Press)，2016年版。
- 截至最近的考试周期（已在广东2026年开考课程名单中确认），这仍然是标准教材。
- 大纲涵盖从基础到中级的计算机网络概念，与教材结构一致（通常为9-10章）。

**核心内容（基于 02141 考试的典型覆盖范围）**：

1. 计算机网络概论（历史、分类、delay、throughput 等性能指标）。
2. OSI reference model 和 TCP/IP model（分层、功能、对比）。
3. Physical layer（传输介质、信号、调制、多路复用）。
4. Data link layer（成帧、差错控制、流量控制、HDLC、PPP、MAC sublayer、Ethernet 基础）。
5. Network layer（IP addressing、subnetting、routing algorithms、ICMP、ARP）。
6. Transport layer（TCP 和 UDP、可靠传输、拥塞控制、端口）。
7. Application layer（DNS、HTTP、FTP、SMTP、常用协议和服务）。
8. 网络设备（hubs、switches、routers、VLAN 基础）。
9. 网络安全基础和无线网络（部分版本涉及）。

考试侧重于概念理解、协议原理和基础计算（例如 subnetting、IP 的二进制转换）。

### 考试形式与题型

考试为**闭卷笔试**，通常时间为 150 分钟，总分 100 分。
典型结构（与包括广东在内的许多全国卷一致）：

- **单选题**：20-30 题，每题 1-2 分（常见为 20 题 × 2 分 = 40 分）。覆盖基础概念和定义。
- **多选题或填空题**：有时包含（10-20 分）。
- **简答题**：4-6 题（解释协议、分层、区别等），每题 5-10 分。
- **计算/应用题**：Subnet mask 计算、IP address 分类、二进制-十六进制转换、CRC 校验等。
- **综合/论述题**：1-2 道关于协议工作过程或网络设计的大题。

难度适中，适合自学者。及格分数为 ≥60 分。

### 历年真题分析

02141 的试卷是**全国统考**的，因此广东考生与其他省份使用相同的试卷（该课程没有专门的广东卷）。从 2002 年到近期（直至 2025/2026 周期）的历年真题可通过各类自学考试平台获取。

**历年真题（2000s–2025）中的关键模式**：

- **高频考点**（几乎每年重复）：
  - OSI 与 TCP/IP model 的对比及各层功能。
  - IP address 类别、subnetting、CIDR。
  - TCP three-way handshake（三次握手）、four-way teardown（四次挥手）、可靠传输机制。
  - Ethernet 帧结构、CSMA/CD。
  - 常见协议：HTTP 端口 80、DNS、ARP request/reply。
- **计算题**：子网划分（寻找 Network ID、广播地址、可用主机数），通常占 8-12 分。
- **差错控制**：Hamming code 或 CRC（偶有出现）。
- **随时间的变化**：早期试卷（2000s）更侧重于基础和旧技术；近期试卷（2020+）增加了更多关于 VLAN、无线基础和现代 TCP/IP 应用的内容，但核心保持稳定。
- **稳定性**：题目经常通过略微改动措辞来回收考点。掌握 5-10 年的真题可以覆盖 80-90% 的新考试内容。
- **难度趋势**：总体平稳；选择题考察记忆，简答题考察理解，计算题考察应用。

**广东特有说明**：

- 广东在 02141 科目上使用全国卷。
- 考试时间：通常在 4 月和 10 月（有时会增加 1 月/7 月考试）。
- 资源如 gdszkw.com、zikaosw.cn 及其它平台提供了适用于广东的历年真题（部分合集已收录至 2025 年 4 月）。
- 通过系统复习教材 + 真题，通过率较为合理。

**备考建议**：

- 优先级：重点复习网络模型、IP/TCP/UDP、Data link & Network layer 相关章节。
- 练习：在限定时间内完成至少 8-10 套完整的历年真题。
- 常见陷阱：混淆 OSI 层级与 TCP/IP 层级、计算子网错误、忘记协议端口号。

这门课程测试的计算机网络基础知识在目前依然具有很高的相关性。
