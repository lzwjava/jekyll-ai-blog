## 1. 标准Transformer注意力

常规公式：

\[
Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt d})V
\]

对于一个token：

* 查询向量：

\[
q \in R^d
\]

表示：

> “我在寻找什么信息？”

* 键向量：

\[
k_i \in R^d
\]

表示：

> “这个token提供了什么信息？”

* 值向量：

\[
v_i
\]

包含实际信息。

得分：

\[
s_i=q^Tk_i
\]

衡量几何相似度。

点积大：

```
q  ---> 相同方向 ---> k_i

高注意力
```

点积小：

```
q ⟂ k_i

低注意力
```

# 2. 贝叶斯解释

贝叶斯观点认为：

注意力权重：

\[
a_i =
\frac{e^{q^Tk_i}}
{\sum_j e^{q^Tk_j}}
\]

看起来像后验概率：

\[
P(i|q)
\]

意思是：

> 给定当前查询，哪个token最可能相关？

贝叶斯规则：

\[
P(i|q)
======

\frac{P(q|i)P(i)}
{P(q)}
\]

Transformer注意力大致在做：

```
先验：
    哪些token可能重要？

似然：
    token i与查询q的兼容性如何？

后验：
    注意力权重
```

因此：

```
注意力
    =
对记忆的贝叶斯后验
```
