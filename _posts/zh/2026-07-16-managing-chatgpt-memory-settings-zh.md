**问题：当记忆功能启用时，如何修改 ChatGPT 的记忆？**

**回答：**

你可以通过两种方式管理记忆：

### 1. 直接要求 ChatGPT

使用明确的指令：

```
记住我更喜欢英文回答。
```

或

```
更新你的记忆：我不再使用 AMD MI50。删除这一假设。
```

或

```
忘记我拥有一块 AMD MI50 GPU。
```

如需更正，请尽量具体：

```
修改记忆：
- 旧：我拥有一块 AMD MI50 16GB。
- 新：我只是研究过 MI50，并没有实际拥有。
```

ChatGPT 应会更新/删除存储的内容。

---

### 2. 从设置中管理

打开：

```
ChatGPT → 个人资料图标 → 设置 → 个性化 → 管理记忆
```

在那里你可以：

* 查看已保存的记忆
* 删除单条记忆
* 清除所有记忆
* 开启/关闭记忆功能

---

### 3. 避免错误假设的最佳实践

记忆并非完整的对话数据库。它只存储看似有用的长期事实。有时可能会错误地进行概括。

使用这样的表述：

```
这只是一个研究课题，并非我实际拥有的东西。
```

或：

```
不要将此作为关于我的事实进行存储。
```

对于硬件实验，一个好的模式是：

```
更新记忆：
我讨论过许多用于研究的 GPU。除非我明确说购买，否则不要假设我拥有某个 GPU。
```

这样可以防止未来在处理你研究过的每个 GPU 时，都将它们当作你的硬件。
