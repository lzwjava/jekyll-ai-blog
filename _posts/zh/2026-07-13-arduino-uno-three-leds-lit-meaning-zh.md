CH340 已断开连接，**USB 上未检测到新的 Arduino 板**。因此，如果您看到一块物理 Uno 板上有 3 个 LED 亮起，说明该板要么通过另一根 USB 线供电，要么由外部电源供电，并且正在运行上次上传到它的任何程序。

让我解释一下**这 3 个亮着的 LED** 的含义：

### 在 Arduino Uno R3 板上

| LED | 标签 | 控制源 | 点亮时的可能原因 |
| ----- | ------ | -------- | ------------------ |
| **1** | **ON**（绿色） | 电源轨 | 板子有电 — 正常 |
| **2** | **L** / 引脚 13（黄色） | 您的程序（`LED_BUILTIN`） | 程序中 `digitalWrite(13, HIGH)` 持续为高 |
| **3** | **TX**（黄色） | ATmega16U2 串行芯片 | 串行数据正在发送 — 或 16U2 处于噪声状态 |
| 或 | **RX**（黄色） | ATmega16U2 串行芯片 | 串行数据正在接收 — 或 16U2 处于噪声状态 |

### 如果您看到 ON + L + TX 全部常亮

- **ON** = 正常，电源正常
- **L** = 您的程序将引脚 13 设为 HIGH，并且**没有运行闪烁循环** — 5Hz 的 100ms 闪烁实际上很快，但仍然可见为快速闪烁，而非常亮。如果是**常亮**，则可能是：
  - 板子在将引脚 13 设为 HIGH 后死机/崩溃
  - 或者板子上之前已烧录了不同的程序
- **TX** = 16U2 将其 TX 线拉高（可能是 USB 断开时的空闲线状态）

### 尝试以下步骤

1. **按下 Uno 板上的 RESET 按钮** — 如果程序正在运行，它会重启：L 应该开始明显闪烁
2. **重新插入 USB** 并检查：

   ```bash
   ls /dev/ttyACM*
   ```

   真正的 Uno 会显示为 `/dev/ttyACM0`，而非 `/dev/ttyUSB0`。
3. 如果板子出现，上传标准的 Blink 示例（1 秒延迟）以确认板子正常工作。
