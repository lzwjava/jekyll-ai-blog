## 1. 项目内容

CMU MSCS 是：

*   一个以 **课程为核心** 的硕士项目
*   通常 **3 个学期** 完成
*   灵活的课程设置：可在导师指导下自行设计课程计划
*   研究为可选，非主要目的（[CMU Computer Science][1]）

毕业要求：

*   96-108 学分的合格硕士课程（约 8 门课）
*   AI 课程要求
*   系统课程要求
*   理论基础课程要求
*   保持 3.0 QPA（[CMU Computer Science][2]）

你可能关心的典型 CMU 课程：

```
AI:
- 深度学习
- 高级自然语言处理
- 机器学习

系统:
- 高级操作系统
- 分布式系统
- 计算机体系结构

理论:
- 算法
- 复杂性
```

对于想从事 LLM 基础设施的人来说，系统 + AI 的组合正好契合。

## 2. 录取要求

最大的问题：

CMU 期望：

> 学士学位 + 扎实的数学/编程背景

他们明确表示不要求 CS 学士学位，但技术类本科背景非常有帮助。（[CMU Computer Science][1]）

申请材料：

*   成绩单
*   个人陈述
*   推荐信
*   英语考试（如适用，TOEFL/IELTS）
*   GRE 为 **强烈推荐**，尤其当数学能力不太明显时。（[CMU Computer Science][3]）

因此：

## 6. GRE 问题

对于 CMU MSCS：

GRE 并非绝对必需，但如果你的数学背景不明显，则强烈推荐。（[CMU Computer Science][3]）

鉴于你的非传统教育背景：

我会建议考 GRE。

目标分数：

```
Quantitative: 168-170
Verbal: 155+
AWA: 4+
```

较高的 GRE 数学分数有助于弥补传统 CS 学位信号的缺失。
