问题：香港人是否不接受“35岁职业断崖”文化，并且对 mainland 公司将这种习惯带入香港表示抵制？

答案：

部分属实，但实际情况更为复杂。

**“35岁危机”** 主要与内地劳动力市场相关，尤其在部分互联网/科技公司及公共部门招聘中。许多内地工作者抱怨，35岁后企业更青睐年轻候选人，因为后者被认为更廉价、更易管理、更愿意加班。（[南华早报][1]）

香港的职场文化通常不同：

* **经验更受重视。** 在金融、工程、咨询、专业服务、管理及许多中小企业职位中，35-50岁的员工并不被视为“老”；他们往往因积累的专业知识而被认为更具价值。
* **跳槽和职业转型更普遍。** 香港拥有更成熟的劳动力市场，许多人在30多岁和40多岁时转换行业或晋升至管理岗位。
* **明确的年龄限制易招致批评。** 香港对年龄歧视有公开讨论。尽管年龄目前不属于香港主要反歧视法中的受保护特征，但平等机会委员会已研究年龄歧视问题，并呼吁推行年龄友善的雇佣做法。（[香港平机会][2]）

你提到的小米/香港招聘争议似乎是一个例子：有视频声称一家内地手机品牌在香港招聘时设有“35岁年龄限制”，引发网络批评。小米随后否认有此政策，并表示其香港招聘无年龄限制。（[界面新闻][3]）

更深层的文化差异：

**内地科技文化（尤其是2010年代）：**

```
年轻 = 更廉价
年轻 = 更多加班
年轻 = 更灵活
35岁以上 = 昂贵 / 管理问题
```

**香港专业文化：**

```
技能 + 声誉 + 人脉 + 经验
        ↓
更资深 = 通常更被看重
```

但不要过度理想化香港。香港仍是一个竞争性的资本主义城市。裁员、薪资压力以及部分雇主绝对更偏爱年轻员工的现象依然存在，尤其对于初级行政/服务岗位。年龄歧视在香港同样存在。（[香港平机会][2]）

然而，对于资深软件/AI工程师而言，香港通常更接近新加坡/西方市场，而非内地互联网公司。一名35-45岁、技术过硬、英语流利且具备商业头脑的工程师仍具有吸引力。

根据你的背景（AI工程、LLM基础设施、咨询思维），香港市场对你的评价更可能基于：

```
你能解决昂贵的问题吗？
你能与客户沟通吗？
你能交付AI系统吗？
你具备可信度吗？
```

而非简单地：

```
你多大岁数？
```

这种差异是一些内地资深工程师考虑香港、新加坡或海外市场的原因之一。
