**问题：** 航嘉睿智300S电源是什么？

**答案：** **航嘉睿智300S**（Ruizhi 300S）是一款面向入门级台式电脑的电源供应器（PSU），由航嘉（Huntkey）制造，该公司成立于1995年，总部位于深圳。

以下是其官方页面上的主要规格：

| 规格 | 详情 |
| --- | --- |
| **额定功率** | 200W |
| **风扇尺寸** | 80mm (8CM) |
| **效率** | 78% |
| **输入电压** | 230V（固定，非宽幅） |
| **PFC类型** | 被动式PFC |
| **CPU接口** | 4-pin |
| **GPU接口** | 无 |
| **SATA接口** | 2个 |
| **大4-pin (Molex)** | 2个 |
| **主接口** | 20+4 PIN |
| **尺寸 (宽×高×深)** | 150 × 86 × 140 mm |

**关键要点：**

- 支持英特尔酷睿双核处理器，待机功耗低于3W（0.3A），采用20+4 PIN主接口，支持SATA硬盘或光驱。
- 尽管名称中有“300”，但**实际额定功率仅为200W**——仅适用于没有独立显卡的非常基础、低功耗的办公电脑。
- 这是一款入门级/预算型电源，不建议用于游戏或高性能配置。
