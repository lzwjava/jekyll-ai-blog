## 我作为人工智能工程师的视角

有趣的部分并非“王小川失败了”。

更深层的教训在于**基础模型战略**。

一家前沿模型公司面临不同的游戏规则：

```
模型质量
      |
      v
开发者采用
      |
      v
应用涌现
      |
      v
收入
```

许多公司犯的错误是：

```
传统初创思维：

寻找垂直市场
      |
构建人工智能解决方案
      |
销售给客户
```

但基础模型更接近于：

```
首先构建智能

然后智能创造市场
```

这就是OpenAI、Anthropic、DeepSeek等公司持续在模型能力上投入巨大资源的原因。

医疗人工智能可能规模巨大，因为：

+

## 创始人的教训

一种非常硅谷式的解读：

王小川在搜索时代取得成功，是因为：

```
搜索引擎：
信息检索问题

→ 工程 + 算法 + 产品
```

大语言模型时代：

```
智能规模化问题

→ 算力 + 数据 + 研究速度 + 生态系统
```

不同的游戏规则。

一位创始人可以在一种范式下世界一流，但依然需要重新学习下一种范式。

类似例子：

* Yahoo → Google（门户 → 搜索）
* Nokia → iPhone（硬件 → 软件生态系统）
* Intel → NVIDIA（中央处理器 → 加速计算）

问题不在于“王小川聪明吗？”

他显然很聪明。

问题是：

> 当人工智能范式改变时，他的心智模型更新得足够快吗？

这就是文章所讨论的。（[AITNT News][1]）
