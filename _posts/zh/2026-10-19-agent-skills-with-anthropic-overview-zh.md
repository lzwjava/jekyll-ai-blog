**问题：** 介绍 DeepLearning.AI 上的《Agent Skills with Anthropic》课程。

---

**回答：**

## 课程概述

**Agent Skills with Anthropic** 是由 DeepLearning.AI 与 Anthropic 合作推出的短期课程，由 **Elie Schoppik**（Anthropic 技术教育负责人）讲授。请注意：虽然该系列课程发布在 Andrew Ng 的 DeepLearning.AI 平台上，但本课程的具体讲师是 Elie Schoppik，而非 Andrew Ng 本人。

该课程于 **2026 年 1 月 28 日** 发布。

---

## 什么是"Skills"？

Skills 是**指令文件夹**，通过专业知识扩展智能体的能力。由于它们遵循开放标准格式，您可以一次构建，然后部署到任何兼容 skills 的智能体上。

---

## 您将学到什么

本课程涵盖：

- **为什么要使用 Skills**（第一部分和第二部分）
- **Skills 与 Tools、MCP 和 Subagents 的区别** — 理解概念上的差异
- **探索预构建的 Skills** — Anthropic 内置的 Excel、PowerPoint 和 Skill Creation 技能
- **创建自定义 Skills** — 用于代码生成、数据分析和研究工作流
- **在 Claude API、Claude Code 和 Claude Agent SDK 中使用 Skills**

---

## 目标受众与时长

本课程面向**所有希望通过可复用工作流和专业知识扩展智能体能力的 AI 构建者**。总时长约为 **2 小时 19 分钟**，属于入门级别。
