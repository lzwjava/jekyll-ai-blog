问题：如果我的Thermalright Frozen Prism 240 White ARGB AIO风扇持续发出噪音怎么办？

答案：

**240 mm AIO在待机状态下不应产生响亮的持续风扇噪音。** 负载下有一定风扇噪音是正常的，但如果风扇始终接近最高转速运行，通常是配置错误或系统确实温度过高。

以下是按可能性排序的常见原因：

| 原因               | 症状                         | 修复方法                                       |
| ------------------ | ---------------------------- | ---------------------------------------------- |
| 风扇曲线设为100%   | 待机时持续响亮的吹风声       | 在BIOS中配置PWM曲线                            |
| 风扇连接错误       | 风扇始终全速运转             | 将风扇连接到CPU_FAN或CPU_OPT PWM接口           |
| PWM被禁用          | 风扇忽略速度控制             | 将接口模式设为PWM而非DC                        |
| CPU温度过高        | 风扇持续加速                 | 检查硅脂、水泵、CPU负载                        |
| 水泵噪音           | 尖锐的嗡鸣声而非吹风声       | 如果支持，降低水泵转速                         |
| 原装风扇质量一般   | 电机或轴承噪音               | 更换风扇                                       |

### 1. 配置合理的风扇曲线

许多主板默认采用激进的散热策略。

合理的曲线示例：

```
CPU温度    风扇转速
30°C       20%
40°C       30%
50°C       45%
60°C       60%
70°C       80%
80°C       100%
```

对于现代CPU，这通常能让系统在浏览网页或编码时几乎静音。

---

### 2. 检查PWM模式

Thermalright风扇是**4针PWM**。

在BIOS中：

```
CPU_FAN
    模式 = PWM
```

如果主板将其检测为DC风扇，它们通常会保持更响。

---

### 3. 水泵转速

大多数AIO建议：

```
水泵：
    60–100%
```

某些水泵在特定转速下会因共振而产生更大噪音。

示例：

```
100% -> 安静
70%  -> 嗡嗡声
50%  -> 安静
```

值得测试几个固定转速。

---

### 4. Thermalright原装风扇

附带的120 mm风扇在**性价比方面表现不错**，但**并非最安静的型号**。

与高端风扇对比：

| 风扇                       | 噪音水平       |
| -------------------------- | -------------- |
| Thermalright原装           | 尚可           |

很多人保留冷排，后续只更换风扇。

---

### 5. 检查实际温度

如果你的CPU

```
待机：30–45°C
```

但风扇转速为1800 RPM，

这几乎肯定是风扇曲线问题，而非散热问题。

如果待机温度是

```
65–80°C
```

则需要排查：

* 冷头安装压力
* 硅脂
* 水泵运行
* 冷头底部的塑料保护膜是否忘记撕掉（出乎意料地常见）

---

### 6. 这款特定散热器如何？

**Thermalright Frozen Prism 240 White ARGB** 通常被认为是一款性价比不错的240 mm AIO。其散热性能在同价位中具有竞争力，但噪音表现并非其突出特点。标称最大风扇转速为**1850 RPM**，这意味着如果风扇长时间接近最大转速，你肯定会听到声音。

如果你的首要目标是**低噪音**，可以：

* 使用更温和的PWM风扇曲线。
* 启用主板风扇迟滞功能（避免转速快速变化）。
* 保留冷排，将原装风扇更换为更安静的型号。

### 应该有多响？

在正确配置的系统下：

* **待机（桌面、编码）：** 几乎听不见，或只有轻微的风声。
* **编译或游戏时：** 明显可闻但不会分散注意力。
* **压力测试（Cinebench、Prime95）：** 响亮是正常的，因为风扇可能接近1850 RPM。

如果散热器**始终100%很响**，即使CPU温度低且闲置，这并非预期行为，通常是由BIOS风扇设置或安装问题引起，而非散热器本身的问题。
