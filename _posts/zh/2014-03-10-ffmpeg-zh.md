## 背景

如果你还不熟悉 FFmpeg，可以先看看 [FFmpeg 常用命令](https://ffmpeg.org/ffmpeg.html)。研究它的功能——比如音视频合并、解码播放、片段提取、将多张图片合成带音频的视频、格式转换等——看看它能否为你的应用增添更多功能和乐趣。

例如，“配音秀”这类应用将配音或添加音轨变成了非常吸引人的用户功能。我们决定开发这样一个配音模块，并发现 FFmpeg 是 Android 上实现这些功能的强力候选。经过大约 3-4 天的尝试，网上很多教程都没有用——直到我偶然看到一篇题为“android usage of ffmpeg and how to invoke it”的教程，才最终成功移植。通过实验，我发现 **FFmpeg 1.2** 加上 **ndk-r9** 是我这边唯一能正常工作的组合。

## 方法

FFmpeg 是用 C 语言编写的，包含一个 `main()` 函数。我们的计划是：

1. 使用 Android NDK 编译出 `libffmpeg.so`。
2. 然后编译（并稍作修改）`ffmpeg.c`，将其 `main()` 函数重命名为 `video_merge(int argc, char **argv)`。这样我们就可以通过 JNI 直接调用它来执行视频合并等操作。

例如，要合并视频——类似于在终端中执行 `ffmpeg -i src1 -i src2 -y output`——你可以这样做：

```c
video_merge(5, argv);  // 其中 argv 模拟命令行参数
```

## 修改接口和 Android.mk

在创建 FFmpeg 的 JNI 接口时，你需要编写一个 `Android.mk` 文件来链接库并生成可用的 `.so` 库。网络上有些示例 `Android.mk` 文件可能在你特定的环境中无法工作。本质上，`Android.mk` 文件告诉 NDK 要编译哪些源文件以及要链接哪些库。

我的方法分两步：

1. 首先编译一个名为 `myffmpeg` 的共享库。
2. 在第二个模块（例如 `ffmpeg-jni`）中链接 `myffmpeg` 以生成最终的 `.so`。

请确保将编译好的 `libffmpeg.so` 放在 `jni` 目录下，这样链接器才能找到它。

## 调试 FFmpeg

将 FFmpeg 移植到 Android 后，你很可能通过 JNI 调用其函数。你可能需要调试 C 层，如果能看到详细的日志会轻松很多——就像在命令行中运行 FFmpeg 一样。

在 Eclipse 中，如果你按住 <kbd>Ctrl</kbd> 键并点击 `av_log` 这样的函数，它会跳转到 `ffmpeg/libavutil/log.c`，其中 `av_log_default_callback` 会调用 Android 的 `__android_log_print` 将日志输出到 Logcat。通过查看这些日志，你可以排查与不支持的格式、合并失败等相关的问题。

如果遇到崩溃，运行：

```bash
adb shell logcat | ndk-stack -sym obj/local/armeabi
```

查看异常发生在哪里。另外，请注意，如果 FFmpeg 原始的 `main()` 函数以 `exit(0)` 结束，你需要将其删除或注释掉，否则你的整个应用都会关闭。

### 内存泄漏与 Service 方案

有时，重复调用 FFmpeg 可能会引发类似 `"INVALID HEAP ADDRESS IN dlfree ffmpeg"` 的错误，这通常是由 FFmpeg 内部的内存泄漏导致的。一种解决方法是把整个合并/编码过程放到一个单独的 Service 中，并在完成后杀死该 Service 以释放内存。

```xml
<!-- AndroidManifest.xml -->
<service android:name=".FFmpegService" />
```

然后注册一个 `Receiver` 在合并完成后结束 Service。这样就能避免在同一进程中重复调用而无法正确清理的问题。

## 可能遇到的问题

1. **AAC 播放失败**
   某些设备（如小米 2s）可能无法使用默认的 `MediaPlayer` 播放 AAC 音频文件。
2. **编解码器支持**
   要支持 AMR-NB 或 MP3 等格式，必须在编译 FFmpeg 时启用它们。如果构建脚本找不到所需的库/头文件，构建会失败。
3. **合并速度慢**
   在一台设备上合并一个 10 秒的 1280×720 视频片段并添加音频，可能需要 30–60 秒，这可能会让用户感到不耐烦。你可以让用户在合并前预览录制的片段，或者将任务交给服务器处理。

对于“配音秀”这类应用来说：

1. 原始视频、字幕数据以及部分音频（中间某些片段被静音以便配音）通常提前下载好。
2. 用户录制自己的声音。要生成最终输出，只需将新录制的音频与预先生成的静音片段混合即可。
3. 如果本地合并太慢，你可以将所需数据上传到服务器，让服务器完成合并，然后下载最终文件。

## 在 Eclipse 中使用 NDK

你不需要每次都从命令行运行 `ndk-build`。在 Eclipse 中，只需右键点击项目，选择 **Android Tools → Add Native Support**，Eclipse 就会在运行项目时自动调用 `ndk-build`。

### 自动生成 JNI 头文件

手动创建 JNI 头文件很繁琐。你可以使用 `javah` 命令。在 Eclipse 中，你可以将其配置为外部工具，例如：

```bash
javah -jni -classpath bin/classes -d jni com.example.ffmpeg.MyFFmpeg
```

运行后，它会在 `jni` 文件夹中生成一个类似 `com_example_ffmpeg_MyFFmpeg.h` 的文件。然后，在你的 C 代码中 include 它，并实现相应的函数签名即可。
