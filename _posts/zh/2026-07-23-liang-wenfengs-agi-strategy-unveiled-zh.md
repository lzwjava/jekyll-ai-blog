**问题：梁文锋最近在融资会上说了什么？**

**回答：**

所谓的“4小时投资人会议”，指的是近期流传的一份DeepSeek非公开投资者沟通纪要。据报道，梁文锋在会中讨论了DeepSeek的愿景、AGI战略、开源理念、商业化以及为何公司选择了与典型初创公司不同的道路。所有流传的会议记录的真实性尚未得到独立验证，但多家中国科技媒体均报道了类似的主题。（[新浪财经][1]）

他传达的主要观点如下：

### 1. DeepSeek的首要目标并非利润最大化

他的核心论点：

> DeepSeek的目标不是“成为一家赚钱的公司”；目标是AGI。

据报道，他表示公司最初的动机并非IPO、估值或赚钱。早期团队成员加入是因为他们想推动AI向前发展，而不是出于经济激励。（[新浪][2]）

逻辑如下：

```
AGI成功
    ↓
创造巨大价值
    ↓
即使只占价值的一小部分也足够
    ↓
不为短期利润优化
```

---

### 2. “克制是一种策略”

被反复提及的观点之一：

> 放弃一些机会，会增加实现更大目标的概率。

据报道，他论证DeepSeek有意避免：

* 追逐用户数量
* 构建大量消费产品
* 封闭模型
* 进入每一个AI应用市场
* 立即制作视频生成/3D/世界模型

思路如下：

```
有限的团队 + 有限的注意力
        ↓
聚焦最难的问题
        ↓
更有可能实现AGI突破
```

（[凤凰网财经][3]）

---

### 3. 开源是战略，而非慈善

他的观点：

闭源：

```
公司拥有模型
公司占据应用层
```

开源：

```
每个人构建应用
生态成长
模型成为基础设施
```

据报道，他认为DeepSeek应专注于基础模型层，而让其他人创建应用。（[Reddit][4]）

---

### 4. AI进步路径：推理 → 智能体 → 自我改进

据传的路线图：

```
2024年：
推理 / 思维链

2025年：
智能体

未来：
持续学习

更远：
AI改进AI
```

重要的一点：他认为如今的聊天机器人仅是一个中间阶段。（[凤凰网财经][3]）

---

### 5. 他拒绝“AI天才创始人”叙事

另一个有趣的点：

据报道，他反驳了“DeepSeek是由少数几个天才创造”的观点。

传达的信息：

```
不是天才英雄故事

=
长期的工程文化
+
众多研究人员
+
耐心的实验
```

（[凤凰网财经][3]）

---

### 6. 融资理念

据报道，这次融资之所以不寻常，是因为DeepSeek此前一直强调独立性。新的融资被描述为精心选择合作伙伴，这些合作伙伴的利益与DeepSeek的长期目标一致，而非单纯接受最高估值。（[Reddit][4]）

---

我的解读：

梁文锋的策略非常接近“研究实验室 + 开放生态系统”的模式：

```
早期OpenAI：
研究 → GPT → 生态系统

DeepSeek：
研究 → 开放模型 → 生态系统 → AGI
```

赌注在于：

> 发现下一个智能范式的公司，比优化今天AI产品的公司捕获更多价值。

这就是为什么他的想法能引起Karpathy/早期OpenAI等人的共鸣：瓶颈不在于制造另一个SaaS包装器，而在于解决智力问题。（[Elsewhere News][5]）
