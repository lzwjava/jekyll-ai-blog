**问题：** 如何使用 Microsoft Visio？

**回答：**

Visio 是一款用于流程图、网络图、组织结构图、UML 等的图表绘制工具。以下是实用要点：

**入门**

- 打开 Visio → 选择模板（流程图、网络、UML 等）或空白画布
- 模板会在左侧面板预加载相关的形状模具

**核心工作流**

1. **拖拽形状**——从左侧模具面板拖到画布上
2. **连接形状**——将鼠标悬停在形状边缘，直到出现蓝色箭头/点，然后拖到另一个形状以创建连接线
3. **标注形状/连接线**——双击任意形状或线条即可输入文字
4. **格式化**——右键单击 → 设置形状格式，或使用功能区（填充、线条颜色、字体）

**关键面板**

- **形状面板（左侧）**——模具库；可使用搜索框搜索形状
- **页面选项卡（底部）**——多页图表
- **视图 → 连接点**——切换显示连接线的吸附位置

**实用快捷键**

| 操作 | 快捷键 |
| --- | --- |
| 平移 | 按住 Ctrl + 拖动 |
| 缩放 | Ctrl + 滚轮 |
| 全选 | Ctrl + A |
| 复制形状 | Ctrl + D |
| 自动连接 | 悬停在形状边缘 → 蓝色箭头 |
| 对齐/分布 | 开始选项卡 → 排列 |

**导入/导出**

- 导出：文件 → 导出 → PDF、PNG、SVG 或 VSDX
- 你也可以直接将 Visio 图表粘贴到 PowerPoint/Word 中

**针对你的工作流的实在建议：** 鉴于你以终端优先且正在构建 AI 工具，你可能会从 **draw.io（diagrams.net）**（免费，有 VS Code 扩展）、**Mermaid**（文本转图表，可嵌入 markdown/GitHub）或 **D2**（声明式图表语言）中获得更多价值。Visio 主要在你所处的企业环境以 `.vsdx` 文件为标准交换格式时有用。

如果你因工作不得不使用 Visio，需要知道的关键点是：使用**粘合点**（形状上的蓝色 X）而非浮动连接来连接形状，连接线的表现会更稳定——这是在移动形状时导致图表损坏的头号原因。
