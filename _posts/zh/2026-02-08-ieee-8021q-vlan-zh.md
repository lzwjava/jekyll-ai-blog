Question: 根据 IEEE 802.1Q 标准（定义了 Virtual LAN 环境下的 Ethernet frame 格式），用于指示发送该帧的主机所属 Virtual LAN 的 4-byte 字段是什么？

Answer:

正确答案是 **VLAN Tag**（中文技术资料中通常也称为 **VLAN标记** 或简称为 **Tag**）。

**Explanation:**

IEEE 802.1Q 是在 Ethernet networks 上实现 **VLANs** (Virtual Local Area Networks) 的工业标准。它定义了如何在标准 Ethernet frame 中插入一个额外的 4-byte 字段来携带 VLAN 信息。

这个 4-byte 字段在 802.1Q 标准中正式命名为 **Tag**，在网络领域中更常被称为 **VLAN Tag**。

带有 802.1Q 标记的 Ethernet frame 结构如下：

- Destination MAC Address (6 bytes)
- Source MAC Address (6 bytes)
- **Tag Protocol Identifier (TPID)** — 2 bytes (对于 802.1Q 始终为 0x8100)
- **Tag Control Information (TCI)** — 2 bytes，包含：
  - Priority Code Point (PCP) — 3 bits
  - Drop Eligible Indicator (DEI) — 1 bit (原为 CFI)
  - **VLAN Identifier (VID)** — 12 bits (这是实际的 VLAN 编号，0–4095)
- EtherType / Length (2 bytes)
- Payload
- Frame Check Sequence (FCS)

完整的 4-byte 标签头 (TPID + TCI) 就是识别该帧属于哪个 VLAN 的标识。因此，问题中所要求的字段是 **VLAN Tag** (或简称 **Tag**)。

在大多数中文教材、认证资料（如 CCNA, HCIA 等）和考试题目中，这个 4-byte 字段直接被称为 **VLAN标记** 或 **Tag**。

所以参考答案 "VLAN标记/Tag" 是正确的。
