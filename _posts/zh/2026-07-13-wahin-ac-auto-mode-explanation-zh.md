问题：华凌空调遥控器上的“自动”模式是如何工作的？

回答：

我在网上没有找到华凌的专用手册（华凌是美的的子品牌，其手册索引不太完善），因此以下是自动模式的一般工作原理——华凌遵循与市场上几乎所有分体式/窗式空调相同的标准逻辑，因为这类设备使用相同的通用微控制器参考设计（通常来自美的跨品牌使用的同一OEM固件供应商）。

**核心逻辑：**

```
每几秒循环一次：
    室温 = 读取传感器()
    如果室温 > 设定温度 + 滞回值：
        模式 = 制冷  # 压缩机运行，吹冷风
    否则如果 室温 < 设定温度 - 滞回值：
        模式 = 制热  # （仅限热泵型号；反转制冷剂循环）
    否则：
        压缩机 = 关闭
        风扇 = 低速 / 间歇  # 仅循环空气

    风扇速度 = 自动  # 设备根据 |室温 - 设定温度| 自行选择速度
```

在自动模式下无法覆盖的关键点：

1. **无法手动选择模式**——你不能强制选择制冷/制热/除湿/送风；设备根据温差自行选择。
2. **无法手动调节风扇速度**——风扇按钮通常被禁用或在自动模式下无实质作用；压缩机/风扇逻辑完全自动（这与YMGI手册的描述一致：选择自动模式时，空调将按出厂设置运行，设定温度不可调节且不会显示在屏幕上——不过某些品牌如三星，允许在自动模式下调整设定点）。
3. **滞回区间**——存在一个死区（通常在设定点周围1–2°C），防止压缩机频繁启停。一旦室温偏离该区间，压缩机重新启动——这与一般模式相符：达到目标温度后压缩机关闭，温度再次偏离设定点时压缩机重新启动。
4. **热泵型设备**会自动翻转制冷剂流向以在制冷和制热之间切换，非热泵型（仅制冷）设备则仅在制冷和送风之间交替。

**给你的实际建议：** 如果你希望获得确定性行为（例如，通过红外发射器+ESP32/Home Assistant来自动化控制空调，这符合你偏向代理/CLI工具的本能），不要使用自动模式——应捕获原始红外码以明确使用制冷/16°C/高风等。自动模式的实际阈值根本不在红外协议中；决策发生在室内机的固件中，而非遥控器，因此你无法从遥控器端检查或覆盖滞回逻辑。如果你愿意，我可以教你如何用ESP32+IRremoteESP8266嗅探并重放华凌的红外码，从而建立确定性自动化，而非依赖其自动模式的黑箱。
