**问题：** 以香港公司 → 美国子公司结构拓展 L-1 转调路径，尤其针对我的创业者/AI 工程师背景。

**回答：**

对你的情况而言，L-1 很有趣，因为你不仅仅是一名求职者。你已经拥有：

* 软件工程经验
* AI 咨询/商业方向
* 公司创办经验
* 国际客户潜力

L-1 基本上是一种 **“将你从你的外国公司调动到你的美国公司”** 的签证。

核心结构：

```
                所有权
                    |
                    |
        +-----------------------+
        |                       |
        v                       v

 香港公司                 美国公司
 (境外实体)                (子公司/关联公司)

        |
        |
 你在此工作 1 年以上
        |
        |
        v

       L-1 转调

        |
        |
        v

   在美国工作
   建立美国业务
```

美国实体和外国实体必须存在合格的关系（母公司、子公司、关联公司、分公司）。你通常需要在申请前的三年内为外国公司连续工作满一年。美国的职位必须是管理、行政或涉及专业知识。([Family Assistance Management][1])

---

# 1. 举个你的例子：AI 咨询公司

假设：

## 第一步：创立香港公司

例如：

```
LZW AI Limited
香港
```

业务：

```
AI 咨询
LLM 训练
AI 代理开发
软件外包
```

你成为：

```
创始人 / 董事
技术主管
```

你运营公司 12 个月以上：

* 合同
* 发票
* 客户
* 银行账户
* 会计记录
* 员工/承包商
* GitHub/开源活动

重要的是证明这是一家真实运营的公司，而不仅仅是空壳。

---

## 第二步：创立美国公司

例如：

```
LZW AI Inc.
美国特拉华州
```

关系：

```
LZW AI Limited 香港
        |
        |
        拥有
        |
        v
LZW AI Inc 美国
```

美国公司可以：

* 签署美国客户合同
* 雇佣美国员工
* 销售 AI 服务
* 开发产品

---

## 第三步：调动你自己

你的角色变化：

之前：

```
香港

创始人 + 工程师
编写代码
构建模型
```

之后：

```
美国

CEO / 技术总监

- 管理工程
- 招聘开发人员
- 管理美国客户
- 制定产品策略
- 监督承包商
```

这通常更接近 **L-1A**。

---

# 对你而言，L-1A 与 L-1B 的比较

## L-1A（经理/高管）

可能更适合你。

美国职位：

```
CEO
创始人
工程总监
AI 产品负责人
```

证据：

* 你拥有公司
* 你做决策
* 你管理人员
* 你控制预算
* 你在美国建立业务

最长停留时间可达 7 年。([LegalClarity][2])

---

## L-1B（专业知识）

替代方案：

```
AI 基础设施工程师
LLM 训练专家
```

论点：

“我对我们 AI 系统、模型、训练流程和专有技术的了解具有专业性。”

证据：

* 内部 AI 平台
* 专有代码
* 模型
* 使用你技术的客户

最长停留时间通常比 L-1A 短（通常可达 5 年）。([LegalClarity][2])

# “新办公室” L-1 案例

这是创业者喜欢的地方。

你不需要一个已经存在的庞大的美国公司。

你可以说：

```
香港公司
     |
     |
开设
     |
     v
美国办公室
```

USCIS 在满足要求的情况下，允许 L-1 受益人前来设立新的美国办公室。公司需要提供场所、合格关系以及开展业务能力的证据。([Family Assistance Management][1])

但挑战在于：

一个一人公司声称：

```
我昨天创立了特拉华 LLC。
给我 L-1。
```

这通常看起来很薄弱。

你需要的是：

```
香港公司
 |
 +-- 收入
 |
 +-- 客户
 |
 +-- 技术
 |
 +-- 运营

然后

向美国扩张
```

# 为什么这比 H-1B 更适合你的背景

H-1B：

```
你
 |
寻找雇主
 |
抽签
 |
担保
```

你依赖别人。

L-1：

```
你
 |
创办公司
 |
扩张公司
 |
调动自己
```

这与创始人特质更加契合。

---

# 更宏观的视角：L-1 → 绿卡

常见的创业者路径：

```
香港公司
        |
        |
       L-1A
        |
        |
 美国公司发展
        |
        |
      EB-1C
        |
        |
    绿卡
```

EB-1C 是跨国公司经理/高管的移民路径。L-1A 常被用作准备阶段，因为两者都聚焦于跨国管理角色。

---

# 我对你的评估

你最强有力的移民组合很可能是：

```
短期：
香港 AI 公司
        |
        |
L-1A 创业者路径


并行：
        |
        |
EB-2 NIW / O-1A 声誉建设


长期：
        |
        |
绿卡
```

关键心态：

不要创建一家“签证公司”。

创建一家真实的 AI 公司，它恰好也能开辟一条移民路径。

对于你的背景，难点不在于编码。而在于构建 **商业证据**：

```
客户
收入
员工
技术
公众声誉
```

这些资产对 L-1A 以及未来的 NIW/O-1A 申请都有帮助。
