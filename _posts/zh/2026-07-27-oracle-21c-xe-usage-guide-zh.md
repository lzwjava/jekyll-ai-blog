问题：**如何使用 Oracle Database 21c Express Edition (XE)？**

答案：

Oracle XE 21c 是一款轻量级的免费 Oracle 数据库，适用于开发/测试。典型的工作流程如下：

```
安装 XE
   ↓
启动数据库服务
   ↓
使用 SQL*Plus / SQL Developer 连接
   ↓
创建用户/模式
   ↓
创建表
   ↓
从 Java/Python 应用连接
```

Oracle XE 21c 会创建：

* 容器数据库：`XE`
* 可插拔数据库：`XEPDB1`
* 监听器：默认端口 `1521`
* Enterprise Manager Express：通常为 `5500`
  ([Oracle 文档][1])

---

## 1. 安装 Oracle Database XE 21c

### Windows

下载并运行安装程序：

```
setup.exe
```

以管理员身份运行。安装程序会创建数据库 SID：

```
XE
```

并提示您设置以下账户的密码：

```
SYS
SYSTEM
PDBADMIN
```

([Oracle 文档][2])

---

## 2. 检查 Oracle 服务

Windows：

```
Win + R

services.msc
```

找到：

```
OracleServiceXE
OracleOraDB21Home*TNSListener
```

启动它们。

([Oracle][3])

## 3. 使用 SQL*Plus 连接

打开终端：

```bash
sqlplus / as sysdba
```

您应该看到：

```
SQL>
```

检查数据库：

```sql
select name from v$database;
```

输出：

```
XE
```

检查 PDB：

```sql
show pdbs;
```

示例：

```
CON_ID CON_NAME   OPEN MODE

2      XEPDB1     READ WRITE
```

---

## 4. 如有需要，打开 PDB

Oracle 21c 使用多租户架构。

登录：

```sql
sqlplus / as sysdba
```

运行：

```sql
alter pluggable database XEPDB1 open;
```

设置为自动打开：

```sql
alter pluggable database XEPDB1 save state;
```

---

## 5. 创建应用程序用户

不要对应用程序使用 `SYSTEM`。

切换到 PDB：

```sql
alter session set container=XEPDB1;
```

创建用户：

```sql
create user app identified by password123;
```

授予权限：

```sql
grant connect, resource to app;
```

对于开发环境：

```sql
grant unlimited tablespace to app;
```

---

## 6. 以您的用户身份连接

连接字符串：

```
用户名: app
密码: password123

主机: localhost
端口: 1521
服务名: XEPDB1
```

SQL*Plus：

```bash
sqlplus app/password123@localhost:1521/XEPDB1
```

## 7. 创建表

示例：

```sql
create table users (
    id number generated by default as identity,
    name varchar2(100),
    email varchar2(200),
    created_at timestamp default current_timestamp,
    primary key(id)
);
```

插入数据：

```sql
insert into users(name,email)
values('Alice','alice@test.com');

commit;
```

查询：

```sql
select * from users;
```

## 8. 从 Java Spring Boot 使用 Oracle

Maven：

```xml
<dependency>
    <groupId>com.oracle.database.jdbc</groupId>
    <artifactId>ojdbc11</artifactId>
    <version>23.8.0.25.04</version>
</dependency>
```

`application.yml`

```yaml
spring:
  datasource:
    url: jdbc:oracle:thin:@localhost:1521/XEPDB1
    username: app
    password: password123
    driver-class-name: oracle.jdbc.OracleDriver

  jpa:
    database-platform: org.hibernate.dialect.OracleDialect
```

然后：

```java
@Entity
class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    Long id;

    String name;
}
```

## 11. Docker 选项（通常更简单）

对于开发，在 Docker 中使用 Oracle XE 通常更干净：

```bash
docker run \
-d \
--name oracle21c \
-p 1521:1521 \
-e ORACLE_PASSWORD=<PASSWORD> \
gvenzl/oracle-xe
```

连接：

```
localhost:1521/XEPDB1
```
