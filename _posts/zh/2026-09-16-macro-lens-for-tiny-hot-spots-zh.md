问题：**为什么FR03D需要微距镜头？**

答案：**因为热像仪的空间分辨率有限，而PCB上有很多微小元件。** 微距镜头可以让相机物理上更靠近被测物体，从而分辨出那些微小的热点。

可以这样理解：

```text
无微距镜头

相机
  ↓
 [ PCB ]
 ┌──────────────────────────────┐
 │  ▪ IC    ▪ C    ▪ R    ▪     │
 │                              │
 └──────────────────────────────┘

相机看到的：
      █████████████
      █████████████
      █████████████
```

在正常工作距离下，一个热像仪像素可能对应PCB上几毫米的区域。一个1毫米的过热点电容的发热，可能会**与周围的PCB温度平均在一起**。

有微距镜头时：

```text
相机
  ↓
  🔍
 ┌─────────────┐
 │  C  C  R    │
 │  ▓▓▓▓▓      │ ← 局部发热
 │  IC         │
 └─────────────┘
```

现在你可以分辨出：

```text
PCB：       38°C
电容：      41°C
IC：        43°C
MOSFET：    91°C  ← 明显热点
```

而不是看到一个模糊的约50°C的区域。

### 重要的区别

微距镜头**并不会提高热像仪传感器的原生分辨率**。

如果FR03D的传感器是240×240：

```text
传感器 = 240 × 240 像素
```

仍然是这个值，不会改变。

微距镜头改变的是**视场角/放大倍率**，因此这240×240个像素覆盖的物理面积更小：

```text
普通镜头：

240像素 → 约100 mm PCB宽度

微距镜头：

240像素 → 约20 mm PCB宽度
```

所以你是用覆盖面积换取**空间细节**。

### 针对你的使用场景

如果你要做的是：

**PC主板 / GPU / 电源 / 大面积PCB**

→ 微距镜头有用，但并非绝对必要。

**手机 / 笔记本主板 / 小型SMD元件**

→ **我强烈建议配备微距镜头。**

**查找哪个微小元件导致短路**

→ **微距镜头尤其有价值。**

最高效的操作流程是：

```text
1. 给板子上电
2. 注入电流
3. 扫描整块PCB
4. 找到发热区域
5. 装上微距镜头
6. 非常靠近目标
7. 识别具体元件
```

所以我认为微距镜头**不是用于"提高温度测量精度"的附件；它是用于提高微小物体空间分辨率的附件。**
