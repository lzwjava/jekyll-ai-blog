以下是测试 **8针PCIe输入端的12V电压** 的具体方法：

## 准备工作

- **万用表档位：** 直流电压 — 旋至 **20V DC**（“V⎓”区域，选择“20”，不是“200m”）
- **主板状态：** 已开机（通过转接卡或测试台连接正常工作的电源）
- **安全提示：** 不要让表笔同时接触相邻引脚 — 短路12V到地会打火

## 1. 找到8针接口

它是**显卡顶部边缘的8针电源插座**（PCIe电源线插入处）。从PCB背面看，可以看到**8个焊点** — 每行4个引脚，共2行。

## 2. 识别+12V和GND引脚

8针PCIe的引脚定义如下：

```
   [12V] [12V] [12V] [GND]     ← 顶行
   [GND] [GND] [GND] [GND]     ← 底行
```

实际上，标准PCIe 8针（从插头正面看，卡扣朝上）：

| 引脚 | 功能 |
| ----- | ---------- |
| 1 | +12V |
| 2 | +12V |
| 3 | +12V |
| 4 | GND（检测） |
| 5 | GND |
| 6 | GND |
| 7 | GND |
| 8 | GND |

所以：**3个引脚为+12V，5个引脚为GND。**

## 3. 测量方法

1. **黑色表笔** → 接接口上的任意**GND引脚**（或显卡金属挡板/安装孔的接地焊盘）
2. **红色表笔** → 依次接触**3个+12V引脚**，每次一个
3. 读取显示屏数值

**预期结果：约12.0V（11.4–12.6V均为正常）**

## 4. 结果解读

| 读数 | 含义 |
| --------- | --------- |
| **~12V** | ✅ 输入电源正常 — 继续测试5V/3.3V |
| **0V** | ❌ 显卡未收到电源 — 电源/线缆/接口/保险丝问题 |
| **<11V** | ⚠️ 电压下降 — 电源功率不足或线缆/接口接触不良 |

## 快速提示

- 如果使用**转接卡/测试台**，先确认电源线本身：直接测量电源端的8针插头（同样的测试），排除线缆故障。
- 有些显卡的8针接口在**侧面**而非顶部 — 沿着电源线插入的位置寻找。
- 如果显卡还有**6针**接口，也测量那里的所有+12V引脚。
