**什么是 Intel 第6代 CPU？**

**Intel 第6代 = Skylake**，主要在 **2015–2016 年**发布。

常见的桌面 CPU 有：

| CPU | 核心 / 线程 | 基础频率 | 插槽 |
| -------- | --------------: | ---------: | ------- |
| i3-6100 | 2 / 4 | 3.7 GHz | LGA1151 |
| i5-6500 | 4 / 4 | 3.2 GHz | LGA1151 |
| i5-6600K | 4 / 4 | 3.5 GHz | LGA1151 |
| i7-6700 | 4 / 8 | 3.4 GHz | LGA1151 |
| i7-6700K | 4 / 8 | 4.0 GHz | LGA1151 |

### 关于寻找主板

**第6代 = Skylake = LGA1151 + DDR4/DDR3L**

典型芯片组：

```text
H110
B150 / B250
H170 / H270
Z170 / Z270
```

一个重要的细节：**第6代和第7代都使用 LGA1151**，所以一块标称为：

> "支持 6/7 代 CPU"

的主板，通常意味着可以支持类似 **i5-6500 / i7-6700 + i5-7500 / i7-7700** 这样的 CPU。

对于你的 GPU 实验室使用场景，**Z170/Z270 主板特别值得关注**，因为它们往往比便宜的 H110/B150 主板拥有更多的 PCIe 配置选项。但拥有多个 x16 物理插槽**并不**自动意味着你可以用足够的 PCIe 资源或 Above 4G Decoding 来运行多个 GPU。

我还可以将 **Intel 第2代到第14代 CPU 映射到插槽 + 芯片组 + 内存 + PCIe 代数**，作为你购买二手硬件时的简洁参考。
