Question: Is it correct that when applying Yunnan Baiyao spray on the feet, we can tell if it is dry by swaying the feet — if we feel cold, it means the spray/liquid is still evaporating into air, and if we feel nothing, then it is already dry?

Answer: 

**是的，这种判断方法基本正确，且符合物理学原理。**

当你喷洒 Yunnan Baiyao（或几乎任何含有 Alcohol 成分的外用喷雾/液体）时，在晃动脚部时感受到的主要凉意源于 **evaporative cooling**（蒸发冷却）。

- 该喷雾通常含有高比例的 **ethanol/alcohol**（在包括 Yunnan Baiyao 各版本在内的许多中草药气雾剂中都很常见）。
- Alcohol 的挥发速度**远快于**水。
- 在蒸发过程中，它会吸收皮肤的热量 → 皮肤温度下降 → 你感知到**寒冷**。
- 当你轻轻摆动/晃动脚部时，你增加了 airflow（气流） → 蒸发速度加快 → 冷却效果感觉更强烈、更明显。

实际使用中的迹象：

- **摆动时有强烈/持续的寒冷感** = 表面仍有较多液体/alcohol → **尚未完全干燥**。
- **即使摆动脚部也感觉不到寒冷（或仅有极微弱的感觉）** = 大部分 volatile solvents（挥发性溶剂）已经蒸发 → 剩余物质主要是非挥发性的草药成分和成膜物质 → **基本已干**。

一些细微的补充：

- 极薄的涂层干燥速度极快（通常为 10–60 秒，取决于喷洒量、室温、湿度和 airflow）。
- 即使在强烈的寒冷感消失后，仍可能有一层极薄的薄膜在接下来的 30–120 秒内带有粘性。
- 如果你喷得**非常厚/湿**，即使在还很湿的时候你也可能只感到轻微的凉爽（因为较厚的液体深层蒸发较慢）。

但在正常使用情况下（每个区域喷洒 1–3 秒），你描述的方法 —— **摆动脚部并检查是否有明显的寒冷感** —— 是人们判断药用 alcohol 喷雾是否已充分干燥的最可靠且最常用的实际方法之一。

因此，从日常实用角度来看，你的理解是**正确**的。
