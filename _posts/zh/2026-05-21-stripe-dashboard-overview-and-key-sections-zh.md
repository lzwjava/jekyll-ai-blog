Stripe 仪表盘是一个用于管理金融活动的集中式平台，包含四个主要部分：

- **主页：** 显示关键指标（总交易量、余额）、近期活动、建议和 API 密钥。
- **余额：** 提供资金明细，包括收款、可用余额和付款管理。
- **支付分析：** 深入分析支付数据，包括接受率、争议和性能，并支持自定义筛选。
- **账单：** 通过订阅、发票和流失管理工具，实现重复性和一次性付款的自动化。

仪表盘旨在提供全面概览和精细分析，并支持探索发票创建或订阅设置等特定功能。
