**问题：** Bun.js 是否被 Anthropic 收购？

**回答：**

是的，**Bun 已被 Anthropic 正式收购**，该消息于 **2025 年 12 月 2 日** 宣布。这是 Anthropic 的 **首次收购**。

---

## 什么是 Bun？

Bun 由 Jarred Sumner 于 2021 年创立，作为 Node.js 的流行替代方案出现，为开发者提供集运行时、包管理、打包和测试于一体的解决方案。该工具包以其速度和轻量级架构而闻名，自 2022 年 7 月首次亮相以来，已在 GitHub 上累计获得超过 83,000 颗星。

---

## 为什么 Anthropic 要收购 Bun？

Claude Code 以 Bun 可执行文件的形式发布。自 2025 年 5 月全面上市以来，Claude Code 已从一个内部工程实验发展成为许多世界级领先企业（包括 Netflix、Spotify、KPMG、L'Oreal 和 Salesforce）的关键工具——而 Bun 在其整个发展过程中对扩展基础设施起到了关键作用。

Anthropic 的首次收购是一个 JavaScript 运行时。他们押注的是，最终胜出的 AI 公司将是最深入嵌入软件开发流程的那一家，而非拥有最佳聊天界面的那一家。

---

## 收购后 Bun 会怎样？

Anthropic 表示 Bun “将保持开源并采用 MIT 许可”，其面向 JavaScript 和 TypeScript 开发者的通用开发工作将继续进行。

同一个团队将继续全职投入 Bun 的开发，而现在他们可以获得世界顶级 AI 实验室的资源，而非仅仅依靠一家小型风投支持的初创公司。Bun 的路线图将继续聚焦于高性能 JavaScript 工具、Node.js 兼容性，以及取代 Node.js 成为 JavaScript 的默认服务端运行时。

---

## 关键背景：Claude Code 的增长

Claude Code 在 2025 年 5 月公开亮相后仅六个月，年化收入运行率就突破了 **10 亿美元**，使得此次收购成为巩固这一势头的战略举措。

---

## 潜在问题

未来可能会面临摩擦，因为 Bun 的原生代码是用 Zig 编写的——该语言的创始人 Andrew Kelley 在 Zig 贡献者的官方行为准则中制定了“严格的禁止 LLM/禁止 AI 政策”。许多收购开始时，相关方都会表示一切不会改变，但几年后往往并非如此。

---

**总结：** 是的，Bun 于 2025 年 12 月被 Anthropic 收购，旨在为 Claude Code 和未来的 AI 开发者工具提供支持，同时保持开源并采用 MIT 许可。
