### Linux 从不告诉新手的真相

与 Windows 不同，Linux **不会** 自动分区或自动挂载新硬盘。你得手动操作：

```bash
# 第一步：找到磁盘
lsblk

# 第二步：分区
sudo fdisk /dev/sdb   # 或使用 gdisk 进行 GPT 分区

# 第三步：格式化
sudo mkfs.ext4 /dev/sdb1

# 第四步：挂载
sudo mount /dev/sdb1 /mnt/data
```

如果你跳过了这些步骤——那么这块硬盘就只是 **存在** 而已，静静地待在那里，什么事都不做，就像一个昂贵的纸镇。
