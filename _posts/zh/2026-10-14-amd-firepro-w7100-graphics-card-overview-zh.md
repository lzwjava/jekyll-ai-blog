**问题：** AMD FirePro W7100 8GB 显卡是什么？

---

**答案：**

AMD FirePro W7100 是一款**专业工作站 GPU**，面向工程师、设计师以及媒体与娱乐专业人士。

**概述**

FirePro W7100 于 2014 年 8 月 12 日发布。它采用 28 nm 工艺，基于 **Tonga** 图形处理器（Tonga PRO GL 版本），芯片面积为 366 mm²，拥有 50 亿个晶体管。

**关键规格一览**

| 项目 | 详情 |
|---|---|
| GPU | Tonga PRO GL (GCN 3rd Gen) |
| Stream Processors | 1792 |
| Base Clock | 920 MHz |
| VRAM | 8 GB GDDR5 |
| Memory Bus | 256-bit |
| Memory Bandwidth | 160 GB/s |
| TDP | 150 W |
| Interface | PCIe 3.0 x16 |
| Display Outputs | 4× DisplayPort 1.2a |
| API Support | DirectX 12, OpenGL 4.5, OpenCL 2.0 |

**亮点**

- 它是全球首款配备 8 GB GPU 显存的专业单插槽显卡，并支持 4K 多显示器输出。

- **GeometryBoost** 允许 W7100 每个时钟周期处理四倍几何数据——与上一代相比，每个时钟周期的图元和顶点处理速率翻倍。

- 通过 DisplayPort 输出，它支持**多达 4 台显示器**，每台分辨率可达 4K，并在搭配支持的显示器时提供完整的 **10-bit-per-channel（每通道 10 位）色彩**。

- 它支持 **DirectGMA**（直接图形内存访问）和 **Adaptive-Sync / FreeSync** 技术，在旋转模型或观看视频时可提供无撕裂、无抖动的图像质量。

- 计算性能达到 **3.3 TFLOPs**（单精度）/ **0.206 TFLOPs**（双精度），并通过 PCIe 3.0 ×16 连接。

**目标应用场景**

- CAD / 3D 建模（大型装配）
- 4K 视频编辑和调色
- 多显示器专业工作站
- 科学与工程可视化
