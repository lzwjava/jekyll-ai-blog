**问题：** 如何从 MSI MAG B760M Mortar 主板上移除 BIOS/CMOS 电池并释放残余电量？目前电源供应器（PSU）发出嗡嗡声/啸叫声，且无显示输出。

**回答：**

这是针对系统无法开机自检（POST）且电源供应器发出线圈啸叫/嗡嗡声时的标准故障排除步骤——这通常意味着电源供应器正在尝试供电，但某些部件（VRM、显卡辅助供电、或 CMOS 状态异常）导致其出错，或者主板未能进入 POST 阶段。以下是针对 B760M Mortar 主板进行 CMOS 重置+完全放电的具体操作步骤：

### 1. 首先完全断电（关键——这是“放电”步骤）

```
1. 通过背面的物理开关关闭电源供应器
2. 将电源供应器从墙壁插座上完全拔下
3. 按住机箱电源按钮 10-15 秒
   （这将消耗主板/电源供应器上的电容电量——这就是“放电”步骤）
```

在拔掉电源插头后按下电源按钮，可以释放主板供电电路中的残余电容电量。如果不拔掉墙壁电源，即使系统处于“关闭”状态，待机电压（+5VSB）仍然带电。

### 2. 取出 CMOS 电池

在 MAG B760M Mortar 主板上，CMOS 电池（CR2032）位于主板右下角附近，PCIe 插槽下方，SATA 接口旁边。步骤如下：

```
1. 确保电源供应器已拔下，且已完成放电（已执行步骤 1）
2. 找到圆形银色纽扣电池（CR2032）
3. 推动其旁边的金属卡扣——电池会弹起
4. 将电池完全取出
5. 等待 5-10 分钟（你原先感觉的 5 分钟是正确的）
6. 重新插入电池，正极（+）朝上（与之前方向相同）
```

### 3. 替代方法：JBAT1 跳线（更快，效果相同）

除了取出电池，MSI 主板在电池附近还有一个 `JBAT1`（清除 CMOS）2 针跳线，PCB 上有时会丝印有“Clear CMOS”字样：

```
1. 电源供应器拔下，已完成放电（步骤 1）
2. 找到 JBAT1 针脚（请查阅你的主板说明书 PDF——在 B760M Mortar 说明书中搜索“JBAT1”）
3. 用螺丝刀尖端短接这两个针脚 5-10 秒钟
   （或使用附带的跳线帽，短接 5-10 秒后移除）
```

这与取出电池的效果完全一致——将 CMOS/BIOS 设置重置为出厂默认值——但速度更快，且不会丢失小电池或弄弯固定卡扣的风险。

### 4. 重新组装后

```
1. 重新插入电池 / 移除跳线短接
2. 重新连接 24 针 ATX 电源线和 8 针 CPU EPS 电源线
3. 重新连接显卡的 PCIe 8 针/6+2 针电源线（你已确认这已经连接——很好，这对于显卡获取超过插槽 75W 的电力是必需的）
4. 将电源供应器插回墙壁插座，打开电源供应器开关
5. 开机——清除 CMOS 后的首次启动会显示“CMOS 校验和错误，请按 F1”或类似信息→只需进入 BIOS 并加载默认设置，然后保存并退出
```

### 电源供应器发出嗡嗡声最可能意味着什么

开机时出现“滋滋滋”（线圈啸叫）且无显示，通常由以下原因之一引起：
- **VRM/MOSFET 线圈啸叫**：在负载尖峰时产生——通常无害，但有时表明主板正在吸取电力并在 POST 前出错（常见于 CMOS 状态异常、内存接触不良或显卡供电问题）
- **显卡在 PCIe 插槽中未完全插到位**：重新插拔显卡，你应该能听到/感觉到锁扣发出“咔哒”声
- **内存插错插槽**：B760M Mortar 需要在特定插槽才能单条启动（通常是插槽 2，请检查 CPU 附近丝印的 A2/B2 标识）
- **电源供应器本身故障**：如果 CMOS 重置、内存重新插拔、显卡重新插拔后嗡嗡声仍然存在，请尝试使用其他电源供应器（如有的话）进行测试

### 如果 CMOS 重置无法解决问题，请执行以下快速诊断检查清单

```
1. 移除显卡，尝试通过主板上的 HDMI/DP 接口使用核显（如果 CPU 支持）启动
2. 如果核显工作正常→则为显卡或显卡电源线问题
3. 如果核显也不工作→在 A2 插槽中仅插入一条内存，移除其他所有内存
4. 检查 24 针和 8 针 CPU 电源线是否已完全插紧（常见的半插问题会导致嗡嗡声）
5. 查看 B760M Mortar 主板上的调试 LED/调试代码显示——它有 CPU/DRAM/VGA/BOOT LED 指示灯序列，能精确告知你哪个阶段失败
```

位于 24 针电源接口附近的调试 LED（CPU、DRAM、VGA、BOOT）是你最好的诊断工具——开机时检查哪个灯常亮，这能直接告诉你哪里出了问题，而不是仅凭嗡嗡声猜测。
