这是来自**美国国务院DS-160在线签证申请系统**的页面。它告知您DS-160申请表已开始创建，并提供后续继续填写所需的信息。

### 1. 申请编号

> **您的申请编号为：XXXXX**

**申请编号**是您的DS-160表格的唯一识别码。

您需要该编号来：

* 后续继续填写未完成的DS-160申请
* 检索已保存的申请
* 在网站出现问题时恢复申请
* 提交后获取确认页

示例：

```
申请编号：AA00BBBBCC
安全问题答案：您选择的答案
```

请保密此编号。它并非您的签证号码，仅为DS-160表格的识别码。

---

### 2. 安全问题

系统要求您选择：

```
安全问题：
[ 下拉菜单 ]

答案：
[ 您的答案 ]
```

这类似于恢复密码功能。

示例：

问题：

```
您第一只宠物的名字是什么？
```

答案：

```
 Lucky
```

之后重新打开DS-160时，您需要：

1. 申请编号
2. 完全一致的安全问题答案

重要提示：

* 某些系统区分大小写。
* 请准确记住拼写。
* 不要使用您会忘记的答案。

### 4. "打印申请编号"

您应点击此按钮并保存。

建议：

* 截屏保存
* 保存为PDF文件
* 存放在安全位置

示例文件：

```
DS160_申请编号_2026.pdf
```

---

### 5. 60天有效期限

提示信息：

> 超过六十（60）天未更新或未提交的申请将被清除

这意味着：

如果您开始填写DS-160但**60天内**没有任何操作，未完成的申请可能会被删除。

示例：

* 开始时间：2026年8月19日
* 直至约2026年10月18日无更新
* 系统可能将其删除
* 您需要重新创建新的DS-160

保存申请并**不**等于提交。

---

### 6. 后续流程

DS-160申请流程：

```
创建DS-160
       │
       ▼
填写个人信息
       │
       ▼
核对答案
       │
       ▼
电子签名并提交
       │
       ▼
获取DS-160确认页（含条形码）
       │
       ▼
支付签证费
       │
       ▼
预约美国使/领馆面试
       │
       ▼
签证面试
```

针对您的情况（中国公民在中国申请），提交DS-160后，通常需按照您将进行面试的使/领馆（例如广州、上海、北京等）的指示操作。

### 实用建议

在填写大量信息之前：

* 保存您的**申请编号**
* 选择一个多年后仍能记住的安全问题
* 定期下载/保存您的DS-160数据
* 确保护照信息与护照完全一致

您的DS-160尚未提交，目前仅处于初始阶段。
