问题：如何准备香港优秀人才入境计划（QMAS）申请所需文件？

回答：

对于QMAS，您主要需要准备证明**身份、计分资格、财政能力、学历、工作履历、语言能力及成就**的文件。作为中国内地居民，典型的文件包应如下所示：

---

## 1. 有效旅行证件

对于内地申请人：

准备：

* [ ] 中国护照（如有）

  * 个人信息页
  * 所有含签证/盖章的页面（如有）
* [ ] 如无护照/旅行证件：

  * 内地居民身份证

建议：

* 扫描为彩色PDF
* 保留原件以备后续入境要求

---

## 2. 近期照片

准备：

* [ ] 符合香港入境处要求的照片

通常要求：

* 护照规格照片
* 近期（一般6个月内）
* 纯色背景
* 电子文件 + 打印件

---

## 3. 香港身份证（如有）

如无香港身份证：

* 留空/不适用

如曾在港居住：

* 复印身份证正反面

---

# 4. 个人资产净值证明

目的：
证明您有能力负担本人及受养人在港生活，无需依赖公共援助。

可能文件：

### 银行资产

* [ ] 银行流水单（通常近几个月）
* [ ] 银行存款证明
* [ ] 投资账户对账单

示例：

* 现金存款
* 股票
* 债券
* 基金

### 房产

如拥有房产：

* [ ] 房产证
* [ ] 购房合同
* [ ] 估值报告（可选）

针对您的情况：

* 广州房产可计入
* 需披露按揭情况

示例：

```
房产价值：
2,000,000 人民币

按揭：
900,000 人民币

净资产：
1,100,000 人民币
```

---

# 5. 学历/专业资格

准备：

### 学位

* [ ] 大学毕业证书
* [ ] 学位证书
* [ ] 成绩单

如为自考学历：

* [ ] 毕业证书
* [ ] 成绩单

如大学未毕业：

* 通常不计入资格

### 专业证书

示例：

* 云计算认证
* AI/ML证书
* 软件类认证

通常不计主要分数，但可辅助个人背景。

---

# 6. 工作经验证明

这对QMAS非常重要。

准备：

每家公司需提供：

* [ ] 工作证明
* [ ] 劳动合同
* [ ] 社保缴纳记录
* [ ] 工资单
* [ ] 纳税记录

工作证明应包含：

```
公司名称
您的职位
在职期间
工作职责
薪资
公司盖章/签名
```

示例：

```
LeanCloud
软件工程师
2016-2018

职责：
- 后端开发
- 云平台工程
- API设计
```

如为自由职业/自营公司：

准备：

* [ ] 商业登记证
* [ ] 客户合同
* [ ] 发票
* [ ] 付款记录
* [ ] 项目说明

---

# 7. 公司相关证明

适用于曾任职或拥有公司的申请人。

雇主方面：

* [ ] 公司注册信息
* [ ] 公司网站
* [ ] 营业执照
* [ ] 雇佣确认函

自有AI公司方面：

准备：

* [ ] 公司注册证书
* [ ] 客户合同
* [ ] 收入记录
* [ ] 网站
* [ ] 产品截图
* [ ] 相关媒体报道/文章（如有）

---

# 8. 收入记录证明

准备：

* [ ] 个人所得税纳税记录
* [ ] 工资单
* [ ] 银行工资流水
* [ ] 劳动合同

中国地区：

有用文件：

* 个人所得税纳税记录
* 社保缴纳记录
* 银行流水

尽量体现：

* 稳定收入
* 高级技术职位
* 专业价值

---

# 9. 语言能力证明

认可示例：

英语：

* [ ] 雅思
* [ ] 托福

中国申请人可使用：

* [ ] 雅思6.5（您现有的成绩很有用）

保留：

* 成绩单
* 证书

---

# 10. 成就证明

此部分可获额外加分。

可能证据：

## 技术成就

* [ ] 专利
* [ ] 发表论文
* [ ] 开源项目
* [ ] 训练的AI模型
* [ ] 技术博客

针对您的背景，可提供：

* GitHub个人主页
* AI训练项目
* GPT/nanoGPT训练报告
* 技术博客统计数据
* 会议演讲
* 开源贡献

示例：

```
在分布式GPU基础设施上训练了GPT-2 760M模型。

证据：
- GitHub仓库
- 训练日志
- 博客文章
```

---

# 11. 其他辅助文件

内地居民通常需提供：

* [ ] 户口簿
* [ ] 内地身份证

家庭方面：

因您提到妻子和两个女儿：

后续申请受养人签证时准备：

* 结婚证
* 子女出生证明
* 家庭关系证明

针对您的个人背景，QMAS中最具优势的部分可能是：

1. **工作经验**（11年软件/AI领域）
2. **收入记录**
3. **雅思6.5分**
4. **AI成就/开源/训练项目**
5. **资产净值证明**

薄弱环节可能是**正式学历**，因为QMAS对认可的学术资质给予较高权重。完成自考学历将有助于提升申请竞争力。
