问题：如何在 FNIRSI DSO153 便携示波器上连接红黑表笔？

答案：

关键要点：

* **黑色表笔 = 地/参考点（GND）**
* **红色表笔 = 测量点**
* 示波器测量的是 **电压差：`V(红) − V(黑)`**

例如，要测量一个 **12 V DC 电源轨**：

```text
12 V 电源 / 主板

       +12V ────────────────●  ← 红色表笔
                            │
       GND ────────────────●  ← 黑色表笔
```

屏幕应显示约 **+12 V DC**。

### 针对您的主板/GPU 实验

如果主板已通电，您想测量一个 GPU 电源轨：

```text
万用表 / 示波器

黑色 ───────── GND
红色 ───────── 测试点 / 电感 / 电容正极
```

良好的接地点通常包括：

* 主板金属屏蔽罩 / 接地的机箱
* 电源 GND
* 大电容负极
* 明确标注 `GND` 的测试点
* PCIe 插槽地引脚

然后将 **红色表笔** 接触您想检查的电压轨。

例如：

```text
             GPU
       ┌───────────────┐
       │               │
       │   VRM         │
       │  [电感]       │
       │    ●──────────┤ ← 红色表笔
       │               │
       └───────────────┘
             │
             GND ──────── 黑色表笔
```

### 与万用表的重要区别

使用 **万用表**，您可以将表笔跨接在两个点之间，读取直流电压。

而使用 **示波器**，通常需要：

```text
黑色 → 稳定的 GND
红色 → 信号 / 电源轨
```

这样 DSO153 就能显示 **随时间变化的波形**，而不仅仅是电压值。

例如，一个开关稳压器的波形大致如下：

```text
电压
  ^
  |    ┌───┐   ┌───┐   ┌───┐
  |    │   │   │   │   │   │
  |────┘   └───┘   └───┘   └───→ 时间
  |
  +---------------------------->
```

### ⚠️ 一个非常重要的警告

**不要随意将黑色表笔接到任意点上。**

在普通接地的直流主板上，找到 GND 很简单。但如果您正在测量 **市电交流、隔离电源初级侧或其他高压电路**，表笔连接可能导致短路或触电危险。

对于您当前的 **Lenovo L-IG41M3 + GT730 维修实验**，请从 **低压直流侧** 开始：

```text
黑色 → 主板 GND
红色 → 12V / 5V / 3.3V / GPU VRM 测试点
```
