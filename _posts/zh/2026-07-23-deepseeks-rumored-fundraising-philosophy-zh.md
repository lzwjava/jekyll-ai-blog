## 1. 那场“4小时投资者会议”

故事称，DeepSeek 在 5 月中旬左右举行了一场线上投资者会议。

形式：

```
梁文锋 演示
        ↓
投资者提问
        ↓
梁文锋 深入回答
```

有趣之处在于对梁文锋的刻画：

* 语速缓慢
* 并非典型富有魅力的创始人
* 耐心回答技术与业务问题
* 不试图兜售宏大的创业故事

文章强调了对比：

典型融资场景：

```
创始人：
“我们将主导市场。
我们有巨大的增长。
我们需要资金。”
```

DeepSeek 的风格：

```
创始人：
“AGI 是一件大事。
资金/资源是次要的。
团队才是最重要的资产。”
```

## 2. “少即是多”的理念

文章称梁文锋反复强调：

> 只关注与提升智能相关的事情。

意思是：

DeepSeek 并非试图成为：

* AI SaaS 公司
* AI 应用商店
* 企业咨询公司
* 消费级聊天机器人公司

而是：

```
研究 → 模型能力 → AGI
```

一种非常研究实验室式的理念。

这与以下机构的思维相似：

* OpenAI 早期
* Google DeepMind

使命主导着业务优化。

## 3. 融资规模变化：50亿 → 15亿人民币

文章称：

初始要求：

```
单一投资者：
>= 50亿人民币

结构：
纯人民币资金
不接受联合投资
```

问题：

很少有中国基金能单笔出资 50 亿人民币。

所以最终：

```
最低出资额：
约 15亿人民币

结构更灵活
```

暗示：

DeepSeek 拥有异常强的议价能力。

通常初创公司会问：

> “请投资我们。”

这个故事表明 DeepSeek 更接近：

> “我们在选择战略合作伙伴。”

大多数初创公司担心：

```

DeepSeek 担心的是：

```

稀缺资源不是资金。

而是：

```
顶尖 AI 研究人才 + 积累的知识
```

## 6. 为什么投资者感到兴奋

文章将 DeepSeek 描述得几乎像一家“使命驱动型公司”。

投资逻辑：

不是：

```
AI 聊天机器人市场份额
+
收入增长
+
企业合同
```

而是：

```
如果 AGI 带来巨大的经济变革，
最接近前沿智能的公司
将捕获巨大价值。
```

一种 VC 式的期望值计算：

```
成功概率 × AGI 市场价值

即使概率很低，
上行空间也巨大。
```

## 我的技术解读

对于 AI 工程师来说，有趣的信号不是融资本身。

而是这一点：

```
资本正在变得次要。

前沿 AI 的优势 =
    研究人员
  + 算法洞见
  + 训练基础设施
  + 迭代速度
  + 文化
```

DeepSeek 的策略更接近一个**研究实验室**，而非普通初创公司。

这也是小团队能够竞争的原因：

一个 50 人的精英 AI 团队可以胜过 5000 人的组织，如果：

```
研究质量 > 组织规模
```

这个融资故事本质上是在说：

> 投资者买的不是今天的收入。他们买的是靠近前沿的席位。
