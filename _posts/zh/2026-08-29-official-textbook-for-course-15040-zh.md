### 📗 必用教材

**《习近平新时代中国特色社会主义思想概论》**

| 项目 | 详情 |
|------|------|
| **全称** | 习近平新时代中国特色社会主义思想概论 |
| **英文名称** | Introduction to Xi Jinping Thought on Socialism with Chinese Characteristics for a New Era |
| **出版社** | 高等教育出版社 + 人民出版社（联合出版） |
| **版本** | 2023年版（当前标准版） |
| **组织编写单位** | 中宣部 + 教育部 |

本书是第一部**全面系统**阐述习近平新时代中国特色社会主义思想的统一教材，是高校思想政治理论课的**权威文本**。全书由导论、**17个主体章节**及结语构成。每章均包含学习目标、本章小结、思考题，以及习近平重要论述摘编、知识拓展和图表。

---

### 📚 教材结构

本教材充分体现了马克思主义中国化时代化的最新成果、新时代伟大实践与变革，以及学术共识研究成果。

17个章节大致涵盖以下主题：

| 章节 | 主题 |
|------|------|
| 导论 | 习近平新时代中国特色社会主义思想概述 |
| 第1–3章 | 新时代、历史使命、两个一百年奋斗目标 |
| 第4–6章 | 五位一体总体布局 |
| 第7–9章 | 四个全面战略布局 |
| 第10–12章 | 经济、创新、乡村振兴 |
| 第13–14章 | 文化、社会治理 |
| 第15–16章 | 生态文明、国防 |
| 第17章 | 党的建设（从严治党） |
| 结语 | 构建人类命运共同体 |
