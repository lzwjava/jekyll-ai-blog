问题：解释一个 IP 子网，比如 `130.22.14.192/26`。

答案：

一个 IPv4 子网通常写成：

```text
IP地址 / 前缀长度
```

例如：

```text
130.22.14.192/26
```

`/26` 表示**前 26 位是网络部分**，剩余的 **6 位用于主机**。

### 1. IPv4 是 32 位

```text
130.22.14.192
│    │  │  │
│    │  │  └── 8 位
│    │  └───── 8 位
│    └──────── 8 位
└───────────── 8 位

总计 = 32 位
```

将地址转换为二进制：

```text
130       .22        .14        .192
10000010  .00010110 .00001110 .11000000
```

使用 `/26`：

```text
10000010.00010110.00001110.11000000
<-------- 26 个网络位 -------->
                              <-6->
                               主机
```

所以子网掩码是：

```text
/26
```

等同于：

```text
255.255.255.192
```

因为：

```text
11111111.11111111.11111111.11000000
   255      255      255      192
```

### 2. 有多少个 IP？

有 6 个主机位：

```text
2^6 = 64
```

所以 `/26` 每个子网提供 **64 个地址**。

对于 `130.22.14.192/26`：

```text
网络地址：  130.22.14.192
广播地址：  130.22.14.255

地址范围：
130.22.14.192  ← 网络地址
130.22.14.193  ← 第一个可用主机
...
130.22.14.254  ← 最后一个可用主机
130.22.14.255  ← 广播地址
```

传统上，这意味着：

```text
总共 64 个地址
62 个可用主机地址
```

因为网络地址和广播地址不会分配给普通主机。

### 3. 为什么 `/26` 从 `.192` 开始？

有趣的部分是最后一个八位组：

```text
/26 → 掩码 = 255.255.255.192
```

块大小是：

```text
256 - 192 = 64
```

因此，`/24` 中的 `/26` 子网是：

```text
130.22.14.0/26
130.22.14.64/26
130.22.14.128/26
130.22.14.192/26
```

每个包含 64 个地址：

```text
0   ───── 63
64  ───── 127
128 ───── 191
192 ───── 255
```

所以：

```text
130.22.14.192/26
```

意思是：

```text
网络地址 = 130.22.14.192
范围   = 130.22.14.192 → 130.22.14.255
主机   = 130.22.14.193 → 130.22.14.254
广播地址 = 130.22.14.255
```

### 4. 通用公式

对于：

```text
A.B.C.D/n
```

`n` 告诉你有多少位属于网络。

```text
网络位 = n
主机位    = 32 - n
地址数    = 2^(32-n)
```

示例：

| CIDR | 主机位 | 总 IP 数 | 典型可用数 |
| ----- | --------: | --------: | -------------: |
| `/24` | 8 | 256 | 254 |
| `/25` | 7 | 128 | 126 |
| `/26` | 6 | 64 | 62 |
| `/27` | 5 | 32 | 30 |
| `/28` | 4 | 16 | 14 |
| `/30` | 2 | 4 | 2 |
| `/32` | 0 | 1 | 1* |

关键的思维模型是：

```text
/24
11111111.11111111.11111111.00000000
|------ 网络 ------|主机位|

/26
11111111.11111111.11111111.11000000
|---------- 网络 ---------|主机|
```

所以 **增加 `/N` 会使子网变小**：

```text
/24 → 256 个 IP
/25 → 128 个 IP
/26 →  64 个 IP
/27 →  32 个 IP
```
