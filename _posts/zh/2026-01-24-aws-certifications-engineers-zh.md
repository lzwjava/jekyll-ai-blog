Question: 作为一名 Software Engineer，我可以考取哪些 AWS 认证？

Answer:

作为一名 **Software Engineer**，AWS 认证可以帮助验证你的云端技能，特别是在 AWS 上构建、部署和维护应用程序的能力。以下是 2026 年最相关的认证，大致按推荐的学习顺序排列：

### Foundational (如果你刚接触 AWS，这是一个很好的起点)

- **AWS Certified Cloud Practitioner**
  涵盖基础的 AWS 服务、云概念、定价、安全和架构基础。
  几乎是所有人的理想首选认证 —— 不需要深入的经验。
  (考试代码：CLF-C02)

- **AWS Certified AI Practitioner** (同样属于 Foundational)
  专注于 AI/ML 概念和 AWS AI 服务 —— 如果你有兴趣在应用程序中添加 AI 功能，这将非常有用。

### Associate Level (对 Software Engineer 最实用)

- **AWS Certified Developer – Associate**
  **这通常是给 Software Engineer / Developer 的首选推荐。**
  验证使用 AWS SDKs、CLI、APIs（Lambda, API Gateway, DynamoDB, S3 等）、CI/CD 以及安全最佳实践来开发、测试、部署和调试云原生应用程序的技能。
  (考试代码：DVA-C02 或更高版本)

- **AWS Certified Solutions Architect – Associate**
  非常受欢迎且认可度极高。专注于设计可扩展、高可用、具有成本效益的系统。
  许多 Software Engineer 参加此考试，因为它提供了强大的架构知识，对 System Design 面试和构建真实应用非常有帮助。
  在简历上通常被认为比单纯的 Developer Associate 更具深度和价值。

### Professional Level (进阶 —— 建议在获得 1-2 个 Associate 认证及相关经验后考取)

- **AWS Certified DevOps Engineer – Professional**
  非常适合处理 CI/CD、Infrastructure as Code (IaC)、自动化、监控和运营的 Software Engineer。
  涵盖高级主题，如 CodePipeline, CodeBuild, CloudFormation, OpsWorks, Elastic Beanstalk 等。

- **AWS Certified Solutions Architect – Professional**
  深度的架构专业知识 —— 非常受尊重，但挑战性很大。

### Specialty (根据你的专业领域选择)

- **AWS Certified Machine Learning – Specialty** — 如果你构建 ML 模型
- **AWS Certified Security – Specialty** — 如果你对安全感兴趣
- **AWS Certified Data Engineer – Associate** — 如果你大量处理 Data Pipelines
- **AWS Certified Advanced Networking – Specialty** — 对纯 Software Engineer 来说较少见

### 针对大多数 Software Engineer 的推荐路径 (2026)

1. AWS Certified Cloud Practitioner（可选，如果你是云端新手，它会很有帮助）
2. AWS Certified Developer – Associate **或** AWS Certified Solutions Architect – Associate（很多人两者都会考）
3. 随后：AWS Certified DevOps Engineer – Professional（如果你喜欢自动化和部署）
   或 AWS Certified Solutions Architect – Professional（如果你的目标是高级/架构师角色）

**Developer – Associate** 与编写代码和在 AWS 上构建应用程序结合得最紧密，而 **Solutions Architect – Associate** 通常在求职时能打开更多大门。

所有认证有效期为 **3 年**，可以通过重新参加考试或获得更高等级的认证来进行续期。

可以开始通过 AWS Skill Builder 上的免费数字培训、官方模拟考试和动手实验室（构建真实项目！）进行准备。
