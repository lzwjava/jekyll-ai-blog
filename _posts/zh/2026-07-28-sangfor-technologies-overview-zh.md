## 概述

深信服科技（Sangfor Technologies）是一家成立于2000年的中国企业IT公司，专注于：

1. **网络安全**
2. **云计算**
3. **IT基础设施**
4. **企业数字化转型**

它在深圳证券交易所上市（股票代码：300454）。该公司主要为企事业单位、政府、高校、银行及大型组织提供产品。（[深信服][1]）

## 1. 网络安全业务（智安全）

这是深信服起家的领域。

主要产品：

### 下一代防火墙（NGAF）

等效分类：

```
传统防火墙
        |
        v
下一代防火墙
        |
        +-- 应用识别
        +-- 入侵防御
        +-- 恶意软件检测
        +-- 威胁情报
```

部署于企业网络边界。

示例：

```
互联网
   |
   |
[深信服防火墙]
   |
企业局域网
   |
服务器/个人电脑
```

---

### EasyConnect / SSL VPN

这可能是你看到的那个产品。

深信服 EasyConnect 提供对企业网络的远程访问。

典型架构：

```
员工笔记本电脑
       |
       |
   EasyConnect VPN
       |
       |
 深信服VPN网关
       |
       |
 企业网络
       |
       +-- RDP服务器
       +-- 内部Web应用
       +-- 数据库
```

常见于：

* 银行
* 政府
* 高校
* 大型企业

它允许员工远程工作，同时执行安全策略。（[深信服科技][2]）

## 2. 云与基础设施业务（信服云）

深信服与以下公司在同一大市场竞争：

* VMware
* Nutanix
* OpenStack
* 华为云Stack

主要技术：

### HCI（超融合基础设施）

传统架构：

```
服务器
 |
 +-- CPU
 +-- 存储阵列
 +-- 网络
```

HCI架构：

```
节点1
 CPU + 内存 + 磁盘

节点2
 CPU + 内存 + 磁盘

节点3
 CPU + 内存 + 磁盘


软件层：
----------------
虚拟化
存储
网络
管理
----------------
```

产品：

* 深信服 HCI
* aStor 存储
* 云平台

（[深信服科技][3]）
