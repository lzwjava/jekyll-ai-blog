**问题：** Intel Core i5-6600 和 i5-6600K 有什么区别？

**回答：**

两者都是 **Skylake 架构、4 核 / 4 线程、LGA1151** 接口的 CPU。最大的区别在于 **K 代表解锁倍频**。

|                 |   i5-6600 |     i5-6600K |
| --------------- | --------: | -----------: |
| 核心 / 线程      |     4 / 4 |        4 / 4 |
| 基础频率         |   3.3 GHz |  **3.5 GHz** |
| 最大睿频         |   3.9 GHz |  **3.9 GHz** |
| 倍频             |    锁定   | **未锁定**   |
| TDP              |      65 W |         91 W |
| 接口             |   LGA1151 |      LGA1151 |
| 集成显卡         |    HD 530 |       HD 530 |
| 内存支持         | DDR4-2133 |    DDR4-2133 |

### 针对您的 ReBarUEFI + Intel Arc 使用场景

如果价格差距不大，我会选择 **6600K**。

但不要指望 `K` 本身对 Arc 显卡有太大影响。关键在于两者都是 Skylake CPU，可以在相应的 Z170/Z270 平台上工作。

6600K 的真正优势在于：

```text
i5-6600
  3.3 → 3.9 GHz
  锁定倍频

i5-6600K
  3.5 → 3.9 GHz
  未锁定倍频
       ↓
   超频
       ↓
   ~4.4–4.6 GHz
```

在 **Z170/Z270 主板**上，6600K 因此可以超频，前提是 BIOS/微码配置允许。

不过，如果您只是**买一颗便宜的二手 CPU 专门喂 Arc 显卡**，那么如果 **6600 便宜得多，它往往是更有性价比的选择**。GPU/ReBAR 配置比微小的默认频率差异重要得多。
