问题：成熟主要是指更多地考虑他人的生活和视角吗？

回答：

是的，这是成熟的一个重要部分。一个成熟的人通常会形成一个更广泛的**世界模型**：不仅包括“我想要什么？”，还包括“从他人的角度看，现实是什么样的？”

一个简单的进展过程：

```
儿童：
    我的感受就是世界。
    “我不开心，所以一切都是糟糕的。”

年轻人：
    我的目标和选择很重要。
    “我需要建立自己的生活。”

成熟的成年人：
    多个世界同时存在。
    “他人有自己的历史、限制、梦想、恐惧和痛苦。”
```

关键能力是**换位思考**。

例如：

* 一个担心考试的中国20岁学生
* 一个担心家庭开支的40岁工厂工人
* 一个担心健康和人生意义的60岁老人
* 一个担心裁员的硅谷软件工程师
* 一个担心天气和收成的异国农民
* 一个担心生存的初创公司创始人

他们都在玩完全不同的“游戏”。他们的问题无法直接比较，因为他们的限制、机会和期望各不相同。

一个成熟的人开始看到：

```
人 = 生物学 + 家庭 + 文化 + 教育 + 经济 + 运气 + 选择 + 时间
```

而不是：

```
人 = 他们当前的行为
```

例如，一个看似懒惰的人可能具有：

* 抑郁，
* 教育不足，
* 家庭压力，
* 缺乏机会，
* 不同的价值观。

一个看似成功的人可能具有：

* 隐藏的焦虑，
* 孤独，
* 家庭问题，
* 害怕失去地位。

然而，成熟不仅仅是同理心。它还包括：

1. **看清现实**

   理解激励因素、系统、经济学、人类心理。

2. **接受权衡**

   每一种人生道路都有代价。

   研究人员可能有智力自由但钱较少。
   创始人可能有财富潜力但不确定性巨大。
   稳定工作的员工可能有安全感但自主性较少。

3. **减少自我**

   年轻时，人们常常认为：

   > “我的经历是正常的经历。”

   成熟是意识到：

   > “我的经历只是巨大分布中的一个样本。”

一个好的思维练习是：

“想象我生来就是这个人。”

改变：

* 国家
* 家庭
* 智力
* 健康
* 历史时期
* 经济环境

我还会做出同样的选择吗？

答案通常是否定的。

这并不意味着变得被动或认同所有人。你仍然可以评判行为并做出决定。这意味着你区分了：

```
理解一个人
        ≠
赞同他们所做的一切
```

许多伟大的思想家都培养了这种能力。阅读历史、传记、文学，以及与不同背景的人交流，可以扩展这个“人类模拟器”。

在人工智能时代，这种能力可能变得更加宝贵，因为信息和推理越来越自动化。人类可能更多地通过以下方面来区分：

* 判断力，
* 价值观，
* 情感理解，
* 知道什么对他人重要。
