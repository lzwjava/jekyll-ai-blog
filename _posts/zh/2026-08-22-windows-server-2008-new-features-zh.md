**问题：** Windows Server 2008 新增了哪些功能？

**回答：**

Windows Server 2008 引入了以下主要新功能：

1.  **Server Core** – 一种最小安装选项，无图形界面，减少了攻击面和维护开销。
2.  **Windows PowerShell** – 用于系统管理自动化的强大命令行外壳和脚本环境。
3.  **虚拟化（Hyper-V）** – 内置的 Hypervisor 技术，可直接在服务器上运行虚拟机。
4.  **网络访问保护（NAP）** – 一种策略实施平台，根据客户端运行状态控制网络访问。
5.  **只读域控制器（RODC）** – 托管 Active Directory 只读副本的域控制器，适用于分支机构。
6.  **具有高级安全性的 Windows 防火墙** – 集成的双向防火墙，支持 IPsec 和精细的规则管理。
7.  **服务器管理器** – 统一的管理控制台，可一览配置角色、功能和服务器运行状态。
8.  **增强的终端服务** – 包括 RemoteApp、TS Gateway 和 TS Web Access 在内的改进，用于灵活的远程应用程序交付。
9.  **下一代加密技术（CNG）** – 支持现代算法的加密 API，取代了旧的 CryptoAPI。
