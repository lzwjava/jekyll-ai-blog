**问题：** 如何在 VSCode 中触发“使用 5.4 nano 的 Codex 智能体”架构？我只看到智能体模式和提问模式。

**答案：**

看到 **智能体** 和 **提问** 模式，说明你已经处于 **正确的界面**。
但 **Codex 与非 Codex** 的区别 **并非一个单独的按钮** —— 它是由 **模型选择** 控制的。

你触发的是：

```
智能体模式
   + 模型 = codex / 5.4 / 5.4 nano
```

这就变成了：

```
VSCode
 └─ Copilot Chat
     └─ 智能体模式
         └─ 模型 (5.4 nano / codex / 等)
```

---

# 逐步操作：如何触发 Codex 智能体

在 VSCode 中执行以下操作：

### 1. 打开 Copilot Chat

```
Cmd/Ctrl + Shift + I
```

你应该能看到：

* 提问
* 智能体

切换到 **智能体**

---

### 2. 更改模型（这是关键步骤）

聊天面板顶部 → 模型下拉菜单

示例：

```
GPT-5.4
GPT-5.4 mini
GPT-5.4 nano
Claude
Codex
```

选择：

```
5.4 nano
```

现在智能体模式将使用：

```
智能体规划器 + 5.4 nano 执行器
```

这正是：

```
Copilot
  → 智能体
     → 5.4 nano
```

---

# 如果你看不到模型选择器

企业组织可能：

* 锁定模型选择
* 设置默认模型
* 隐藏下拉菜单

那么智能体模式已经使用了 **管理员配置的模型**。

你可以检查：

```
VSCode 设置
→ GitHub Copilot Chat
→ Model
```

或者

```
命令面板
→ "Copilot: Change Chat Model"
```

---

# 提问模式与智能体模式的区别（重要）

提问模式：

* 单次响应
* 不编辑文件
* 无规划

智能体模式：

* 多步骤计划
* 编辑文件
* 运行命令
* 迭代式

Codex 仅在 **智能体模式** 下激活

所以你已经找对地方了。

---

# 如何确认你正在使用智能体（Codex 风格）

当智能体激活时，你会看到：

* “正在规划…”
* “正在分析代码库…”
* “正在编辑 4 个文件…”
* “正在运行命令…”

这就是 Codex 风格的行为。

---

# 如果你想要完整的 Codex 行为

使用类似这样的提示：

```
将整个代码库中的 Angular 14 升级到 17
```

或者

```
重构所有服务以使用 fetch 替代 axios
```

提问模式不会这样做
智能体模式会
