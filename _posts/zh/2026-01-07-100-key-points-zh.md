### 模块 1：浏览器与编辑器基础操作

1.  **主流引擎：** Chrome 使用 Blink，Firefox 使用 Gecko，Edge 使用 Blink（此前为 EdgeHTML）。
2.  **浏览器渲染：** 浏览器解释代码的方式存在差异，因此需要进行 "Cross-browser testing"。
3.  **缓存：** 清除浏览器缓存 (Ctrl+Shift+Del) 对于查看 CSS 的实时更新至关重要。
4.  **Developer Tools：** 使用 `F12` 检查元素、调试 CSS 并查看控制台。
5.  **VS Code 安装：** 考试推荐使用的主要编辑器。
6.  **扩展：** 安装 "Chinese (Simplified)" 用于界面中文化，安装 "JS-CSS-HTML Formatter" 用于代码美化。
7.  **Live Server：** 一个常用的插件，用于在浏览器中即时预览网页。
8.  **文件命名：** 使用小写字母、数字或下划线；避免使用空格和中文字符。
9.  **保存文件：** 养成频繁使用 `Ctrl + S` 的习惯；考试要求特定的命名规则（例如 `姓名_html.html`）。
10. **VS Code 快捷键：** `! + Tab` 可快速生成 HTML5 模板（Boilerplate）。
11. **自动缩进：** 使用 `Shift + Alt + F` 格式化混乱的代码。
12. **多光标编辑：** 按住 `Alt` 并点击可以同时在多个位置输入。
13. **注释切换：** `Ctrl + /` 是 HTML 和 CSS 中添加/删除注释的快捷键。
14. **项目结构：** 将图片存放在 `images/` 文件夹，样式存放在 `css/` 文件夹，以保持组织有序。

### 模块 2：HTML5 页面设计（结构）

15. **Doctype 声明：** `<!DOCTYPE html>` 告诉浏览器文档类型是 HTML5。
16. **语言属性：** `<html lang="zh-CN">` 辅助搜索引擎和屏幕阅读器。
17. **字符编码：** `<meta charset="UTF-8">` 防止文本乱码。
18. **Head 部分：** `<head>` 包含 Metadata、标题和链接，不包含可见内容。
19. **Body 部分：** `<body>` 包含网页的所有可见内容。
20. **语义化标签：** `<header>`、`<footer>`、`<nav>`、`<aside>` 和 `<article>` 可提高 SEO 和可访问性。
21. **标题：** `<h1>` 到 `<h6>` 定义层级；`<h1>` 在每个页面中应只使用一次。
22. **段落：** `<p>` 是用于文本块的 Block-level 元素。
23. **换行：** `<br>` 是用于单行换行的 Void element（无闭合标签）。
24. **水平分割线：** `<hr>` 创建主题分隔或水平线。
25. **预格式化文本：** `<pre>` 保留代码中原样写入的空格和换行。
26. **加粗与斜体：** 语义上优先使用 `<strong>` 和 `<em>`，而非 `<b>` 和 `<i>`。
27. **区块：** `<div>` 是用于布局的最通用容器（Block container）。
28. **行内容器：** `<span>` 是用于为特定文本部分设置样式的 Inline container。
29. **相对路径：** `./` 代表当前文件夹，`../` 代表向上移动一级。
30. **绝对路径：** 完整的连接，如 `https://www.google.com`。
31. **超链接：** `<a href="url">` 创建链接。
32. **Target 属性：** `target="_blank"` 在新标签页中打开链接；`_self` 是默认值。
33. **锚点链接：** 使用 `<a href="#id">` 跳转到具有特定 ID 的元素。
34. **图像标签：** `<img src="..." alt="...">` 用于显示图形。
35. **Alt 属性：** 如果图片加载失败，`alt` 提供替代文本（对可访问性至关重要）。
36. **图像尺寸：** `width` 和 `height` 属性（可在 HTML 或 CSS 中设置）。
37. **图像格式：** 照片使用 JPG，透明图使用 PNG，简单动画使用 GIF。
38. **图像映射：** `<map>` 和 `<area>` 允许在单个图像上创建可点击区域。
39. **表格基础：** `<table>`、`<tr>`（行）、`<td>`（单元格）。
40. **表头：** `<th>` 定义表头单元格，默认通常为加粗并居中。
41. **单元格合并：** `colspan` 合并列；`rowspan` 合并行。
42. **表格标题：** `<caption>` 为表格提供标题。
43. **表单容器：** `<form action="server-url" method="get/post">`。
44. **文本输入：** `<input type="text">` 和 `<input type="password">`。
45. **单选按钮：** `<input type="radio" name="group">`；`name` 必须相同才能实现分组。
46. **复选框：** `<input type="checkbox">` 允许选择多项。
47. **下拉列表：** `<select>` 配合 `<option>` 子元素。
48. **文本域：** `<textarea>` 用于多行用户输入。
49. **提交按钮：** `<input type="submit">` 或 `<button type="submit">`。
50. **占位符：** `placeholder="..."` 在输入框内提供提示。
51. **必填属性：** `required` 如果字段为空则阻止表单提交。
52. **HTML5 新输入类型：** `email`、`url`、`number`、`date` 和 `color`。
53. **音频：** `<audio src="..." controls>` 用于播放音乐。
54. **视频：** `<video src="..." controls width="...">` 用于播放影片。
55. **自动播放与循环：** 媒体属性；注意浏览器通常会拦截自动播放的音频。
56. **列表：** `<ul>`（无序）和 `<ol>`（有序）都使用 `<li>`（列表项）。

### 模块 3：CSS3 基础与样式（表现）

57. **行内 CSS：** HTML 标签内的 `style="..."` 属性。
58. **内部 CSS：** `<head>` 内部的 `<style>` 块。
59. **外部 CSS：** `<link rel="stylesheet" href="style.css">`（最佳实践）。
60. **元素选择器：** 选择某种类型的所有标签（例如 `p { ... }`）。
61. **类选择器：** `.classname`（可重复用于多个元素）。
62. **ID 选择器：** `#idname`（仅用于唯一元素）。
63. **后代选择器：** `div p` 选择 div 内部的所有段落。
64. **优先级优先级：** Inline > ID > Class > Element。
65. **颜色关键字：** `red`、`blue`、`transparent`。
66. **十六进制颜色：** `#RRGGBB`（例如白色为 `#FFFFFF`）。
67. **RGB/RGBA：** `rgba(255, 0, 0, 0.5)` 支持透明度 (Alpha)。
68. **字体库：** `font-family: "Microsoft YaHei", sans-serif;`。
69. **字体大小：** 固定大小使用 `px`，相对大小使用 `em`/`rem`。
70. **字体粗细：** `bold` 或数值（如 `700`）。
71. **文本对齐：** `left`、`right`、`center` 或 `justify`。
72. **文本装饰：** `none`（用于移除链接下划线）或 `underline`。
73. **行高：** `line-height` 控制文本行之间的间距。
74. **文本缩进：** `text-indent: 2em;` 常用于段落首行缩进。
75. **盒模型：** 由 Content（内容）、Padding（内边距）、Border（边框）和 Margin（外边距）组成。
76. **宽度/高度：** 定义内容区域的大小。
77. **Padding：** 内容与边框之间的内部空间。
78. **Margin：** 边框与其他元素之间的外部空间。
79. **边框样式：** `solid`、`dashed`、`dotted` 或 `double`。
80. **圆角：** `border-radius: 50%;` 使元素变圆。
81. **背景颜色：** `background-color` 填充元素区域。
82. **背景图像：** `background-image: url('bg.jpg');`。
83. **背景重复：** `no-repeat`、`repeat-x` 或 `repeat-y`。
84. **背景尺寸：** `cover`（填满区域）或 `contain`（显示全图）。
85. **Float：** `float: left;` 或 `right;` 用于简单的水平布局。
86. **Clearfix：** 使用 `clear: both;` 防止元素环绕浮动。
87. **Display 属性：** `block`、`inline`、`inline-block` 或 `none`。
88. **可见性：** `visibility: hidden;` 隐藏元素但保留其空间。
89. **伪类：** `:hover`（鼠标悬停）、`:active`（点击中）、`:visited`。
90. **列表样式：** `list-style: none;` 移除 `<ul>` 的默认项目符号。

### 模块 4：综合网页开发（布局）

91. **DIV+CSS 概念：** 使用 `div` 负责结构，`CSS` 负责所有视觉样式。
92. **居中块元素：** 使用 `width` 和 `margin: 0 auto;`。
93. **导航栏：** 通常使用 `<ul>` 和 `<li>` 配合 `float: left` 或 `display: inline-block` 构建。
94. **相对定位：** `position: relative;` 相对于其正常位置移动元素。
95. **绝对定位：** `position: absolute;` 相对于最近的已定位祖先元素移动元素。
96. **固定定位：** `position: fixed;` 即使滚动也停留加速在同一位置。
97. **Z-index：** 控制定位元素的堆叠顺序（数值越大越靠上）。
98. **盒尺寸：** `box-sizing: border-box;` 将 Padding 和 Border 包含在总宽度内。
99. **Flexbox 基础：** `display: flex;` 是现代易用的对齐方式。
100. **页面结构：** 标准页面具有一个包裹 `.header`、`.nav`、`.main` 和 `.footer` 的 `.container`。
