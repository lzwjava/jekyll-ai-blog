## 问题：保罗·格雷厄姆在2014年斯坦福讲座中说的“不要在大学期间创业”是什么意思？

在2014年斯坦福大学**《如何开始创业》第三讲：创业之前**中，保罗·格雷厄姆认为，**大学通常不是开始真正创业的正确时机**。（[YouTube][1]）

他的理由有些反直觉：

> 真正的创业会占据你的全部生活。如果你认真开始创业，你就不再是学生了。

（[VideoToBe][2]）

他的主要观点：

---

## 1. 创业无法像学校科目那样被学习

大学可以教授：

* 创业词汇
* 融资概念
* 商业计划
* 创业历史

但重要的知识是：

> “用户真正需要什么？”

这无法从讲座中学到。你只能通过构建产品、与用户交流、发布、失败和迭代来学习。（[Paul Graham][3]）

创业不像微积分：

```
class Startup101:
    学习理论
    通过考试
    成为创始人
```

它更接近于：

```
构建产品
    ↓
用户拒绝
    ↓
与用户交流
    ↓
修改产品
    ↓
重复100次
```

---

## 2. 真正的创业与学生身份相冲突

格雷厄姆的核心论点：

> 你无法真正以学生身份创业，因为如果你认真创业，你就不再是学生了。（[VideoToBe][2]）

为什么？

因为创业需要：

* 极度专注
* 与客户沟通
* 招募人才
* 调试问题
* 融资
* 在不确定性中生存

例如：

一名大学生：

```
周一：
  上课

周二：
  作业

周三：
  创业会议
```

一位创始人：

```
每天：
  怎么获取用户？
  用户为什么流失？
  为什么收入为零？
  怎么活下去？
```

第二种状态会吞噬一切。

---

## 3. 20岁拥有独特的机会

这是更深层的观点。

格雷厄姆说，创办公司不仅仅关乎金钱。它关乎设计一种好的生活。

在20岁时，你可以：

* 探索各种兴趣
* 深入学习
* 廉价旅行
* 做一些奇怪的副项目
* 结识许多不同的人

这些机会会在以下情况后消失：

* 结婚
* 生孩子
* 财务责任
* 公司承诺

他将其比作一种搜索策略：

```
20岁：

广度优先搜索

尝试很多事情：
 ├── 生物学
 ├── 编程
 ├── 艺术
 ├── 人工智能
 ├── 创业
 └── 旅行


之后：

深度优先搜索

选择一条有希望的路：
 └── 公司
      └── 产品
           └── 市场
```

在20岁时，他认为探索的预期价值更高。（[Xiaolai][4]）

---

## 4. 例外：那些无法避免创业的人

格雷厄姆并不是说：

> “任何人都不应该在大学期间创办公司。”

存在例外：

* 比尔·盖茨
* 马克·扎克伯格
* 一些YC创始人

但他的建议是：

如果你正在问：

> “我现在应该创业吗？”

那你很可能应该等待。

因为真正非凡的创始人通常想的是：

> “我必须做这件事。我无法不去做。”

YC的理念变成了：只资助那些无法被说服不创业的本科生。（[Paul Graham][5]）

---

## 5. 学生应该做什么？

他的建议：

不要学习“创业技巧”。

而要：

### 学习有力量的东西

例如：

* 计算机科学
* 数学
* 生物学
* 人工智能
* 物理学
* 设计

### 研究有趣的问题

好的创业公司通常始于副项目：

```
有趣的问题
        |
        |
        v
小项目
        |
        |
        v
用户喜欢它
        |
        |
        v
创业公司
```

例如：

* Google 始于一个研究项目
* Facebook 始于一个学生项目
* Apple 始于黑客们自己动手做东西

想法应该从深层知识中自然产生，而不是来自：

> “让我们想一个创业点子吧。”

（[Paul Graham][3]）

---

## 对于今天的人工智能工程师来说，现代解读是：

保罗·格雷厄姆的建议非常适用于当今的AI时代：

不好的做法：

```
大学生：
“让我们创建一个AI创业公司，因为AI很火。”
```

更好的做法：

```
学习：
  Transformers
  分布式训练
  智能体
  机器人学
  生物学

构建：
  工具
  实验
  开源项目

注意到：
  “很多人都有这个痛苦的问题”

然后：
  创业
```

今天最好的AI公司通常始于研究人员/构建者解决一个他们亲身理解的问题。
