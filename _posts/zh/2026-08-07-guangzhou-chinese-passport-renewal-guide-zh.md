问题：如何在广州换发中国护照？

回答：

如果你指的是在广州**换发中国普通护照（中华人民共和国普通护照）**，流程如下：

## 1. 检查资格

如果出现以下情况，你可以申请**护照换发**：

* 护照即将到期
* 护照页满
* 护照损坏
* 个人信息变更
* 其他需要换发的情况

广州在出入境管理部门受理中国公民的申请。([Gaj][1])

---

## 2. 预约

推荐方式：

### 方式A — 微信/支付宝

搜索：

```
移民局12367
```

或

```
穗好办
```

然后：

```
出入境
→ 中国公民出入境预约
→ 护照
```

广州市政务服务平台通过“穗好办”App和小程序支持护照预约。([Guangzhou Gov Data Admin][2])

---

## 3. 前往出入境管理部门

携带：

* 中国身份证
* 旧护照
* 预约信息
* 护照照片/照片采集（通常可以现场办理）
* 其他根据情况需要的文件

广州市主要市民出入境服务大厅：

广州市公安局出入境管理局接待大厅

还有各区级的出入境大厅。([Gaj][3])

---

## 4. 现场流程

通常：

```
排队/核验预约
        ↓
拍照+指纹采集
        ↓
提交申请
        ↓
缴纳费用
        ↓
领取回执
```

你可以选择：

* 自行领取
* 邮寄（EMS）

---

## 5. 办理时间

通常需要：

```
7–15 个工作日
```

但节假日和工作量可能会影响。

---

## 6. 费用

普通护照换发通常费用为：

```
¥120 元
```

（支付方式：微信支付/支付宝/银行卡）

---

## 实用建议

既然你在广州：

1. 如果你计划以下事项，请在**护照有效期不足6个月之前**换发：

   * 美国签证申请
   * 出国留学
   * 国际旅行

2. 建议在8月初尽早办理，因为许多学生和旅行者会在秋季出行前换发护照。

3. 换发后保留旧护照，如果上面有签证（美国签证、申根签证、日本签证等）。通常，如果同时携带新旧两本护照，旧签证仍然有效。
