问题：什么是差分曼彻斯特编码？

答案：

**差分曼彻斯特编码** 是一种数字线路编码方案，其中**每个比特周期起始位置是否有跳变**来表示比特值。

核心思想：

* **每个比特周期的中间始终有一次跳变** → 提供时钟同步。
* **比特周期起始位置**的跳变承载数据。
* 根据约定：

  * **0** = 起始位置有跳变
  * **1** = 起始位置无跳变

因此，与普通曼彻斯特编码不同，**绝对电压电平无关紧要**——只关注信号是否变化。

### 示例

使用约定 `0 = 比特边界有跳变`：

```text
bits:       1     0     0     1
           |-----|-----|-----|-----|
信号:       ────┐ │┌───┐ │┌───┐ └──
                └─┘   └─┘   └─┘
                 ↑     ↑     ↑
              中间跳变
```

更清晰的一种理解方式：

```text
           起始位置         中间位置
               ↓              ↓
bit = 0     ───┐             ┌───
               └─────────────┘

bit = 1     ─────────────────┐
                              └────
```

具体的高低电平方向可以反转而不影响解码数据，因为接收端关心的是**跳变**，而不是电压极性。

### 为什么使用它？

主要优势是**时钟恢复**。

对于NRZ：

```text
111111111111
────────────
```

可能长时间没有跳变，导致时钟同步困难。

差分曼彻斯特保证：

```text
每个比特:    |----跳变----|
```

因此接收端可以从信号本身恢复比特时钟。

它还具有**极性不敏感**特性：将所有高电平 ↔ 低电平互换不会改变解码后的比特值。

这就是为什么它被用于**IEEE 802.5 Token Ring**等系统中。

### 曼彻斯特编码 vs 差分曼彻斯特编码

|                    | 曼彻斯特编码                     | 差分曼彻斯特编码                          |
| ----------------- | -------------------------------- | ----------------------------------------- |
| 数据由...编码     | 中间跳变的方向                  | 比特边界是否有跳变                        |
| 中间跳变          | 总是存在                         | 总是存在                                  |
| 极性反转          | 改变解释结果                     | 不影响                                    |
| 时钟恢复          | 支持                             | 支持                                      |

我建议你记住的心智模型是：

> **曼彻斯特编码：** “中间跳变是朝哪个方向？”
> **差分曼彻斯特编码：** “边界处有没有跳变？”

这就是两者的全部区别。
