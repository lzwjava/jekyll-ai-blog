用户询问错误 “Your GitHub token might be expired or doesn't have Copilot access.” 这是 Copilot Chat 应用中可能出现的一个特定错误。从 App.tsx 代码来看，此错误在无法获取 Copilot token 时显示。

1. GitHub token 可能已过期
2. GitHub token 可能没有必要的权限/范围用于 Copilot
3. 用户可能没有有效的 GitHub Copilot 订阅
4. 可能存在网络问题或 API 错误
5. token 可能无效或已被撤销

错误发生在 App.tsx 的第 103-106 行：
```typescript
} catch (err) {
  console.error('Failed to get copilot token:', err)
  setMessages(prev => [...prev, { role: 'assistant', content: 'Error: Your GitHub token might be expired or doesn\'t have Copilot access.' }])

}
```

这由 `AuthService.fetchCopilotToken(githubToken)` 失败触发。

查看 auth.ts，fetchCopilotToken 方法调用 `https://api.github.com/copilot_internal/v2/token`。此端点需要：
- 有效的 GitHub token 具有适当的范围
- 用户必须有有效的 GitHub Copilot 订阅

常见原因：
1. GitHub token 没有 `copilot` 范围。login.js 中的设备流仅请求 `read:user` 范围，不足以用于 Copilot。
2. 用户没有 GitHub Copilot 订阅。
3. token 已过期或被撤销。
4. 速率限制或 API 问题。

查看 login.js 脚本，它仅请求 `scope: 'read:user'`，这对于 Copilot 访问不足。GitHub Copilot 通常需要额外的范围或用户账户必须明确启用 Copilot。

此错误发生在应用尝试用你的 GitHub token 交换 Copilot token 但 GitHub API 返回错误时。主要原因是：

## 常见原因

1. **缺少 Copilot 访问权限** - 你的 GitHub 账户没有有效的 GitHub Copilot 订阅。Copilot API 仅适用于具有有效 Copilot 订阅（个人、商业或企业）的用户。

2. **范围不足** - 通过 `npm run login` 获取的 GitHub token 在 `scripts/login.js:98` 中仅请求 `read:user` 范围。然而，Copilot token 端点需要与你的 GitHub 账户绑定的隐式 Copilot 访问权限，而不仅仅是 token 范围。

3. **token 已过期/被撤销** - 存储在 `localStorage` 中的 GitHub token 可能已过期或被撤销。

4. **速率限制** - 对 GitHub API 的过多请求可能导致临时阻塞。

## 如何修复

1. **验证 Copilot 订阅**：确保你的 GitHub 账户在 https://github.com/settings/copilot 有有效的 Copilot 订阅

2. **重新认证**：删除 token 并重新登录：
   ```bash
   rm public/config.json
   npm run login
   ```

3. **使用具有适当范围的 token**：当前的设备流使用 VSCode 的 client ID (`01ab8ac9400c4e429b23`)。如果你的账户有权限，它应该继承 Copilot 访问。

4. **检查 token 有效性**：GitHub token 可能已过期。如果你之前使用不同的 GitHub 账户授权，确保它是具有 Copilot 访问权限的正确账户。

5. **手动测试 API**：你可以直接调用端点验证：
   ```bash
   curl -H "Authorization: token YOUR_GITHUB_TOKEN" https://api.github.com/copilot_internal/v2/token
   ```

如果直接 API 调用失败并返回 `403 Forbidden` 或类似错误，则肯定是账户权限问题，而不是此应用的 bug。
