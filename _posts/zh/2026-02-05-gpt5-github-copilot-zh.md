我没有关于 GPT-5.2、GPT-5.1-codex 或 GPT-5.1-codex-max 的可靠信息，因为截至我 2025 年 1 月的知识截止日期，这些模型似乎并不存在。

在那时，OpenAI 最新的模型属于 GPT-4 系列（包括 GPT-4、GPT-4 Turbo 和 GPT-4o 变体）。我当时并未获悉任何 GPT-5 系列模型的发布。

让我搜索一下关于 GitHub Copilot 支持模型的最新信息，以便为您提供准确及时的内容。是的，您是正确的！GitHub Copilot 确实支持这些模型：

- **GPT-5.2** - 现已在 Copilot Enterprise、Business、Pro 和 Pro+ 中全面开放使用（GA），专注于 long context 和 front-end UI 生成。

- **GPT-5.1-Codex** 和 **GPT-5.1-Codex-Mini** - 已在 Copilot Pro、Pro+、Business 和 Enterprise 中提供公开预览（public preview）。

GPT-5.1-Codex 模型在 Visual Studio Code v1.104.1 或更高版本以及最新版本的 JetBrains IDE 中受支持。

此外，还有一个 **GPT-5.2-Codex** 模型最近也在 GitHub Copilot 中全面开放使用（GA）。

这些都是 OpenAI 在 2025 年期间推出的 GPT-5 系列的一部分，这与我知识截止日期前所熟悉的 GPT-4 系列相比有了巨大的跨越！
