Question: What's inside an apple? That is, the core, rot, inner core — can we eat that part?

Answer:

以下是苹果内部不同部分的详细拆解以及它们是否可以食用：

- **Flesh / Pulp**（你通常吃的白色多汁部分）
  → 完全安全，是可以食用的主要部分。

- **Core**
  Core 是中心部分，包括：
  - **Seed cavity**（5 个种腔 / carpels）
  - **Seeds** 本身
  - 纤维状/木质化的 **central axis**（最中间的纤维部分）
  - 种子周围的一层较硬的组织

  大多数人扔掉整个 core 主要是因为 **seeds** 和木质化的口感。

- **Seeds**（棕色或黑色的小种子）
  → 技术上**可以食用**但**不建议**大量食用
  Apple seeds 含有一种名为 **amygdalin** 的化合物，在咀嚼和消化时会释放出微量的 **cyanide**（氢氰酸）。
  1–10 颗种子中的含量远不足以伤害一个健康的成年人（你需要一次性咀嚼并吞下大约 150–300 颗种子才会达到危险水平）。
  大多数人不小心吞下几颗是没有任何问题的。

- **最中心部分 (central axis / inner core / placenta)**
  这是位于 core 正中间的、细长的、有时呈微绿色或褐色的纤维束。
  → **100% 安全可食用**，只是纤维感很强且不好吃。有些人（尤其是儿童或习惯吃掉整颗苹果的人）吃这部分也没有问题。

- **Rot / moldy / bruised parts**（腐烂/发霉/碰伤部分）
  → **请勿食用**任何褐色、变软、变烂、发霉或发酵的部分。
  这些部分可能含有 mycotoxins（霉菌毒素）或细菌，即使你切掉了明显坏掉的部分，毒素也可能已经扩散到了肉眼看不见的地方，从而导致食物中毒。

**Summary – 大多数人认为安全/正常的食用范围：**

- 可以吃 → 所有白色多汁的 flesh
- 通常可以（少量） → 不小心吞下几颗 seeds
- 安全但口感不佳 → 纤维状的 central string / inner core
- 不可以吃 → 大量的 seeds（一次性超过 50 颗）
- 绝对不要吃 → 任何 rotten, moldy 或严重 bruised 的部分

所以当人们说“不要吃 core”时，他们主要是指“不要故意吃 seeds 和中间那个木质化的部分”，并不是说在正常摄入量下它具有活性毒性。
