Question: 裁缝如何通过机器修补衣物或鞋子，以及使用哪些工具？

Answer:

**核心机器：“补丁机”（cylinder-arm sewing machine）**

普通平板缝纫机无法伸入鞋子或管状衣物（裤腿、袖子、靴筒）内部。因此，修补店使用**cylinder-arm patcher**——一根窄长的水平臂（12-18英寸）取代了平板，使得你可以将鞋子、靴子、包包或袖子套上去，直接缝合内缝。

从机械结构上看，它仍然是标准的**lockstitch**机器——机针线 + 梭芯线互锁——但送料机构不同：

- 布料下方没有送布牙（鞋面下方没有任何东西可以推动）。
- 相反，**压脚本身可以360°旋转**并完成送料——它根据缝线的曲线方向旋转，因为鞋口不是一条直线。这是补丁机与普通缝纫机唯一区别的关键技巧。
它们用于修补鞋面和靴面的缝线和撕裂。这些机器的独特之处在于，送料完全由压脚完成，压脚可360°全向旋转。

**线材**： bonded nylon或polyester thread，通常为#69或更细，重工作时可达#138——比棉线更坚固、更耐磨，因为鞋底/鞋面缝线承受持续弯曲和摩擦。

**鞋子/皮革修补全套工具：**

| 工具 | 用途 |
| --- | --- |
| Cylinder-arm patcher（如Cowboy CB29） | 缝合鞋面、接缝、补丁 |
| 锥子 + 蜡线（手工，无马达） | 快速修补、沿条缝合、机器无法触及的部位 |
| 削皮刀 | 在胶合/折叠前削薄皮革边缘，使接缝不鼓包 |
| 鞋底压机/夹具 | 用接触胶将新鞋底压合固定 |
| 修整机（打磨/抛光轮组） | 换底后修整和打磨边缘 |
| 鞋楦（鞋型铁砧） | 鞋钉/胶合时鞋子套在上面以保持形状 |
| 热风枪/熨斗 | 激活接触胶，软化旧胶 |

**对于衣物（非鞋子）**，只需常规平板**lockstitch或overlock machine**——无需cylinder arm，因为布料可平放——再加上剪刀、拆线器和熨斗用于熨烫。

如果你实际上是想建模或自动化这一过程（例如，视觉模型检测撕裂类型→推荐修补方法），那是一个不同且更有趣的问题——如果这才是你的真正方向，我很乐意深入探讨。
