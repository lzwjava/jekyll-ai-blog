## 背景

* 出生年份：1958年，美国
* 教育背景：

  * 斯坦福大学学士学位
  * 哈佛商学院MBA

他来自风险投资家族的第三代：

* 祖父：小威廉·亨利·德雷珀（William Henry Draper Jr.）——硅谷最早的风险投资家之一。
* 父亲：威廉·H·德雷珀三世（William H. Draper III）——Sutter Hill Ventures的创始人。

因此，蒂姆在风险投资生态系统中长大。

## 比特币赌注

蒂姆·德雷珀因其比特币投资而特别出名。

2014年：

* 美国政府拍卖了约**30,000枚**从丝绸之路查获的比特币。
* 德雷珀以约**每枚600美元**的价格买下了这些比特币。

在比特币后来的高峰期，这笔投资价值数亿美元。

他一直是比特币最坚定的支持者之一，认为：

> 比特币是一场类似于互联网的技术革命。

他的理念：

```
互联网 = 信息去中心化
比特币 = 货币去中心化
人工智能 = 智能去中心化
```

## 投资哲学

德雷珀是一位典型的**高风险、高回报**的风险投资家。

他喜欢：

* 具有强大技术愿景的创始人
* 可能变得巨大的市场
* 能够取代现有系统的技术

他的模式：

```
成功概率小
        ×
巨大的市场影响
        =
风险投资回报
```

例子：

```
100项投资

70项失败
20项获得小额回报
10项成为巨头

一个Tesla / Coinbase / Hotmail
就能覆盖所有成本
```
