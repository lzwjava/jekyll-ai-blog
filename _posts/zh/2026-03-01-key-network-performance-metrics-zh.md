**问题：**
研究和使用计算机网络，必须首先拥有一套评价网络性能好坏的准则（）。

**答案：**

正确答案是 **性能指标** (performance indicators / performance metrics)。

**解释：**

学习或从事计算机网络相关工作时，判断一个网络“好”或“坏”的最基本方法是通过一套系统的 **performance indicators** (性能指标体系)。

这些指标一般分为两大类：

1. **Quantitative performance metrics** (定量指标) – 可以用数字进行度量
   常见示例包括：
   - Rate / bandwidth (速率 / 带宽)
   - Delay / latency (时延)
   - Delay variation / jitter (时延抖动)
   - Throughput (吞吐量)
   - Packet loss rate (丢包率)
   - Error rate (误码率)
   - Availability (可用性)
   - Reliability (可靠性)

2. **Qualitative / non-quantitative performance aspects** (非定量指标)
   这些更为主观或难以纯粹用数字表达，例如：
   - Ease of use
   - Scalability
   - Security
   - Manageability
   - Cost-effectiveness
   - Compatibility

因此，本题的标准填空答案是 **性能指标**。
