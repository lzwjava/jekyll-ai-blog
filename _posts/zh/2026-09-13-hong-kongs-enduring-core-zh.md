问题：**尽管科技和产品发生了改变，香港生活的核心是否基本保持不变？**

回答：**是的——你的直觉相当准确。** *表层*发生了巨大变化，但底层经济/社会模式的连续性要大得多。

可以理解为：

```text
1985年的香港                   2026年的香港
────────────────────────────────────────────────
粤语                           粤语
密集城市                       密集城市
小店铺                         小店铺 / 连锁店
湿货市场                       湿货市场
餐厅                           餐厅
房地产                         房地产
金融                           金融
贸易                           贸易
航运                           航运
国际商业                       国际商业
港铁 / 巴士                    港铁 / 巴士
消费文化                       消费文化
长工时                         长工时
中国 ↔ 世界门户               中国 ↔ 世界连接
```

**物件**发生了变化：

```text
CRT 电视       → OLED 电视
胶片相机       → iPhone
丰田           → EV
传真机         → WhatsApp
银行分行       → 手机银行
CD 店          → Spotify
报纸           → 网络媒体
```

但基本的人类循环却惊人地持久：

```text
工作 → 赚钱 → 吃饭 → 购物 → 社交
     → 通勤 → 租房/买房 → 养家
     → 试图改善经济状况
```

### 但有一个*巨大*的差异

我不会说**商业/经济核心**没有改变。

*功能*相似，但**香港底层的经济引擎已发生重大变化**。

1985年，你走在街上会遇到很多实际上在**制造实体物品**或直接促进贸易的企业：

> 工厂 → 批发商 → 出口商 → 航运 → 海外客户

如今更多是：

> 金融 → 房地产 → 专业服务 → 零售 → 旅游 → 物流 → 科技/服务

香港制造业基本上已跨过边境转移到珠江三角洲。

因此存在一个有趣的错觉：

**街道看起来仍然像市场。**

但这个市场建立在完全不同的生产体系之上。

而这正是香港让人感觉如此连续的原因。

香港历来更少关于*制造实体物件*，更多关于**高效地流动资金、人员、货物和信息**。

那才是更深层的不变因素。

```text
        全球世界
             │
             │
      ┌──────▼──────┐
      │    香港      │
      │             │
      │ 资本        │
      │ 贸易        │
      │ 物流        │
      │ 金融        │
      │ 人员        │
      │ 信息        │
      └──────┬──────┘
             │
             ▼
        华南
        / 中国
```

因此，当你今天走在旺角，看到：

**餐厅 → 药房 → 手机店 → 服装 → 市场 → 银行 → 珠宝 → 便利店**

几乎能感到像是1990年代。

**交换的技术**变了。

**交换的经济行为**没有变。

这就是为什么旧香港的影像可以让人感到惊人地熟悉，而非一个完全陌生的历史时期。
