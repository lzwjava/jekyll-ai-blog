**问题：** 有哪些最好的 open source 工具可以 self-hosted？

---

**回答：**

以下是 popular self-hosted open source 工具的精选分类 overview：

---

### 📁 File Storage & Collaboration

- **Nextcloud** — 最接近 self-hosted Google Workspace 的方案：提供 file sync and share，以及 calendar、contacts、mail、video calls 和 collaborative office suite。

---

### 📝 Knowledge Base & Documentation

- **Docmost** — 一个 collaborative wiki 和 knowledge base，是 self-hosted 版的 Confluence 或 Notion。
- **Outline** — 一个 modern 的 open source wiki 和 documentation tool。
- **AppFlowy** — 一个 open source AI workspace，旨在成为 Notion 的有力 alternative，让 organizations 完全保持对其 data 的 ownership。
- **AFFiNE** — 一个 open source、local-first 的 workspace，融合了 document editing 和 whiteboard functionality。

---

### 🔐 Security & Password Management

- **Bitwarden** — 一个 secure 的 open source password manager。

---

### 📊 Analytics & BI

- **Plausible** — 尊重你 visitors 隐私的 self-hosted analytics tool。Community Edition (CE) 的成本仅为 VPS hosting：对于大多数 site 来说，每月 6–12 美元。
- **Metabase** — 一个 open source business intelligence tool，用于 creating dashboards 和 visualizing data。

---

### 🔄 Workflow Automation

- **n8n / Activepieces** — 强大的、self-hosted 的 Zapier 和 Make 替代方案。

---

### 🖥️ Monitoring & Observability

- **Uptime Kuma** — 一个 self-hosted 的 monitoring tool 和 status page，用于追踪你的 services 的 availability。
- **Beszel** — 用于 systems 和 Docker 的 lightweight monitoring，支持 real-time alerts。

---

### 💻 Developer Tools

- **Gitea** — 一个高效的 open source Git server，让 teams 能够 host 自己的 code repositories。
- **Woodpecker CI** — 一个 lightweight 的 open source continuous integration server，可以与 Gitea 以及其他 self-hosted Git services 无缝集成。

---

### 🗃️ Database / No-Code

- **NocoDB** — 一个 self-hosted 的 open source database interface。

---

### 📰 Blogging & CMS

- **Ghost** — 一个 elegant 的 open source 替代方案，可替代 WordPress，适用于 content creators 和 bloggers。

---

### 🎬 Media & Photos

- **Plex** — 一个 personal media streaming server（可以看作是“self-hosted 版的 Netflix”）。

---

### 🤖 AI & Machine Learning

- 现在有超过 47 个 self-hosted open source AI/ML 替代方案，包括 AI chatbots、使用 local AI 进行 photo/video management（face recognition、semantic search）、具备 AI search 功能的 personal knowledge bases，以及 AI camera monitoring systems 等工具。

---

> 💡 **提示：** 这些 tool 大多提供 Docker images，因此你可以轻松地在月费 12 美元的 VPS 上 run 它们。Self-hosting 是用 subscription fee 来换取你的一些 time 和 attention，但你将获得完全的 data ownership、privacy，并且不受 SaaS limitations 的限制。
