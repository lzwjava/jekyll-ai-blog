问题：在macOS版CapCut中，当我的图片无法填满4:3画幅比例时，如何设置模糊背景/画布？

解答：

在macOS版CapCut中，当素材无法填满画布时，会出现黑边。要改为模糊背景，请按以下步骤操作：

**直接操作流程：**

1. **导入素材** 到4:3项目中
2. **选择时间轴上的视频/图片轨道**
3. **右键点击** → 查找 **"画布"** 或 **"背景"** 选项（或检查右侧的检查器面板）
4. **为背景应用模糊：**
   - 查找 **背景模糊** 或 **画布填充** 选项
   - 选择 **模糊** 作为填充类型
   - 调整模糊强度（通常为0-100的滑块）

**如果找不到直接选项，替代方案：**

1. 在下方图层复制你的图片/视频
2. 将其放大以填满整个4:3画布（会出现模糊/变形，但没问题）
3. 对该图层应用 **高斯模糊** 滤镜（效果 → 模糊 → 高斯模糊）
4. 将原始图片按正确宽高比放在上层

**如果CapCut没有提供清晰的操作路径：**

最可靠的替代方案——使用 **MacBook Air上的FFmpeg** 进行预处理：

```bash
ffmpeg -i input.mp4 -vf "scale=640:480:force_original_aspect_ratio=decrease,pad=640:480:(ow-iw)/2:(oh-ih)/2,boxblur=10" output.mp4
```

此命令将视频缩放到适应4:3比例，填充两侧空白，并应用强度为10的模糊。调整 `boxblur=10` 中的数值可改变模糊强度。

然后将处理后的视频导入CapCut。

**CapCut版本很重要**——较新的macOS版本拥有更好的画布控制功能。通过 **CapCut菜单 → 关于** 查看你的版本号。如果使用的是旧版本，使用FFmpeg比在界面中寻找功能更高效。
