问题：什么是谷歌大脑实习生计划（Google Brain Residency Program）？

答案：

**谷歌大脑实习生计划**是谷歌创建的一项研究培训计划，旨在将人们培养成**机器学习研究员**。后来它更名为**谷歌人工智能实习生计划**，因为其范围已扩展至最初的谷歌大脑团队之外。（[谷歌研究][1]）

可以这样理解：

> **谷歌内部为期一年的带薪“AI研究学徒”项目，介于硕士/博士项目与研究岗位之间。**

谷歌大脑于2015年启动了该计划。实习生直接与谷歌研究员合作，解决前沿机器学习问题，阅读论文、运行实验、撰写论文，并学习如何进行大规模研究。（[谷歌研究][2]）

典型的实习生工作流程：

```
第1-2周：
    谷歌入职培训
    深度学习培训

第1个月：
    寻找导师
    确定研究方向

第2-12个月：
    阅读论文
    实现想法
    在谷歌计算资源上运行实验
    撰写论文
    投稿至NeurIPS / ICML / ICLR
```

研究领域包括：

* 深度学习优化
* 计算机视觉
* 自然语言处理
* 强化学习
* 生成模型
* 机器人技术
* 医疗人工智能
* 人工智能安全

部分实习生在项目期间于顶级机器学习会议上发表了论文。（[谷歌研究][1]）

---

## 哪些人被录取？

有趣的是：**并非只有博士**。

候选人包括：

* 博士毕业生
* 硕士生
* 本科毕业生
* 转行进入AI研究的工程师
* 拥有非传统背景的人

谷歌明确表示，等效的STEM（科学、技术、工程、数学）经验可能符合条件，并鼓励非传统背景的人申请。（[谷歌研究][1]）

示例：

* 拥有计算机科学硕士学位、希望转入深度学习研究的人
* 辍学但拥有丰富ML研究经验的人
* 具备强大编码和数学技能的工程师

（[谷歌研究][1]）

## 为什么它很重要？

在该计划之前，通常的路径是：

```
学士
   |
硕士
   |
博士
   |
研究科学家
```

谷歌大脑实习生计划创造了另一条路径：

```
优秀工程师
       |
       v
谷歌大脑实习生（1年）
       |
       v
研究工程师/科学家
       |
       v
顶级AI实验室
```

它成为了一条人才输送管道。

许多AI研究员都通过类似项目成长起来：

* 谷歌大脑实习生计划
* OpenAI实习生计划
* Meta AI研究实习
* DeepMind实习

## 难度有多大？

竞争非常激烈。

一位强有力的候选人通常具备：

### 编程能力

```python
PyTorch
CUDA基础
分布式训练
大规模实验
```

### 数学能力

```
线性代数
概率论
优化
统计学
```

### 研究能力

最重要的因素：

你是否能提出：

> “下一步该运行什么实验？”

而不仅仅是：

> “我能实现这篇论文吗？”

## 针对你的具体背景

你的背景实际上比普通软件工程师更接近目标。

你拥有：

* 从头训练过GPT-2
* 使用过nanoGPT/nano-vLLM
* GPU优化经验
* LLM基础设施

与典型的谷歌大脑实习生相比，你缺少的部分是：

```

=
论文
+
可重复实验
+
开源贡献
```


最初的谷歌大脑实习生计划本身已不再是原来的项目；谷歌将其扩展为谷歌AI实习生计划。（[谷歌研究][1]）
