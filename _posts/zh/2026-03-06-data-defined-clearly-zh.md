**问题：** 在数据通信的基本概念中，哪个术语指的是记录客观事物的性质、状态和相互关系的物理符号及其组合？

**答案：**

## 正确答案：C — Data (数据)

### 为什么答案是“Data”（C），而不是“Signal”（B）

这是一个概念定义题，需要精确理解数据通信中的四个关键术语。您选择的答案（B: Signal）是错误的，因为“signal”指的是数据的物理/电学载体——而不是符号记录本身。

---

### 所有四个选项的定义

**A. Message (消息)**

通信的目的是传输消息。示例包括语音、文本、图像和视频——这些都是消息的形式。消息是通信系统中*被传输的对象*，作为信息载体。

**B. Signal (信号)**

信号是数据的电学或电磁表示。换句话说，信号是用于通过传输信道携带数据的*物理介质*（例如，电压、光波、电磁波）。它**不是**事实的符号记录。

**C. Data (数据) ✅ — 正确答案**

Data 是用于传达信息的实体——它由可识别的、抽象的符号组成，用于记录和表达信息，例如数字、文本、字母及其组合、图形、图像、视频和音频。

更精确地说，根据 RFC 4949，data 是以特定方式表示的信息，通常是有意义的符号序列。这种表示可以被计算机、其他机器或人类处理或生成。

这与问题的定义完全匹配：**记录客观事物的性质、状态和相互关系的物理符号及其组合**。

**D. Information (信息)**

Information 强调“处理”和“使用”的方面。一件材料在使用前属于 data 类别；只有在使用后才转化为 information。Information 是从 data 中提取的*含义或价值*——它是内容，而不是符号形式本身。

---

### 关键关系总结

| 术语 | 中文 | 通信中的作用 |
| ------ | ------ | -------------- |
| Information (信息) | 信息 | 含义/内容（抽象的、语义的） |
| Message (消息) | 消息 | 信息载体（文本、语音、图像） |
| **Data (数据)** | **数据** | **客观事实的符号记录** |
| Signal (信号) | 信号 | Data 的物理/电学传输 |

Information 是本质；Message 是 Information 的载体；Signal 是传输方法。没有 Information，通信系统失去目的；没有 Message，Information 无法传达；没有 Signal，Information 无法传输。

---

### 为什么学生混淆 Data 和 Signal

混淆的原因是因为 Data 和 Signal 都具有物理性质。然而：

- **Data** = 符号/逻辑表示（数字、字母、符号）
- **Signal** = 用于传输的物理/电学形式（电压、电磁波）

Data 是计算机系统传达含义的实体；Signal 是传输 Data 的方法。当 Data 从网络一端发送到另一端时，无论使用物理还是无线链路，Data 都会被转换为 Signal。

---

**结论：** 问题询问“记录客观事物的物理符号及其组合”——这是教科书上 **Data (数据)** 的定义。正确答案是 **C**。
