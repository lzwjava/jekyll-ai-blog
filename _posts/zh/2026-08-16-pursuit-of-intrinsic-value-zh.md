问题：如何理解像王垠那样按照自己的原则生活的渴望——不被社会、金钱或地位控制，而是遵循自然、数学和计算机科学？

回答：

你所描述的其实是一个非常古老的想法：**追求内在价值而非外在价值**。

许多人优化的是：

```
social approval
        ↓
money
        ↓
title
        ↓
status
        ↓
security
```

但有些人优化的是：

```
truth
  ↓
beauty
  ↓
understanding
  ↓
creation
  ↓
freedom
```

第二条道路更接近你在王垠的文章中所钦佩的东西：一个想法应该由其内在的正确性来判断，而不是由说出它的人或这个人的名气来判断。他明确主张，真理不需要依赖“地位”或“职位”；价值应该来自推理本身。([王垠][1])

对于程序员来说，这种感觉尤其自然，因为计算机是少数几个现实极其诚实的地方之一：

```python
def add(a, b):
    return a + b
```

机器不会在意：

* 你是否毕业于 MIT？
* 你是否是 VP？
* 人们是否尊重你？
* 你是否富有？

它只问：

```
Does the program work?
Does the logic hold?
Is the design elegant?
```

这就是为什么许多工程师热爱编程。这是一个由规则支配的小宇宙。

数学也是类似的：

一个定理为真，是因为证明成立，而不是因为作者有名。

计算机科学也是类似的：

一个系统是好的，是因为它简单、可靠、可理解、有用。

这种心态接近于“工匠”心态：

> 构建某样东西，因为它值得存在。

而不是：

> 构建某样东西，因为市场当前会回报它。

---

但有一个重要的区别。

摆脱社会并不意味着**无视**现实。

即使王垠的哲学也仍然与工程现实紧密相连：编程必须面对计算机的严格规则。他经常强调编程是一种创造性的艺术，其中优雅和正确性很重要。([Tumblr][2])

这种哲学的一个好的版本是：

```
Ignore shallow human judgment
        +
Respect deep reality
```

而不是：

```
Ignore everyone
        +
Do whatever feels good
```

自然、数学和计算机实际上比社会更严格。

社会可能会说：

> “这个人很成功，因为他筹集了 1 亿美元。”

计算机科学会问：

> “你能设计一个能在大规模下工作的系统吗？”

数学会问：

> “你能证明它吗？”

自然会问：

> “它能生存吗？”

---

对于构建 AI 系统的人来说，我认为这种哲学可以变得非常实用。

不要问：

“哪个 AI 趋势能让我致富？”

而要问：

“哪个问题足够优美，让我愿意花 10 年时间去理解它？”

例子：

* 构建一门更好的编程语言。
* 构建一个更好的智能体架构。
* 从第一性原理理解智能。
* 训练模型并发现新的扩展定律。
* 创造让程序员更强大的工具。

金钱可以成为一种**衡量标准**，而不是**目标**。

一个有用的类比：

```
Artist:
    creates because beauty matters

Scientist:
    discovers because truth matters

Engineer:
    builds because reality matters

Entrepreneur:
    creates because value matters
```

最强大的企业家往往不是主要追求金钱的人。他们是痴迷的建造者。金钱是创造出人们深切需要的东西的副产品。

---

你的这句话：

> “遵循自然、数学、计算机的规则，而不是人/社会的规则”

实际上非常接近黑客传统：

```
The computer is not impressed by your reputation.
The compiler is not impressed by your confidence.
The GPU is not impressed by your ambition.

Only reality answers.
```

那是一个有力的立足点。

挑战在于平衡：

```
inner compass
      +
technical excellence
      +
understanding humans
      +
economic sustainability
```

你不需要变成一个拒绝金钱的僧侣。一位伟大的工程师可以创办公司、赚钱，同时仍然忠于更深层的动机：

“我建造这个，是因为我相信它应该存在。”

这可能是最接近你所描述的那种生活的道路。
