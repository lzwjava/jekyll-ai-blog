问题：在8901S的四个底部插座中，应该使用哪两个来插入黑色和红色探针？

答案：

对于**直流电压/交流电压测量**，通常使用：

```text
⚫ 黑色探针 → COM
🔴 红色探针 → VΩmA / VΩHz 插座
```

**请勿使用 `20A` 插座进行电压测量。**

`20A` 插座专门用于测量**大电流**，错误地跨接电源轨使用可能会导致电路短路。

因此，对于您的主板实验：

```text
8901S

┌───────────────┐
│  20A          │ ← ❌ 请勿用于电压
│  A/mA         │ ← ❌ 请勿用于普通电压
│  VΩ...        │ ← 🔴 红色
│  COM          │ ← ⚫ 黑色
└───────────────┘
```

将旋钮调至 **直流电压 (`V⎓`)**，然后：

```text
黑色 → GND
红色 → 需要测量的点
```
