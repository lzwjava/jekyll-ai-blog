## 问题：西班牙的 **Título Propio** 是什么？

## 回答

**Título Propio** 意为 **大学自授学位/文凭**。

这是由西班牙大学创建并颁发的学历资格，但 **并非国家官方认可的硕士学位**。

西班牙存在两种不同的概念：

```
硕士学位
    |
    +-- 官方大学硕士
    |       |
    |       + 西班牙政府认可
    |       + 属于欧洲高等教育区 (EHEA)
    |       + 欧洲学分转移系统 (ECTS) 学分
    |       + 通常可继续攻读博士学位
    |
    +-- 自授学位
            |
            + 大学自行创建
            + 职业 / 继续教育
            + 认可度取决于雇主/机构
```

---

## 示例

假设：

瓦伦西亚理工大学创建：

```
官方硕士：人工智能
```

这是官方硕士。

但如果该大学创建：

```
自授硕士：人工智能
```

这便属于自授学位。

两者在英语宣传材料中可能都标注为"Master"。

这容易造成混淆。

---

## 西班牙为何存在自授学位？

因为大学可以快速开设职业化课程。

例如：

行业需求：

```
人工智能 + 大数据 + 云计算
```

大学可以创建：

```
自授硕士：人工智能工程
```

而无需走完整的政府审批流程。

优势：

* 课程更新更快
* 面向行业需求
* 入学门槛更低
* 适合在职人士

## 认可度对比

| | 官方硕士 | 自授学位 |
| ------------------------------ | ----------------- | ---------------------------------- |
| 西班牙政府认可 | ✅ 是 | ❌ 否 |
| EHEA 认可 | ✅ 是 | 通常 ❌ |
| ECTS 学分 | 通常有 | 可能使用 ECTS 但含义不同 |
| 攻读博士学位 | ✅ 通常 | ❌ 通常不行 |
| 私营企业 | ✅ | 常被接受 |
| 国际人力资源 | ✅ 更优 | 视情况而定 |
| 移民 | 更安全 | 需核实 |

## 针对你的情况

你的目标并非学术领域。

你的目标：

```
汇丰/星展银行级别公司
人工智能工程师岗位
新加坡/香港/欧盟
签证选项
解决人力资源筛选问题
```

因此自授学位仍有一定价值。

招聘人员可能会认为：

> "他拥有西班牙大学硕士级学历 + 11年经验 + 人工智能项目经验。"

这或许足够。

但政府移民官员或学术机构可能会说：

> "这不是官方硕士学位。"

```
人工智能工程经验
+
博客
+
项目
+
企业背景
```

学位只是一个 **资质包装**。

但如果相同价格可以获得：

```
官方大学硕士
```

每次都选择后者。

区别不在于学习内容，而在于 **法律认可度和未来选择性**。
