**问题：** 如果万用表处于 **200 Ω 档位**，且 `5KA51` 两端都显示 `0.1–0.2`，是否需要乘以 200？

**答案：** **不需要。不要乘以 200。**

在 **200 Ω 档位** 下，显示的数字已经是以欧姆（Ω）为单位的值。因此：

```text
0.1  →  0.1 Ω
0.2  →  0.2 Ω
10.0 →  10.0 Ω
50.0 →  50.0 Ω
```

这里的 `200` 是 **最大量程**，而不是倍数。典型的 200 Ω 档位分辨率为 0.1 Ω。（[Fluke][1]）

### 你的测量结果

你得到的数据是：

```text
5KA51

焊盘 A → 地 = 0.1–0.2 Ω
焊盘 B → 地 = 0.1–0.2 Ω
```

这意味着 **两侧基本上都接地**。

但有一个非常重要的后续测试：

**将两个表笔短接，然后在 200 Ω 档位下读数。**

例如：

```text
表笔 + ─────┐
             ├── 短接在一起
表笔 - ─────┘

万用表读数 = 0.1 Ω
```

如果读数为 `0.1 Ω` 或 `0.2 Ω`，这很可能是 **表笔/导线的电阻**。Fluke 指出，测试导线通常会引入约 `0.2–0.5 Ω` 的电阻，在测量极低电阻时应考虑这一因素。（[Fluke][1]）

因此，如果：

```text
表笔短接：        0.1 Ω
5KA51 焊盘 → 地： 0.1 Ω
```

你 **无法得出结论说 GPU 供电 rails 的电阻恰好是 0.1 Ω**。你的万用表可能只是在测量与表笔电阻大致相同的值。

### 另外一个重要点

如果 **两个电容焊盘在扣除表笔电阻后** 仍保持在 ~0.1 Ω，那么该电容实际上位于：

```text
GPU 供电 rails ──[ 5KA51 ]── 地
   │
   └──────── ~0 Ω ────── 地
```

这表示 **从该 GPU 供电 rails 到地之间存在极低电阻的路径**，对于电源 rails 来说，这很可疑。

然而，不要立即断定 `5KA51` 本身是坏的。在元件仍焊接在 GPU 上时进行测量，测得的是 **PCB 上所有并联路径的总和**，而不仅仅是该电容的值。（[Fluke][1]）

**请执行以下步骤并告诉我读数：**

```text
1. 两个表笔尖端互相接触 = ___ Ω

2. 5KA51 左侧焊盘 → 地 = ___ Ω
3. 5KA51 右侧焊盘 → 地 = ___ Ω
```

有了这三个数值，我们就能判断 `0.1–0.2 Ω` 究竟是表笔电阻，还是 RTX 3060 供电 rails 上真正的近似短路。
