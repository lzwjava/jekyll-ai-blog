问题：如果我已经在 arXiv 上发布了一篇论文，之后还能更新吗？

回答：

是的。arXiv 支持版本管理——你可以提交修订版，这些修订版会变成 v2、v3 等。原始版本始终可访问，不会被删除。

运作方式：

- 登录后，进入你的论文页面，点击 **“提交新版本”**（或使用文章的 admin 页面）。上传新的源文件/PDF。通常会在下一个公告周期后发布为新版本（`v2`）。
- 摘要页面会显示所有版本，并提供一个 `[v1] [v2] ...` 选择器和日期。基础标识符（例如 `arXiv:2401.12345`）始终解析为 **最新** 版本；`arXiv:2401.12345v1` 则固定指向原始版本。
- 添加你的 GitHub 和 Hugging Face 链接正是那种值得修订的编辑——这是实质性的可复现性改进，而不是修正拼写错误。

重要限制：

- **你无法删除某个版本。** 所有先前版本将永久公开。因此，没有链接的 v1 仍然可见，但带有链接的 v2 会成为默认版本。这没问题——版本管理是预期的，审稿人不会因此扣分。
- **arXiv ID 永远不会改变**，这正是关键所在：对你的论文的引用会持续有效，并自动指向最新版本。这比一条推文 *更好*，因为规范链接是稳定的，而内容仍可更新。
- **撤稿** 是可能的，但性质不同——它会把论文标记为已撤稿（带有墓碑注释），而不是删除。你不需要这个；你只需要一个修订版。
- 有一条不成文的规矩：不要频繁发送琐碎的每日更新。将有意义的更改批量整合到一个版本中。在同一个 v2 里添加工件链接（以及你积累的任何文字润色）是完全正常的。

所以你的计划成立：先发布，然后推送一个 v2，在脚注和“代码与模型可用性”部分添加固定的 GitHub/HF 链接。arXiv ID 保持不变，推文可以链接到稳定的 ID，论文保持规范。
