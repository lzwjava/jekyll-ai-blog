问题：如何使用OBS向微信视频号进行直播？

回答：

可以。基本架构如下：

```text
摄像头 / 屏幕 / 麦克风
        ↓
       OBS
        ↓
  RTMP推流
        ↓
   微信视频号
        ↓
     观众
```

### 1. 安装OBS

安装 [OBS Studio](https://obsproject.com/?utm_source=chatgpt.com)。

### 2. 获取视频号直播凭证

在微信中，进入 **视频号 → 直播**，打开直播设置/管理页面。

你需要获取 **推流地址 + 推流密钥**，前提是你的账号已获得OBS/外部推流权限。

格式大致如下：

```text
服务器地址：
rtmps://...

推流密钥：
<占位符>
```

**请勿分享推流密钥。**

如果未显示推流地址/密钥，说明你的视频号账号可能尚未开通外部/OBS推流功能。微信会频繁调整该功能的开放资格和界面。

### 3. 配置OBS

在OBS中：

```text
设置
  → 直播
```

选择：

```text
服务：自定义
服务器：<微信RTMP服务器地址>
推流密钥：<占位符>
```

然后：

```text
应用
→ 确定
→ 开始直播
```

### 4. 搭建OBS场景

例如，如果你想直播修显卡的过程：

```text
场景：显卡维修

来源：
├── 视频采集设备     # 显微镜/摄像头
├── 显示器采集       # Linux/Windows桌面
├── 音频输入采集     # 麦克风
└── 文本            # 标题/状态
```

一个特别适合你的配置方式：

```text
显微镜摄像头
       │
       ├──────────────┐
       ↓              ↓
      OBS ←──── 桌面采集
       │
       ↓
   视频号直播
```

你可以将 **PCB/显微镜画面作为主视频**，在较小窗口中显示终端 / `nvidia-smi` / 示波器读数。

### 5. 重要区别

有两种截然不同的工作流程：

**手机直播**

```text
手机摄像头 → 微信 → 视频号
```

**OBS直播**

```text
摄像头/桌面 → OBS → RTMP → 视频号
```

OBS能让你对 **多摄像头、屏幕采集、叠加画面、音频混合、场景切换、码率控制、录制和源切换** 拥有更多控制权。

针对你的使用场景，建议使用 **OBS + USB显微镜/摄像头 + 桌面采集**，而非直接通过手机直播。

### 推荐的OBS初始设置

先从保守设置开始：

```text
分辨率：1920×1080
帧率：  30
编码器：NVENC
码率：  ~4,500–6,000 Kbps
音频：  AAC, 128–160 Kbps
```

由于你使用的是NVIDIA显卡，NVENC是更优选择，因为编码过程不会占用太多CPU。
