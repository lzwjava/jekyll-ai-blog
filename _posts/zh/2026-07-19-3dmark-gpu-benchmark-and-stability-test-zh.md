**问：GPU 工具中的 3DMark 测试是什么？**

**答：**

3DMark 是一款 **GPU 性能基准测试和稳定性测试工具**。它通过渲染复杂的 3D 场景（类似于游戏引擎），测量 GPU 处理这些场景的速度。

人们主要用它来做以下事情：

1. **性能对比**
2. **检查二手显卡是否健康**
3. **超频/降压稳定性测试**
4. **检测散热问题**

常见的 3DMark 测试：

| 测试             | 测量内容                     | 典型用途                   |
| ---------------- | ---------------------------- | -------------------------- |
| Time Spy         | DirectX 12, 1440p 游戏性能   | 最常见的 GPU 对比测试      |
| Time Spy Extreme | DX12, 4K 负载                | 高端 GPU                   |
| Port Royal       | 光线追踪性能                 | RTX 显卡                   |
| Fire Strike      | DirectX 11 性能              | 较旧的 GPU                 |
| Steel Nomad      | 现代跨平台 GPU 负载          | 较新的 GPU                 |

示例：

一位出售二手 RTX 3090 的卖家可能会说：

> "3DMark 99.3%，温度大约 70°C"

意思是：

* 显卡完成了基准测试。
* 其分数与同一基准测试数据库中其他 RTX 3090 显卡的分数相近。
* 很可能没有明显的 GPU 核心或显存问题。
* 在负载下 70°C 对 3090 来说是一个不错的温度。

购买二手 GPU 时的典型流程：

```bash
1. 运行 GPU-Z
   -> 检查型号
   -> 检查显存大小
   -> 检查 BIOS

2. 运行 3DMark Time Spy
   -> 对比分数

3. 运行 FurMark
   -> 压力测试温度

4. 运行显存测试
   -> 检测显存错误
```

**3DMark 与 FurMark 的区别**：

|                     | 3DMark                             | FurMark                       |
| ------------------- | ---------------------------------- | ----------------------------- |
| 目标                | 真实的游戏基准测试                 | 极限压力测试                  |
| 负载                | 类游戏场景                         | 非常重的 GPU 负载             |
| 分数                | 有                                 | 无有效性能分数                |
| 检测过热            | 是                                 | 极佳                          |
| 检测 GPU 故障       | 好                                 | 好                            |
| 游戏玩家使用情况    | 非常普遍                           | 测试中常用                    |

针对 RTX 3090 而言：

典型 Time Spy 图形分数：

* RTX 3090 公版：大约 **19,000–20,000**
* 优秀厂商标定超频卡：**20,000+**
* 散热差 / 降频卡：显著偏低

对于二手矿卡，3DMark 很有用，因为一张看似正常的显卡可能存在以下问题：

* 显存性能下降
* 显存频率不稳定
* 持续负载下过热

我更信任：

* **3DMark + GPU-Z + 温度测试 + 外观检查**
    而不是仅仅听信"它能正常工作"。
