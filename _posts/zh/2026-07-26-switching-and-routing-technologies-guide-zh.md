广东自学考试课程 **13833 交换与路由技术**

## 答案

**13833 交换与路由技术** 是广东高等教育自学考试中的一门专业核心课程，主要面向 **计算机应用技术** 专业。这是一门专注于企业网络配置与管理的实践性网络课程。 ([广东考试院][1])

# 3. 交换

交换机工作在第二层。

示例：

```
PC1
 |
 |
交换机
 |
 |
PC2
```

交换机学习 MAC 地址：

```
MAC 地址表：

AA:BB:CC -> 端口1
DD:EE:FF -> 端口2
```

---

## VLAN

非常重要。

没有 VLAN：

```
        交换机

PC1 -------- PC2 -------- PC3
```

所有设备都在同一个广播域中。

使用 VLAN：

```
VLAN10

PC1
 |
交换机


VLAN20

PC2
 |
交换机
```

逻辑隔离。

华为命令示例：

```
system-view

vlan 10

interface GigabitEthernet 0/0/1

port link-type access

port default vlan 10
```

# 4. STP（生成树协议）

问题：

网络环路：

```
        交换机A
       /        \
      /          \
 交换机B ------ 交换机C
```

以太网原本没有 TTL。

广播风暴：

```
数据包
 ↓
A → B → C → A → ...
```

STP 阻塞一条路径：

```
        交换机A
       /
      /
 交换机B ------ 交换机C
        阻塞
```

考试喜欢考：

* 根桥
* 端口角色
* 阻塞状态

# 5. 路由

路由器连接不同的网络：

```
192.168.1.0

     |
   路由器
     |

192.168.2.0
```

路由表：

```
目标网络          下一跳

192.168.2.0/24     eth0
```

---

## 静态路由

手动配置：

```
ip route-static
192.168.2.0 255.255.255.0 10.0.0.2
```

适用于小型网络。

---

## 默认路由

“其他所有流量都走这里”

```
0.0.0.0/0
        |
      互联网
```

---

## 动态路由

路由器自动学习。

### RIP

较老的协议：

```
距离矢量

度量：
跳数
```

最大跳数：

```
15 跳
```

---

### OSPF

重要。

用于企业网络。

概念：

```
路由器A
   |
 OSPF
   |
路由器B
```

特性：

* 链路状态
* 最短路径
* 区域

算法：

```
Dijkstra
```

# 9. 与人工智能基础设施的关系

实际上，这门学科与现代人工智能集群相关联。

例如：

GPU 集群：

```
GPU 服务器
    |
以太网 / InfiniBand
    |
交换机
    |
路由器
    |
存储
```

大型训练集群需要：

* 拓扑设计
* 带宽
* 拥塞控制
* 路由

相同的概念出现在：

* NVIDIA 网络
* RDMA
* RoCE
* 人工智能数据中心设计

所以，这并不是一门过时的课程。

它是人工智能基础设施之下的基础层。
