问题：今天还能再造一个DeepSeek或Kimi来降低AI成本吗？

回答：

简短回答：**可以，但并非通过从头训练另一个前沿基础模型。** 机会已从"构建更大的GPT"转向**构建更便宜的AI系统**。

DeepSeek和Kimi是很好的例子，因为它们的优势不仅在于模型规模，而是整个技术栈：

```
数据
 ↓
训练方案
 ↓
架构
 ↓
分布式训练
 ↓
推理优化
 ↓
产品 + 用户反馈循环
```

新公司仍可以攻克这个技术栈的某些部分。

---

## 1. 再造一个DeepSeek规模的模型？非常困难

DeepSeek-V3规模：

```
671B 总参数
37B 激活参数（MoE）
14.8T 训练token
数千块H100级GPU
数月的工程开发
```

资金需求巨大。

护城河在于：

```
GPU集群
+
研究人才
+
训练基础设施
+
数据流水线
+
模型评估
+
后训练
```

小型初创公司无法正面竞争。

---

## 2. 但"降低AI成本"是一个巨大机遇

下一波浪潮很可能不是：

> "我们训练一个10万亿参数的模型"

而是：

> "我们将智能的成本降低10倍"

例子：

### A. 更好的推理

当前LLM推理：

```
请求
 |
token生成
 |
KV缓存
 |
GPU内存带宽瓶颈
```

成本高昂。

公司可以通过以下方式获胜：

* 推测解码
* 量化
* KV缓存压缩
* 稀疏性
* MoE路由
* 模型蒸馏

示例：

```
教师模型：

Claude/GPT-5
     |
     v
小型专用模型

70B → 7B
质量损失：小
成本降低：10倍
```

---

## 3. 垂直模型仍有空间

与其构建：

```
通用智能
```

不如构建：

```
房地产AI
法律AI
金融AI
编程AI
医疗AI
```

一个拥有优质数据的7B-30B模型可以击败通用的400B模型。

示例：

```
通用模型：

GPT-5
100%能力
$1/查询


垂直模型：

房地产GPT
85%能力
$0.01/查询
```

对业务而言，后者获胜。

---

## 4. "Kimi式机会"值得关注

Kimi的历史优势：

* 长上下文
* 高效推理
* 中国市场
* 产品执行力

长上下文本身就是一个成本问题。

朴素方案：

```
100万token
 ↓
注意力机制

O(n²)
```

成本高昂。

更优方案：

```
检索
+
记忆
+
压缩
+
智能体规划
```

未来可能不是：

```
1亿上下文窗口
```

而是：

```
AI记忆系统
```

## 6. 硬件正在改变游戏规则

过去：

```
只有超大规模公司才能训练
```

因为：

```
10000块H100
```

现在：

```
8块RTX 5090
8块MI300X
云端GPU租赁
```

已经可以获取。

特别是用于：

* 微调
* 蒸馏
* 小型MoE
* 推理模型

你自己的实验已经接近这个方向：

```
从零训练GPT-2 124M
RTX 4070
150亿token数据集
```

下一步不是训练GPT-5。

而是：

```
小模型
+
更好的数据
+
推理训练
+
智能体循环
```

## 我的观点

下一个DeepSeek不太可能是：

> "我们训练了一个更大的模型。"

它很可能是：

> "我们找到了一种方法，以1/50的成本获得GPT-5级别的实用智能。"

可能的领域：

1. **AI推理优化**
2. **智能体架构**
3. **领域专用模型**
4. **合成数据生成**
5. **模型压缩/蒸馏**
6. **开源AI基础设施**

现在的机会实际上更大，因为智能正在变成商品。瓶颈从**模型训练**转向**高效部署**。
