**问题：** 安装前是否需要扩展分区？为什么一直因相同的“恢复环境”触发而失败？

**回答：** 不需要——扩展分区与此无关。你的磁盘 0 布局已经没问题（安装程序会自动从未分配空间创建 EFI/MSR/主分区/恢复分区；手动扩展或创建分区只会带来麻烦）。

由于它再次因**完全相同的 `0xC19001F4` 触发**而失败，这不太可能是意外按键——在同一位置重复出现相同的失败，通常表明以下两种情况之一：

1. **U 盘介质确实损坏**——每次都在同一阶段失败，强烈指向 U 盘上的某个文件安装程序无法读取，而安装程序的回退行为（被错误地记录为“用户请求恢复”）会在遇到该坏读取时触发。
2. **你未注意到的物理触发**——某些联想笔记本电脑有一个 **Novo 按钮** 或 **一键恢复** 组合键，如果暴露在外，可能会因振动或背包压力而触发按键；或者如果该型号有触摸屏，也可能因意外触碰而触发。

**接下来请这样做，跳过更多日志分析：**

1. 从微软官网重新下载 Windows 11 ISO（不要使用当前的文件）。
2. 如果有的话，重刷一个**不同的 U 盘**——使用 Rufus，选择 GPT + UEFI 目标。
3. 在整个安装过程中，一旦“正在安装 Windows”进度开始，**不要触碰键盘、触摸板或触摸屏**——完全不要操作，直到 OOBE 阶段。
4. 如果有第二个 USB 端口（避免使用 USB 集线器），请直接插入主板后置端口。

如果使用全新的 ISO、全新的 U 盘且完全不触碰，第三次仍然同样失败，那可能指向硬件问题（内存故障或 NVMe 控制器不稳定），而非介质问题——但先排除 U 盘问题，因为这是导致此类重复且无法解释的安装中断的最常见原因。
