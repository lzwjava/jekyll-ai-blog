Paul Graham（Y Combinator 创始人）撰写了数篇文章，直接或间接地批评了传统的 MBA 课程和大多数顶尖商学院教授的传统商业智慧。以下是 PG 观点与标准 MBA 教学形成鲜明对比的关键理念：

| 传统 MBA 智慧 | Paul Graham 的对比观点 | 关键 PG 文章 |
| ------------------------ | -------------------------------- | --------------- |
| 花数年时间撰写详细的商业计划 | 商业计划大多是虚构的；你无法预测未来。应该从原型开始。 | “Do Things That Don’t Scale”，“How to Get Startup Ideas” |
| 尽早筹集大量资金（A 轮、大型演示、注重估值） | 从很少的钱（或没有钱）开始。在实现产品与市场契合之前保持精简。 | “Startup = Growth”，“How to Start a Startup” |
| 关注竞争、竞争优势、进入壁垒 | 痴迷于用户/客户。如果你创造出人们迫切需要的东西，竞争就不那么重要。 | “How to Get Startup Ideas”，“Schlep Blindness” |
| 管理、领导力培训、组织行为、招聘流程 | 早期阶段的初创公司应该由创作者（会编程/写作/设计的创始人）运营，而不是职业经理人。晚期才招聘，并且只有在痛苦时才招聘。 | “Maker’s Schedule, Manager’s Schedule”，“What Microsoft Is This the Altair Basic of?” |
| 研究大型成功公司（GE、P&G、IBM 等）的案例 | 大公司是前初创公司的尸体。你几乎无法从它们那里学到如何创建下一个公司的有用知识。 | “You Weren’t Meant to Have a Boss” |
| 营销、品牌、定位至关重要 | 创造用户喜欢的东西 → 他们会为你做营销（有机增长胜过营销支出）。 | “Do Things That Don’t Scale” |
| 获得 MBA 以学习如何运营公司 | 学习如何创办公司的唯一真正方法是创办一家公司。MBA 主要是一种信号和人脉，而不是教育。 | “How to Start a Startup” 讲座 (2014)，“The Lesson to Unlearn” |
| PowerPoint 演示和推介资料至关重要 | 好的初创公司通常可以用简单的英语在几句话内解释清楚。过度润色的演示文稿是危险信号。 | YC 申请建议，“How to Convince Investors” |
| 从第一天起就高效扩展（单位经济、CAC/LTV 等） | 在初期不惜一切代价做一些无法扩展的事情（手动用户引导、礼宾 MVP 等）。过早优化会扼杀初创公司。 | “Do Things That Don’t Scale”（他最著名的反 MBA 文章） |
| 风险最小化、多元化、职业规划 | 初创公司是孤注一掷的赌注；年轻时你的职业生涯也应如此。最大的风险是不承担足够的风险。 | “How to Do Great Work”，“The Refragmentation” |
| 财富创造源于管理大型组织 | 过去 40 年的大部分新财富都是由科技初创公司创造的，而不是通过攀登公司阶梯或传统管理。 | “Economic Inequality”，“Mind the Gap” |

简而言之，Paul Graham 的理念可以总结为：

传统 MBA → 优化用于管理相对静态行业中的现有大型组织。
Paul Graham / YC 理念 → 优化用于在高度不确定、快速变化的环境中创建全新的科技公司。

他基本认为，如果你的目标是创立下一个 Google、Airbnb 或 Stripe，那么经典 MBA 课程中教授的几乎所有内容要么无关紧要，要么甚至有害。

他直接抨击传统商业教育的大部分文章：

- The Lesson to Unlearn (2019)
- Do Things That Don’t Scale (2013)
- How to Start a Startup (2014 系列讲座)
- You Weren’t Meant to Have a Boss (2008)
- The 18 Mistakes That Kill Startups (2006)

如果你只想读一篇来了解这种对比，请阅读“Do Things That Don’t Scale”——这是最直接与传统商业教育中痴迷于效率、侧重计划的方法相悖的一篇文章。
