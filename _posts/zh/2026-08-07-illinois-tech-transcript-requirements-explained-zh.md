**问题：请解释伊利诺伊理工大学研究生申请的教育背景/成绩单要求。**

**回答：**

此部分要求你声明**所有就读过的高等教育机构（高中之后）**，而不仅仅是获得学位的学校。

关键点：

### 1. 列出所有就读过的学院/大学

> “请列出所有您已获得或预计获得学位的学院/大学。您必须包含所有机构，无论是否获得学位……”

意思是：

你必须包含：

* 已毕业的大学 ✅
* 就读过但未毕业的大学 ✅
* 转学分来源的学校 ✅
* 目前未完成的学位项目 ✅

示例：

如果有人：

* 在北京林业大学学习1年后辍学
* 后来在广东外语外贸大学自学本科课程

他们仍应列出这两所院校。

**不要**隐瞒未完成的学习经历。

---

### 2. 美国学校申请者

此条仅适用于在美国上过大学的人。

他们要求：

✅ 大学注册处出具的成绩单原件

**不接受**：

* 学生门户网站截图
* 学位审核报告
* 学生自己制作的成绩单PDF

---

### 3. 国际申请者（包括中国）

对于中国申请者：

你需要：

1. 每所就读大学出具的正式成绩单

例如：

* 北京林业大学成绩单
* 广东外语外贸大学成绩单

即使未毕业也需要提供。

成绩单必须由原学校出具。

---

### 4. 学位证书要求

仅在你已毕业时需要提供。

示例：

你于2024年完成四年制本科项目：

需要：

* 成绩单
* 学位证书
* 毕业证书

如果你仍在读：

示例：

“预计2027年毕业”

那么：

* 需要成绩单
* 暂时不需要学位证书

---

### 5. 中国教育文件

针对中国地区：

他们要求：

如果已毕业：

中文：

* 学位证
* 毕业证
* 成绩单

英文：

* 这些文件的英文翻译

两种语言都需要。

他们说：

> 母语成绩单以及任何英文出具的文件

意思是：

不要只上传英文翻译。

请上传：

```
中文成绩单.pdf
+
英文翻译成绩单.pdf
```

---

### 6. 翻译要求

如果你的文件是中文：

错误做法：

```
仅英文成绩单
```

正确做法：

```
中文原版成绩单
+
官方英文翻译
```

翻译通常应由以下机构出具：

* 大学
* 认证翻译服务

---

### 7. 学期/课程要求

对于常规四年制本科学位：

他们需要足够的学习记录：

```
至少6个学期
课程 + 成绩 + 学分
```

对于三年制本科：

```
至少4个学期
```

他们希望看到你完成了有意义的大学学习。
