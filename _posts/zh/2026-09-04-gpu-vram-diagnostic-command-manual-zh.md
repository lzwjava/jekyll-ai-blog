## 问题：这个PDF是什么？

回答：**`显卡测试命令手册.pdf` 是一份GPU显存诊断/测试手册**。它描述了一个可启动的多系统测试环境，供GPU维修技术人员诊断**NVIDIA和AMD显卡**，尤其是显存（VRAM）故障。

该手册本质上是一份**MATS/Tserver维修技术人员的命令参考**。

### 它的作用

核心思路如下：

```text
GPU
 │
 ├── GPU核心
 │
 ├── VRAM芯片 ──┐
 │                 │
 └── VRAM总线 ─────┘
        ↓
     MATS / Tserver
        ↓
   显存测试
        ↓
   通过 / 失败
        ↓
   识别有问题的显存通道
        ↓
   定位物理VRAM芯片
```

对于NVIDIA，重要的程序是**MATS**：

```bash
./mats -e 10
```

根据手册，`-e 10` 表示测试 **10 MB 显存**。

对于**无显示输出**的GPU，手册展示了使用主板的核显启动机器，同时测试独立显卡的方法：

```text
显示器
   │
   ▼
主板HDMI/DP接口
   │
   ▼
Intel核显
   │
   ├────────── 系统
   │
   └── PCIe ── 损坏的NVIDIA GPU
                    │
                    ▼
                  MATS
```

手册明确建议在这种场景下使用支持多GPU/核显协同工作的主板。

### 对GPU维修有帮助的部分

它不仅仅说**“显存坏了”**。

它试图告诉你**哪个内存通道/字节通道出现故障**，然后将该结果映射到物理显存芯片上。

例如：

```text
report.txt

FBI0A0
A0 = 31760个错误
```

手册中的示例将其解释为低字节显存问题，然后映射到显卡上的特定物理内存位置。

它还给出了物理映射规则：

```text
NVIDIA — 双面显存布局

A面 → 高字节 → 位32–63
B面 → 低字节 → 位0–31
```

以及针对单面显存布局的另一种排列方式。

这对于你正在学习的维修流程**非常有用**：

```text
GPU无法工作
       ↓
MATS能否初始化？
       ↓
    是
       ↓
运行显存测试
       ↓
   通过 / 失败
       ↓
失败 → 识别通道
       ↓
映射通道 → 物理显存
       ↓
检查显存 / 焊接 / 供电 / 走线
       ↓
可能重新植球 / 更换显存
```

### 它同时涵盖NVIDIA和AMD

该文档提供了不同的环境：

| 厂商       | 工具                     | 示例                          |
| ---------- | ------------------------ | ----------------------------- |
| NVIDIA     | `mats` / `mods`          | `./mats -e 10`                |
| AMD 旧款   | 独立的测试程序           | `./rx580a6`                   |
| AMD 新款   | `tserver`                | `./tserver -boardtest=memfa`  |

对于较新的AMD显卡，结果存储在 `memfa.log` 中。

### 一个重要的局限性

这**不是一种通用的PCIe诊断工具**，就像把汽车诊断仪插到车上那样简单。

MATS/Tserver 在更深的层次上工作，但仍然需要GPU达到足够可用的状态。

手册特别指出，如果测试环境本身无法初始化，可能的原因包括**供电异常或GPU核心问题**，这意味着你可能连显存测试阶段都进不去。

因此从概念上讲，你可以将维修层次结构视为：

```text
             GPU
              │
       ┌──────┴──────┐
       │             │
   供电/VRM      初始化
       │             │
       └──────┬──────┘
              ↓
          GPU核心
              ↓
       MATS初始化
              ↓
          显存测试
              ↓
       坏通道 / 坏芯片
```

**对于你一直在探索的GPU维修工作，这份PDF非常相关。**  对你最有价值的部分是第**5–18页**，因为它们展示了实际的 `mods`、`mats`、`report.txt`、通道映射，以及用于区分**显存故障 vs GPU核心故障**的额外测试。
