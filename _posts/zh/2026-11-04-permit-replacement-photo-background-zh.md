是的。对于中国大陆《往来港澳通行证》的补发，两种背景都可以接受：

- 纯白色（白色）— 可以接受。
- 淡蓝色（淡蓝色）— 可以接受。

根据国家移民管理局的照片要求，两者都有效。&#x20;

[image](https://www.google.com/s2/favicons?domain=https://www.shanwei.gov.cn\&sz=32)

汕尾政府+2

其他照片要求：

| 项目       | 要求                            |
| ---------- | ------------------------------ |
| 照片尺寸   | 33 × 48 毫米                   |
| 背景       | 纯白色或淡蓝色                 |
| 拍摄时间   | 6个月以内                      |
| 着装       | 建议深色、有领                 |
| 表情       | 中性，嘴巴闭合                 |
| 面部       | 清晰可见，无阴影               |
| 修图       | 不得修改面部特征               |

我的建议：选择淡蓝色或白色。两者都可以。向照相馆要求：

> 往来港澳通行证证件照，33×48mm，白底或淡蓝底，符合出入境证件相片照相指引。
