问题：**为什么人们有勇气创办一家初创公司？**

答案：

大多数创始人在开始之前实际上并不感到“勇敢”。他们通常开始是因为**尝试的预期价值开始高于留在原地的预期价值**。

一个创业决策大致是：

\[
EV = P(成功) \times 奖励 - P(失败) \times 成本
\]

例如：

```
传统工作：
    薪资：$100k/年
    大幅上升的概率：低
    下行风险：稳定

初创公司：
    成功概率：5%
    结果：$10M 的公司
    失败成本：2年 + 机会成本

预期价值：
    0.05 × $10M - 成本
    = 可能具有吸引力
```

创始人并没有在想“我很勇敢”。他们通常在想：

> “如果我不尝试这个，我会后悔。”

---

## 1. 他们看到了不对称的机会

许多创始人有这样的心理模型：

```
最坏情况：
    损失2-3年
    学到很多东西
    重回职场

最好情况：
    创造有价值的东西
    获得自由
    改变人生
```

下行风险有限，而上行空间巨大。

对于工程师来说尤其如此，因为技能是可迁移的：

```
编码能力
+
AI知识
+
系统设计
+
人脉

= 可以恢复
```

一个25岁的工程师辞职与一个没有可转移技能的人相比，风险状况截然不同。

---

## 2. 他们早已对现有世界感到不满

许多初创公司始于：

```
“我讨厌这个问题”
        +
“我知道更好的方法”
        +
“没有人解决它”
```

例子：

* Airbnb创始人：酒店太贵，空余房间存在。
* Uber创始人：交通效率低下。
* OpenAI创始人：AI发展需要新的组织模式。

情感驱动力往往不是勇气，而是执念。

---

## 3. 他们在跳入之前先降低风险

优秀的创始人很少盲目跳入。

他们创造了一个“最低可行退路”：

```
晚上/周末：
    构建原型

↓

用户出现

↓

收入出现

↓

辞职
```

很多成功的初创公司都是这样开始的。

对于今天的AI工程师来说：

```
第1个月：
    构建agent工具

第2个月：
    100个用户

第3个月：
    $2k MRR

第6个月：
    决定是否全职
```

互联网使这成为可能。

---

## 4. 他们对失败有不同看法

很多人认为：

```
失败 = 身份损害
```

创始人通常认为：

```
失败 = 数据
```

例子：

```
尝试1：
    没人想要产品

学到：
    客户错了

尝试2：
    不同市场

学到：
    定价错误

尝试3：
    成功了
```

他们把初创公司当作强化学习：

```
环境
     |
     v
 行动
     |
 奖励/错误
     |
 更新策略
```

---

## 5. 时机很重要

当环境变化时，人们会变得勇敢。

例如，AI改变了等式：

之前：

```
1个工程师
+
想法

无法与大公司竞争
```

现在：

```
1个工程师
+
Claude/GPT/Qwen
+
开源模型
+
云端GPU

可以构建一个严肃的产品
```

实验成本大幅下降。

---

## 6. 许多创始人实际上是“被迫”的

有些人开始是因为：

* 找不到好工作
* 不喜欢公司政治
* 想要自主权
* 有经济压力
* 看到市场空白

必要性催生勇气。

---

对于拥有你背景（交付产品、训练模型、构建agent）的人来说，有趣的问题不是“我有勇气吗？”

更技术性的问题是：

```
我能找到一个10倍的问题吗
其中：
    我的AI优势是真实的
    用户愿意付费
    分销是可能的？
```

现代创始人的循环是：

```
观察问题
      ↓
在几天内构建agent/产品
      ↓
放到用户面前
      ↓
衡量
      ↓
迭代
```

现在障碍不再是勇气。障碍通常是**找到一个足够痛苦的问题并快速行动**。
