**问题：估算在你参加2013年广东高考时，出生于1994-1995年左右的广东人口有多少，包括未参加高考的人。**

我假设你指的是**2013年广东高考**，而非中考。年龄对应如下：

* 出生于**1994年** → 大多数在**2013年**参加高考，年龄18-19岁。
* 出生于**1995年** → 部分人如果跳级或早出生可能在2013年参加，但大多数在2014年参加。

2013年广东高考报名人数约为**727,000-730,000人**。([高考在线][1])

要估算**整个出生队列**，需要加上：

1. 未进入高中的人。
2. 进入高中但未参加高考的人。
3. 迁出/改变教育路径/职业路径的人。

一个粗略的人口统计计算：

### 步骤1：估算1994-1995年广东出生人口

20世纪90年代中期，中国每年出生约**2100-2200万**人。

广东人口占比大约5-6%，因此：

```
2150万 × 5.5% ≈ 118万出生/年
```

所以广东大概有：

```
1994年队列：约110-120万
1995年队列：约110-120万
```

### 步骤2：与高考参与人数比较

2013年高考：

```
约73万参与者
```

参与率：

```
73万 / 115万 ≈ 63%
```

这合理，因为并非所有人都继续走普通高中路线。

### 我的估算：

| 组别                     |       约有人数 |
| ------------------------- | -------------------: |
| 1994年出生于广东          |      110-120万 |
| 1995年出生于广东          |      110-120万 |
| 1994+1995年队列合计       |  **220-240万** |
| 2013年高考参与者          |               约73万 |
| 未参加高考者              | **约150-170万** |

所以如果你问：

> "在广东，和我年龄相仿（1994/1995年出生）的人有多少，包括那些没参加高考的？"
