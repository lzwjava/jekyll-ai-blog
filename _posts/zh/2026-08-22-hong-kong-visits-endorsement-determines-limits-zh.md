问题：持有港澳通行证，内地居民可以前往香港多少次，每次停留多长时间？

答案：

这取决于港澳通行证上附带的**签注**。通行证本身不够，还需要有效的香港签注。([国家移民管理局][1])

对于普通内地居民以旅游为目的前往香港：

| 类型                                      |                                  访问次数 | 每次停留时间 |
| ----------------------------------------- | ----------------------------------------: | ----------: |
| 香港个人旅游签注 (G)                              | 通常1次或2次，取决于签注                            |      ≤ 7天 |
| 香港团队旅游签注 (L)                              |                          通常1次或2次 |      ≤ 7天 |
| 多次入境（部分符合条件的城市/人员） |              有效期内多次 | 每次≤ 7天 |

([国家移民管理局][2])

示例：

* **3个月一次签注** → 在3个月内可进入香港一次，每次停留不超过7天。
* **3个月二次签注** → 在3个月内可进入两次，每次停留不超过7天。
* **1年一次签注** → 在一年内可进入一次，每次最多7天。
* **1年二次签注** → 在一年内可进入两次，每次最多7天。 ([辽宁省公安厅][3])

对于生活在广东（例如广州/深圳）的人来说，前往香港相对容易：

* 可以申请香港个人旅游签注。
* 广东居民通常可以享受个人旅游政策。 ([国家移民管理局][1])
* 深圳居民在特定条件下可能享有特殊的多次入境安排。 ([辽宁省公安厅][3])

如果你的目的是**在香港进行商务活动/会见客户**，旅游签注并不合适。通常需要**商务签注 (S)**，根据资格允许多次入境，每次停留通常不超过7天。 ([国家移民管理局][1])

对于你的情况（广州 + AI/软件咨询），一个实用的模式是：

1. 办理港澳通行证 + 香港签注。
2. 前往香港进行人脉拓展/客户会议。
3. 如果开始在那里进行常规的有偿业务，可以考虑设立香港公司并做相应的商务/工作安排。

香港离得足够近，许多内地创业者将其视为“近在咫尺的国际商务枢纽”，而非一次性旅游目的地。
