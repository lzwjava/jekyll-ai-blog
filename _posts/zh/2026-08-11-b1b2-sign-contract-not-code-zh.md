问题：中国公民可以持B1/B2签证进入美国，签署软件项目合同并执行该项目吗？

答案：

**签署合同：通常可以。在美国境内从事软件开发工作：通常不可以。**

B1/B2签证允许进行**商务访问活动**，包括：

* 会见客户
* 讨论项目
* 谈判合同
* 与商业伙伴咨询
* 参加会议

美国国务院明确将**"谈判合同"**列为允许的B-1商务活动。（[Travel.state.gov][1]）

示例：

✅ 中国AI/软件顾问飞往加州：

```
第1-5天：
- 与初创公司创始人会面
- 讨论需求
- 谈判价格
- 签署咨询协议
- 返回中国
```

这通常与B1签证兼容。（[Travel.state.gov][1]）

但是：

❌ 进入美国后：

```
- 在美国办公室坐班
- 为美国公司编写代码
- 收取在美国境内进行的软件开发报酬
- 像当地雇员/承包商一样工作
```

很可能被视为**未经授权的就业**。B1签证并非用于在美国境内受雇或执行劳动。（[Travel.state.gov][1]）

海外软件顾问的常见架构是：

```
中国公司/个人
        |
        | 合同
        v
美国公司

开发工作发生地：
中国/美国境外

美国访问：
- 销售
- 会议
- 架构讨论
- 培训
- 谈判
```

这样安全得多。

关键区别在于：

| 活动                                       | B1/B2     |
| ------------------------------------------ | --------- |
| 会见客户                                   | ✅         |
| 谈判合同                                   | ✅         |
| 签署协议                                   | ✅         |
| 讨论架构                                   | 通常 ✅    |
| 参加会议                                   | ✅         |
| 在美国境内编写产品代码                     | ❌ 有风险  |
| 作为美国承包商工作                         | ❌         |
| 收取美国薪资                               | ❌         |

（[Travel.state.gov][1]）

对于AI/软件创业者来说，通常的路径是：

```
中国实体
    |
    | 远程交付
    |
美国客户

偶尔的B1访问：
    - 销售
    - 合作
    - 融资会议
```

如果业务增长，你确实需要在美国工作，则应考虑其他移民途径（例如L-1、O-1、H-1B、E-2（如适用）等），而不是勉强使用B1/B2签证。（[USCIS][2]）
