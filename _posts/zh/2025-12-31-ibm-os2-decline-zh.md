# IBM OS/2: A Comprehensive Introduction

IBM OS/2 (Operating System/2) 是 20 世纪 80 年代末和 90 年代开发的一种先进的个人电脑 Operating System，以其在稳定性、Multitasking（多任务处理）和兼容性功能方面的技术优越性而闻名。尽管拥有这些优势，它最终未能实现广泛普及，并在桌面市场输给了 Microsoft Windows。

## History and Development

OS/2 由 IBM 和 Microsoft 自 1985 年开始联合开发，作为 MS-DOS 的继任者，针对 Intel 80286 及更高版本的处理器。它于 1987 年 4 月与 IBM 的 Personal System/2 (PS/2) 系列计算机一同发布，后者引入了 VGA Graphics 和 PS/2 键盘/鼠标端口等标准。

1987 年 12 月发布的第一个版本 OS/2 1.0 是一个文本模式系统，专注于 Multitasking 和 Protected Mode（保护模式）操作。1.1 版本（1988 年）增加了 Presentation Manager 图形用户界面 (GUI)。早期版本由双方共同开发，但双方在未来方向上产生了分歧——Microsoft 优先考虑 Windows，而 IBM 则专注于 OS/2。

到 1990 年，随着 Windows 3.0 的成功，合作伙伴关系解体。Microsoft 将重心完全转向 Windows，IBM 则取得了独立控制权。OS/2 2.0（1992 年）成为 IBM 开发的首个完全 32-bit 版本，并引入了面向对象的 Workplace Shell (WPS) 桌面。

最受欢迎的版本是 OS/2 Warp 3.0（1994 年），它通过内置 Internet 支持和改进的多媒体功能向消费者进行了强力推广。Warp 4.0（1996 年）增加了语音导航、Java 支持和更新的 GUI。IBM 继续提供修复补丁直到 2001 年，并于 2006 年停止支持。

## Key Features

OS/2 在当时的技术是非常先进的：

- **Preemptive Multitasking and Stability**: 真正的 Protected Mode 操作防止了应用程序崩溃影响整个系统，这与早期的 Windows 不同。
- **Compatibility**: 运行 DOS 应用程序的效果比 DOS 本身更好（“better DOS than DOS”），后续版本还能无缝运行 Windows 3.x 程序（“better Windows than Windows”）。
- **Workplace Shell (WPS)**: 一种创新的面向对象桌面，文件、文件夹和程序被视为具有拖放功能的 Object（对象）。
- **File System**: 引入了 High Performance File System (HPFS)，支持长文件名，且性能优于 FAT。
- **Multimedia and Networking**: Warp 版本包含了强大的多媒体工具、Internet 工具和 Peer-to-peer 联网功能。
- **Later Additions**: Warp 4 具备语音听写/控制、OpenGL 和 Java 集成功能。

OS/2 的目标市场既包括 Enterprise（如银行、ATM），也包括消费者市场，但因其可靠性，在任务关键型环境中表现尤为出色。

## Why It Failed Against Windows

尽管具有优势，但 OS/2 从未获得显著的市场份额：

- **Microsoft's Tactics**: 激进的市场营销，通过 OEM 协议在 PC 上预装 Windows，以及所谓的破坏行为（例如，在更新中破坏 OS/2 的 Windows 兼容性）。
- **IBM's Missteps**: 消费者营销不力、定价过高、被认为与昂贵的 IBM 硬件绑定、发布延迟以及缺乏对第三方硬件的 Driver（驱动程序）支持。
- **Application Ecosystem**: 开发者因 Windows 拥有庞大的用户群而青睐它；OS/2 优秀的 Windows 兼容性反而降低了开发原生应用的动力。
- **Timing and Perception**: 发布时正值 Windows 3.x 激增期；消费者认为 OS/2 占用资源过多，且缺乏足够的独特软件。

到 20 世纪 90 年代中期，Windows 95 凭借类似的功能和更广泛的支持占领了市场。

## Legacy

OS/2 影响了现代 OS 的设计（例如 Windows NT 中的 Multitasking 概念）。它在衍生系统如 ArcaOS（由 Arca Noae 维护）和 eComStation 中继续存在。爱好者们仍因其稳定性而使用它，它也依然为银行和工业领域的旧有系统提供动力。

OS/2 代表了计算历史上的一种“假设”——一个因商业动态而非技术缺陷而被削弱的优秀操作系统。
