| ---------------- | --------------------: |
| 架构              |                Turing |

| Tensor 核心数     |                   544 |
| RT 核心数         |                    68 |
| 显存              | 11GB GDDR6（原始）    |
| 显存位宽          |               352-bit |

## 为什么存在 22GB 版本？

GPU 芯片本身没有变化。升级主要体现在：

```
原始版本：

GPU
 |
 +-- 11GB GDDR6


改装版本：

GPU
 |
 +-- 22GB GDDR6
```

RTX 2080 Ti 拥有 352-bit 显存位宽。制造商可以将 1GB GDDR6 芯片替换为 2GB 芯片：

* 11 × 1GB 芯片 → 11GB
* 11 × 2GB 芯片 → 22GB

由于位宽不变，带宽大致保持不变。

## AI / LLM 用途

22GB 的 RTX 2080 Ti 之所以受关注，是因为对于许多 AI 工作负载而言，显存比原始算力更重要。

### 模型加载示例（近似显存需求）

| 模型          |  FP16 |  INT8 | 4-bit |
| ---------- | ----: | ----: | ----: |
| Llama 7B   | ~14GB |  ~7GB |  ~4GB |
| Qwen2.5 7B | ~14GB |  ~7GB |  ~4GB |
| Qwen3 8B   | ~16GB |  ~8GB |  ~5GB |
| 13B 模型    | ~26GB | ~13GB |  ~7GB |
| 30B 模型    | ~60GB | ~30GB | ~15GB |

一张 22GB 的卡可以流畅运行：

* Qwen 7B/8B FP16
* 13B INT8
* 30B+ 量化模型

对于微调：

### LoRA / QLoRA

22GB 比你的 RTX 4070 12GB 要好得多。

示例：

```
Qwen2.5-7B QLoRA

RTX 12GB：
- 可行
- batch size 很紧
- 需要梯度检查点

RTX 22GB：
- 轻松得多
- 更大的上下文
- 更大的 batch
```

| ---------------- | -----------: | ---------------: |
| 架构              | Ada Lovelace |           Turing |
| 显存              |         12GB |             22GB |

| Tensor 核心数     |          184 |              544 |
| FP32 算力         |   ~29 TFLOPS |       ~13 TFLOPS |
| 显存带宽          |     504 GB/s |         616 GB/s |

对于推理：

* 小模型 → RTX 4070 胜出
* 受限于显存的大模型 → 2080 Ti 22GB 胜出

对于 LLM 训练/微调：

```
显存 > 算力
```

一张 22GB 的卡可以解锁在 12GB 上无法进行的实验。

## RTX 2080 Ti 22GB 的缺点

1. **无官方 NVIDIA 支持**

   * 这是改装卡。
   * 驱动通常能正常工作，因为 GPU ID 未变。

2. **更老的 Tensor 核心**

   * 没有像 Ampere/Ada 那样的 BF16 加速。
   * Transformer 性能较差。

3. **能效**

   * 250W+ 功耗，但性能远低于现代卡。

4. **二手市场风险**

   * 许多改装卡来自矿场。
