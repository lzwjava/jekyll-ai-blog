### 最大优势：极致的便携性

富士通历来近乎偏执地追求让 LIFEBOOK U/UH 系列机型变得轻盈。

例如，13.3 英寸的 LIFEBOOK UH75/B1 仅重约 **761 克**。富士通通过采用镁锂/镁合金材质和大量的结构优化实现了这一目标。([PC Watch][1])

更早的 U937 型号重约 **920 克**，采用镁合金结构，并配备了非常丰富的接口，包括 USB-A、USB-C、HDMI、SD 卡槽、以太网接口，甚至可选 LTE。([Tech Advisor][2])

这就是富士通特有的权衡：

```text
          便携性
              ↑
              │
       Fujitsu LIFEBOOK
              │
              │
ThinkPad ─────┼───── MacBook
              │
              │
         性能
```

它的设计基本围绕：

> **“我需要一台几乎感觉不到重量的真正的电脑。”**

### 键盘：出人意料的出色

这是我认为你可能会喜欢它的原因之一。

富士通在键盘工程上投入了大量精力。后来的 UH 系列设计采用了约 **19mm 的键距**、合理的方向键布局以及精心调校的按键力度。一些评测者认为其键盘是机器最出色的部分之一。([PC Watch][1])

但有一个重要的注意事项：**LIFEBOOK 的键盘质量因代际而异。** 一些较老型号的键盘手感偏浅或绵软，并且有记录显示特定 UH75 机型存在按键失灵的问题。([PC Watch][3])

所以，不要仅凭品牌就购买 LIFEBOOK。**具体型号至关重要。**

### 做工质量：情况更为复杂

这是评测中意见不一的地方。

镁合金机身可以在非常轻的同时，仍能通过严格的耐用性测试。例如，UH 系列经历了跌落、振动、压力和键盘耐久性测试。([PC Watch][1])

但由于材料极薄，一些机型 ****感觉不如 ThinkPad 扎实**。例如 U937，尽管极其轻便，但也因其机身刚性不足而受到批评。([IT Pro][4])

所以：

```text
ThinkPad:
    “我大概可以把这个扔进背包里。”

LIFEBOOK U/UH:
    “我几乎感觉不到背包里有它。”
```

后者并不一定更脆弱；只是**感觉**上没有前者那么厚重。

### LIFEBOOK 特别值得关注的领域：二手市场

这实际上是我会留意的领域。

较老的商务版 LIFEBOOK 在二手市场上可能**非常便宜**，同时仍然能提供：

*   13–14 英寸屏幕
*   极佳的便携性
*   USB-A 接口
*   USB-C 接口
*   HDMI 接口
*   部分型号带以太网接口
*   SD 卡槽
*   部分代际的组件可更换/可维护
*   企业级的 Windows 支持
*   有时带 LTE 功能
*   出人意料的优秀键盘

对于主要从事以下工作的人来说：

```bash
vim
tmux
ssh
python
git
docker
claude
browser
terminal
```

一台较旧的 LIFEBOOK U 系列可以作为绝佳的 **Linux/SSH/旅行伴侣**。
