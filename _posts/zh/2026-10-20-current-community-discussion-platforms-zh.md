**问题：** 目前有哪些正在运行的社区/讨论网站和平台——例如 Discord 及其他，包括开源和 BBS 风格的系统？

---

**回答：**

以下按类别分类：

---

### 💬 聊天式（实时）

| 平台 | 开源 | 备注 |
|---|---|---|
| **Discord** | ❌ | 主导性聊天平台；免费，专有 |
| **Matrix / Element** | ✅ | 去中心化、加密；用户数达数亿，在政府和公共部门市场表现良好 |
| **Rocket.Chat** | ✅ | 可自托管的 Slack 替代品；2015 年发布 |
| **Mattermost** | ✅ | 面向团队，自托管 |
| **Zulip** | ✅ | 组织有序的线程化对话 |
| **Telegram** | ❌ | 群聊和频道中广受欢迎 |

---

### 📋 论坛 / BBS 风格（异步讨论）

| 平台 | 开源 | 备注 |
|---|---|---|
| **Discourse** | ✅ | 2026 年排名第一的论坛软件；现代设计，强大的审核工具 |
| **Flarum** | ✅ | 基于 Laravel 构建；轻量级，现代设计 |
| **phpBB** | ✅ | 经典免费 BBS；基于 PHP，久经考验 |
| **MyBB** | ✅ | 活跃的开发者社区，定期提供更新和安全修复 |
| **NodeBB** | ✅ | 基于 Node.js 的现代论坛 |
| **Vanilla Forums** | ✅ | 基于 PHP，带有插件 API |
| **XenForo** | ❌ | 传统论坛软件，为多个大型社区提供支持 |
| **Forem** | ✅ | 旨在帮助建立包容、可持续的在线社区（为 dev.to 提供支持） |

---

### 🌐 Fediverse / 去中心化（ActivityPub）

这些平台相互联合——一个平台上的用户可以与另一个平台上的用户互动：

| 平台 | 类型 | 备注 |
|---|---|---|
| **Mastodon** | 微博客 | 截至 2026 年 3 月约 77.7 万月活跃用户 |
| **Lemmy** | 类 Reddit 链接聚合器 | 2026 年稳步发展，定期发布版本，客户端生态系统不断壮大；约 455 个实例，约 4.86 万月活跃用户 |
| **Mbin / Kbin** | 链接聚合器 | 兼容 Lemmy 的 threadiverse 替代方案 |
| **PieFed** | 类 Reddit | 增长迅速——从一年前的 295 月活跃用户增长至现在的约 4926 月活跃用户 |
| **PeerTube** | 视频托管 | Fediverse 中的 YouTube 替代方案 |
| **Bluesky** | 微博客 | 去中心化协议（AT 协议），非 ActivityPub；据报道目前正在蚕食 Mastodon 的用户 |

---

### 📊 开源社区通常聚集的地方

在分析的开源软件社区中：Discord 占 41%，GitHub 占 32%，Slack 占 18%，Reddit 占 14%，Discourse 占 5%。

---

**按使用场景推荐：**

- **想要经典 BBS/论坛？** → Discourse 或 Flarum（自托管）
- **想要实时聊天？** → Matrix/Element（开源、加密）或 Rocket.Chat
- **想要 Reddit 替代品？** → Lemmy 或 PieFed（联合、开源）
- **想要类似 Twitter 的微博客？** → Mastodon 或 Bluesky
- **只想即插即用？** → Discord（专有但免费）
