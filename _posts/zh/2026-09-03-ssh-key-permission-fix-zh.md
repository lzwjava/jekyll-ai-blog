已修复。文件权限从 `0644`（`-rw-r--r--`）改为 `0600`（`-rw-------`）。

## 权限含义说明

| | 修改前 (`0644`) | 修改后 (`0600`) |
|---|---|---|
| 所有者 | 读取 ✅ 写入 ✅ | 读取 ✅ 写入 ✅ |
| 用户组 | 读取 ✅ | ❌ |
| 其他用户 | 读取 ✅ | ❌ |

如果**非文件所有者之外的任何人**能够读取私钥文件，SSH 会拒绝使用该密钥，因为这存在安全风险。

## 注意事项

- `0600` = 仅限所有者访问（个人密钥最常见设置）
- `0400` = 所有者只读（更严格的设置，同样可行）
- 权限后的 `@` 符号表示该文件包含**扩展属性**（可能是 macOS 的隔离/Spotlight 元数据）—— 这无害且与 SSH 错误无关
- 无需使用 `chown`（更改所有者）—— 文件已属于您（`lzwsta`）。问题仅在权限**位**上，`chmod` 已修复

现在您应该可以正常使用该密钥，不会出现"权限错误"提示：

```bash
ssh -i private_key.pem user@host
```
