问题：**为搭载 Tesla P100 的华南金牌 X99-BD4 主板，应该搭配哪款 CPU？**

答案：选择 **Xeon E5 v4**，尤其是当这台机器用作 AI/计算节点时。

### 我的推荐

| CPU | 核心/线程 | TDP | 理由 |
| -------------- | ---------: | ---: | ---------------------------------- |
| **E5-2683 v4** | 16 / 32 | 120W | **最佳性价比选择** |
| **E5-2690 v4** | 14 / 28 | 135W | 更高频率 |
| **E5-2697 v4** | 18 / 36 | 145W | 更强的 CPU 吞吐能力 |
| E5-2680 v4 | 14 / 28 | 120W | 廉价替代品 |
| E5-2699 v4 | 22 / 44 | 145W | 核心数最多，但通常性价比不高 |

对于 **单路 P100**，我会选择 **E5-2683 v4**。

```text
X99-BD4
   │
   └── E5-2683 v4
          │
          ├── 16C / 32T
          ├── 40条 PCIe 3.0 通道
          └── 120W
                  │
                  └── Tesla P100 16GB
```

在你的配置中，关键在于 **PCIe 通道数**，而非 CPU 的浮点算力。E5-2683 v4 提供了充足的 PCIe 连接能力，足以支撑一个 P100 + NVMe + 网卡。

### 如果你要组建双路 P100

我仍然推荐：

**E5-2683 v4 → 绝佳的廉价选择**

或

**E5-2697 v4 → 如果你确实有 CPU 端的工作负载。**

我不会为了喂饱 GPU 而把钱花在 E5-2699 v4 上。P100 才是计算的主力。

### 一个警告

这些国产 X99 主板对 BIOS/CPU 兼容性比较挑剔。**E5-2683 v4 是 Broadwell-EP 架构**，所以在批量购买前，务必确认 BD4 的特定 BIOS 版本支持 v4 系列 CPU。

如果你要买 **200 块 X99-BD4 主板**，我建议先在单块主板上用 **E5-2683 v4 + P100 + 128GB DDR4** 实际测试以下命令，再决定是否批量采购：

```bash
lscpu
lspci -nn
nvidia-smi
```
