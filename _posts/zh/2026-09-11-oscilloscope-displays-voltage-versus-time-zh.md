问题：为什么示波器有时显示正弦/余弦波，有时显示三角波或方波？

答案：

因为示波器只是绘制**电压随时间变化**的图像：

$$
y = V(t)
$$

你看到的**波形就是电路/设备实际产生的时域波形**。

### 1. 正弦波

正弦波来自某种平滑振荡的源：

$$
V(t)=A\sin(2\pi ft+\phi)
$$

例如：交流电源、函数发生器或振荡器。

概念上：

```text
电压
  ^
 A|      /‾\       /‾\
  |     /   \     /   \
  |----/-----\---/-----\----> 时间
  |   /       \ /       \
-A|__/         V         \__
```

电压**连续且平滑地变化**。

---

### 2. 三角波

三角波发生器使电压近似线性上升，再线性下降：

```text
电压
  ^
  |      /\
  |     /  \
  |    /    \
  |   /      \
  |__/        \__
  +-----------------> 时间
```

数学上，它基本上是**线性上升斜坡 + 线性下降斜坡**。

所以，示波器并没有“把正弦波变成三角波”——电路本身就在产生三角波形。

---

### 3. 方波

数字电路可以在两个电压电平之间切换：

```text
电压
  ^
  | ┌──────┐      ┌──────┐
  | │      │      │      │
  | │      │      │      │
  |─┘      └──────┘      └──> 时间
  |
```

例如：

```text
LOW  = 0 V
HIGH = 3.3 V
```

一个微控制器GPIO产生：

```python
while True:
    GPIO = 1
    GPIO = 0
```

理想情况下会输出方波。

---

### 4. 重要概念

把示波器看作一台**随时间记录电压的摄像机**。

它测量：

```text
时间 ───────────────>
        |
        v
     电压
```

因此：

| 电路输出 | 示波器显示       |
| -------- | ---------------- |
| 正弦波   | 平滑正弦         |
| 三角波   | 三角形           |
| 方波     | 矩形             |
| 锯齿波   | 斜坡 + 突然下降  |
| 直流     | 水平线           |
| 噪声信号 | 不规则波形       |

这就是为什么示波器对你的GPU维修工作如此有用：**你可以探测一条电源轨，观察其电压是否实际行为正常**，而不仅仅是用万用表测量其平均直流电压。

例如，一个GPU VRM可能在万用表上显示“1.0 V”，而示波器却揭示出“1.0 V + 50 mV 纹波，频率为数百kHz”。这个纹波可能极其重要。

我也可以进一步讲解**示波器是如何对电压进行物理采样并重建这些波形的**，包括ADC → 采样缓冲区 → 触发 → 显示。
