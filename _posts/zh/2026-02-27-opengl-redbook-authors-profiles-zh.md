**Jackie Neider**、**Tom Davis** 和 **Mason Woo** 是《*The OpenGL Programming Guide*》第一版（通常称为“Red Book”）的主要作者，该书由 Addison-Wesley 于 1993 年出版。这本书是学习 OpenGL 的官方指南，OpenGL 是一种跨平台图形 API，由 Silicon Graphics (SGI) 最初开发。他们是 SGI 在 OpenGL 早期开发和推广期间的关键人物。

- **Mason Woo**
  Mason Woo 是 Silicon Graphics (SGI) 的著名工程师和图形专家。他负责图形技术许可，包括与 OpenGL 相关的努力，并在 OpenGL Architecture Review Board 中发挥重要作用。他合著了多版 Red Book，并参与在 SIGGRAPH 会议上呈现 OpenGL 课程。在职业生涯后期，他贡献于其他图形项目，包括编写 Apple 的 Metal Programming Guide 早期版本。Woo 经常被认为是早期 OpenGL 文档和教育的领军人物。

- **Jackie Neider**
  Jackie Neider（旧来源有时使用男性代词，但细节有限）是 SGI 工程师，深入参与 OpenGL 开发和文档工作。他编写了第一个商业 OpenGL 培训课程，到该书出版时已有超过二十年的计算机图形应用开发经验。Neider 在 Red Book 中对 OpenGL 功能进行了重要解释，并继续参与后续版本（例如版本更新的致谢）。他的工作重点是实用图形编程和培训。

- **Tom Davis**
  Tom Davis 是 Silicon Graphics 的数学家和软件工程师，具有扎实的计算机图形背景。他拥有 Caltech 的学士学位和 Stanford 的数学博士学位，随后在 Stanford 电气工程系进行博士后工作。在 SGI，他贡献于图形工具和库（包括与用户界面元素相关的早期工作，如用于 SGI dogfight demo 的 MUI）。Davis 合著了初版 Red Book，并帮助定义了对 OpenGL 几何建模、渲染和管线概念的清晰解释。

这三人共同在 OpenGL Architecture Review Board 的支持下编写了 1993 年的基础版本，使 OpenGL 为全球开发者所用。他们的书成为基石参考资料（因封面颜色而常称为“Red Book”），并影响了几代图形程序员，包括 NVIDIA 在早期 GPU 开发时期的程序员。
