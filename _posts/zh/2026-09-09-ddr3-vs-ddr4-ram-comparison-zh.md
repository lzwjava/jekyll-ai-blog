问题：比较 **DDR3 与 DDR4 RAM**。

答案：

| 特性                    |                       DDR3 |                          DDR4 |
| ----------------------- | -------------------------: | ----------------------------: |
| 典型电压                |     **1.5V**（1.35V DDR3L） |                      **1.2V** |
| 典型速度                |             1333–2133 MT/s |               2133–3200+ MT/s |
| 常见台式机容量          |              4–8 GB/模块   |                8–32 GB/模块   |
| 理论带宽                |                      较低  |                         更高  |
| 延迟                    | 通常绝对纳秒值较低         | 通常实际延迟相似              |
| 针脚数（台式机 DIMM）   |                        240 |                           288 |
| 缺口位置                |                      不同  |                         不同  |
| 兼容性                  |        仅限 DDR3 主板       |          仅限 DDR4 主板       |
| 内存控制器架构          |                      较旧  |                         较新  |
| 能效                    |                      较差  |                         更好  |

### 重要部分：DDR4 不向后兼容

**不能将 DDR3 插入 DDR4 主板**，尽管两者都称为 DIMM，外观相似。

例如：

```text
Intel B85 / H81 / Z97
        │
        └── DDR3

Intel B150 / B250 / B360 / B365
        │
        └── DDR4

Intel B760 DDR4
        │
        └── DDR4
```

物理缺口位置不同，电气接口也不同。

### 性能

简化的带宽计算：

```text
带宽 = MT/s × 8 字节
```

所以：

```text
DDR3-1600
1600 × 8 = 12.8 GB/s 每通道

DDR4-3200
3200 × 8 = 25.6 GB/s 每通道
```

对于双通道：

```text
DDR3-1600 → 25.6 GB/s
DDR4-3200 → 51.2 GB/s
```

因此 DDR4-3200 的理论内存带宽大约是 DDR3-1600 的 **2 倍**。

但不要指望应用程序速度提升 2 倍——CPU 缓存层次结构和工作负载影响巨大。

### 对于你的廉价主板/显卡测试平台项目

购买二手硬件时这种区别尤其有用：

```text
B85 / H97 / Z97  → DDR3
B150 / B250      → DDR4
B360 / B365      → DDR4
B660 / B760      → DDR4 或 DDR5，具体取决于主板型号
```

而且 **B760M DDR4** 和 **B760M DDR5** 是不同版本的主板。DDR4 的 B760 主板不能使用 DDR5。

如果你要购买二手内存，我还可以给你一份 **按 Intel CPU 代际（第 4 代 → 第 14 代）划分的 DDR3/DDR4 兼容性速查表**，这对你在闲鱼上淘硬件很有用。
