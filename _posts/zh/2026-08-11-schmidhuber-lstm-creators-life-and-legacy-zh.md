问题：LSTM作者朱利安·xxx的生平故事是怎样的？

回答：

我认为你指的是 **Jürgen Schmidhuber**，LSTM背后的关键人物之一，而不是"Julien"。LSTM由 **Sepp Hochreiter 和 Jürgen Schmidhuber** 在20世纪90年代共同创建。（[维基百科][1]）

Jürgen Schmidhuber 作为人工智能研究员，有着非常不寻常的人生故事。

### 早年生活

* 1963年出生于德国慕尼黑。
* 小时候，他对创造能够自我改进的人工智能的想法着迷。
* 与许多通过传统计算机科学进入人工智能领域的研究者不同，他深受**自我改进机器和人工好奇心**的影响。

他早期的思考不仅仅是"解决一个任务"，而是：

> 我们能否建造一台能够自行发现更好算法的机器？

这个主题贯穿了他的整个职业生涯。

### 学术道路

他在慕尼黑工业大学学习计算机科学。

他的博士研究方向是神经网络和学习算法。在此期间，他与 Sepp Hochreiter 合作，后者在其论文中研究了循环神经网络中的**梯度消失问题**。这项工作成为LSTM的基础。（[维基百科][1]）

### LSTM的发明（20世纪90年代）

传统的RNN存在一个主要问题：

在训练时：

```
h_t = f(W_h h_(t-1) + W_x x_t)
```

梯度：

```
∂Loss / ∂h_t
```

会在多个时间步中反复相乘。

如果数值小于1：

```
0.9^100 ≈ 0.000026
```

模型就会"忘记"长期信息。

Hochreiter 和 Schmidhuber 提出了LSTM：

```
遗忘门
输入门
输出门
记忆单元
```

关键思想：

不再强制信息通过重复的非线性变换，而是创建一个受控的记忆高速公路：

```
c_t = f_t * c_(t-1) + i_t * g_t
```

其中：

* `f_t` 决定遗忘什么
* `i_t` 决定哪些新信息进入
* `c_t` 存储长期记忆

第一篇LSTM论文出现在20世纪90年代中期，后来的版本增加了遗忘门，这成为标准配置。（[维基百科][1]）

### LSTM之后的职业生涯

Schmidhuber 继续研究：

* 元学习
* 神经架构搜索
* 人工好奇心
* 自我改进的人工智能
* 将压缩视为智能

他在瑞士创立了AI研究实验室IDSIA，并以预测现代深度学习的许多方向而闻名。

他的学生和合作者影响了许多后来的AI系统。

### 个性与哲学

他是一位非常注重"第一性原理"的研究者。

一个反复出现的想法：

> 智能 = 压缩 + 预测 + 自我改进。

他经常认为，一个足够强大的学习系统应该能够发现模式并自我改进。

这在精神上与当代LLM的扩展类似：

```
更多数据
+
更大模型
+
更优优化
=
涌现能力
```

### 与现代AI创始人的比较

有趣的对比：

| 人物        | 主要贡献                              |
| ----------- | ------------------------------------- |
| Schmidhuber | 学习算法、LSTM、自我改进AI思想        |
