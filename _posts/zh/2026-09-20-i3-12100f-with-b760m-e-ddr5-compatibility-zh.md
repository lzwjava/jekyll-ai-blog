**问题：** Intel Core i3-12100F 是否与 MSI PRO B760M-E DDR5 主板兼容？

**回答：**

是的，**Intel Core i3-12100F** 与这款主板兼容。以下是简要说明：

### ✅ 兼容性检查

| 特性 | 详情 |
|---|---|
| **插槽** | LGA1700 ✅ |
| **代次** | 第12代（Alder Lake） ✅ |
| **芯片组支持** | B760 支持第12代 ✅ |
| **内存类型** | DDR5 ✅ |

### 📊 i3-12100F 快速规格

| 规格 | 参数 |
|---|---|
| **核心 / 线程** | 4 核 / 8 线程 |
| **基础频率** | 3.3 GHz |
| **加速频率** | 4.3 GHz |
| **TDP** | 58W |
| **核显** | ❌ 无（F = 无核显） |

### ⚠️ 重要提示 — “F” 后缀

由于 i3-12100**F** 没有**集成显卡**，您需要一块**独立显卡**才能获得显示输出。如果没有带核显的 CPU，主板上的 HDMI/DisplayPort 接口将**无法工作**。

### 💡 结论

对于 B760M-E DDR5 来说，这是一个不错的预算选择——能效高，可满足日常任务和轻度游戏需求，而且价格非常实惠。只需确保搭配一块独立显卡即可。
