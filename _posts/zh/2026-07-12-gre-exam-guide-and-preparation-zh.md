问题：如何参加GRE考试以及如何备考？

答案：

GRE（研究生入学考试）是一项主要用于**研究生院招生**（尤其是硕士、博士、MBA及部分计算机科学/人工智能项目）的标准化考试。由美国教育考试服务中心（ETS）主办。

## 1. GRE考试结构（当前）

GRE普通考试包含3个部分：

| 部分 | 时间 | 内容 |
| ---------------------- | ------: | --------------------------------------------------- |
| 分析性写作 | 30分钟 | 一篇作文：分析一个议题 |
| 语文推理 | ~41分钟 | 词汇、阅读理解、逻辑 |
| 数学推理 | ~47分钟 | 数学（代数、几何、统计、数据分析） |

总时长：约**1小时58分钟**。

评分：

* 语文：130–170
* 数学：130–170
* 写作：0–6

对于计算机科学/人工智能申请者：

* 数学：通常目标**165–170**
* 语文：150–160通常可接受
* 写作：3.5–5.0较为常见

---

## 2. 如何报名

1. 创建ETS账号：

   * [GRE官方网站](https://www.ets.org/gre?utm_source=chatgpt.com)

2. 选择：

   * 考试中心（机考）
   * 或在家考GRE（在线监考）

3. 支付考试费用：

   * 通常约为**220–230美元**（因国家而异）

4. 选择成绩接收院校：

   * 可向大学发送成绩。

GRE可多次参加。ETS允许大约每21天重考一次。

# 备考策略

鉴于您的背景（软件工程师 + 人工智能/机器学习），瓶颈很可能在于**语文**而非数学。

一个现实的时间规划：

## 3个月备考

### 第1个月：基础

### 数学

您可能已经掌握了大部分数学知识。

复习内容：

* 算术
* 代数
* 函数
* 几何
* 概率
* 统计
* 组合数学

资源：

* 官方GRE超级力量包
* Manhattan Prep 5磅GRE练习题集

目标：

* 完成所有概念
* 做不计时练习

---

### 语文

这是大多数国际工程师的难点。

GRE词汇是传统的学术英语。

示例词汇：

* ubiquitous（无处不在的）
* ephemeral（短暂的）
* pragmatic（务实的）
* ambivalent（矛盾的）
* corroborate（证实）
* exacerbate（加剧）
* mitigate（减轻）

大约需要：

* 1000–1500个高频GRE词汇

工具：

* Anki
* Quizlet
* Magoosh GRE词汇

每日安排：

```
30分钟 词汇
30分钟 阅读
```

阅读材料：

* 《科学美国人》
* 《经济学人》
* 《纽约时报》评论

这项技能不仅仅是词汇，更是理解密集的论点。

# 第2个月：练习

开始计时练习。

使用官方材料：

* [ETS GRE练习题](https://www.ets.org/gre/test-takers/general-test/prepare/practice-tests.html?utm_source=chatgpt.com)

安排：

```
周一：
数学练习

周二：
语文练习

周三：
词汇复习

周四：
阅读理解

周五：
作文

周末：
完整模拟测试
```

记录错题。

示例：

```
题目：
为什么错？

类型：
词汇

错误原因：
不认识"laconic"

改进：
添加Anki卡片
```

# 作文准备

GRE作文有固定模式。

结构：

```
引言

第1段：
主要论点

第2段：
反驳论点

第3段：
例子

结论
```

不需要创意写作。

需要的是：

* 清晰的论点
* 逻辑推理
* 具体例子
