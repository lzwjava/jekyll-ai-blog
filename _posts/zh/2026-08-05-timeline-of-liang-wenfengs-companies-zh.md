问题：梁文锋是什么时候注册公司的？他是先回到成都，待了几年，之后才创办雅克比吗？

回答：

时间线大致如下：

```
2002-2010
  浙江大学
  - 学习电子信息工程
  - 攻读硕士学位
  - 开始探索机器学习/量化交易相关想法

约2010-2013
  毕业后回到成都
  - 尝试了几个AI相关的创业想法
  - 这些尝试并未成功
  - 之后将重心转向金融+AI
```

“回到成都待了几年才注册公司”的说法大致符合他早期履历的描述，但成都这段时期的具体细节公开资料并不多。([维基百科][1])

然后：

```
2013-09-10
  创办：
  杭州雅克比投资管理有限公司

  创始人：
  梁文锋 + 徐进（浙江大学校友）

  业务：
  量化投资 / AI辅助交易
```

公司注册日期为**2013年9月10日**。([BOSS直聘][2])

接着：

```
2015
  创办：
  杭州幻方科技有限公司 / 幻方量化（High-Flyer相关）

  方向：
  量化对冲基金
  机器学习 + 交易
```

([火山引擎开发者社区][3])

之后：

```
2023-07-17
  创办：
  杭州深度求索人工智能基础技术研究有限公司（DeepSeek）

  方向：
  基础模型 / AGI研究
```

([维基百科][4])

所以你的理解基本正确：

**梁文锋并非毕业后直接注册AI公司。**

实际路径更像是：

```
浙江大学
        |
        个
回到成都
（尝试AI创业想法，经历失败）
        |
        个
量化交易 + AI
        |
        个
2013 雅克比
        |
        个
2015 幻方 / High-Flyer
        |
        个
2023 DeepSeek
```

有趣的是，DeepSeek并非他的第一家创业公司。到进入大语言模型领域时，他已经拥有约**10年的公司运营经验**、一家盈利的量化交易企业，以及大规模计算方面的经验。([Business Insider Japan][5])

这也是为什么DeepSeek的起源故事与许多AI初创公司不同：它更接近于**“一个量化研究实验室演变为AI研究实验室”**，而非普通的软件创业公司。([维基百科][4])
