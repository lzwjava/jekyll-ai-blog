**问题：** "芒果冰箱"是否可行？将芒果放入后，成熟后自动开始冷却？由于成熟时间不同，是否需要单独处理每个芒果？

**答案：** 是的，这正是核心挑战。一台智能芒果冰箱很可能需要对每个芒果进行单独感知/控制，而不仅仅是一个全局计时器。

芒果的成熟过程变化很大：

* 不同芒果品种 → 不同的成熟曲线
* 不同采收成熟度 → 不同时间
* 运输过程中的温度历史 → 不同
* 大小、糖度、硬度 → 不同
* 一个芒果可能2天成熟，另一个可能需要7天

一个简单的实现：

```
芒果进入冰箱

        |
        v

摄像头 + 传感器估算成熟度

        |
        v

AI 预测"可食用"时间

        |
        v

当成熟时：
    ↓
启动冷却
    ↓
减缓进一步成熟
```

理想的产品并非真正的"芒果冰箱"，更像是一个**水果成熟管理系统**。

对于每个芒果：

```
芒果 #1：
  第0天：青绿
  第3天：成熟
  → 冷却开启

芒果 #2：
  第0天：青绿
  第6天：成熟
  → 冷却开启

芒果 #3：
  第0天：接近成熟
  第1天：成熟
  → 冷却开启
```

从技术上讲，你可以用以下方式构建：

### 1. 重量传感器

成熟过程中会导致水分流失变化。

### 2. 气体传感器

芒果释放乙烯：

```
成熟 → 乙烯 ↑
```

一个小型腔体可以测量乙烯浓度。

### 3. 计算机视觉

摄像头估算：

* 颜色变化
* 果皮纹理
* 皱纹
* 形状

一个小型视觉模型可以分类：

```
青绿 → 转色 → 成熟 → 过熟
```

### 4. 独立隔间

例如：

```
+----------------+
| 芒果1 | 温度 |
| 芒果2 | 温度 |
| 芒果3 | 温度 |
| 芒果4 | 温度 |
+----------------+
```

每个槽位控制气流/冷却。

更重要的见解：**冷却不是难点，预测才是难点。**

普通冰箱已经知道如何冷却。AI的挑战在于：

> "在精确的这一刻，这个特定的芒果达到了最佳食用品质。"

这与以下情况类似：

* 智能酒柜
* 奶酪陈化柜
* 雪茄保湿盒
* 智能肉类熟成系统

第一个MVP可以更简单：

```
智能芒果盒

- 摄像头
- 温度传感器
- 湿度传感器
- 小风扇
- App 通知

"您的芒果明天将成熟。
已开始冷却。"
```

你可能不需要每个芒果配一个压缩机。单独感知 + 共享冷却腔体可能已经抓住了大部分价值。"一芒果一处理"这个想法在**预测/控制层**是正确的，但在硬件冷却层不一定需要。
