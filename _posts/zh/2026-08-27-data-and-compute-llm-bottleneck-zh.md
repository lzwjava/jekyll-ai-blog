问题：LLM的进步更可能来自架构创新，还是主要瓶颈仍然是数据？

回答：

是的，架构创新值得探索，但对于当前的LLM，瓶颈往往是**数据 + 计算 + 扩展方法**，而不仅仅是Transformer模块。

一个有用的分解：

```
模型质量 ≈ 架构 × 数据 × 优化 × 计算
```

对于GPT规模的模型，架构改进通常带来**10–30%的收益**，而更好的数据则可能带来**数倍**的提升。

---

## 1. 为什么数据成了难点

早期的GPT：

```
GPT-2 (2019)
参数：1.5B
训练token数：~40B
```

如今：

```
大型模型：
参数：数千亿
token数：数万亿
```

互联网是有限的。高质量文本更是有限。

问题不在于：

> “我们能收集更多文本吗？”

而是：

> “我们能创造更多高质量的学习信号吗？”

例子：

### 低质量数据

```
“猫坐在垫子上。”
“猫坐在垫子上。”
（重复100万次）
```

没有新信息。

### 高质量数据

```
一本讲解物理的教科书
一个包含bug和修复的GitHub仓库
一个数学证明
一篇科学论文
一段长推理链
一段高质量对话
```

模型学习的是底层分布。

## 2. 架构仍有巨大机会

Transformer很可能不是最终架构。

当前的Transformer：

```
Token
 |
Embedding
 |
Attention
 |
MLP
 |
Attention
 |
MLP
 |
...
 |
输出
```

核心限制：

Attention：

$$
O(n^2)
$$

对于上下文长度：

```
4K tokens    尚可
128K tokens  昂贵
1M tokens    痛苦
```

可能的方向：

---

### A. 更好的记忆系统

人脑不会把所有信息都放在工作记忆中。

当前的LLM：

```
输入上下文
     |
Transformer
     |
回答
```

未来：

```
短期记忆
        |
        v
推理引擎
        |
        v
长期记忆数据库
```

这就是为什么Agent系统有趣。

---

### B. 混合专家模型 (MoE)

不是：

```
每个token使用所有参数

70B模型
==========
70B活跃
```

而是：

```
70B总参数

Token 1 -> 专家 3
Token 2 -> 专家 7
Token 3 -> 专家 12
```

只激活部分参数。

这带来了：

```
更大的知识量
更低的推理成本
```

---

### C. 神经+符号混合

当前的LLM：

```
权重 = 记忆
```

问题：

更新知识需要重新训练。

未来：

```
LLM
 |
 +-- 神经推理
 |
 +-- 数据库
 |
 +-- 代码执行
 |
 +-- 模拟器
```

类似于人类的工作方式。

---

### D. 新的训练目标

当前：

预测下一个token：

$$
P(x_{t+1}|x_1...x_t)
$$

可能不是最优的。

人类学习：

* 预测未来
* 交互
* 实验
* 失败
* 纠正

婴儿不是通过阅读10万亿个token来学习的。

未来：

```
世界模型
+
模拟
+
行动
+
反馈
```

## 3. 对于像你这样的人，探索架构实际上是合理的

因为你已经训练过：

* GPT-2 124M
* nanoGPT实验
* 小模型

下一步不一定非得是“再训练一个GPT-2”。

更有趣的是：

构建能测试想法的小模型。

例子：

```
my-model/
 ├── transformer.py
 ├── moe.py
 ├── memory.py
 ├── retrieval.py
 ├── trainer.py
```

实验：

### 实验1：添加外部记忆

基线：

```
GPT-124M
```

对比：

```
GPT-124M
+
向量记忆
```

衡量：

* 困惑度
* 长上下文召回
* QA准确率

---

### 实验2：替换Attention

实现：

```
Attention
      |
      v
Linear Attention
      |
      v
状态空间模型 (Mamba风格)
```

对比：

```
速度
内存
质量
```

---

### 实验3：数据工程

这实际上可能带来更大的收益。

例子：

拿你的FineWeb数据集：

```
100B tokens
```

不是随机采样：

```
原始网页
 |
质量过滤
 |
去重
 |
教育评分
 |
代码评分
 |
推理评分
 |
训练
```

一个10B token的高质量数据集可以胜过100B token的垃圾数据。

我的看法：

未来几年：

```
基础模型实验室：
    架构 + 海量数据 + 计算

小团队/个人：
    数据创新 + Agent架构 + 专业化模型
```

一个人可能无法在发明下一个Transformer上击败NVIDIA/OpenAI。

但一个人绝对可以发现：

* 更好的数据集
* 更好的训练方法
* 更好的记忆系统
* 更好的小模型架构

你目前的路（训练小模型 + 理解硬件 + 分布式训练）实际上更接近许多重要思想的诞生方式：构建小模型，测量，迭代。
