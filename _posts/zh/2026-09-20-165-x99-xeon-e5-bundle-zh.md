**问题：** 一套 X99/DDR4 主板 + Xeon E5-2678 v3 + 散热器，售价 165 元，划算吗？

**回答：** 划算 —— **165 元已经很便宜，我认为值得入手**，前提是它真的能点亮，并且主板没有隐藏重大问题。

E5-2678 v3 是 **12 核/24 线程的 Haswell-EP 架构，基础频率 2.5 GHz，睿频最高约 3.3 GHz，TDP 120 W，支持四通道 DDR4**。([eComputerTips][1])

对于 165 元的价格，包含：

* X99 系列 DDR4 主板
* E5-2678 v3
* 散热器
* "很新"
* 确认能开机

……在这种情况下，**CPU 本身基本上是白送的附加值**。

### 需要注意的地方

这里主板比 CPU 重要得多。这些国产 X99 主板在 VRM、BIOS 质量、内存兼容性和 NVMe 支持方面差异巨大。目前国内商家列表显示，即使是基础款的 X99 + E5-2678 V3 套装也要 188 元左右，较新的品牌 X99 主板则在 300~500 元以上。([Dazhe][2])

所以对于 **165 元的二手货**，我的分类如下：

| 项目           | 我的看法                         |
| -------------- | -------------------------------- |
| E5-2678 v3     | 👍 廉价多核场景仍有用            |
| DDR4 X99 主板  | ⚠️ 主要风险                     |
| 散热器         | 基本白送                         |
| 总计 165 元    | **🔥 非常便宜**                  |

### 付款前我会检查什么

要求卖家提供 **CPU-Z 截图**，显示：

```text
CPU: E5-2678 v3
核心: 12
线程: 24

主板:
  制造商:
  型号:
  BIOS:

内存:
  DDR4
  实际容量
```

最好还有照片或视频，运行以下命令：

```bash
lscpu
free -h
sudo dmidecode -t baseboard
```

同时确认 **是否不包含内存**。你的描述写的是 "DDR4 主板"，不是 "主板 + DDR4 内存"。如果 **连内存也包含在内**，那 165 元就特别离谱了。

需要重点注意：**E5-2678 v3 没有集成 GPU**，所以实际使用中你需要一张独立显卡。([eComputerTips][1])
