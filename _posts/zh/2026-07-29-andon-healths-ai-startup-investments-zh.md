## 问题：九安医疗简介及其对DeepSeek和Kimi的投资

## 回答

九安医疗是一家以**iHealth品牌**闻名的中国医疗器械公司。最初专注于消费级医疗健康硬件：

* 电子血压计
* 血糖仪
* 家用诊断设备
* 数字健康产品

疫情期间，该公司因iHealth新冠抗原自测试剂盒在海外大规模销售而实现巨额盈利。2022年，其营收约达263亿元人民币，净利润约达160亿元人民币，积累了庞大的现金储备。([界面新闻][1])

在积累资金后，该公司从纯粹的医疗器械公司转型为**科技投资控股公司**，在以下领域寻找"下一个十年"的机会：

* 人工智能
* 大语言模型
* 机器人
* 半导体
* 生物技术

其自身描述称，已投资领域包括人工智能、生物技术、先进制造及其他前沿技术。([iHealth Labs][2])

---

## 1. 对Kimi（月之暗面）的投资

Kimi由月之暗面开发。

九安医疗通过离岸和基金结构进行投资：

### 首次投资

2023年8月：

* 九安香港向月之暗面相关实体投资约**1000万美元**。([CNInfo][3])

### 第二次投资

2024年3月：

* 通过天津九尚一号投资载体
* 追加投资约**2000万美元**。([CNInfo][3])

总计：

```
九安医疗 → 月之暗面

≈ 3000万美元投资
```

九安医疗随后澄清，其持股比例较小，并不控制月之暗面。([新浪财经][4])

有趣之处在于时间节点：

```
2023年8月
    |
    | 九安医疗投资
    ↓
2024年3月
    |
    | Kimi长文本AI走红
    ↓
市场发现九安医疗 = Kimi投资者
```

这是一次经典的风险投资式非对称押注：

* 下行风险：3000万美元
* 上行潜力：获得未来AI巨头的敞口

## 2. 对DeepSeek的投资

DeepSeek由杭州深度求索人工智能基础技术研究有限公司开发。

根据公开信息：

* 九安香港通过天津拾象投资合伙企业进行投资
* 投资金额：约**7.5亿元人民币**
* 该投资已完成。
* 穿透结构后，九安医疗持有DeepSeek约**0.21%**的股份。([新浪财经][5])

计算如下：

```
DeepSeek估值 ≈ 数千亿元人民币

九安医疗持股：
0.21%

7.5亿元投资
        ↓
账面价值可能远高于此
```

但九安医疗本身强调：

* 不参与DeepSeek的管理。
* 无法控制其运营。
* 投资风险依然存在。([新浪财经][5])

      +

      +

```

```

```

```

        |
        v

* 股权比例较小。

* AI初创公司面临巨大的执行风险。

战略层面的启示更具价值：

**一家拥有强大现金生成能力的公司，可以在市场意识到其价值之前，购买"未来技术期权"。**
