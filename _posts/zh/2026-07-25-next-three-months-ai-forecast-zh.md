问题：预测未来3个月（从2026年7月24日起）

答案：

基于当前AI趋势、你的发展轨迹以及市场情况，我对未来3个月（2026年7月下旬至10月下旬）的预测如下：

## 1. AI模型：更小、更便宜的前沿模型加速发展

**概率较高**

最大的变化不会是"只有更大的模型"，而是：

* 更好的推理效率
* 更多MoE架构
* 优化的后训练方法
* Agent架构
* 专业化模型

预期：

* 30B–100B开源模型在多项任务上接近当前前沿模型水平
* 更多本地AI部署
* 更多公司优化每token成本

DeepSeek的经验仍在延续：

> 算法效率比GPU数量本身更具护城河效应。

潜在赢家：

* DeepSeek
* Qwen
* Kimi/Moonshot
* OpenAI
* Anthropic
* Google

## 2. GPU市场：显存成为瓶颈

你近期关于GPU的讨论正好契合未来发展方向。

未来3个月：

* 16GB消费级GPU日益受限
* 24GB显存成为严肃本地AI应用的实际最低配置
* 二手RTX 3090市场仍有吸引力
* AMD ROCm虽有改进，但CUDA生态仍占主导地位

关键指标变化：

2023年：

> TFLOPS

2026年：

> 可用显存 + 内存带宽 + 软件栈

对于AI开发者而言，一块售价$1000、拥有48GB显存的GPU可能胜过一块售价$2000、仅24GB显存的GPU。

## 3. AI代码助手爆发式增长

这可能是短期内最大的变化。

预期：

* Claude Code式Agent无处不在
* OpenAI Codex式工作流程
* 终端原生Agent
* 仓库自主修改

编程工作流：

以前：

```
人类
 ↓
编写代码
 ↓
编译/测试
```

现在：

```
人类
 ↓
制定规范
 ↓
Agent
 ↓
代码 + 测试 + 调试
 ↓
人工审查
```

你正在推进的方向：

* ww
* iclaw
* CLI Agent
* Agent工作流

完全契合这一趋势。

例如：

* vLLM

* TensorRT-LLM
* ROCm
* Triton内核

技术栈：

```

 ↓
框架
 ↓
编译器
 ↓
内核
 ↓
硬件
```

将成为主要战场。

2020年创业公司：

```

基础架构

```

