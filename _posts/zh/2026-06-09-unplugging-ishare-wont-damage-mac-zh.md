**问题：** 突然从 Mac 上拔掉 iShare（无线 HDMI 发射器）会导致损坏吗？朋友这样做后 Mac 黑屏，无法启动。

**回答：**

直接回答：**不会，拔掉设备不会对 Mac 硬件造成物理损坏。** 黑屏几乎肯定与此无关或纯属巧合——现代 Mac 具有强大的电源传输和隔离保护，突然断开 USB 设备不会造成电气损坏。

可能的情况：

1. **时间巧合**——Mac 本身存在已有问题（硬盘故障、内存问题、GPU 问题）恰好在那时显现
2. **内核崩溃**——设备驱动程序崩溃触发了内核恐慌，导致启动分区损坏或系统进入不可恢复状态
3. **显示输出卡死**——外接显示器连接被卡住，Mac 实际仍在运行但输出信号未正确路由

**给朋友的故障排查步骤：**

```bash
# 强制重启（按住电源键 10 秒以上直至关机）
# 尝试两次

# 然后按顺序尝试以下操作：

# 1. 重置 SMC（Intel Mac）
# 关机 → Cmd + Shift + Ctrl + 电源键（按住 10 秒）→ 同时松开 → 等待 → 开机

# 2. 重置 SMC（Apple Silicon Mac）
# 关机 → 按住电源键 10 秒 → 松开 → 等待 10 秒 → 开机

# 3. 尝试进入恢复模式
# 开机 → Cmd + R（立即按住）→ 等待恢复屏幕出现

# 4. 如果恢复模式加载成功，运行磁盘工具检查损坏
# 磁盘工具 → 选择硬盘 → 急救 → 修复磁盘
```

如果恢复模式无法加载，问题很可能出在**启动前阶段**（固件、SSD 或逻辑板），而非 USB 设备导致。

**实际风险：** 在活跃文件写入过程中拔掉设备*理论上*可能损坏正在打开的文件，但这属于文件系统问题，而非硬件损坏。在 modern macOS 上，因 USB 设备崩溃导致启动损坏的情况极为罕见。

**结论：** iShare 没有损坏 Mac。你的朋友要么是恰好遇到了硬件故障，要么需要通过 DFU 恢复（使用另一台 Mac 和 USB-C 线缆）来恢复操作系统。拔掉设备本身是无害的。
