是的，几乎可以确定是 **5G NSA**。以下是来自你诊断数据的证据：

**决定性证据：**

```
1. 两处 CGNAT IP 相同：     14.31.170.218
   → 核心网络未改变，仅无线层发生变化
   → SA 会给出不同的 IP 段和路由

2. 路由追踪结构相同：  172.20.10.1 → 192.168.147.x → 192.168.242.x
   → 相同的私有 IP 跳数 = 相同的 4G EPC 核心
   → SA 会显示不同的网关路径

3. NAT 类型相同：             端口受限锥形
   → 由核心网络决定，而非无线层
   → 未变化 = 相同核心 = NSA

4. 延迟和抖动更差：     89ms→136ms，±3.6ms→±44ms
   → NSA 引入了 4G/5G 协调开销
   → SA 的延迟会比 4G 更低
```

你也可以直接在 iPhone 上确认：

```
设置 → 蜂窝网络 → 蜂窝数据选项 → 语音与数据
```

如果显示“5G 自动”或“5G”（而不是“5G SA”或“5G+ 独立”），那就是 NSA。中国电信的 5G 部署以 NSA 为主——SA 仅在部分试点城市可用，且需要特定套餐/SIM 卡支持。

**结论：** 你的 5G 运行在 4G 核心上，搭载了 5G 无线层。2 倍的速度提升是真实的（更宽的管道），但延迟代价是 NSA 的附加成本。只有等到中国电信在你所在地区部署 SA 时，你才能看到真正的 5G 延迟（<10ms）——这恐怕还需要好几年。
