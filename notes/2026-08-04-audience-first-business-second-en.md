## Question: What's this story about? How did Jason turn AI influence into a business?

This is basically a case study of **"creator → personal brand → business"**, especially in the AI era.

The core idea:

> Technical skill alone does not automatically create business value. Distribution + trust + network can turn expertise into revenue.

Jason did not win because he built one amazing product. He built an **audience asset**, then converted that attention into commercial opportunities.

The model is:

```
Technical ability
        |
        v
Public sharing (X/Twitter)
        |
        v
Audience + reputation
        |
        v
Business opportunities
        |
        v
Services / consulting / MCN / products
        |
        v
Revenue
```

## 1. The first failure: building before distribution

He spent one month building a recipe website:

```
Frontend
Backend
Payment
AI coding tools
```

Technically complete.

Result:

```
Launch
 |
 v
0 users
```

Why?

Because he solved:

> "Can I build this?"

instead of:

> "Does anyone care?"

This is a very common engineer failure mode.

Engineers optimize:

```
idea -> architecture -> implementation -> launch
```

Market-driven founders optimize:

```
pain point -> audience -> distribution -> MVP -> payment
```

A product without distribution is invisible.

## 2. The turning point: publishing himself

The biggest change was not technical.

It was:

```
private engineer
       |
       v
public builder
```

He started posting on X/Twitter.

One post:

> "I left big tech and drove to Dali"

got:

```
+1000~2000 followers overnight
```

Why?

Because humans follow **stories**, not resumes.

Compare:

Bad:

> "I know PyTorch, LLM fine tuning, Kubernetes."

Good:

> "I quit my job, built AI tools, traveled while running my company."

The second creates emotional connection.

## 3. 9000 tweets: the power law of content

The interesting number:

```
11 months
9000 tweets
```

That means:

```
9000 / 330 days ≈ 27 tweets/day
```

Very high frequency.

But only:

```
4-5 tweets -> huge traffic
7-8 tweets -> meaningful growth
```

This follows the power law:

```
Content output

|
|
|                 *
|              *
|          *
|     *
| *
+-------------------------
many posts     few winners
```

Most content does nothing.

A few pieces create exponential growth.

This is similar to venture investing:

```
100 experiments
       |
       v
5 winners
       |
       v
1 breakout
```

## 7. The deeper lesson

Traditional career:

```

   |
Salary
```

Creator/AI entrepreneur:

```
Knowledge
    |
Public proof
    |
Trust
    |
Network
    |

    |
Money
```

The internet rewards people who make their expertise visible.

Jason's formula:

```
Skill × Distribution × Consistency = Leverage
```

A lot of engineers have:

```
Skill = 9/10
Distribution = 0
```

so market value stays low.

The goal is not "become an influencer".

The goal is:

> Build a public proof-of-work graph so the right opportunities can find you.

For someone doing AI infra/LLM engineering, this is especially valuable because the audience is small but high-value. A 20k follower AI engineering account can be worth more commercially than a 500k general tech account.
