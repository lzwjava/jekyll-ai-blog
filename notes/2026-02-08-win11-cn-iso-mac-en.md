Question: If I only have a Mac, how can I download the ISO for Windows 11 China Home Edition?

Answer:

You can download the official Windows 11 **家庭版（仅限中国）** (China Home Edition) ISO directly from Microsoft's website using your Mac's web browser. Here's the step-by-step guide:

1. Open Safari (or any browser) on your Mac and go to:
   <https://www.microsoft.com/zh-cn/software-download/windows11>

2. Scroll down to the section **"下载适用于 x64 设备的 Windows 11 磁盘映像 (ISO)"** (Download Windows 11 Disk Image (ISO) for x64 devices).

3. From the dropdown menu for editions/versions, select:
   **Windows 11 家庭版（仅限中国）**
   (This is the China-specific Home edition, which is distinct from the multi-edition ISO.)

4. Click **"确认"** (Confirm), then choose the language:
   **中文(简体)** (Chinese Simplified) is usually pre-selected or the default for this edition.

5. Select the architecture: **64-bit** (x64).

6. Click **"下载"** (Download). The ISO file (around 5-7 GB) will start downloading directly to your Mac.

**Important notes:**

- This ISO is specifically for the China Home edition (pre-configured with Chinese language, region settings, and some China-specific features/apps).
- No product key is required to download, but you will need a valid Windows 11 Home product key (China region) to activate it after installation.
- If you want to install this on a physical PC, you can create a bootable USB from the ISO using tools on Mac like **balenaEtcher**, **Rufus** (via Parallels/VM), or Terminal commands (dd).
- For virtual machines on Mac (e.g., Parallels, UTM, VMware Fusion), you can directly use the downloaded ISO.
- The Media Creation Tool is Windows-only and cannot run natively on macOS, so direct ISO download is the best and official method on a Mac.
- This works for the latest version (e.g., 25H2 as of 2026).

If the page behaves differently (e.g., region detection), try using a VPN set to China or clear browser cache/cookies. The China-only edition is explicitly listed on the zh-cn page.
