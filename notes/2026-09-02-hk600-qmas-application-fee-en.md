Question: What does this HK$600 payment notice mean?

Answer: This is the **application fee for your Hong Kong Quality Migrant Admission Scheme (QMAS) application**.

* **Fee:** HK$600 for **each application**
* **Your total:** **HK$600**
* You need to pay it to **complete/submit the application process**.
* **“Proceed to payment”** → pay HK$600 now and finish the application.
* **“Exit and Pay Later”** → leave the payment step and pay later using the **Temporary Application Reference Number**.
* If payment fails, you can also return to the payment page using that reference number.
* **Important:** your application data is only temporarily saved until **12 September 2026**. So don't leave it unpaid for too long.

### In your case

If this is the QMAS application you've been filling out, **HK$600 is the government application fee**. It is not a visa/landing fee or an agent fee.

I'd recommend **paying it now** if you've reviewed the application and everything is correct. Keep the payment receipt/reference afterward.
