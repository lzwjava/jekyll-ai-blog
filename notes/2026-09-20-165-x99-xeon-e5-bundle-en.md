### What I'd check before paying

Ask the seller for **CPU-Z screenshots** showing:

```text

Cores: 12
Threads: 24

Mainboard:
  Manufacturer:
  Model:
  BIOS:

Memory:
  DDR4
  actual capacity
```

And ideally a photo/video of:

```bash
lscpu
free -h
sudo dmidecode -t baseboard
```

Also verify **there is no RAM included**. Your description says "DDR4 motherboard", not "motherboard + DDR4 RAM". If **RAM is included too**, ¥165 becomes an especially ridiculous deal.

One important point: **E5-2678 v3 has no integrated GPU**, so for actual operation you'll need a discrete GPU. ([eComputerTips][1])
