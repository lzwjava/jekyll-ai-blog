**Question:** What are the new features added in Windows Server 2008?

**Answer:**

Windows Server 2008 introduced the following major new features:

1. **Server Core** – A minimal installation option with no GUI, reducing attack surface and maintenance overhead.

2. **Windows PowerShell** – A powerful command-line shell and scripting environment for system administration automation.

3. **Virtualization (Hyper-V)** – Built-in hypervisor technology enabling virtual machines directly on the server.

4. **Network Access Protection (NAP)** – A policy enforcement platform that controls network access based on a client's health status.

5. **Read-Only Domain Controller (RODC)** – A domain controller that hosts a read-only copy of Active Directory, ideal for branch offices.

6. **Windows Firewall with Advanced Security** – Integrated two-way firewall with IPsec support and granular rule management.

7. **Server Manager** – A unified management console for configuring roles, features, and server health at a glance.

8. **Enhanced Terminal Services** – Improvements including RemoteApp, TS Gateway, and TS Web Access for flexible remote application delivery.

9. **Next Generation Cryptography (CNG)** – A cryptographic API supporting modern algorithms, replacing the older CryptoAPI.
