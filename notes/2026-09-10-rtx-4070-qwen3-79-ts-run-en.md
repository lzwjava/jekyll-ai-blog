Works. Ran it successfully on the RTX 4070.

**Result:** model loaded with full GPU offload, generated ~79 t/s. Note this is a Qwen3 *thinking* model, so by default it emits a `[Start thinking]` block before the answer (my 128-token cap cut it off mid-thought).

To chat interactively yourself:

```bash
cd /mnt/data/llama.cpp
./build/bin/llama-cli -m models/Qwen3-8B-abliterated-q4_k_m.gguf -ngl 99 -c 8192 -cnv
```

A few notes:
- `-no-cnv` no longer exists in this build (b10894). Use `-cnv` for conversation mode; `-st` is the old single-turn behavior.
- This tool can't hold an interactive TTY, so I ran it non-interactively with `-p ... -st`.
- Disable thinking if you want direct answers: `/no_think` in the prompt, or appending `-sys "/no_think"`.
- Heads-up: `models/Qwen3.8-27B-Uncensored-draft-Q8_0.gguf` is 3.1 GB, which is too small for a 27B Q8_0 (that'd be ~27 GB). The name looks wrong/mislabeled - verify before using it as a speculative draft.
