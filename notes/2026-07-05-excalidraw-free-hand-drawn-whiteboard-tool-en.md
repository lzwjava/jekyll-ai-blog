Question: What is Excalidraw (excalidraw.com)?

Answer:

Excalidraw is a **free, open-source online whiteboard tool** used for drawing diagrams, flowcharts, wireframes, and rough sketches directly in the browser.

You can think of it as a mix between a **digital whiteboard + sketchpad + diagram tool**, but with a special style: everything looks like it was hand-drawn.

### What it does

* Lets you draw shapes (boxes, circles, arrows, lines)
* Supports freehand sketching like pen on paper
* Helps you build:

  * system architecture diagrams
  * flowcharts
  * UI wireframes
  * brainstorming sketches
* Runs directly in the browser (no install needed)

### Key features

* **Infinite canvas** (you can zoom and pan freely)
* **Hand-drawn aesthetic** (intentionally “rough” look)
* **Real-time collaboration** (share a link and draw together)
* **Autosave in browser**
* **Export to PNG / SVG**
* **Works offline (PWA support)**
* **Open source (MIT license)** ([GitHub][1])

### Why people use it

* Developers use it for quick **system design diagrams**
* Designers use it for **wireframes**
* Teachers / learners use it for **explaining ideas visually**
* It’s much faster and more “lightweight” than tools like Figma or Visio when you just want to sketch ideas

### Simple way to understand it

If Google Docs is for writing text,
Excalidraw is like a **Google Docs for sketching ideas visually**, but with a hand-drawn style.
