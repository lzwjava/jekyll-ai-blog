**Question:** What key is near number 1 on a typical macOS keyboard — two keys: up from Tab, and below Esc?

**Answer:**

The backtick/tilde key: **` ~**

- Below `Esc`
- Left of `1`
- Above `Tab`

Used constantly in shell: command substitution, markdown code fences, and tmux prefix (if you remap).
