Especially check:

### 1. Battery

iPhone X battery is the biggest weakness now.

If battery health:

* > 85% → good
* 80-85% → acceptable
* <80% → expect replacement

### 2. Screen

Cheap iPhone X often has replaced screens.

Check:

* True Tone / 原彩
* OLED black level
* touch edges
* brightness

### 3. Face ID

This is the key.

A broken Face ID iPhone X can be much cheaper. Since this seller explicitly mentions Face ID, test it yourself after receiving.

### 4. iOS limitation

A11 + 3GB RAM is old. Good for:

* WeChat
* calls
* camera
* music
* backup phone
* iOS testing

Not ideal for:

* heavy games
* long-term main phone

My personal buying threshold:

* **485 CNY + Face ID + original screen + battery >80% → buy**

* **Face ID broken → don't buy**
