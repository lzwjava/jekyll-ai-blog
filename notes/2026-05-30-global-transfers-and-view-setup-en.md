**Question:** How do I understand and use HSBC's Global View / Global Transfers feature as described in this email?

**Answer:**

This is a service email from HSBC Hong Kong explaining their **Global View** feature — essentially a unified dashboard to manage HSBC accounts across multiple countries and do free inter-HSBC transfers.

Here's the practical breakdown:

---

## What it is

- **Global View** = link your HSBC HK account to HSBC accounts in other countries (Singapore, UK, etc.) so you can see all balances in one login
- **Global Transfers** = move money between those linked HSBC accounts, **free of charge**

---

## How to link an overseas HSBC account (e.g. Singapore)

1. Log into **HSBC HK Online Banking via browser** (not the mobile app — this step requires browser + Security Device)
2. Navigate to **Global Account Services → Add Country/Region**
3. Select your country (e.g. Singapore)
4. Accept the T&Cs
5. You'll be redirected to that country's HSBC portal — log in there to complete linking

After that, both the browser and mobile app will show all linked accounts.

---

## Key constraints

- **Initial setup requires browser + physical Security Device** (not mobile app)
- Free transfers only between **qualifying HSBC personal accounts** — not all account types qualify
- Supported currencies/countries: check HSBC HK site → Banking → Transfers → Global Transfers

---

## What you should do if you have HSBC accounts in multiple countries

If you receive salary in HKD (HSBC HK) and need funds in another country, this is a **zero-cost alternative** to SWIFT/Wise for intra-HSBC moves. Worth setting up once.

For anything beyond HSBC-to-HSBC (e.g. moving to a non-HSBC account overseas), Wise or similar still wins on fees.
