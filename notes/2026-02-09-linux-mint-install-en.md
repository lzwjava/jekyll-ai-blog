Question: How to install Linux Mint?

Answer:

Below is a **clear, beginner-friendly, step-by-step guide** to installing **Linux Mint**, written with **parents / non-technical users** in mind. This is the safest and most common way to install it on a normal PC or laptop.

---

## 1. Prepare What You Need

### Hardware

* A computer (PC or laptop)
* A **USB flash drive (8 GB or larger)**
* Internet connection (recommended)

### Software You’ll Download

* Linux Mint ISO file
* A USB writing tool (Balena Etcher or Rufus)

---

## 2. Download Linux Mint

1. Go to the official website:
   👉 [https://linuxmint.com](https://linuxmint.com)
2. Click **Download**
3. Choose **Linux Mint Cinnamon**

   * This is the most user-friendly and Windows-like edition
4. Select a mirror and download the `.iso` file

💡 *Cinnamon is strongly recommended for parents.*

---

## 3. Create a Bootable USB

### On Windows / macOS

1. Download **Balena Etcher**:
   👉 [https://etcher.balena.io](https://etcher.balena.io)
2. Insert your USB drive
3. Open Etcher and:

   * Select the Linux Mint `.iso`
   * Select the USB drive
   * Click **Flash**
4. Wait until it finishes (USB will be erased)

---

## 4. Boot from the USB Drive

1. Insert the USB into the computer where Mint will be installed
2. Restart the computer
3. Press the **Boot Menu key** repeatedly during startup:

   * Common keys: `F12`, `F10`, `ESC`, `DEL`
4. Select the **USB device**
5. Choose **“Start Linux Mint”**

👉 Linux Mint will now run in **Live Mode** (no changes yet).

---

## 5. Try Linux Mint (Optional but Recommended)

In Live Mode you can:

* Check Wi-Fi
* Test sound, keyboard, mouse
* See if the screen looks normal

If everything works → double-click **“Install Linux Mint”** on the desktop.

---

## 6. Install Linux Mint (Main Steps)

### Step 1: Language

* Choose your preferred language
* Click **Continue**

### Step 2: Keyboard Layout

* Usually auto-detected
* Click **Continue**

### Step 3: Multimedia Codecs

✅ Check **“Install multimedia codecs”**
(This enables MP3, video playback, etc.)

### Step 4: Installation Type (IMPORTANT)

For parents, choose one of these:

#### Option A: Replace Windows Completely (Simplest)

* **“Erase disk and install Linux Mint”**
* This removes Windows completely

#### Option B: Install Alongside Windows

* **“Install Linux Mint alongside Windows”**
* You can choose OS at startup

⚠️ If unsure, **back up important files first**.

### Step 5: Time Zone

* Select your city
* Click **Continue**

### Step 6: User Account

* Name: Parent’s name
* Computer name: anything
* Username: auto-generated
* Password: simple but safe
* Choose **“Log in automatically”** if you want zero hassle

---

## 7. Finish Installation

* Wait 10–20 minutes
* Click **Restart Now**
* Remove the USB when asked

🎉 Linux Mint is now installed!

---

## 8. First Things to Do After Installation

### Update System

1. Click the **shield icon** (Update Manager)
2. Install all updates

### Install Common Apps

* Firefox (already installed)
* LibreOffice (Word / Excel alternative)
* VLC Media Player
* Zoom / WeChat (via browser or Flatpak)

### Enable Chinese Input (if needed)

* Settings → Input Methods
* Add **Fcitx** + Pinyin

* Very stable
* Safe from most viruses
* Easy software installation
* Minimal maintenance
