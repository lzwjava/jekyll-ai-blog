Question: How to prepare the required documents for Hong Kong Quality Migrant Admission Scheme (QMAS) application?

Answer:

For QMAS, you prepare documents mainly to prove **identity, points eligibility, financial ability, education, career history, language ability, and achievements**. Since you are a Mainland Chinese resident, the typical package would look like this:

---

## 1. Valid travel document

For Mainland Chinese applicants:

Prepare:

* [ ] Mainland Chinese passport (if you have one)

  * Personal information page
  * All pages with visas/stamps (if any)
* [ ] If no passport/travel document:

  * Mainland Resident Identity Card (居民身份证)

Recommended:

* Scan color PDF
* Keep original for later immigration requests

---

## 2. Recent photograph

Prepare:

* [ ] Hong Kong immigration photo meeting requirements

Usually:

* Passport-style photo
* Recent (normally within 6 months)
* Plain background
* Digital file + printed copies

---

## 3. Hong Kong Identity Card (if any)

If you do not have HKID:

* Leave blank / not applicable

If you previously lived in HK:

* Copy both sides of HKID

---

# 4. Proof of personal net worth

Purpose:
Show you can support yourself and family without relying on public assistance.

Possible documents:

### Bank assets

* [ ] Bank statements (usually recent months)
* [ ] Bank balance certificate
* [ ] Investment account statements

Examples:

* Cash deposits
* Stocks
* Bonds
* Funds

### Property

If you own property:

* [ ] Property ownership certificate
* [ ] Purchase contract
* [ ] Valuation report (optional)

For your situation:

* Guangzhou property can be included.
* Mortgage should be disclosed.

Example:

```
Property value:
2,000,000 RMB

Mortgage:
900,000 RMB

Net equity:
1,100,000 RMB
```

---

# 5. Academic / professional qualifications

Prepare:

### Degree

* [ ] University graduation certificate
* [ ] Degree certificate
* [ ] Transcript

For self-study degree:

* [ ] Graduation certificate when completed
* [ ] Transcript

If you have incomplete university study:

* Usually not counted as qualification.

### Professional certificates

Examples:

* Cloud certifications
* AI/ML certificates
* Software certifications

Not usually major points but can support profile.

---

# 6. Proof of work experience

This is very important for QMAS.

Prepare:

For each company:

* [ ] Employment certificate
* [ ] Employment contract
* [ ] Social insurance record
* [ ] Salary slips
* [ ] Tax records

Employment certificate should contain:

```
Company name
Your position
Employment period
Job duties
Salary
Company stamp/signature
```

Example:

```
LeanCloud
Software Engineer
2016-2018

Responsibilities:
- Backend development
- Cloud platform engineering
- API design
```

For freelancer / own company:

Prepare:

* [ ] Business registration
* [ ] Client contracts
* [ ] Invoices
* [ ] Payment records
* [ ] Project descriptions
