**Question:** What are the differences between Claude's Pro and Max plans, and does Claude Code require a Pro or Max subscription?

**Answer:**

## Claude Plans Overview (2026)

---

### Free Plan

The Free plan provides access to Claude on the web, iOS, Android, and desktop. Users can generate code, analyze text and images, create content, and search the web. However, the free plan does not support Claude Code access — you need at least a Pro subscription or API credits to use Claude Code.

---

### Claude Pro — $20/month (or $17/month billed annually)

The Pro plan costs $17 per month with an annual subscription ($20 billed monthly). It includes all Free plan features and adds access to Claude Code in the terminal, file creation and code execution, and support for unlimited projects to manage documents and chats. Pro users can also access research tools, connect to Google Workspace, use remote MCP connectors to integrate other tools, and access extended reasoning capabilities with more Claude models.

Pro is well-suited for developers working on small-to-medium codebases, people learning Claude Code, or anyone doing focused coding sessions rather than running Claude Code continuously throughout the day. Where Pro falls short: if you're working on large codebases, running Agent Teams workflows, or using Claude Code as your primary coding partner for 6+ hours a day, you'll hit the session limits regularly.

---

### Claude Max — $100/month (5x tier) or $200/month (20x tier)

The Max plan starts at $100 per person monthly and is for power users. It includes all Pro features and offers a choice between 5x or 20x more usage compared to Pro. Max users benefit from higher task output limits, persistent memory across conversations, early access to new Claude features, and priority access during peak traffic times.

**Max $100/month (5x tier):**
Claude Max $100 provides access to Claude Sonnet 4.6 with 5x higher usage limits than Pro, plus access to Claude Opus 4.6 with 1M context window, agent teams (research preview), and adaptive thinking. It includes higher output limits for all tasks, early access to advanced Claude features, and priority access during high traffic times.

**Max $200/month (20x tier):**
Claude Max $200 provides access to all Claude models including Claude Opus 4.6, with 20x higher usage limits than Pro. This plan handles professional development with large projects and complex tasks, extended coding sessions without hitting limits, and full access to Opus 4.6 for state-of-the-art software engineering.

---

### Does Claude Code Require Pro or Max?

There is no free Claude Code plan. You need at least a Pro subscription or API credits to access it.

The Max plan combines Claude desktop and mobile apps and Claude Code in one subscription, with up to 20x more usage per session than Pro.
