Question: What is [https://coding.btelo.com](https://coding.btelo.com)? Give an introduction.

Answer:

**Btelo Coding** is a **developer tool that lets you code and control your development machine remotely using your phone, powered by AI.** ([Btelo Coding][1])

---

## 🧠 Core Idea (in simple terms)

It turns your **phone into a remote AI-powered coding terminal**:

* You **talk to AI (like Claude, Codex, Gemini)**
* The AI **executes real commands on your computer**
* You can **develop, debug, deploy, and manage projects remotely**

👉 It’s not just remote desktop — it’s **AI controlling your actual dev environment**. ([Btelo Coding][1])

---

## ⚙️ How It Works

1. Install a small agent on your computer
2. Connect your phone by scanning a QR code
3. Use the mobile app to:

   * Chat with AI
   * Run shell commands
   * Access files, Git, logs, etc. ([Btelo Coding][2])

## 🚀 Key Features

### 1. AI Remote Terminal

* Chat with AI → AI runs real commands on your machine
* Supports tools like Claude Code, Codex, Gemini ([Btelo Coding][1])

### 2. Code From Anywhere

* Use your phone (iPhone/iPad/Mac)
* Example scenarios:

  * Fix production bugs on the go
  * Deploy while traveling
  * Review PRs without a laptop ([Btelo Coding][3])

### 3. No VPN / No Port Forwarding

* Works behind NAT/firewalls automatically
* No need for complex networking setup ([Btelo Coding][1])

### 4. Persistent Sessions

* Your terminal sessions **never die**
* You can reconnect anytime without losing progress ([App Store][4])

### 5. Full Dev Workflow on Phone

* Git operations (commit, push, diff)
* File browsing
* Logs & monitoring
* Even access your local `localhost` remotely ([Btelo Coding][1])

### 6. End-to-End Encryption

* Fully encrypted communication
* Relay server cannot read your data ([Btelo Coding][1])
