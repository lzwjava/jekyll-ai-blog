**Question:** Can the Pentium G3260 3.30 GHz work in the MSI B760M-E DDR5?

**Answer:** **No. ❌**

The **Pentium G3260** is a **4th-generation Haswell CPU** using **LGA1150**.

The **MSI B760M-E DDR5** uses **LGA1700** and supports Intel **12th/13th/14th Gen** CPUs.

| CPU                | Socket      | B760M-E DDR5 |
| ------------------ | ----------- | ------------ |
| Pentium G3260      | **LGA1150** | ❌            |
| Pentium G4560      | LGA1151     | ❌            |
| Pentium Gold G7400 | **LGA1700** | ✅            |
| Celeron G6900      | **LGA1700** | ✅            |
| i3-12100           | **LGA1700** | ✅            |
| i5-12400           | **LGA1700** | ✅            |

So **3.30 GHz isn't the important part**. The physical/electrical CPU socket and platform have to match.

If you're seeing a **G3260 bundled with this motherboard**, don't buy it as a compatible combo.
