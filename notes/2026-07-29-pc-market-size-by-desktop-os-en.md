Question: **How large is the consumer personal computer market by desktop OS (Windows, macOS, Linux) and laptop/PC market size?**

Answer:

The personal computer (PC) market is still huge, but the OS market is extremely concentrated. Windows dominates by installed base; macOS dominates the premium segment; Linux is small on desktops but important in servers and developers.

## 1. Global PC market size

Approximate annual global PC shipments:

| Year          |             PC shipments |
| ------------- | -----------------------: |
| 2020          | ~300M units (COVID boom) |
| 2021          |                    ~340M |
| 2022          |                    ~290M |
| 2023          |                    ~250M |
| 2024          |                    ~260M |
| 2025 estimate |                    ~270M |

The installed base is much larger:

* Around **1.5–2 billion active personal computers worldwide**
* Most users keep PCs for **5–7 years**
* Laptops are now the majority of consumer PCs

Major vendors:

* Lenovo
* HP Inc.
* Dell Technologies
* Apple
* ASUS

## 2. Desktop OS market share (consumer + general desktop)

Approximate global desktop/laptop OS share:

| OS            | Market share |
| ------------- | -----------: |
| Windows       |      ~70–75% |
| macOS         |      ~15–20% |
| Linux desktop |        ~3–5% |
| ChromeOS      |        ~2–5% |
| Others        |          <1% |

The numbers vary by measurement source because they count differently (web traffic vs installed devices).

### Windows

Installed base:

* Roughly **1.4 billion Windows devices**
* Still the default enterprise and consumer PC OS

Strengths:

* Gaming
* Enterprise software
* OEM ecosystem
* Hardware compatibility

Weaknesses:

* Lower margins
* Fragmented hardware
* Security complexity

Microsoft's strategy has shifted:

```
Windows
   |
   +-- Office / Microsoft 365
   |
   +-- Azure
   |
   +-- Copilot / AI
   |
   +-- Gaming
```

Windows itself is less important than the ecosystem.

## 7. Long-term trend with AI

The interesting question is not OS share but **where intelligence runs**.

Traditional:

```

```

AI era:

