**Question:** What is the GitHub repository `basecamp/omarchy`?

**Answer:**

**Omarchy** is a "Beautiful, Modern & Opinionated Linux" distribution created by DHH (David Heinemeier Hansson), the founder of Basecamp. It's essentially a pre-configured, opinionated Linux setup — think of it as DHH's personal Linux environment packaged and shared for others to use.

Key highlights from the repo:

- **23.7k stars** and **2.4k forks**, with 4,355 commits — indicating strong community traction since its release.
- Primarily written in **Shell (82.1%)**, with Lua, Go Template, QML, CSS, and Python — Shell scripts being the backbone of the installation and configuration system.
- The latest release is **v3.8.2** (May 24, 2026), showing it's actively maintained.
- It covers themes, applications, config, and migrations — essentially the full desktop Linux experience.
- Released under the **MIT License**.

In short, it's DHH's take on what a perfect Linux desktop setup looks like, shipped as a one-command installer so others can replicate it.
