Question: Is the article's idea that "avoiding making money is fundamentally caused by childhood loss of autonomy" correct?

Answer:

The article captures **one possible psychological mechanism**, but it presents it too absolutely. It mixes some valid psychology with a lot of "Naval-style" self-help extrapolation.

The core idea:

> Some people do not actually hate money; they hate the psychological associations attached to pursuing money.

This is plausible.

For example:

* A child who repeatedly experiences:

  * "Your opinion doesn't matter"
  * "You must do what others want"
  * "Your value depends on obedience"

may later associate success with:

```
success
  ↓
more responsibility
  ↓
more expectations from others
  ↓
loss of freedom
```

So when a high-paying opportunity appears, the emotional prediction is not:

```
money → freedom
```

but:

```
money → more control by others → loss of self
```

That can create avoidance.

This is close to concepts in psychology like:

* learned helplessness
* self-efficacy
* autonomy needs (Self-Determination Theory)
* avoidance coping
* fear of success

However, the article overstates several things.

## 1. Childhood is not always the root cause

Avoiding money can come from many sources:

### Wrong incentives

Example:

A person grows up seeing:

```
rich people = greedy / corrupt
money = immoral
```

Then earning more creates identity conflict.

### Lack of skill/confidence

Sometimes the reason is simpler:

```
I don't know how to create value → I avoid trying
```

Not trauma.

### Risk calculation

An engineer may reject entrepreneurship because:

```
startup expected value < stable salary + family obligations
```

That is rational, not psychological avoidance.

### Personality

Some people genuinely value:

* autonomy
* leisure
* research
* family time

more than maximizing income.

That is not necessarily a block.

---

## 2. Naval's actual idea is more about freedom, not childhood trauma

Naval Ravikant usually emphasizes:

```
wealth = assets that earn without your time being consumed
```

and:

```
wealth is freedom from needing permission
```

The famous idea is:

> Wealth is a tool to buy back your time.

The article reframes this into:

```
poverty mindset ← childhood loss of power
```

That is a different psychological interpretation.

Useful, but not Naval's main framework.

---

## 3. The deeper engineering analogy: internal reward model

A useful way to think about this:

Human behavior has an internal "reward model".

Suppose two people see the same opportunity:

```
Opportunity:
Build company → earn $1M
```

Person A's internal model:

```
action:
  build company

prediction:
  freedom
  achievement
  creativity

reward:
  +++
```

Person B's internal model:

```
action:
  build company

prediction:
  stress
  losing weekends
  disappointing people
  being judged

reward:
  ---
```

Same external event.

Different internal model.

The problem is not money itself; it is the learned mapping:

```
money → meaning
```

---

## 4. A more accurate version would be:

Not:

> "You avoid money because your childhood took away your power."

Better:

> "Sometimes people avoid wealth-building because their past experiences taught them that achievement comes with loss of autonomy, pressure, or identity conflict. Rebuilding a sense of agency can change their relationship with money."

That is much closer to psychology.

---

A practical test:

Ask:

"When I imagine earning 10x more money, what is the first negative thought?"

Common answers:

```
"I will have no free time."
"I will become someone I dislike."
"People will expect more from me."
"I will fail publicly."
"My family will depend on me."
```

The answer reveals the actual bottleneck.

For many ambitious technical people, the issue is not laziness. It is often a hidden equation:

```
more success = less freedom
```

The goal is to replace it with:

```
more value creation = more choice
```

That part of the article is quite insightful. The childhood explanation is only one possible path to that belief.
