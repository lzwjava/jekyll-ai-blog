**Question:** What is an introduction to the NVIDIA CMP 50HX graphics card?

**Answer:**

The NVIDIA CMP 50HX is a dedicated **Cryptocurrency Mining Processor (CMP)** released in mid-2021, designed specifically for miners rather than gamers.

**Background & Purpose**

The CMP 50HX is part of NVIDIA's Cryptocurrency Mining Processor (CMP) lineup, which aimed to put more GeForce products into gamers' hands by giving miners specialized mining graphics cards.

**GPU Architecture**

The CMP 50HX utilizes a cut-down version of the TU102 silicon, which powered popular Turing models such as the GeForce RTX 2080 Ti. It features 3,584 CUDA cores — even fewer than the RTX 2080 Ti's 4,352 cores — which reduces peak FP32 performance to around 11 TFLOPs.

**Key Specifications**

| Spec | Value |
| --- | --- |
| CUDA Cores | 3,584 |
| Memory | 10 GB GDDR6 |
| Memory Speed | 14 Gbps |
| Memory Bus | 320-bit |
| Base / Boost Clock | 1,350 / 1,545 MHz |
| TDP | 225 W |
| Power Connectors | 2× 8-pin |
| Interface | PCIe 1.0 x4 |

The card's Ethereum hash rate is rated at 45 MH/s (at Epoch 394 reference conditions).

**Design Decisions**

Being a product oriented toward cryptocurrency mining, the CMP 50HX lacks display outputs. Instead, the I/O bracket area is left open for exhaust ventilation. The MSI variant uses a blower-style "AERO" cooler with double ball bearings, designed for long-term continuous operation.

**Summary**

The CMP 50HX is a Turing-era mining card — purpose-built, no display output, optimized for hash rate per watt rather than gaming or general rendering tasks.
