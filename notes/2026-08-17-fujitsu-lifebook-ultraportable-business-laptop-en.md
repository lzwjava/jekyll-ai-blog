### The biggest strength: absurd portability

Fujitsu has historically been almost obsessive about making LIFEBOOK U/UH machines light.

For example, the 13.3" LIFEBOOK UH75/B1 was only **~761 g**. Fujitsu achieved this using magnesium-lithium/magnesium construction and extensive structural optimization. ([PC Watch][1])

The older U937 was around **920 g**, with magnesium construction and a very good selection of ports, including USB-A, USB-C, HDMI, SD, Ethernet and even optional LTE. ([Tech Advisor][2])

That's the characteristic Fujitsu tradeoff:

```text
          portability
              ↑
              │
       Fujitsu LIFEBOOK
              │
              │
ThinkPad ─────┼───── MacBook
              │
              │
        performance
```

It is basically designed around:

> **"I need a real computer that weighs almost nothing."**

### Keyboard: surprisingly serious

This is one reason I think you'd probably like it.

Fujitsu spent a lot of engineering effort on its keyboards. The later UH designs use roughly **19 mm key pitch**, sensible arrow-key positioning, and carefully tuned key forces. Some reviewers consider the keyboard one of the best parts of the machine. ([PC Watch][1])

But there's an important caveat: **LIFEBOOK keyboard quality varies substantially by generation.** Some older models had shallow/mushy keyboards, and there were documented issues with missed keystrokes on particular UH75 units. ([PC Watch][3])

So I wouldn't buy a LIFEBOOK purely based on the brand. **The exact model matters.**

### Build quality is more nuanced

This is where reviews disagree.

The magnesium chassis can be very light while still passing substantial durability testing. For example, the UH series underwent drop, vibration, pressure and keyboard durability tests. ([PC Watch][1])

But because the material is extremely thin, some models **feel less solid than a ThinkPad**. The U937, for example, received criticism for chassis flex despite being extremely light. ([IT Pro][4])

So:

```text
ThinkPad:
    "I can probably throw this in a backpack."

LIFEBOOK U/UH:
    "I can barely feel it in the backpack."
```

The second one isn't necessarily weaker; it just **feels** less massive.

### Where LIFEBOOK is particularly interesting: used market

This is actually where I'd pay attention.

Older business LIFEBOOKs can be **very cheap used**, while still giving you:

* 13–14" display
* excellent portability
* USB-A
* USB-C
* HDMI
* Ethernet on some models
* SD
* replaceable/serviceable components on some generations
* business-class Windows support
* sometimes LTE
* surprisingly good keyboards

For someone who primarily does:

```bash
vim
tmux
ssh
python
git
docker
claude
browser
terminal
```

an older LIFEBOOK U-series can be an excellent **Linux/SSH/travel machine**.

### But don't buy one for GPU/AI

For your workload, I'd separate the roles:

```text
Desktop RTX 4070
        │
        └── training / CUDA / local LLM

LIFEBOOK U/UH
        │
        ├── coding
        ├── SSH
        ├── agent control
        ├── papers
        ├── writing
        └── travel
```

That's actually a pretty compelling combination.

A ~1 kg LIFEBOOK + SSH into your GPU machine/cloud is much more interesting than trying to cram an RTX GPU into a laptop.

**Bottom line:** If you find a **LIFEBOOK U/UH around 800–1,000 g with a modern-ish Intel CPU, 16–32 GB RAM and USB-C**, I'd seriously consider it as a coding/travel laptop. Its strongest selling point isn't benchmark performance—it's the combination of **real keyboard + ports + business functionality + ridiculously low weight**.
