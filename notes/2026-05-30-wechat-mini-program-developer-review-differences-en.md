**Question:** Does WeChat Mini Program allow individual developers to submit for review? And is it surprising that WeChat reviews even on weekends, unlike Apple?

**Answer:**

Yes — WeChat Mini Program **does allow individual developers** (个人开发者) to register and submit apps for review. No company/business license required.

Key differences from Apple:

| | WeChat Mini Program | Apple App Store |
|---|---|---|
| Individual dev | ✅ Yes | ✅ Yes |
| Weekend review | ✅ Yes (often 7 days) | ❌ No (weekdays only) |
| Review time | Usually **1-3 days** | Usually **1-2 days** weekdays |
| Cost | Free (no annual fee) | $99/yr |
| Category restrictions for individuals | Some (e.g. payments, certain verticals need bizlicense) | Fewer |

**Caveats for individual accounts:**

- Certain categories are **blocked** for individuals: e.g. financial services, medical, government, certain e-commerce features
- You can't use **WeChat Pay** merchant features without a business entity
- Daily active user caps and some API access is more restricted

But for a general utility/tool app — individual account is totally fine and the review pipeline is clearly well-staffed. Weekend turnaround is a genuine operational advantage over Apple.
