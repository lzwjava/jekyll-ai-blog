### Chapter 3: HTML Fundamentals

8. Multiple-choice: Which HTML5 semantic tag should be used to represent the main navigation area of a page?
   - A. <header>   B. <nav>   C. <section>   D. <aside>

### Chapter 4: CSS Styling and Layout

12. Multiple-choice: Which property is used to make a flex container arrange items in a row on large screens and column on small screens?
