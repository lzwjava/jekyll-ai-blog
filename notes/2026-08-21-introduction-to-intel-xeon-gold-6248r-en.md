**Question:** What is an introduction to the Intel Xeon Gold 6248R processor?

**Answer:**

The Intel Xeon Gold 6248R is a server-grade processor worth knowing well. Here's a breakdown:

**Overview**

It is a 64-bit, 24-core x86 high-performance server microprocessor introduced by Intel in early 2020, based on the **Cascade Lake** microarchitecture and manufactured on a **14 nm** process.

**Key Specs**

| Spec | Value |
|---|---|
| Cores / Threads | 24 / 48 |
| Base Clock | 3.0 GHz |
| Turbo Boost | 4.0 GHz |
| L3 Cache | 35.75 MB |
| TDP | 205 W |
| Socket | LGA 3647 |
| Memory | DDR4-2933, 6-channel, up to 1 TB |
| Memory Bandwidth | 141 GB/s |
| Launch Price | $2,700 |

**Architecture Highlights**

This chip supports 2-way multiprocessing, sports 2 AVX-512 FMA units, and two Ultra Path Interconnect (UPI) links. Notably, the 6248R features a larger-than-default 35.75 MiB of L3 cache — a size normally found on a 26-core part.

**Why It Was Significant**

The 6248R represented a radical departure from previous Intel Xeon CPUs, offering higher clock speeds as a direct response to competition from the AMD EPYC 7002 "Rome" series. Intel shifted its SKU strategy from power optimization toward performance optimization with this 205 W TDP part.

**Target Use Cases**

It is optimized for demanding mainstream data center, cloud compute, and network and storage workloads, with up to 4-socket scalability suitable for an expanded range of workloads.

**Status**

The processor is now discontinued, with its End of Servicing Updates date having passed on June 30, 2025.
