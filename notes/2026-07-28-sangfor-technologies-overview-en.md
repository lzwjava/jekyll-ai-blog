## Overview

Sangfor Technologies (深信服科技) is a Chinese enterprise IT company founded in 2000, focused on:

1. **Cybersecurity**
2. **Cloud computing**
3. **IT infrastructure**
4. **Enterprise digital transformation**

It is listed on the Shenzhen Stock Exchange (300454). The company provides products mainly for enterprises, governments, universities, banks, and large organizations. ([Sangfor][1])

This is where Sangfor started.

### EasyConnect / SSL VPN

This is probably what you saw.

Sangfor EasyConnect provides remote access into enterprise networks.

Typical architecture:

```
Employee Laptop
       |
       |
   EasyConnect VPN
       |
       |
 Sangfor VPN Gateway
       |
       |
 Enterprise Network
       |
       +-- RDP Server
       +-- Internal Web Apps
       +-- Database
```

Common in:

* banks
* government
* universities
* large companies

It allows employees to work remotely while enforcing security policies. ([Sangfor Technologies][2])

## 2. Cloud & Infrastructure Business (信服云)

Sangfor competes in the same general market as:

* VMware
* Nutanix
* OpenStack
* Huawei Cloud Stack

Main technologies:

### HCI (Hyper-Converged Infrastructure)

Traditional:

```
Server
 |
 +-- CPU
 +-- Storage Array
 +-- Network
```

HCI:

```
Node 1
 CPU + RAM + Disk

Node 2
 CPU + RAM + Disk

Node 3
 CPU + RAM + Disk


Software layer:
----------------
Virtualization
Storage
Network
Management
----------------
```

Products:

* Sangfor HCI
* aStor storage
* cloud platform

([Sangfor Technologies][3])
