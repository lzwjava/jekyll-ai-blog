**Question:** Does Azure have on-site certification exams, similar to the GCP Professional Cloud Developer certification?

**Answer:**

Yes, Microsoft Azure certifications do offer **on-site (in-person)** proctored exam options, just like Google Cloud Platform (GCP) certifications.

The most comparable Azure certification to **Google Cloud Professional Cloud Developer** is **Microsoft Certified: Azure Developer Associate** (exam code: **AZ-204**). This is the main developer-focused role-based certification on Azure.

For both Azure and GCP certifications:

- Exams are delivered through **Pearson VUE** (the same testing provider used by Google Cloud).
- You can choose between two main delivery methods:
  - **Online proctored** (OnVUE) — taken remotely from home/office with webcam monitoring.
  - **On-site / Test center proctored** — taken in person at a Pearson VUE authorized test center.

This has been the standard option for many years for Microsoft role-based certifications (including AZ-204, AZ-104, AZ-305, etc.). When scheduling your exam via the Microsoft Certification dashboard or Pearson VUE website, you select the delivery method (test center or online), and test center locations are shown based on your region.

So Azure does have "onsite cert" options — there is no fundamental difference in exam delivery availability compared to GCP's Professional Cloud Developer exam.
