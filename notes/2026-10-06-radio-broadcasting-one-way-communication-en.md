**Question: Is radio broadcasting a one-way communication?**

**Answer: Yes, traditional radio broadcasting is a one-way (simplex) communication system.**

In radio broadcasting:

* The **radio station (sender)** transmits electromagnetic waves.
* Many **listeners (receivers)** receive the signal.
* The listeners normally **cannot send a signal back through the same system**.

Example:

```
Radio station
     |
     |  FM/AM radio waves
     v
Many listeners
```

This is called **broadcast communication** because one sender communicates with many receivers.

Comparison:

| Communication type                         | Example                       | Direction              |
| ------------------------------------------ | ----------------------------- | ---------------------- |
| Simplex (one-way)                          | Radio broadcast, TV broadcast | Sender → Receiver only |
| Half-duplex (two-way but not simultaneous) | Walkie-talkie                 | A ↔ B, take turns      |
| Full-duplex (two-way simultaneous)         | Phone call                    | A ↔ B at the same time |

Modern systems can add feedback channels (for example, digital radio apps using the internet), but the **radio broadcast signal itself is fundamentally one-way**.
