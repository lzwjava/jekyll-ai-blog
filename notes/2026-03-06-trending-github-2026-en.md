Question: What projects are trending on GitHub in the past few months?

Answer:

Here is a comprehensive overview of trending GitHub projects as of early March 2026, grouped by category:

---

## 🤖 AI & LLM Agents (Hottest Category Right Now)

**OpenClaw** — The fastest-growing GitHub repository in history, going from 9,000 to 188,000 stars in just 60 days. It's an open-source personal AI assistant that runs on your own hardware and connects to WhatsApp, Telegram, Slack, Discord, Signal, iMessage, and Microsoft Teams. Its ClawHub skill registry has over 5,700 community-built skills.

**Ollama** — Crossed 162,000 stars. The simplest way to run LLMs locally — one command downloads and runs any supported model including DeepSeek, Gemma, Qwen, and Llama.

**Dify** — Hit 130,000 stars. A workflow builder that fits teams needing AI-powered automations connected to existing tools.

**agency-agents** — A complete AI agency framework — from frontend wizards to Reddit community agents and reality checkers. Each agent is a specialized expert with personality, processes, and proven deliverables.

**Shannon Lite** — A fully autonomous AI pentester for web apps and APIs, achieving 96.15% on a hint-free, source-aware variant of the XBOW benchmark.

**CyberStrikeAI** — An AI-native security testing platform built in Go, integrating 100+ security tools, an intelligent orchestration engine, and role-based testing with predefined security roles.

## 🛠️ Developer Tools & Utilities

**DevToys** — Brings dozens of essential utilities like JSON formatting, encoding, regex testing, and more into a single offline desktop app. Great for developers who often manipulate, test, or inspect data.

**Hoppscotch** — A lightning-fast interface for REST, GraphQL, and WebSocket API testing — a powerful open-source alternative to Postman.

**D2** — Lets you create clear, maintainable diagrams using a simple scripting language. Useful for documenting architectures or workflows without manual drag-and-drop tools.

**GitInsights** — Transforms your engineering team's GitHub activity into actionable metrics such as average PR size, pick-up time, and defect rate, delivered via web dashboard, email, or Slack.

---

## ☁️ Infrastructure & Local Development

**Localstack** — Allows you to spin up a complete AWS environment locally, perfect for rapid prototyping and CI testing — great for running serverless stacks in isolation before deploying to production.

**Netdata** — 77,965 stars, actively maintained. Provides AI-powered full-stack observability, even for lean teams.

**Puppeteer** — A Node.js library that lets you control Chrome or Chromium programmatically — ideal for end-to-end testing, UI automation, and data scraping.

---

## 🧠 AI/ML Research & Frameworks

**Open R1 (Hugging Face)** — An ambitious project to reproduce and extend the DeepSeek-R1 pipeline in an open-source environment, democratizing cutting-edge AI research by making advanced reasoning, math, and coding models accessible to everyone.

**Hugging Face Transformers** — The model-definition framework for state-of-the-art machine learning models in text, vision, audio, and multimodal — supports both inference and training.
