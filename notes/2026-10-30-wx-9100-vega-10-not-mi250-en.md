The GPU here is **not** an AMD MI25/MI250. It's:

| Item | Value |
| ------ | ------- |
| GPU | **AMD Radeon Pro WX 9100** |
| Architecture | Vega 10 XT (`gfx900`, `xnack-`) |
| PCI ID | `Advanced Micro Devices, Inc. [AMD/ATI] Vega 10 XT [Radeon PRO WX 9100]` |
| Other GPU | Intel HD Graphics 530 (Skylake-S GT2) — integrated |
| ROCm | `rocminfo` / `rocm-smi` present; device name `amdgcn-amd-amdhsa--gfx900` |

Note: the WX 9100 is essentially the workstation sibling of the **Vega 10** die used in the Instinct **MI25**. So it's gfx900 **Vega 10** silicon, not the CDNA MI250 (gfx90a) or MI25 default IOMMU variant. If you specifically need MI25 behavior, this is the same generation/chip class but a Radeon Pro SKU.

Run `rocm-smi` for live VRAM/utilization details if needed.
